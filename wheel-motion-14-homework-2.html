עבודת בית 2: נקודה על גלגל, עם תבנית לפתרון

מתחת לכל שאלה יש תבנית לפתרון: כותרות השלבים והנוסחאות כבר כתובות, ובמקום כל ערך יש קו. קראו את השאלה, מצאו מה כל ערך בנוסחה, והשלימו את הקווים לפי הסדר. הכותרות, אחת מתחת לשנייה, הן סדר הפעולות שצריך לבצע.

\(x = x_C + R\cos(\theta_0 + \omega t)\)
\(y = y_C + R\sin(\theta_0 + \omega t)\)
\(\omega = \tfrac{360^\circ}{T}\)
תוכן
  1. רמה א׳: בעיה הפוכה וזווית התחלה (1–4)
  2. רמה ב׳: גלגל של עגלה בתנועה (5–6)

רמה א׳: בעיה הפוכה וזווית התחלה שאלות 1–4

  1. כנף של טחנת רוח באורך 8 מ׳ מסתובבת סביב ציר C בגובה 20 מ׳, ‏10 סיבובים לדקה עם כיוון השעון. בהתחלה הכנף פונה אנכית למעלה. מצאו את המהירות הזוויתית ואת זמן המחזור. מתי לראשונה קצה הכנף P בגובה 24 מ׳, ומתי בפעם השנייה? כמה זמן בכל סיבוב הוא מעל 24 מ׳? מצאו את כל הזמנים שבהם הוא בגובה 24 מ׳.
    תבנית לפתרון: השלימו את הערכים במקום הקווים
    דרך החשיבה

    בעיה הפוכה: הגובה נתון ומחפשים זמן. מבודדים את sinθ, מוצאים שתי זוויות, ובוחרים לפי כיוון הסיבוב איזו מגיעה קודם. עם כיוון השעון הזווית יורדת, ו־ω שלילית.

      הזווית יורדת מ־θ₀, ולכן מגיעים קודם ל־
      \(\theta_0 + \omega t = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}:\ \ {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} + {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\cdot t = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} \ \Rightarrow\ t = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)

  2. מרכז C של גלגל ענק נמצא בגובה 20 מ׳, ורדיוס הגלגל 16 מ׳. הגלגל מסתובב עם כיוון השעון, סיבוב בכל 90 שניות. בהתחלה קרונית P נמצאת משמאל לציר, בגובה הציר. מתי לראשונה P בגובה 12 מ׳, ומתי בפעם השנייה? כמה זמן בכל סיבוב היא נמוך מ־12 מ׳? מצאו את כל הזמנים שבהם היא בגובה 12 מ׳.
    תבנית לפתרון: השלימו את הערכים במקום הקווים
    דרך החשיבה

    1. רושמים את הנתונים בסימני הנוסחה
      \(y_C = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)מ׳
      \(R = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)מ׳
      \(T = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)שניות
      משמאל לציר, בגובה הציר

    2. מחלקים 360° בזמן המחזור ומקבלים את ω; עם כיוון השעון ω שליליתשאלת מרחק זוויתי

    3. מציבים את הגובה בנוסחה ומבודדים את \(\sin\theta\)שאלת מיקום
      \(y = y_C + R\sin\theta\)
      \({\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} + {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\sin\theta = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)
      \(\sin\theta = \dfrac{{\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} - {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}}{{\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}} = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)
      \(\theta = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\ \ \text{or}\ \ \theta = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)
    4. מציבים כל זווית ב־\(\theta = \theta_0 + \omega t\) ופותרים את t, לפי הסדר שבו הזווית מגיעה אליהןשאלת מרחק זוויתי
      מ־180° הזווית יורדת: 90°, 0°, ואז ו־
      \(\theta_0 + \omega t = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}:\ \ {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} + {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\cdot t = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} \ \Rightarrow\ t = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)
      \(\theta_0 + \omega t = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}:\ \ {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} + {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\cdot t = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} \ \Rightarrow\ t = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)

      \({\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} - {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)שניות

    \({\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)שניות מתחת ל־12 מ׳
    \(t = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} + {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}k,\ \ t = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} + {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}k\)

  3. מרכז הגלגל C, רדיוסו 6, ונקודה P על הגלגל נמצאת בהתחלה בנקודה A:
    \(C(1,\ -2)\)
    \(A(1+3\sqrt3,\ 1)\)
    הגלגל מסתובב נגד כיוון השעון, 5 סיבובים לדקה. מצאו את זווית ההתחלה, את המהירות הזוויתית ואת זמן המחזור. איפה P אחרי 4 שניות? מתי לראשונה P בנקודה הנמוכה ביותר של הגלגל, ומתי בפעם השנייה?
    תבנית לפתרון: השלימו את הערכים במקום הקווים
    דרך החשיבה

    כשנקודת ההתחלה נתונה בקואורדינטות, מחסירים את המרכז ומחלקים ברדיוס: מקבלים cos ו־sin של זווית ההתחלה. הסימנים שלהם קובעים את הרביע.

    1. רושמים את הנתונים בסימני הנוסחה
      \(x_C = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}},\ \ y_C = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)
      \(R = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)
      \(x_A = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}},\ \ y_A = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}},\ \ t_A = 0\)

      \(\cos\theta_0 = \dfrac{x_A - x_C}{R} = \dfrac{{\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}}{{\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}} = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)

      לפי הסימנים של cos ו־sin: רביע
      \(\theta_0 = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)

      \(\theta = \theta_0 + \omega t = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} + {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\cdot{\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)

      \(y = y_C + R\sin\theta = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} + {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\sin{\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)

    \(\theta_0 = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}},\ \ \omega = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}},\ \ T = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)
    \(t = 4:\ P({\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}},\ {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}})\)
