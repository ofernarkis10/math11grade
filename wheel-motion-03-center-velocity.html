תרגול: מהירות המרכז

18 שאלות על המשוואה הלינארית של המרכז, \(x_C = x_0 + v_x t\), \(y_C = y_0 + v_y t\): איך מוצאים את \(v_x, v_y, x_0, y_0\) מתוך הנתונים. בכל פתרון: דרך החשיבה, השלבים, התשובה ובדיקה. ההסבר בדף התאוריה.

תוכן

  2. רמה ב׳: מחשבים נתונים (9–14)

כלים לדף: \(v_x = \dfrac{\Delta x}{\Delta t}\) · \(v_y = \dfrac{\Delta y}{\Delta t}\) · \(v_x = |v|\cos\alpha\) · \(v_y = |v|\sin\alpha\) · \(|v| = \sqrt{v_x^2+v_y^2}\) · \(x_0 = x_1 - v_x t_1\)

רמה א׳: נתונים ישירים שאלות 1–8

שתי נקודות, תנועה אופקית, גודל וזווית.

  1. מרכז גלגל נמצא ב־\(t=0\) בנקודה \((2,1)\), וב־\(t=4\) בנקודה \((14,9)\). (א) מצאו את \(v_x\) ואת \(v_y\). (ב) רשמו את משוואות המרכז. (ג) איפה המרכז ב־\(t=10\)?
    הצג פתרון
    דרך החשיבה

    נתונות שתי נקודות ושני זמנים. מהירות בציר היא כמה הקואורדינטה משתנה בשנייה: השינוי בקואורדינטה חלקי השינוי בזמן. נקודת ההתחלה נתונה ישירות כי אחת הנקודות היא ב־t = 0.

    1. נתונים: \((x,y)\big|_{t=0} = (2,1),\ (x,y)\big|_{t=4} = (14,9)\)
    2. נוסחה: \(v_x = \dfrac{\Delta x}{\Delta t},\ v_y = \dfrac{\Delta y}{\Delta t}\)
    3. חישוב: \(v_x = \dfrac{14-2}{4} = 3,\ v_y = \dfrac{9-1}{4} = 2\)
    4. משוואות: \(x_C = 2 + 3t,\ y_C = 1 + 2t\)
    5. הצבה t = 10: \(x_C = 2 + 30 = 32,\ y_C = 1 + 20 = 21\)

    תשובה: \(v_x = 3,\ v_y = 2\); \(x_C = 2+3t,\ y_C = 1+2t\); ב־\(t=10\) המרכז ב־\((32,21)\).

    בדיקה: ב־\(t=4\): \((2+12,\ 1+8) = (14,9)\) ✓

  2. מרכז גלגל נע ימינה בקו אופקי. הוא מתחיל ב־\((-5,4)\) ועובר 30 יחידות ב־6 שניות. מצאו את \(v_x, v_y\) ורשמו את משוואות המרכז.
    הצג פתרון
    דרך החשיבה

    ״קו אופקי״ אומר ש־y לא משתנה, ולכן המהירות בציר y היא 0. ״ימינה״ אומר שהמהירות בציר x חיובית. המהירות היא מרחק חלקי זמן.

    1. כיוון: אופקי ימינה \(\Rightarrow v_y = 0,\ v_x \gt 0\)
    2. חישוב: \(v_x = \dfrac{30}{6} = 5\)
    3. משוואות: \(x_C = -5 + 5t,\ y_C = 4\)

    תשובה: \(v_x = 5,\ v_y = 0\); \(x_C = -5+5t,\ y_C = 4\)

    בדיקה: אחרי 6 שניות \(x_C = -5+30 = 25\): עבר \(25-(-5) = 30\) יחידות ✓

  3. מרכז גלגל יוצא מהראשית במהירות 10 יחידות לשנייה, בכיוון של \(30^\circ\) מעל הכיוון החיובי של ציר x. מצאו את \(v_x, v_y\) ורשמו את משוואות המרכז.
    הצג פתרון
    דרך החשיבה

    נתונים גודל המהירות והזווית שלה, כמו קואורדינטות קוטביות. מפרקים את המהירות לרכיבים: הרכיב בציר x הוא הגודל כפול קוסינוס הזווית, והרכיב בציר y הוא הגודל כפול סינוס הזווית.

    1. נתונים: \(|v| = 10,\ \alpha = 30^\circ,\ (x_0,y_0) = (0,0)\)
    2. פירוק: \(v_x = 10\cos 30^\circ = 10\cdot\tfrac{\sqrt3}{2} = 5\sqrt3 \approx 8.66\)
    3. פירוק: \(v_y = 10\sin 30^\circ = 10\cdot\tfrac12 = 5\)
    4. משוואות: \(x_C = 5\sqrt3\,t,\ y_C = 5t\)

    תשובה: \(v_x = 5\sqrt3 \approx 8.66,\ v_y = 5\)

    בדיקה: \(\sqrt{(5\sqrt3)^2 + 5^2} = \sqrt{75+25} = 10\) ✓

  4. מרכז גלגל מתחיל ב־\((10,0)\) ונע במהירות 6 יחידות לשנייה בכיוון של \(135^\circ\). מצאו את \(v_x, v_y\), הסבירו את הסימנים, ורשמו את משוואות המרכז.
    הצג פתרון
    דרך החשיבה

    אותה שיטה כמו בשאלה הקודמת, אבל הזווית ברביע השני. שם הקוסינוס שלילי והסינוס חיובי, ולכן המרכז זז שמאלה ולמעלה. הסימנים יוצאים לבד מהפירוק, לא צריך לנחש.

    1. פירוק: \(v_x = 6\cos 135^\circ = 6\cdot\left(-\tfrac{\sqrt2}{2}\right) = -3\sqrt2 \approx -4.24\)
    2. פירוק: \(v_y = 6\sin 135^\circ = 6\cdot\tfrac{\sqrt2}{2} = 3\sqrt2 \approx 4.24\)
    3. פירוש: \(v_x \lt 0\) — שמאלה; \(v_y \gt 0\) — למעלה
    4. משוואות: \(x_C = 10 - 3\sqrt2\,t,\ y_C = 3\sqrt2\,t\)

    תשובה: \(v_x = -3\sqrt2,\ v_y = 3\sqrt2\): המרכז נע שמאלה ולמעלה.

    בדיקה: \(\sqrt{18+18} = 6\) ✓

  5. מרכז גלגל נמצא ב־\(t=0\) בנקודה \((-1,3)\), וב־\(t=5\) בנקודה \((9,-7)\). מצאו את \(v_x, v_y\), רשמו את משוואות המרכז, ומצאו את המרכז ב־\(t=2\).
    הצג פתרון
    דרך החשיבה

    שתי נקודות ושני זמנים, ואחת מהן ב־t = 0. y יורד, ולכן נצפה ל־v_y שלילי.

    1. חישוב: \(v_x = \dfrac{9-(-1)}{5} = 2,\ v_y = \dfrac{-7-3}{5} = -2\)
    2. משוואות: \(x_C = -1 + 2t,\ y_C = 3 - 2t\)
    3. הצבה t = 2: \((3, -1)\)

    תשובה: \(v_x=2,\ v_y=-2\); המרכז ב־\(t=2\): \((3,-1)\)

    בדיקה: ב־\(t=5\): \((9,-7)\) ✓

  6. מרכז גלגל עולה אנכית. הוא מתחיל ב־\((4,-2)\) ועולה 18 יחידות ב־3 שניות. מצאו את \(v_x, v_y\) ורשמו את משוואות המרכז.
    הצג פתרון
    דרך החשיבה

    ״אנכית״ אומר ש־x לא משתנה, ולכן v_x = 0. ״עולה״ — v_y חיובי.

    1. כיוון: \(v_x = 0,\ v_y \gt 0\)
    2. חישוב: \(v_y = \dfrac{18}{3} = 6\)
    3. משוואות: \(x_C = 4,\ y_C = -2 + 6t\)

    תשובה: \(v_x=0,\ v_y=6\); \(x_C = 4,\ y_C = -2+6t\)

    בדיקה: ב־\(t=3\): \(y_C = 16\), עלייה של 18 ✓

  7. מרכז גלגל מתחיל ב־\((1,1)\) ונע במהירות 8 בכיוון \(60^\circ\). מצאו את \(v_x, v_y\) ורשמו את משוואות המרכז.
    הצג פתרון
    דרך החשיבה

    מפרקים את המהירות לרכיבים בעזרת cos ו־sin של 60 מעלות.

    1. פירוק: \(v_x = 8\cos 60^\circ = 4,\ v_y = 8\sin 60^\circ = 4\sqrt3 \approx 6.93\)
    2. משוואות: \(x_C = 1 + 4t,\ y_C = 1 + 4\sqrt3\,t\)

    תשובה: \(v_x = 4,\ v_y = 4\sqrt3\)

    בדיקה: \(\sqrt{16+48} = 8\) ✓

  8. מרכז גלגל יוצא מהראשית במהירות 10 בכיוון \(210^\circ\). מצאו את \(v_x, v_y\) והסבירו את הסימנים.
    הצג פתרון
    דרך החשיבה

    210 מעלות ברביע השלישי: גם cos וגם sin שליליים, ולכן המרכז נע שמאלה ולמטה.

    1. פירוק: \(v_x = 10\cos 210^\circ = -5\sqrt3 \approx -8.66\)
    2. פירוק: \(v_y = 10\sin 210^\circ = -5\)
    3. פירוש: שני הרכיבים שליליים — שמאלה ולמטה

    תשובה: \(v_x = -5\sqrt3,\ v_y = -5\)

    בדיקה: \(\sqrt{75+25} = 10\) ✓

רמה ב׳: מחשבים נתונים לפני ההצבה שאלות 9–14

שיפוע במקום זווית, נקודות שאינן ב־t = 0, ומהמשוואה חזרה לגודל ולכיוון.

  1. מרכז גלגל יוצא מהראשית במהירות 13 יחידות לשנייה. על כל 12 יחידות ימינה הוא עולה 5 יחידות. מצאו את \(v_x\) ואת \(v_y\).
    הצג פתרון
    דרך החשיבה

    במקום זווית נתון שיפוע: היחס בין העלייה להתקדמות. היחס בין הרכיבים של המהירות שווה ליחס הזה. מסמנים את הרכיבים בעזרת פרמטר אחד, ומוצאים אותו מגודל המהירות.

    1. יחס: \(\dfrac{v_y}{v_x} = \dfrac{5}{12} \Rightarrow v_x = 12k,\ v_y = 5k\)
    2. גודל: \(\sqrt{(12k)^2 + (5k)^2} = \sqrt{169k^2} = 13k\)
    3. משוואה: \(13k = 13 \Rightarrow k = 1\)
    4. רכיבים: \(v_x = 12,\ v_y = 5\)

    תשובה: \(v_x = 12,\ v_y = 5\)

    בדיקה: \(\sqrt{144+25} = 13\) והיחס \(5:12\) ✓

  2. ב־\(t=2\) המרכז ב־\((7,3)\), וב־\(t=5\) ב־\((1,12)\). (א) מצאו את \(v_x, v_y\). (ב) מצאו את \(x_0, y_0\). (ג) רשמו את משוואות המרכז.
    הצג פתרון
    דרך החשיבה

    אף אחת מהנקודות לא ב־t = 0, ולכן נקודת ההתחלה לא נתונה. קודם מוצאים את המהירות משתי הנקודות, ואחר כך ״חוזרים אחורה בזמן״ מאחת הנקודות: בכל שנייה אחורה מחסירים את המהירות.

    1. מהירות: \(\Delta t = 3:\ v_x = \dfrac{1-7}{3} = -2,\ v_y = \dfrac{12-3}{3} = 3\)
    2. חזרה ל־t = 0: \(x_0 = 7 - (-2)\cdot 2 = 11,\ y_0 = 3 - 3\cdot 2 = -3\)
    3. משוואות: \(x_C = 11 - 2t,\ y_C = -3 + 3t\)

    תשובה: \(x_C = 11-2t,\ y_C = -3+3t\)

    בדיקה: ב־\(t=5\): \((11-10,\ -3+15) = (1,12)\) ✓

  3. משוואות המרכז הן \(x_C = 4 + 2t,\ y_C = 1 - 2t\). מהו מיקום ההתחלה, מהם \(v_x, v_y\), מהו גודל המהירות ומהו כיוון התנועה?
    הצג פתרון
    דרך החשיבה

    כאן הכיוון הפוך: נתונה המשוואה ומחלצים ממנה את הרכיבים. המספר החופשי הוא מיקום ההתחלה, והמקדם של t הוא המהירות. את הזווית מוצאים מטנגנס, ואת הרביע קובעים לפי הסימנים של הרכיבים.

    1. זיהוי: \((x_0,y_0) = (4,1),\ v_x = 2,\ v_y = -2\)
    2. גודל: \(|v| = \sqrt{4+4} = 2\sqrt2 \approx 2.83\)
    3. כיוון: \(\tan\alpha = \dfrac{-2}{2} = -1\)
    4. רביע: \(v_x \gt 0,\ v_y \lt 0\) — רביע רביעי (ימינה ולמטה) \(\Rightarrow \alpha = -45^\circ\)

    תשובה: התחלה \((4,1)\), \(v_x=2,\ v_y=-2\), \(|v| = 2\sqrt2\), כיוון \(-45^\circ\) (או \(315^\circ\)).

    בדיקה: \(2\sqrt2\cos(-45^\circ) = 2\), \(2\sqrt2\sin(-45^\circ) = -2\) ✓

  4. מרכז גלגל יוצא מהראשית במהירות 25. על כל 4 יחידות ימינה הוא עולה 3 יחידות. מצאו את \(v_x, v_y\).
    הצג פתרון
    דרך החשיבה

    היחס בין הרכיבים הוא 3 ל־4. מסמנים בפרמטר אחד ומוצאים אותו מגודל המהירות.

    1. יחס: \(v_x = 4k,\ v_y = 3k\)
    2. גודל: \(\sqrt{16k^2 + 9k^2} = 5k = 25 \Rightarrow k = 5\)
    3. רכיבים: \(v_x = 20,\ v_y = 15\)

    תשובה: \(v_x = 20,\ v_y = 15\)

    בדיקה: \(\sqrt{400+225} = 25\) ✓

  5. ב־\(t=1\) המרכז ב־\((5,0)\), וב־\(t=4\) ב־\((14,-6)\). מצאו את \(v_x, v_y\) ואת \(x_0, y_0\), ורשמו את משוואות המרכז.
    הצג פתרון
    דרך החשיבה

    קודם מהירות משתי הנקודות, ואחר כך חוזרים שנייה אחת אחורה מהנקודה ב־t = 1.

    1. מהירות: \(v_x = \dfrac{9}{3} = 3,\ v_y = \dfrac{-6}{3} = -2\)
    2. חזרה ל־t = 0: \(x_0 = 5 - 3 = 2,\ y_0 = 0 + 2 = 2\)
    3. משוואות: \(x_C = 2 + 3t,\ y_C = 2 - 2t\)

    תשובה: \(x_C = 2 + 3t,\ y_C = 2 - 2t\)

    בדיקה: ב־\(t=4\): \((14,-6)\) ✓

  6. משוואות המרכז הן \(x_C = -1 - 3t,\ y_C = 2 + 4t\). מהו מיקום ההתחלה, מהם \(v_x, v_y\), מהו גודל המהירות ומהו הכיוון?
    הצג פתרון
    דרך החשיבה

    מחלצים את הרכיבים מהמשוואה. v_x שלילי ו־v_y חיובי: רביע שני, ולכן מוסיפים 180 לזווית שהמחשבון נותן.

    1. זיהוי: \((x_0,y_0) = (-1,2),\ v_x = -3,\ v_y = 4\)
    2. גודל: \(|v| = \sqrt{9+16} = 5\)
    3. כיוון: \(\tan\alpha = -\tfrac43\); המחשבון נותן \(-53.13^\circ\), ברביע שני \(\alpha = 180 - 53.13 = 126.87^\circ\)

    תשובה: התחלה \((-1,2)\), \(|v|=5\), כיוון כ־\(126.9^\circ\)

    בדיקה: \(5\cos 126.87^\circ \approx -3\) ✓

רמה ג׳: שאלות הפוכות ומשולבות שאלות 15–18

מתי המרכז מגיע לנקודה, ומרחק במקום מהירות.

  1. מרכז גלגל עובר מ־\(A(1,2)\) ל־\(B(9,8)\) תוך 2 שניות (ב־\(t=0\) הוא ב־A). (א) מצאו את \(v_x, v_y\) ואת גודל המהירות. (ב) מתי המרכז יגיע ל־\(x=25\)? מה יהיה אז y?
    הצג פתרון
    דרך החשיבה

    קודם בונים את משוואות המרכז. אחר כך זו בעיה הפוכה: נתון ערך של x ומחפשים את הזמן. פותרים משוואה ב־t ממשוואת x, ומציבים את הזמן במשוואת y.

    1. מהירות: \(v_x = \dfrac{8}{2} = 4,\ v_y = \dfrac{6}{2} = 3,\ |v| = 5\)
    2. משוואות: \(x_C = 1 + 4t,\ y_C = 2 + 3t\)
    3. זמן: \(1 + 4t = 25 \Rightarrow t = 6\)
    4. y באותו רגע: \(y_C = 2 + 18 = 20\)

    תשובה: \(|v| = 5\); המרכז מגיע ל־\(x=25\) ב־\(t=6\), ואז \(y=20\).

    בדיקה: המרחק מ־A ל־\((25,20)\) הוא \(\sqrt{24^2+18^2} = 30\), ו־\(30/5 = 6\) שניות ✓

  2. מרכז גלגל מתחיל ב־\((0,3)\) ונע בכיוון \(60^\circ\) מעל ציר x. אחרי 4 שניות הוא עבר 20 יחידות. מצאו את גודל המהירות, את \(v_x, v_y\), ורשמו את משוואות המרכז.
    הצג פתרון
    דרך החשיבה

    שני שלבים: מהמרחק והזמן מקבלים את גודל המהירות, ורק אז מפרקים אותו לרכיבים לפי הזווית. מי שמפרק את המרחק 20 במקום את המהירות מקבל רכיבים גדולים פי 4.

    1. גודל: \(|v| = \dfrac{20}{4} = 5\)
    2. פירוק: \(v_x = 5\cos 60^\circ = 2.5,\ v_y = 5\sin 60^\circ = 2.5\sqrt3 \approx 4.33\)
    3. משוואות: \(x_C = 2.5t,\ y_C = 3 + 2.5\sqrt3\,t\)

    תשובה: \(|v|=5\); \(x_C = 2.5t,\ y_C = 3 + 2.5\sqrt3\,t\)

    בדיקה: ב־\(t=4\): תזוזה \((10,\ 10\sqrt3)\), ואורכה \(\sqrt{100+300} = 20\) ✓

  3. מרכז גלגל עובר מ־\(A(0,0)\) ל־\(B(6,8)\) תוך 2 שניות (ב־\(t=0\) הוא ב־A). מתי יגיע ל־\(y=20\)? מה יהיה אז x, וכמה עבר?
    הצג פתרון
    דרך החשיבה

    בונים משוואות, ופותרים משוואה ב־t ממשוואת y. את המרחק מקבלים ממהירות כפול זמן.

    1. מהירות: \(v_x = 3,\ v_y = 4,\ |v| = 5\)
    2. זמן: \(4t = 20 \Rightarrow t = 5\)
    3. x: \(x = 15\)
    4. מרחק: \(5\cdot 5 = 25\)

    תשובה: ב־\(t=5\), ב־\(x=15\), אחרי 25 יחידות

    בדיקה: \(\sqrt{15^2+20^2} = 25\) ✓

  4. מרכז גלגל מתחיל ב־\((2,1)\) ונע בכיוון \(45^\circ\). אחרי 3 שניות הוא עבר \(6\sqrt2\) יחידות. מצאו את גודל המהירות, את \(v_x, v_y\) ואת משוואות המרכז.
    הצג פתרון
    דרך החשיבה

    קודם גודל המהירות ממרחק וזמן, ורק אז פירוק לפי הזווית.

    1. גודל: \(|v| = \dfrac{6\sqrt2}{3} = 2\sqrt2\)
    2. פירוק: \(v_x = 2\sqrt2\cdot\tfrac{\sqrt2}{2} = 2,\ v_y = 2\)
    3. משוואות: \(x_C = 2 + 2t,\ y_C = 1 + 2t\)

    תשובה: \(|v| = 2\sqrt2,\ v_x = v_y = 2\)

    בדיקה: ב־\(t=3\) תזוזה \((6,6)\), ואורכה \(6\sqrt2\) ✓
