תרגול: מהירות המרכז

18 שאלות על המשוואה הלינארית של המרכז, \(x_C = x_A + v_x t\), \(y_C = y_A + v_y t\): איך מוצאים את \(v_x, v_y, x_A, y_A\) מתוך הנתונים. בכל פתרון: דרך החשיבה, השלבים, התשובה ובדיקה. ההסבר בדף התאוריה.

תוכן
  1. רמה א׳: נתונים ישירים (1–8)
  2. רמה ב׳: מחשבים נתונים (9–14)
  3. רמה ג׳: הפוכות ומשולבות (15–18)
כלים לדף: \(v_x = \dfrac{x_B - x_A}{t_B - t_A}\) · \(v_y = \dfrac{y_B - y_A}{t_B - t_A}\) · \(v_x = |v|\cos\alpha\) · \(v_y = |v|\sin\alpha\) · \(|v| = \sqrt{v_x^2+v_y^2}\) · \(x_A = x_B - v_x t_B\) · נקודות: A — נקודת ההתחלה (\(t=0\)), B — נקודה בזמן \(t_B\), D — נקודה נוספת

רמה א׳: נתונים ישירים שאלות 1–8

שתי נקודות, תנועה אופקית, גודל וזווית.

  1. מרכז גלגל נמצא ב־\(t=0\) בנקודה \(A(2,1)\), וב־\(t=4\) בנקודה \(B(14,9)\). (א) מצאו את \(v_x\) ואת \(v_y\). (ב) רשמו את משוואות המרכז. (ג) איפה המרכז ב־\(t=10\)?
    הצג פתרון
    דרך החשיבה

    נתונות שתי נקודות ושני זמנים. מהירות בציר היא כמה הקואורדינטה משתנה בשנייה: השינוי בקואורדינטה חלקי השינוי בזמן. נקודת ההתחלה נתונה ישירות כי אחת הנקודות היא ב־t = 0.

    1. נתונים
      \(A(2,1)\)
      \(t_A = 0\)
      \(B(14,9)\)
      \(t_B = 4\)
    2. נוסחהשאלת מרחק
      \(v_x = \dfrac{x_B - x_A}{t_B - t_A}\)
      \(v_y = \dfrac{y_B - y_A}{t_B - t_A}\)
    3. חישובשאלת מרחק
      \(v_x = \dfrac{x_B - x_A}{t_B - t_A} = \dfrac{14-2}{4-0} = 3\)
      \(v_y = \dfrac{y_B - y_A}{t_B - t_A} = \dfrac{9-1}{4-0} = 2\)
    4. משוואותשאלת מרחק
      \(x_C = x_A + v_x t = 2 + 3t\)
      \(y_C = y_A + v_y t = 1 + 2t\)
    5. הצבה t = 10שאלת מרחק
      \(x_C = x_A + v_x t = 2 + 30 = 32\)
      \(y_C = y_A + v_y t = 1 + 20 = 21\)
    תשובה:
    \(v_x = 3\)
    \(v_y = 2\)
    \(x_C = 2+3t\)
    \(y_C = 1+2t\)
    \(t=10\)
    המרכז
    \((32,21)\)
    בדיקה:
    \(t=4\)
    \((2+12,\ 1+8) = (14,9)\)✓
  2. מרכז גלגל נע ימינה בקו אופקי. הוא מתחיל בנקודה \(A(-5,4)\) ועובר 30 יחידות ב־6 שניות. מצאו את \(v_x, v_y\) ורשמו את משוואות המרכז.
    הצג פתרון
    דרך החשיבה

    ״קו אופקי״ אומר ש־y לא משתנה, ולכן המהירות בציר y היא 0. ״ימינה״ אומר שהמהירות בציר x חיובית. המהירות היא מרחק חלקי זמן.

    1. נתונים
      \(A(-5,4)\)
      \(s = 30\)
      \(t = 6\)
    2. כיוון
      אופקי ימינה
      \(\Rightarrow v_y = 0\)
      \(v_x \gt 0\)
    3. חישובשאלת מרחק
      \(v_x = \dfrac{s}{t} = \dfrac{30}{6} = 5\)
    4. משוואותשאלת מרחק
      \(x_C = x_A + v_x t = -5 + 5t\)
      \(y_C = y_A + v_y t = 4\)
    תשובה:
    \(v_x = 5\)
    \(v_y = 0\)
    \(x_C = -5+5t\)
    \(y_C = 4\)
    בדיקה:
    אחרי 6 שניות
    \(x_C = -5+30 = 25\)
    עבר
    \(25-(-5) = 30\)
    יחידות ✓
  3. מרכז גלגל יוצא מהראשית, נקודה \(A(0,0)\), במהירות 10 יחידות לשנייה, בכיוון של \(30^\circ\) מעל הכיוון החיובי של ציר x. מצאו את \(v_x, v_y\) ורשמו את משוואות המרכז.
    הצג פתרון
    דרך החשיבה

    נתונים גודל המהירות והזווית שלה, כמו קואורדינטות קוטביות. מפרקים את המהירות לרכיבים: הרכיב בציר x הוא הגודל כפול קוסינוס הזווית, והרכיב בציר y הוא הגודל כפול סינוס הזווית.

    1. נתונים
      \(A(0,0)\)
      \(|v| = 10\)
      \(\alpha = 30^\circ\)
    2. פירוקשאלת מרחק
      \(v_x = |v|\cos\alpha = 10\cos 30^\circ = 10\cdot\tfrac{\sqrt3}{2} = 5\sqrt3 \approx 8.66\)
    3. פירוקשאלת מרחק
      \(v_y = |v|\sin\alpha = 10\sin 30^\circ = 10\cdot\tfrac12 = 5\)
    4. משוואותשאלת מרחק
      \(x_C = x_A + v_x t = 5\sqrt3\,t\)
      \(y_C = y_A + v_y t = 5t\)
    תשובה:
    \(v_x = 5\sqrt3 \approx 8.66\)
    \(v_y = 5\)
    בדיקה:
    \(\sqrt{(5\sqrt3)^2 + 5^2} = \sqrt{75+25} = 10\)✓
  4. מרכז גלגל מתחיל בנקודה \(A(10,0)\) ונע במהירות 6 יחידות לשנייה בכיוון של \(135^\circ\). מצאו את \(v_x, v_y\), הסבירו את הסימנים, ורשמו את משוואות המרכז.
    הצג פתרון
    דרך החשיבה

    אותה שיטה כמו בשאלה הקודמת, אבל הזווית ברביע השני. שם הקוסינוס שלילי והסינוס חיובי, ולכן המרכז זז שמאלה ולמעלה. הסימנים יוצאים לבד מהפירוק, לא צריך לנחש.

    1. נתונים
      \(A(10,0)\)
      \(|v| = 6\)
      \(\alpha = 135^\circ\)
    2. פירוקשאלת מרחק
      \(v_x = |v|\cos\alpha = 6\cos 135^\circ = 6\cdot\left(-\tfrac{\sqrt2}{2}\right) = -3\sqrt2 \approx -4.24\)
    3. פירוקשאלת מרחק
      \(v_y = |v|\sin\alpha = 6\sin 135^\circ = 6\cdot\tfrac{\sqrt2}{2} = 3\sqrt2 \approx 4.24\)
    4. פירוש
      \(v_x \lt 0\)
      שמאלה
      \(v_y \gt 0\)
      למעלה
    5. משוואותשאלת מרחק
      \(x_C = x_A + v_x t = 10 - 3\sqrt2\,t\)
      \(y_C = y_A + v_y t = 3\sqrt2\,t\)
    תשובה:
    \(v_x = -3\sqrt2\)
    \(v_y = 3\sqrt2\)
    המרכז נע שמאלה ולמעלה
    בדיקה:
    \(\sqrt{18+18} = 6\)✓
  5. מרכז גלגל נמצא ב־\(t=0\) בנקודה \(A(-1,3)\), וב־\(t=5\) בנקודה \(B(9,-7)\). מצאו את \(v_x, v_y\), רשמו את משוואות המרכז, ומצאו את המרכז ב־\(t=2\).
    הצג פתרון
    דרך החשיבה

    שתי נקודות ושני זמנים, ואחת מהן ב־t = 0. y יורד, ולכן נצפה ל־v_y שלילי.

    1. נתונים
      \(A(-1,3)\)
      \(t_A = 0\)
      \(B(9,-7)\)
      \(t_B = 5\)
    2. חישובשאלת מרחק
      \(v_x = \dfrac{x_B - x_A}{t_B - t_A} = \dfrac{9-(-1)}{5-0} = 2\)
      \(v_y = \dfrac{y_B - y_A}{t_B - t_A} = \dfrac{-7-3}{5-0} = -2\)
    3. משוואותשאלת מרחק
      \(x_C = x_A + v_x t = -1 + 2t\)
      \(y_C = y_A + v_y t = 3 - 2t\)
    4. הצבה t = 2שאלת מרחק
      \(C = (x_A + v_x t,\ y_A + v_y t) = (3, -1)\)
    תשובה:
    \(v_x=2\)
    \(v_y=-2\)
    המרכז
    \(t=2\)
    \((3,-1)\)
    בדיקה:
    \(t=5\)
    \((9,-7)\)✓
  6. מרכז גלגל עולה אנכית. הוא מתחיל בנקודה \(A(4,-2)\) ועולה 18 יחידות ב־3 שניות. מצאו את \(v_x, v_y\) ורשמו את משוואות המרכז.
    הצג פתרון
    דרך החשיבה

    ״אנכית״ אומר ש־x לא משתנה, ולכן v_x = 0. ״עולה״ — v_y חיובי.

    1. נתונים
      \(A(4,-2)\)
      \(s = 18\)
      \(t = 3\)
    2. כיוון
      \(v_x = 0\)
      \(v_y \gt 0\)
    3. חישובשאלת מרחק
      \(v_y = \dfrac{s}{t} = \dfrac{18}{3} = 6\)
    4. משוואותשאלת מרחק
      \(x_C = x_A + v_x t = 4\)
      \(y_C = y_A + v_y t = -2 + 6t\)
    תשובה:
    \(v_x=0\)

  7. מרכז גלגל מתחיל בנקודה \(A(1,1)\) ונע במהירות 8 בכיוון \(60^\circ\). מצאו את \(v_x, v_y\) ורשמו את משוואות המרכז.
    הצג פתרון
    דרך החשיבה

    מפרקים את המהירות לרכיבים בעזרת cos ו־sin של 60 מעלות.

    1. נתונים
      \(A(1,1)\)

      \(\alpha = 60^\circ\)
    2. פירוקשאלת מרחק
      \(v_x = |v|\cos\alpha = 8\cos 60^\circ = 4\)
      \(v_y = |v|\sin\alpha = 8\sin 60^\circ = 4\sqrt3 \approx 6.93\)
    3. משוואותשאלת מרחק
      \(x_C = x_A + v_x t = 1 + 4t\)
      \(y_C = y_A + v_y t = 1 + 4\sqrt3\,t\)
    תשובה:

    \(v_y = 4\sqrt3\)

    \(\sqrt{16+48} = 8\)✓
  8. מרכז גלגל יוצא מהראשית, נקודה \(A(0,0)\), במהירות 10 בכיוון \(210^\circ\). מצאו את \(v_x, v_y\) והסבירו את הסימנים.
    הצג פתרון
    דרך החשיבה

    210 מעלות ברביע השלישי: גם cos וגם sin שליליים, ולכן המרכז נע שמאלה ולמטה.

    1. נתונים

      \(|v| = 10\)

    2. פירוקשאלת מרחק
      \(v_x = |v|\cos\alpha = 10\cos 210^\circ = -5\sqrt3 \approx -8.66\)
    3. פירוקשאלת מרחק
      \(v_y = |v|\sin\alpha = 10\sin 210^\circ = -5\)
    4. פירוש
      שני הרכיבים שליליים — שמאלה ולמטה

רמה ב׳: מחשבים נתונים לפני ההצבה שאלות 9–14

שיפוע במקום זווית, נקודות שאינן ב־t = 0, ומהמשוואה חזרה לגודל ולכיוון.

  1. מרכז גלגל יוצא מהראשית, נקודה \(A(0,0)\), במהירות 13 יחידות לשנייה. על כל 12 יחידות ימינה הוא עולה 5 יחידות. מצאו את \(v_x\) ואת \(v_y\).
    הצג פתרון
    דרך החשיבה

    במקום זווית נתון שיפוע: היחס בין העלייה להתקדמות. היחס בין הרכיבים של המהירות שווה ליחס הזה. מסמנים את הרכיבים בעזרת פרמטר אחד, ומוצאים אותו מגודל המהירות.

    1. נתונים
      \(A(0,0)\)
      \(|v| = 13\)
      \(\dfrac{v_y}{v_x} = \dfrac{5}{12}\)
    2. יחסשאלת מרחק
      \(\dfrac{v_y}{v_x} = \dfrac{5}{12} \Rightarrow v_x = 12k\)
      \(v_y = 5k\)
    3. גודלשאלת מרחק
      \(|v| = \sqrt{v_x^2 + v_y^2} = \sqrt{(12k)^2 + (5k)^2} = \sqrt{169k^2} = 13k\)
    4. משוואה
      \(13k = 13 \Rightarrow k = 1\)
    5. רכיבים
      \(v_x = 12\)
      \(v_y = 5\)
    תשובה:
    \(v_x = 12\)
    \(v_y = 5\)
    בדיקה:
    \(\sqrt{144+25} = 13\)
    והיחס
    \(5:12\)✓
  2. ב־\(t=2\) המרכז בנקודה \(B(7,3)\), וב־\(t=5\) בנקודה \(D(1,12)\). (א) מצאו את \(v_x, v_y\). (ב) מצאו את נקודת ההתחלה \(A(x_A, y_A)\) (ב־\(t=0\)). (ג) רשמו את משוואות המרכז.
    הצג פתרון
    דרך החשיבה

    אף אחת מהנקודות לא ב־t = 0, ולכן נקודת ההתחלה לא נתונה. קודם מוצאים את המהירות משתי הנקודות, ואחר כך ״חוזרים אחורה בזמן״ מאחת הנקודות: בכל שנייה אחורה מחסירים את המהירות.

    1. נתונים
      \(B(7,3)\)
      \(t_B = 2\)
      \(D(1,12)\)
      \(t_D = 5\)
    2. מהירותשאלת מרחק
      \(v_x = \dfrac{x_D - x_B}{t_D - t_B} = \dfrac{1-7}{5-2} = -2\)
      \(v_y = \dfrac{y_D - y_B}{t_D - t_B} = \dfrac{12-3}{5-2} = 3\)
    3. חזרה ל־t = 0שאלת מרחק
      \(x_A = x_B - v_x t_B = 7 - (-2)\cdot 2 = 11\)
      \(y_A = y_B - v_y t_B = 3 - 3\cdot 2 = -3\)
    4. משוואותשאלת מרחק
      \(x_C = x_A + v_x t = 11 - 2t\)
      \(y_C = y_A + v_y t = -3 + 3t\)
    תשובה:
    \(x_C = 11-2t\)
    \(y_C = -3+3t\)
    בדיקה:
    \(t=5\)
    \((11-10,\ -3+15) = (1,12)\)✓
  3. משוואות המרכז הן \(x_C = 4 + 2t,\ y_C = 1 - 2t\). מהו מיקום ההתחלה, מהם \(v_x, v_y\), מהו גודל המהירות ומהו כיוון התנועה?
    הצג פתרון
    דרך החשיבה

    כאן הכיוון הפוך: נתונה המשוואה ומחלצים ממנה את הרכיבים. המספר החופשי הוא מיקום ההתחלה, והמקדם של t הוא המהירות. את הזווית מוצאים מטנגנס, ואת הרביע קובעים לפי הסימנים של הרכיבים.

    1. זיהוי
      \(A(4,1)\)
      \(v_x = 2\)
      \(v_y = -2\)
    2. גודלשאלת מרחק
      \(|v| = \sqrt{v_x^2 + v_y^2} = \sqrt{4+4} = 2\sqrt2 \approx 2.83\)
    3. כיוון
      \(\tan\alpha = \dfrac{v_y}{v_x} = \dfrac{-2}{2} = -1\)
    4. רביע
      \(v_x \gt 0\)
      \(v_y \lt 0\)
      רביע רביעי (ימינה ולמטה)
      \(\Rightarrow \alpha = -45^\circ\)
    תשובה:
    התחלה
    \(A(4,1)\)
    \(v_x=2\)
    \(v_y=-2\)
    \(|v| = 2\sqrt2\)
    כיוון
    \(-45^\circ\)
    (או
    \(315^\circ\)
    )
    בדיקה:
    \(2\sqrt2\cos(-45^\circ) = 2\)
    \(2\sqrt2\sin(-45^\circ) = -2\)✓
  4. מרכז גלגל יוצא מהראשית, נקודה \(A(0,0)\), במהירות 25. על כל 4 יחידות ימינה הוא עולה 3 יחידות. מצאו את \(v_x, v_y\).
    הצג פתרון
    דרך החשיבה

    היחס בין הרכיבים הוא 3 ל־4. מסמנים בפרמטר אחד ומוצאים אותו מגודל המהירות.

    1. נתונים
      \(A(0,0)\)
      \(|v| = 25\)
      \(\dfrac{v_y}{v_x} = \dfrac{3}{4}\)
    2. יחסשאלת מרחק
      \(v_x = 4k\)
      \(v_y = 3k\)
    3. גודלשאלת מרחק
      \(|v| = \sqrt{v_x^2 + v_y^2} = \sqrt{16k^2 + 9k^2} = 5k = 25 \Rightarrow k = 5\)
    4. רכיבים
      \(v_x = 20\)
      \(v_y = 15\)
    תשובה:
    \(v_x = 20\)
    \(v_y = 15\)
    בדיקה:
    \(\sqrt{400+225} = 25\)✓
  5. ב־\(t=1\) המרכז בנקודה \(B(5,0)\), וב־\(t=4\) בנקודה \(D(14,-6)\). מצאו את \(v_x, v_y\) ואת נקודת ההתחלה \(A(x_A, y_A)\), ורשמו את משוואות המרכז.
    הצג פתרון
    דרך החשיבה

      \(v_y = \dfrac{y_D - y_B}{t_D - t_B} = \dfrac{-6-0}{4-1} = -2\)
    3. חזרה ל־t = 0שאלת מרחק
      \(x_A = x_B - v_x t_B = 5 - 3\cdot 1 = 2\)
      \(y_A = y_B - v_y t_B = 0 - (-2)\cdot 1 = 2\)
    4. משוואותשאלת מרחק
      \(x_C = x_A + v_x t = 2 + 3t\)
      \(y_C = y_A + v_y t = 2 - 2t\)
    תשובה:
    \(x_C = 2 + 3t\)
    \(y_C = 2 - 2t\)
    בדיקה:
    \(t=4\)
    \((14,-6)\)✓
  6. משוואות המרכז הן \(x_C = -1 - 3t,\ y_C = 2 + 4t\). מהו מיקום ההתחלה, מהם \(v_x, v_y\), מהו גודל המהירות ומהו הכיוון?
    הצג פתרון
    דרך החשיבה

    מחלצים את הרכיבים מהמשוואה. v_x שלילי ו־v_y חיובי: רביע שני, ולכן מוסיפים 180 לזווית שהמחשבון נותן.

    1. זיהוי
      \(A(-1,2)\)
      \(v_x = -3\)
      \(v_y = 4\)
    2. גודלשאלת מרחק
      \(|v| = \sqrt{v_x^2 + v_y^2} = \sqrt{9+16} = 5\)
    3. כיוון
      \(\tan\alpha = \dfrac{v_y}{v_x} = -\tfrac43\)
      המחשבון נותן
      \(-53.13^\circ\)
      ברביע שני
      \(\alpha = 180 - 53.13 = 126.87^\circ\)
    תשובה:
    התחלה
    \(A(-1,2)\)
    \(|v|=5\)
    כיוון
    \(126.9^\circ\)
    בדיקה:
    \(5\cos 126.87^\circ \approx -3\)✓

רמה ג׳: שאלות הפוכות ומשולבות שאלות 15–18

מתי המרכז מגיע לנקודה, ומרחק במקום מהירות.

  1. מרכז גלגל עובר מ־\(A(1,2)\) ל־\(B(9,8)\) תוך 2 שניות (ב־\(t=0\) הוא ב־A). (א) מצאו את \(v_x, v_y\) ואת גודל המהירות. (ב) מתי המרכז יגיע לנקודה D שבה \(x_D = 25\)? מה יהיה אז \(y_D\)?
    הצג פתרון
    דרך החשיבה

    קודם בונים את משוואות המרכז. אחר כך זו בעיה הפוכה: נתון ערך של x ומחפשים את הזמן. פותרים משוואה ב־t ממשוואת x, ומציבים את הזמן במשוואת y.

    1. נתונים
      \(A(1,2)\)
      \(t_A = 0\)
      \(B(9,8)\)
      \(t_B = 2\)
      \(x_D = 25\)
    2. מהירותשאלת מרחק
      \(v_x = \dfrac{x_B - x_A}{t_B - t_A} = \dfrac{9-1}{2-0} = 4\)
      \(v_y = \dfrac{y_B - y_A}{t_B - t_A} = \dfrac{8-2}{2-0} = 3\)
      \(|v| = \sqrt{v_x^2 + v_y^2} = 5\)
    3. משוואותשאלת מרחק
      \(x_C = x_A + v_x t = 1 + 4t\)
      \(y_C = y_A + v_y t = 2 + 3t\)
    4. זמןשאלת מרחק
      \(x_D = x_A + v_x t_D:\ \ 1 + 4t_D = 25 \Rightarrow t_D = 6\)
    5. y באותו רגעשאלת מרחק
      \(y_D = y_A + v_y t_D = 2 + 3\cdot 6 = 20\)
    תשובה:
    \(|v| = 5\)
    \(t_D = 6\)
    \(D(25, 20)\)
    בדיקה:
    המרחק מ־A
    \(D(25,20)\)
    \(\sqrt{24^2+18^2} = 30\)
    \(30/5 = 6\)שניות ✓
  2. מרכז גלגל מתחיל בנקודה \(A(0,3)\) ונע בכיוון \(60^\circ\) מעל ציר x. אחרי 4 שניות הוא עבר 20 יחידות. מצאו את גודל המהירות, את \(v_x, v_y\), ורשמו את משוואות המרכז.
    הצג פתרון
    דרך החשיבה

    שני שלבים: מהמרחק והזמן מקבלים את גודל המהירות, ורק אז מפרקים אותו לרכיבים לפי הזווית. מי שמפרק את המרחק 20 במקום את המהירות מקבל רכיבים גדולים פי 4.

    1. נתונים
      \(A(0,3)\)
      \(\alpha = 60^\circ\)
      \(s = 20\)
      \(t = 4\)
    2. גודלשאלת מרחק
      \(|v| = \dfrac{s}{t} = \dfrac{20}{4} = 5\)
    3. פירוקשאלת מרחק
      \(v_x = |v|\cos\alpha = 5\cos 60^\circ = 2.5\)
      \(v_y = |v|\sin\alpha = 5\sin 60^\circ = 2.5\sqrt3 \approx 4.33\)
    4. משוואותשאלת מרחק
      \(x_C = x_A + v_x t = 2.5t\)
      \(y_C = y_A + v_y t = 3 + 2.5\sqrt3\,t\)
    תשובה:
    \(|v|=5\)
    \(x_C = 2.5t\)
    \(y_C = 3 + 2.5\sqrt3\,t\)
    בדיקה:
    \(t=4\)
    תזוזה
    \((10,\ 10\sqrt3)\)
    ואורכה
    \(\sqrt{100+300} = 20\)✓
  3. מרכז גלגל עובר מ־\(A(0,0)\) ל־\(B(6,8)\) תוך 2 שניות (ב־\(t=0\) הוא ב־A). מתי יגיע לנקודה D שבה \(y_D = 20\)? מה יהיה אז \(x_D\), וכמה עבר?
    הצג פתרון
    דרך החשיבה

    בונים משוואות, ופותרים משוואה ב־t ממשוואת y. את המרחק מקבלים ממהירות כפול זמן.

    1. נתונים
      \(A(0,0)\)
      \(t_A = 0\)
      \(B(6,8)\)
      \(t_B = 2\)
      \(y_D = 20\)
    2. מהירותשאלת מרחק
      \(v_x = \dfrac{x_B - x_A}{t_B - t_A} = \dfrac{6-0}{2-0} = 3\)
      \(v_y = \dfrac{y_B - y_A}{t_B - t_A} = \dfrac{8-0}{2-0} = 4\)
      \(|v| = \sqrt{v_x^2 + v_y^2} = 5\)
    3. זמןשאלת מרחק
      \(y_D = y_A + v_y t_D:\ \ 4t_D = 20 \Rightarrow t_D = 5\)
    4. x של Dשאלת מרחק
      \(x_D = x_A + v_x t_D = 3\cdot 5 = 15\)
    5. מרחקשאלת מרחק
      \(s = |v|\cdot t_D = 5\cdot 5 = 25\)
    תשובה:
    \(t_D = 5\)
    \(D(15, 20)\)
    \(s = 25\)
    בדיקה:
    \(\sqrt{15^2+20^2} = 25\)✓
  4. מרכז גלגל מתחיל בנקודה \(A(2,1)\) ונע בכיוון \(45^\circ\). אחרי 3 שניות הוא עבר \(6\sqrt2\) יחידות. מצאו את גודל המהירות, את \(v_x, v_y\) ואת משוואות המרכז.
    הצג פתרון
    דרך החשיבה

    קודם גודל המהירות ממרחק וזמן, ורק אז פירוק לפי הזווית.

    1. נתונים
      \(A(2,1)\)
      \(\alpha = 45^\circ\)
      \(s = 6\sqrt2\)
      \(t = 3\)
    2. גודלשאלת מרחק
      \(|v| = \dfrac{s}{t} = \dfrac{6\sqrt2}{3} = 2\sqrt2\)
    3. פירוקשאלת מרחק
      \(v_x = |v|\cos\alpha = 2\sqrt2\cdot\tfrac{\sqrt2}{2} = 2\)
      \(v_y = |v|\sin\alpha = 2\)
    4. משוואותשאלת מרחק
      \(x_C = x_A + v_x t = 2 + 2t\)
      \(y_C = y_A + v_y t = 1 + 2t\)
    תשובה:
    \(|v| = 2\sqrt2\)
    \(v_x = v_y = 2\)
    בדיקה:
    \(t=3\)
    תזוזה
    \((6,6)\)
    ואורכה
