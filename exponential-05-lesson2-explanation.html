שיעור שני - השוואה בין שתי קבוצות

בשיעור הראשון בנינו את הנוסחה f(t) = a · bt לקבוצה אחת שגדלה או קטנה. בשיעור הזה יש שתי קבוצות שגדלות בקצב שונה, ושואלים מתי הן משתוות, או מה היה הערך ההתחלתי של אחת מהן. את אותן שאלות אפשר לראות בהנפשה בדף הדוגמאות של שיעור שני.

בשאלות האלה יש שתי קבוצות שגדלות בקצב שונה. נתחיל בטבלה – שנה אחרי שנה – ונראה מתי הקבוצות משתוות. אחר כך נכתוב את אותו שוויון כמשוואה, ונמצא את החזקה המתאימה בלי לבנות טבלה. בסיום לחצו על "הצג ערכים" ופתחו את השלבים לבדיקה.

שאלה 1 – שתי שמורות דולפינים

בשמורה א' יש 1,728 דולפינים, ומספרם גדל ב-25% בכל שנה.
בשמורה ב' יש 1,000 דולפינים, ומספרם גדל ב-50% בכל שנה.
אחרי כמה שנים יהיה בשתי השמורות אותו מספר דולפינים? כמה דולפינים יהיו אז בכל שמורה?

שנים t0123
שמורה א'1728 216027003375
שמורה ב'1000 150022503375
מתרגמים את אחוזי הגידול של כל שמורה למספר שמכפילים בו (בניית פונקציה)
b = 1 + p/100 bA = 1 + 25/100 = 1.25 bB = 1 + 50/100 = 1.5
שלב א' – טבלה: ממלאים שנה אחרי שנה עד שהמספרים משתווים (חישוב ערכים)
שמורה א': 1728 · 1.25 = 2160 2160 · 1.25 = 2700 2700 · 1.25 = 3375 שמורה ב': 1000 · 1.5 = 1500 1500 · 1.5 = 2250 2250 · 1.5 = 3375

אחרי 3 שנים יש בשתי השמורות 3,375 דולפינים. מכאן והלאה שמורה ב' עוברת את שמורה א', כי היא גדלה מהר יותר.

אבל מה אם השוויון היה מגיע רק אחרי 20 שנה? הטבלה הייתה ארוכה מאוד. לכן נעבור למשוואה.

שלב ב' – מהטבלה למשוואה: כותבים פונקציה לכל שמורה ומשווים ביניהן (פתרון משוואה)
f(t) = a · bt A(t) = 1728 · 1.25t B(t) = 1000 · 1.5t 1728 · 1.25t = 1000 · 1.5t
מעבירים אגפים כך שהחזקות יהיו באגף אחד והמספרים באגף השני
1.5t / 1.25t = 1728 / 1000 (1.5 / 1.25)t = 1.728 1.2t = 1.728
מוצאים איזו חזקה של 1.2 נותנת 1.728
1.22 = 1.44 1.23 = 1.728 t = 3
מציבים t = 3 באחת הפונקציות כדי למצוא את מספר הדולפינים (חישוב ערך)
B(3) = 1000 · 1.53 B(3) = 1000 · 3.375 B(3) = 3375

תשובה: אחרי 3 שנים יהיו בכל שמורה 3,375 דולפינים.

שאלה 2 – שני עדרי כבשים

בעדר א' היו בהתחלה 500 כבשים, ומספרן גדל ב-20% בכל שנה.
בעדר ב' מספר הכבשים גדל ב-50% בכל שנה.
אחרי 3 שנים היה בשני העדרים אותו מספר כבשים. כמה כבשים היו בהתחלה בעדר ב'?

שנים t0123
עדר א'500 600720864
עדר ב' 256384576864
מתרגמים את אחוזי הגידול של כל עדר למספר שמכפילים בו (בניית פונקציה)
b = 1 + p/100 bA = 1 + 20/100 = 1.2 bB = 1 + 50/100 = 1.5
מחשבים כמה כבשים יש בעדר א' אחרי 3 שנים (חישוב ערך)
500 · 1.2 = 600 600 · 1.2 = 720 720 · 1.2 = 864

אחרי 3 שנים יש בעדר א' 864 כבשים – ולכן גם בעדר ב' יש אז 864 כבשים.

שלב א' – טבלה: הולכים אחורה בטבלה של עדר ב' – מחלקים ב-1.5 בכל שנה (מציאת ערך התחלתי)

אם בכל שנה מכפילים ב-1.5, אז כדי לחזור שנה אחורה מחלקים ב-1.5:

t = 2: 864 / 1.5 = 576 t = 1: 576 / 1.5 = 384 t = 0: 384 / 1.5 = 256
שלב ב' – מהטבלה למשוואה: כותבים את הפונקציה של עדר ב' עם ערך התחלתי לא ידוע ומשווים ל-864 (מציאת פרמטר)
f(t) = a · bt B(t) = a · 1.5t B(3) = a · 1.53 864 = a · 3.375 a = 864 / 3.375 a = 256

תשובה: בהתחלה היו בעדר ב' 256 כבשים.

שאלה 3 – שתי בריכות דגים שהתחילו בזמנים שונים

בבריכה א' הכניסו 256 דגים, ומספרם גדל ב-50% בכל שנה.
שנתיים אחרי זה הכניסו דגים לבריכה ב', ושם מספר הדגים מוכפל בכל שנה.
5 שנים אחרי שהכניסו את הדגים לבריכה א', היה בשתי הבריכות אותו מספר דגים. כמה דגים הכניסו לבריכה ב'?

שנים מאז בריכה א' (t)012345
שנים מאז בריכה ב'——0123
בריכה א'25638457686412961944
בריכה ב'——2434869721944
מתרגמים את קצב הגידול של כל בריכה למספר שמכפילים בו (בניית פונקציה)
b = 1 + p/100 bA = 1 + 50/100 = 1.5 bB = 2

בבריכה ב' מספר הדגים מוכפל בכל שנה – גידול של 100%.

מחשבים כמה דגים יש בבריכה א' אחרי 5 שנים (חישוב ערך)
256 · 1.5 = 384 384 · 1.5 = 576 576 · 1.5 = 864 864 · 1.5 = 1296 1296 · 1.5 = 1944

בשנה 5 יש בבריכה א' 1,944 דגים – ולכן גם בבריכה ב' יש אז 1,944 דגים.

מוצאים כמה שנים גדלו הדגים בבריכה ב' עד שהבריכות השתוו (חישוב זמן)

בריכה ב' התחילה שנתיים אחרי בריכה א', ולכן עד שנה 5 הדגים בה גדלו רק 3 שנים:

5 − 2 = 3
שלב א' – טבלה: הולכים אחורה בבריכה ב' – מחלקים ב-2 בכל שנה, עד השנה שבה הוכנסו הדגים (מציאת ערך התחלתי)
t = 4: 1944 / 2 = 972 t = 3: 972 / 2 = 486 t = 2: 486 / 2 = 243

עוצרים בשנה 2, כי זו השנה שבה הכניסו את הדגים לבריכה ב'. לפני כן לא היו בה דגים.

שלב ב' – מהטבלה למשוואה: המעריך הוא מספר השנים שבריכה ב' גדלה, t − 2 (מציאת פרמטר)
f(t) = a · bt B(t) = a · 2t − 2 B(5) = a · 25 − 2 1944 = a · 23 1944 = 8a a = 1944 / 8 a = 243

תשובה: לבריכה ב' הכניסו 243 דגים. שימו לב: אם היינו כותבים 25 (5 שנים מתחילת בריכה א'), היינו מקבלים תשובה שגויה.

סיכום

  • מתחילים בטבלה – שנה אחרי שנה – כדי לראות מתי הקבוצות משתוות.
  • כשהטבלה ארוכה מדי, כותבים פונקציה לכל קבוצה ומשווים: A(t) = B(t).
  • כשהזמן לא ידוע – מגיעים למשוואה מהצורה ct = d ומוצאים את החזקה המתאימה.
  • כשהערך ההתחלתי לא ידוע – הולכים אחורה בטבלה (מחלקים ב-b), או מציבים את הזמן הידוע ומחלצים את a.
  • כשקבוצה התחילה מאוחר יותר, המעריך שלה הוא מספר השנים שהיא גדלה, למשל t − 2.
