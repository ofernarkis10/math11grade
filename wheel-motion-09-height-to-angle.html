מהגובה לזווית ולזמן

בעיה הפוכה: נתון הגובה של נקודה על הגלגל, ומחפשים את הזווית שלה בעזרת \(\sin^{-1}\) ואת הזמן שבו היא מגיעה לשם. חמשת השלבים, שתי הזוויות עם אותו סינוס, כיוון הסיבוב, וארבע דוגמאות פתורות — כולל גלגל מתגלגל וגובה שאי אפשר להגיע אליו.

הרעיון: בעיה הפוכה

עד עכשיו עבדנו בכיוון אחד: מהזמן לזווית, ומהזווית למיקום. בבעיה ההפוכה נתון הגובה של הנקודה, ומחפשים מתי היא שם. הדרך: מהגובה לסינוס, מהסינוס לזווית (בעזרת \(\sin^{-1}\)), ומהזווית לזמן.

הגובה של P הוא \(y = y_C + R\sin\theta\). כאן מטפלים במקרה שבו גובה המרכז \(y_C\) קבוע: גלגל שמסתובב במקום, מרכז שנע אופקית, או גלגל שמתגלגל על הקרקע (\(y_C = R\)).

קו גובה אחד חותך את המעגל בשתי נקודות: לשתי הזוויות θ₁ ו־θ₂ = 180° − θ₁ יש אותו סינוס, ולכן אותו גובה.

חמשת השלבים

שלבמה עושיםהנוסחה
1. נוסחת הגובהמציבים את הגובה הנתון\(y = y_C + R\sin\theta\)
2. בידוד הסינוסמחסירים את \(y_C\) ומחלקים ב־\(R\); בודקים ש־\(|\sin\theta| \le 1\)\(\sin\theta = \dfrac{y - y_C}{R}\)
3. שתי זוויותבמחשבון במצב מעלות (DEG); לזווית השנייה יש אותו סינוס\(\theta_1 = \sin^{-1}\!\left(\dfrac{y - y_C}{R}\right),\ \theta_2 = 180^\circ - \theta_1\)
4. מהזווית לזמןבוחרים את הזווית שמגיעים אליה ראשונה לפי כיוון הסיבוב, ומוסיפים או מחסירים \(360^\circ\) לפי הצורך\(\theta_0 + \omega t = \theta \Rightarrow t = \dfrac{\theta - \theta_0}{\omega}\)
5. בדיקהמציבים את הזמן בנוסחת הגובה\(y(t) = y_C + R\sin(\theta_0 + \omega t)\)
המחשבון נותן רק זווית אחת: \(\sin^{-1}\) מחזיר זווית בין \(-90^\circ\) ל־\(90^\circ\). הזווית השנייה היא תמיד \(180^\circ - \theta_1\), וכל זווית אפשר להזיז בסיבובים שלמים: \(\theta + 360^\circ k\).
סוג השאלה: שלבים 1–3 הם שאלת מיקום (מהגובה של הנקודה לזווית שלה על הגלגל). שלב 4 הוא שאלת מרחק זוויתי (זווית = מהירות זוויתית × זמן). אם אחר כך מחפשים את הקואורדינטה x, חוזרים לשאלת מיקום.

דוגמה 1: זווית מוכרת

השאלה

מרכז גלגל נמצא קבוע בנקודה \(C(0,5)\) והרדיוס 4. הנקודה P מתחילה בצד ימין ומסתובבת נגד השעון ב־\(30^\circ/\text{s}\). מתי P מגיעה לגובה \(y = 7\) בפעם הראשונה ובפעם השנייה? כמה זמן בכל סיבוב היא נמצאת מעל הגובה הזה?

  1. נתונים
    \(C(0,5)\)
    \(R = 4\)
    \(\theta_0 = 0^\circ\)
    \(\omega = 30\)
    \(y = 7\)
  2. נוסחת הגובהשאלת מיקום
    \(y = y_C + R\sin\theta \Rightarrow 7 = 5 + 4\sin\theta\)
  3. בידוד הסינוסשאלת מיקום
    \(\sin\theta = \dfrac{y - y_C}{R} = \dfrac{7-5}{4} = 0.5\)
  4. שתי הזוויותשאלת מיקום
    \(\theta_1 = \sin^{-1}(0.5) = 30^\circ\)
    \(\theta_2 = 180^\circ - \theta_1 = 150^\circ\)
  5. הזמניםשאלת מרחק זוויתי
    \(t = \dfrac{\theta - \theta_0}{\omega}:\ t_1 = \dfrac{30 - 0}{30} = 1\)
    \(t_2 = \dfrac{150 - 0}{30} = 5\)
  6. זמן מעל הגובהשאלת מרחק זוויתי
    \(\Delta t = t_2 - t_1 = 5 - 1 = 4\)
    שניות, מתוך
    \(T = \dfrac{360}{|\omega|} = \dfrac{360}{30} = 12\)שניות
  7. בדיקה
    \(y(1) = 5 + 4\sin 30^\circ = 5 + 2 = 7\)✓
תשובה:
\(t_1 = 1\)
\(t_2 = 5\)
שניות; מעל הגובה 4 שניות בכל סיבוב

דוגמה 2: זווית לא עגולה, מחשבון

השאלה

מרכז גלגל קבוע בגובה 3 והרדיוס 2. הנקודה P מתחילה בראש הגלגל ומסתובבת עם השעון ב־\(45^\circ/\text{s}\). מתי P מגיעה לגובה \(y = 4.2\)?

  1. נתונים
    \(y_C = 3\)
    \(R = 2\)
    \(\theta_0 = 90^\circ\)
    \(\omega = -45\)
    \(y = 4.2\)
  2. בידוד הסינוסשאלת מיקום
    \(\sin\theta = \dfrac{y - y_C}{R} = \dfrac{4.2 - 3}{2} = 0.6\)
  3. מחשבון (DEG)שאלת מיקום
    \(\theta_1 = \sin^{-1}(0.6) \approx 36.87^\circ\)
    \(\theta_2 = 180^\circ - 36.87^\circ = 143.13^\circ\)
  4. כיוון הסיבוב
    עם השעון הזווית יורדת
    \(90^\circ\)
    קודם מגיעים
    \(36.87^\circ\)
    ואחר כך
    \(143.13^\circ - 360^\circ = -216.87^\circ\)
  5. הזמן הראשוןשאלת מרחק זוויתי
    \(t = \dfrac{\theta - \theta_0}{\omega} = \dfrac{36.87 - 90}{-45} \approx 1.18\)
  6. הזמן השנישאלת מרחק זוויתי
    \(t = \dfrac{\theta - \theta_0}{\omega} = \dfrac{-216.87 - 90}{-45} \approx 6.82\)
  7. בדיקהשאלת מיקום
    \(y = y_C + R\sin\theta = 3 + 2\sin(90 - 45\cdot 1.18) \approx 3 + 2\cdot 0.6 = 4.2\)✓
תשובה:
\(t \approx 1.18\)

דוגמה 3: גלגל מתגלגל — מהגובה לזמן ולמיקום

השאלה

גלגל ברדיוס 0.5 מ׳ מתגלגל ימינה בלי החלקה, סיבוב אחד בשנייה. המרכז מתחיל בנקודה \(A(0,\ 0.5)\) והנקודה P מתחילה בקרקע. מתי P מגיעה לראשונה לגובה 0.75 מ׳, ומה הקואורדינטה x שלה באותו רגע?

  1. נתונים
    \(A(0,\ 0.5)\)
    \(R = 0.5\)
    \(n = 1\)
    \(\theta_0 = 270^\circ\)
    \(y = 0.75\)
  2. מהירויותשאלת מרחקשאלת מרחק זוויתי
    \(v_x = L\cdot n = 2\pi\cdot 0.5\cdot 1 = \pi\)
    \(\omega = -360n = -360\)
  3. בידוד הסינוסשאלת מיקום
    \(\sin\theta = \dfrac{y - y_C}{R} = \dfrac{0.75 - 0.5}{0.5} = 0.5\)
  4. שתי הזוויותשאלת מיקום
    \(\theta_1 = \sin^{-1}(0.5) = 30^\circ\)
    \(\theta_2 = 180^\circ - 30^\circ = 150^\circ\)
  5. כיוון הסיבוב
    עם השעון
    \(270^\circ\)
    הזווית יורדת, ולכן מגיעים קודם
    \(150^\circ\)
  6. הזמןשאלת מרחק זוויתי
    \(t = \dfrac{\theta - \theta_0}{\omega} = \dfrac{150 - 270}{-360} = \dfrac13\)
  7. המיקוםשאלת מרחקשאלת מיקום
    \(x = x_A + v_x t + R\cos\theta = 0 + \pi\cdot\tfrac13 + 0.5\cos 150^\circ \approx 1.047 - 0.433 = 0.614\)
תשובה:
\(t = \tfrac13\)שנייה
\(x \approx 0.61\)מ׳

דוגמה 4: גובה שאי אפשר להגיע אליו

השאלה

מרכז גלגל בגובה 3 והרדיוס 2. האם נקודה על הגלגל יכולה להגיע לגובה 6?

  1. בידוד הסינוסשאלת מיקום
    \(\sin\theta = \dfrac{y - y_C}{R} = \dfrac{6 - 3}{2} = 1.5\)
  2. בדיקת תחום
    \(-1 \le \sin\theta \le 1\)
    \(1.5 \gt 1\)
  3. הגובה המרבישאלת מיקום
    \(y_{max} = y_C + R = 3 + 2 = 5\)
תשובה:
לא. הגובה המרבי הוא 5, ולכן למשוואה אין פתרון

טעויות נפוצות

  • מחשבון במצב רדיאנים (RAD): \(\sin^{-1}(0.5)\) יוצא 0.52 במקום \(30^\circ\).
  • שוכחים את הזווית השנייה \(180^\circ - \theta_1\), ומפספסים את הפעם השנייה שהנקודה בגובה הזה.
  • מחלקים ב־\(R\) לפני שמחסירים את גובה המרכז: \(\sin\theta = \dfrac{y - y_C}{R}\), לא \(\dfrac{y}{R} - y_C\).
  • בסיבוב עם השעון (\(\omega \lt 0\)) מקבלים זמן שלילי: צריך להחסיר \(360^\circ\) מהזווית לפני שמחלקים ב־\(\omega\).
  • לא בודקים שהגובה אפשרי: אם \(\left|\dfrac{y - y_C}{R}\right| \gt 1\) — אין פתרון.
