1סכום זוויות במשולש

במשולש \(ABC\) נתון \(\angle A = 48^\circ\), והזווית \(\angle B\) גדולה ב־\(22^\circ\) מ־\(\angle A\). מצאו את \(\angle C\).

פתרון

תשובה: \(\angle C = 62^\circ\)

דרך הפתרון:

  1. מחשבים את \(\angle B\): \(48^\circ + 22^\circ = 70^\circ\).
  2. סכום הזוויות במשולש הוא \(180^\circ\), ולכן \(\angle C = 180^\circ - 48^\circ - 70^\circ = 62^\circ\).
2סכום זוויות במרובע

הזוויות של מרובע מתייחסות זו לזו כמו \(2:3:4:6\). מצאו את הזוויות.

פתרון

תשובה: \(48^\circ,\ 72^\circ,\ 96^\circ,\ 144^\circ\)

דרך הפתרון:

  1. מסמנים את הזוויות \(2x, 3x, 4x, 6x\). יחד יש \(15x\).
  2. סכום הזוויות במרובע הוא \(360^\circ\): \(15x = 360^\circ\), ולכן \(x = 24^\circ\).
  3. מציבים: \(2\cdot 24 = 48^\circ\), \(3\cdot24=72^\circ\), \(4\cdot24=96^\circ\), \(6\cdot24=144^\circ\). בדיקה: \(48+72+96+144=360\).
3סכום זוויות פנימיות במצולע

סכום הזוויות הפנימיות של מצולע הוא \(1440^\circ\). כמה צלעות יש למצולע?

פתרון

תשובה: \(n = 10\)

דרך הפתרון:

  1. משתמשים בנוסחה \(180^\circ (n-2)\) ומשווים לסכום הנתון: \(180(n-2) = 1440\).
  2. מחלקים ב־180: \(n - 2 = 8\), ולכן \(n = 10\).
4זווית במצולע משוכלל

כל זווית פנימית במצולע משוכלל היא \(150^\circ\). כמה צלעות יש למצולע?

פתרון

תשובה: \(n = 12\)

דרך הפתרון:

  1. במצולע משוכלל כל הזוויות שוות, ולכן כל זווית היא \(\frac{180(n-2)}{n}\).
  2. משווים: \(\frac{180(n-2)}{n} = 150\). כופלים ב־\(n\): \(180n - 360 = 150n\).
  3. מעבירים אגפים: \(30n = 360\), ולכן \(n = 12\).
  4. דרך קצרה: הזווית החיצונית היא \(180^\circ-150^\circ=30^\circ\), וסכום הזוויות החיצוניות הוא \(360^\circ\), ולכן \(n = 360 : 30 = 12\).
5סכום הזוויות החיצוניות

כל זווית חיצונית במצולע משוכלל היא \(24^\circ\). כמה צלעות יש למצולע, ומהי הזווית הפנימית שלו?

פתרון

תשובה: \(n = 15,\ \ 156^\circ\)

דרך הפתרון:

  1. סכום הזוויות החיצוניות בכל מצולע הוא \(360^\circ\), ובמצולע משוכלל הן שוות זו לזו.
  2. לכן מספר הצלעות הוא \(360 : 24 = 15\).
  3. זווית פנימית וזווית חיצונית באותו קודקוד צמודות, ולכן הזווית הפנימית היא \(180^\circ - 24^\circ = 156^\circ\).
6זווית חיצונית למשולש

במשולש \(ABC\) הזווית החיצונית ליד הקודקוד \(C\) היא \(115^\circ\). נתון \(\angle A = 3x\) ו־\(\angle B = 2x + 15^\circ\). מצאו את שלוש זוויות המשולש.

פתרון

תשובה: \(\angle A = 60^\circ,\ \angle B = 55^\circ,\ \angle C = 65^\circ\)

דרך הפתרון:

  1. הזווית החיצונית שווה לסכום שתי הזוויות הפנימיות שלא צמודות לה: \(3x + 2x + 15 = 115\).
  2. פותרים: \(5x = 100\), ולכן \(x = 20\). מכאן \(\angle A = 60^\circ\) ו־\(\angle B = 55^\circ\).
  3. \(\angle C\) צמודה לזווית החיצונית: \(\angle C = 180^\circ - 115^\circ = 65^\circ\). בדיקה: \(60+55+65=180\).

7משפט פיתגורס

במשולש ישר זווית היתר הוא 26 ואחד הניצבים הוא 10. מצאו את הניצב השני ואת היקף המשולש.

פתרון

תשובה: \(b = 24,\ \ P = 60\)

דרך הפתרון:

  1. לפי פיתגורס \(a^2 + b^2 = c^2\): \(10^2 + b^2 = 26^2\).
  2. \(b^2 = 676 - 100 = 576\), ולכן \(b = 24\) (אורך הוא חיובי).
  3. ההיקף: \(10 + 24 + 26 = 60\).
8תיכון ליתר

במשולש \(ABC\) הזווית \(C\) ישרה. התיכון \(CM\) ליתר שווה ל־7.5, ונתון \(AC = 9\). מצאו את \(BC\).

פתרון

תשובה: \(BC = 12\)

דרך הפתרון:

  1. במשולש ישר זווית התיכון ליתר שווה למחצית היתר. לכן \(AB = 2 \cdot 7.5 = 15\).
  2. לפי פיתגורס: \(BC^2 = 15^2 - 9^2 = 225 - 81 = 144\), ולכן \(BC = 12\).
9גובה ליתר

הניצבים של משולש ישר זווית הם 15 ו־20. מצאו את הגובה ליתר.

פתרון

תשובה: \(h = 12\)

דרך הפתרון:

  1. מחשבים את היתר לפי פיתגורס: \(c = \sqrt{15^2+20^2} = \sqrt{625} = 25\).
  2. את השטח אפשר לחשב בשתי דרכים: \(\frac{a\cdot b}{2} = \frac{c\cdot h}{2}\). מכאן \(h = \frac{ab}{c}\).
  3. \(h = \frac{15\cdot 20}{25} = \frac{300}{25} = 12\).
10גובה ליתר והיטלים

הגובה ליתר במשולש ישר זווית מחלק את היתר לקטעים באורך 4 ו־9. מצאו את הגובה ואת שטח המשולש.

פתרון

תשובה: \(h = 6,\ \ S = 39\)

דרך הפתרון:

  1. הגובה ליתר יוצר שני משולשים דומים, ומהדמיון מתקבל \(h^2 = p \cdot q\).
  2. \(h^2 = 4 \cdot 9 = 36\), ולכן \(h = 6\).
  3. היתר הוא \(4 + 9 = 13\), ולכן השטח הוא \(\frac{13 \cdot 6}{2} = 39\).
11ניצב והיטלו

היתר של משולש ישר זווית הוא 25. ההיטל של הניצב \(a\) על היתר הוא 9. מצאו את שני הניצבים.

פתרון

תשובה: \(a = 15,\ \ b = 20\)

דרך הפתרון:

  1. ניצב בריבוע שווה למכפלת היתר בהיטל של אותו ניצב: \(a^2 = c \cdot p = 25 \cdot 9 = 225\), ולכן \(a = 15\).
  2. ההיטל של הניצב השני הוא \(q = 25 - 9 = 16\), ולכן \(b^2 = 25 \cdot 16 = 400\) ו־\(b = 20\).
  3. בדיקה בפיתגורס: \(15^2 + 20^2 = 225 + 400 = 625 = 25^2\).
12משולש 30°-60°-90°

במשולש ישר זווית אחת הזוויות היא \(30^\circ\) והיתר הוא 14. מצאו את הניצבים ואת השטח.

פתרון

תשובה: \(7,\ \ 7\sqrt3,\ \ S = \frac{49\sqrt3}{2}\)

דרך הפתרון:

  1. הניצב שמול זווית של \(30^\circ\) שווה למחצית היתר: \(14 : 2 = 7\).
  2. היחס בין הצלעות הוא \(x : x\sqrt3 : 2x\) עם \(x = 7\), ולכן הניצב השני הוא \(7\sqrt3\). (אפשר גם בפיתגורס: \(\sqrt{14^2 - 7^2} = \sqrt{147} = 7\sqrt3\).)
  3. השטח הוא מחצית מכפלת הניצבים: \(\frac{7 \cdot 7\sqrt3}{2} = \frac{49\sqrt3}{2}\).
13משולש 45°-45°-90°

היתר של משולש ישר זווית ושווה שוקיים הוא 10. מצאו את הניצבים ואת השטח.

פתרון

תשובה: \(5\sqrt2,\ \ S = 25\)

דרך הפתרון:

  1. במשולש ישר זווית ושווה שוקיים היחס בין הצלעות הוא \(x : x : x\sqrt2\).
  2. \(x\sqrt2 = 10\), ולכן \(x = \frac{10}{\sqrt2} = 5\sqrt2\).
  3. השטח: \(\frac{5\sqrt2 \cdot 5\sqrt2}{2} = \frac{50}{2} = 25\).
14רדיוס המעגל החוסם משולש ישר זווית

הניצבים של משולש ישר זווית הם 7 ו־24. מצאו את רדיוס המעגל החוסם את המשולש.

פתרון

תשובה: \(R = 12.5\)

דרך הפתרון:

  1. היתר: \(c = \sqrt{7^2 + 24^2} = \sqrt{625} = 25\).
  2. הזווית הישרה היא זווית היקפית, ולכן היא נשענת על קוטר. כלומר היתר הוא קוטר המעגל החוסם, ומרכז המעגל הוא אמצע היתר.
  3. \(R = \frac{c}{2} = 12.5\).
15רדיוס המעגל החסום במשולש ישר זווית

הניצבים של משולש ישר זווית הם 7 ו־24. מצאו את רדיוס המעגל החסום במשולש.

פתרון

תשובה: \(r = 3\)

דרך הפתרון:

  1. היתר הוא 25 (ראו השאלה הקודמת). לפי הנוסחה \(r = \frac{a+b-c}{2} = \frac{7 + 24 - 25}{2} = 3\).
  2. למה הנוסחה נכונה: המשיקים מקודקוד הזווית הישרה שווים ל־\(r\), ולכן המשיקים מהקודקודים האחרים הם \(a-r\) ו־\(b-r\), וסכומם הוא היתר: \((a-r)+(b-r)=c\).
  3. בדיקה בדרך אחרת: \(r = \frac{2S}{P} = \frac{2 \cdot 84}{56} = 3\).

16גובה במשולש שווה צלעות

צלע של משולש שווה צלעות היא 8. מצאו את הגובה.

פתרון

תשובה: \(h = 4\sqrt3\)

דרך הפתרון:

  1. הגובה הוא גם תיכון, ולכן הוא מחלק את הבסיס לשני חצאים של 4.
  2. בפיתגורס במשולש ישר הזווית שנוצר: \(h = \sqrt{8^2 - 4^2} = \sqrt{48} = 4\sqrt3\).
  3. זה מתאים לנוסחה \(h = \frac{a\sqrt3}{2} = \frac{8\sqrt3}{2}\).
17שטח משולש שווה צלעות

שטח של משולש שווה צלעות הוא \(25\sqrt3\). מצאו את היקף המשולש.

פתרון

תשובה: \(P = 30\)

דרך הפתרון:

  1. מציבים בנוסחה \(S = \frac{a^2\sqrt3}{4}\): \(\frac{a^2 \sqrt3}{4} = 25\sqrt3\).
  2. מחלקים ב־\(\sqrt3\) וכופלים ב־4: \(a^2 = 100\), ולכן \(a = 10\).
  3. ההיקף: \(3 \cdot 10 = 30\).
18רדיוס המעגל החוסם משולש שווה צלעות

צלע של משולש שווה צלעות היא \(6\sqrt3\). מצאו את רדיוס המעגל החוסם.

פתרון

תשובה: \(R = 6\)

דרך הפתרון:

  1. במשולש שווה צלעות כל הנקודות המיוחדות מתלכדות, ומרכז המעגל החוסם הוא גם מפגש התיכונים. לכן \(R = \frac{2}{3}h\).
  2. הגובה: \(h = \frac{6\sqrt3 \cdot \sqrt3}{2} = \frac{18}{2} = 9\).
  3. \(R = \frac{2}{3} \cdot 9 = 6\).
19רדיוס המעגל החסום במשולש שווה צלעות

רדיוס המעגל החסום במשולש שווה צלעות הוא 2. מצאו את צלע המשולש.

פתרון

תשובה: \(a = 4\sqrt3\)

דרך הפתרון:

  1. מרכז המעגל החסום הוא מפגש התיכונים, שמחלק את הגובה ביחס \(2:1\). הרדיוס הוא החלק הקטן, ולכן \(r = \frac{1}{3}h\).
  2. \(h = 3 \cdot 2 = 6\).
  3. מ־\(h = \frac{a\sqrt3}{2}\): \(a = \frac{2h}{\sqrt3} = \frac{12}{\sqrt3} = 4\sqrt3\).

20מפגש התיכונים

במשולש \(ABC\) הנקודה \(G\) היא מפגש התיכונים, ו־\(AD\) תיכון באורך 18. מצאו את \(AG\) ואת \(GD\).

פתרון

תשובה: \(AG = 12,\ \ GD = 6\)

דרך הפתרון:

  1. מפגש התיכונים מחלק כל תיכון ביחס \(2:1\), כשהחלק הגדול צמוד לקודקוד.
  2. התיכון מחולק ל־3 חלקים שווים של \(18 : 3 = 6\). לכן \(AG = 2 \cdot 6 = 12\) ו־\(GD = 6\).
21קטע אמצעים במשולש

אורכי הצלעות של משולש הם 10, 14 ו־18. מחברים את אמצעי הצלעות. מהו היקף המשולש שנוצר?

פתרון

תשובה: \(P = 21\)

דרך הפתרון:

  1. כל אחד מהקטעים הוא קטע אמצעים, ולכן הוא שווה למחצית הצלע שמקבילה לו: 5, 7 ו־9.
  2. ההיקף: \(5 + 7 + 9 = 21\), כלומר מחצית מההיקף של המשולש המקורי (\(42\)).
22קטע אמצעים בטרפז

קטע האמצעים של טרפז הוא 13, והבסיס הקטן הוא 8. מצאו את הבסיס הגדול.

פתרון

תשובה: \(18\)

דרך הפתרון:

  1. קטע האמצעים בטרפז שווה למחצית סכום הבסיסים: \(\frac{8 + x}{2} = 13\).
  2. \(8 + x = 26\), ולכן \(x = 18\).
23רדיוס המעגל החסום בכל משולש

אורכי הצלעות של משולש הם 13, 14 ו־15, והגובה לצלע 14 הוא 12. מצאו את רדיוס המעגל החסום.

פתרון

תשובה: \(r = 4\)

דרך הפתרון:

  1. שטח המשולש: \(S = \frac{14 \cdot 12}{2} = 84\). ההיקף: \(13+14+15=42\).
  2. מחברים את מרכז המעגל החסום לשלושת הקודקודים ומקבלים שלושה משולשים שהגובה בכולם הוא \(r\). לכן \(S = \frac{r \cdot P}{2}\), ומכאן \(r = \frac{2S}{P}\).
  3. \(r = \frac{2 \cdot 84}{42} = 4\).
24מרכז המעגל החוסם

במשולש \(ABC\) האנכים האמצעיים של \(AB\) ושל \(AC\) נפגשים בנקודה \(O\), ו־\(OA = 7\). מצאו את \(OB\) ואת \(OC\), והסבירו למה גם האנך האמצעי של \(BC\) עובר דרך \(O\).

פתרון

תשובה: \(OB = OC = 7\)

דרך הפתרון:

  1. כל נקודה על האנך האמצעי של קטע נמצאת במרחקים שווים מקצות הקטע. \(O\) על האנך האמצעי של \(AB\), ולכן \(OB = OA = 7\). \(O\) על האנך האמצעי של \(AC\), ולכן \(OC = OA = 7\).
  2. מכאן \(OB = OC\). לפי המשפט ההפוך, נקודה שנמצאת במרחקים שווים מקצות קטע נמצאת על האנך האמצעי שלו, ולכן \(O\) על האנך האמצעי של \(BC\).
  3. \(O\) נמצאת במרחק 7 מכל הקודקודים, ולכן היא מרכז המעגל החוסם, והרדיוס שלו הוא 7.
25מרכז המעגל החסום

במשולש \(ABC\) נתון \(\angle A = 70^\circ\). הנקודה \(I\) היא מפגש חוצי הזוויות. מצאו את \(\angle BIC\).

פתרון

תשובה: \(\angle BIC = 125^\circ\)

דרך הפתרון:

  1. סכום שתי הזוויות האחרות: \(\angle B + \angle C = 180^\circ - 70^\circ = 110^\circ\).
  2. \(BI\) ו־\(CI\) חוצים את הזוויות, ולכן \(\angle IBC + \angle ICB = 110^\circ : 2 = 55^\circ\).
  3. במשולש \(BIC\): \(\angle BIC = 180^\circ - 55^\circ = 125^\circ\). באופן כללי \(\angle BIC = 90^\circ + \frac{\angle A}{2}\).

27אלכסון בריבוע

תשובה: \(70^\circ\)

דרך הפתרון:

  1. זווית בין מיתרים נחתכים שווה למחצית סכום הקשתות: \(\frac{100^\circ + 40^\circ}{2} = 70^\circ\).
  2. למה: מחברים שניים מקצות המיתרים. הזווית היא זווית חיצונית למשולש שנוצר, ולכן היא שווה לסכום שתי זוויות היקפיות, שכל אחת מהן היא מחצית מאחת הקשתות.
58זווית בין חותכים מחוץ למעגל

שני חותכים יוצאים מנקודה \(P\) מחוץ למעגל. הקשתות שהם כולאים הן \(110^\circ\) (הרחוקה) ו־\(30^\circ\) (הקרובה). מצאו את \(\angle P\).

פתרון

תשובה: \(\angle P = 40^\circ\)

דרך הפתרון:

  1. זווית בין חותכים מחוץ למעגל שווה למחצית ההפרש בין הקשתות: \(\frac{110^\circ - 30^\circ}{2} = 40^\circ\).
  2. למה: זווית היקפית שנשענת על הקשת הרחוקה היא זווית חיצונית במשולש שאחד מקודקודיו הוא P, ולכן הזווית ב־P היא ההפרש בין שתי זוויות היקפיות.
59מרחק מיתר מהמרכז

רדיוס של מעגל הוא 13, ובמעגל יש מיתר באורך 24. מצאו את המרחק של המיתר ממרכז המעגל.

פתרון

תשובה: \(d = 5\)

דרך הפתרון:

  1. האנך ממרכז המעגל למיתר חוצה את המיתר, ולכן נוצר משולש ישר זווית עם יתר \(r = 13\) וניצב \(24 : 2 = 12\).
  2. \(d = \sqrt{13^2 - 12^2} = \sqrt{25} = 5\).
60משיק ורדיוס בנקודת ההשקה

\(PA\) משיק למעגל שמרכזו \(O\), בנקודה \(A\). נתון \(\angle AOP = 55^\circ\). מצאו את \(\angle APO\).

פתרון

תשובה: \(\angle APO = 35^\circ\)

דרך הפתרון:

  1. משיק מאונך לרדיוס בנקודת ההשקה, ולכן \(\angle OAP = 90^\circ\).
  2. במשולש \(OAP\): \(\angle APO = 180^\circ - 90^\circ - 55^\circ = 35^\circ\).
61שני משיקים מאותה נקודה

\(PA\) ו־\(PB\) משיקים למעגל מהנקודה \(P\), ו־\(\angle APB = 50^\circ\). מצאו את \(\angle PAB\).

פתרון

תשובה: \(\angle PAB = 65^\circ\)

דרך הפתרון:

  1. שני משיקים מאותה נקודה שווים, ולכן \(PA = PB\) והמשולש \(PAB\) שווה שוקיים.
  2. זוויות הבסיס שוות: \(\angle PAB = \frac{180^\circ - 50^\circ}{2} = 65^\circ\).
62אורך משיק מנקודה

רדיוס של מעגל הוא 5. הנקודה \(P\) נמצאת במרחק 13 ממרכז המעגל. מצאו את אורך המשיק \(PT\).

פתרון

תשובה: \(PT = 12\)

דרך הפתרון:

  1. המשיק מאונך לרדיוס \(OT\), ולכן המשולש \(OTP\) ישר זווית ו־\(OP\) היתר שלו.
  2. \(PT^2 = OP^2 - r^2 = 169 - 25 = 144\), ולכן \(PT = 12\).

63מיתרים נחתכים

המיתרים \(AB\) ו־\(CD\) נחתכים בנקודה \(E\). נתון \(AE = 4\), \(EB = 9\) ו־\(CE = 6\). מצאו את \(ED\) ואת אורך המיתר \(CD\).

פתרון

תשובה: \(ED = 6,\ \ CD = 12\)

דרך הפתרון:

  1. מכפלת חלקי מיתר אחד שווה למכפלת חלקי המיתר השני: \(AE \cdot EB = CE \cdot ED\).
  2. \(4 \cdot 9 = 6 \cdot ED\), ולכן \(ED = 6\) ו־\(CD = 12\).
  3. מקור המשפט: \(\triangle AEC \sim \triangle DEB\) (ז.ז: זוויות קודקודיות וזוויות היקפיות על אותה קשת).
64משיק וחותך

מהנקודה \(P\) יוצאים משיק \(PT\) וחותך שחותך את המעגל בנקודות \(A\) ו־\(B\) (\(A\) קרובה יותר ל־\(P\)). נתון \(PA = 4\) ו־\(AB = 5\). מצאו את \(PT\).

פתרון

תשובה: \(PT = 6\)

דרך הפתרון:

  1. מחשבים את המרחק לנקודה הרחוקה: \(PB = 4 + 5 = 9\).
  2. \(PT^2 = PA \cdot PB = 4 \cdot 9 = 36\), ולכן \(PT = 6\).
  3. טעות נפוצה: לכפול ב־\(AB\) במקום ב־\(PB\).
65שני חותכים

מהנקודה \(P\) יוצאים שני חותכים: אחד חותך את המעגל ב־\(A\) וב־\(B\), והשני ב־\(C\) וב־\(D\). נתון \(PA = 3\), \(AB = 9\) ו־\(PC = 4\). מצאו את \(CD\).

פתרון

תשובה: \(CD = 5\)

דרך הפתרון:

  1. \(PB = 3 + 9 = 12\).
  2. \(PA \cdot PB = PC \cdot PD\): \(3 \cdot 12 = 4 \cdot PD\), ולכן \(PD = 9\).
  3. \(CD = PD - PC = 9 - 4 = 5\).
