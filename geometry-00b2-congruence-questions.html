שאלות על חפיפת משולשים

26 שאלות בחמש רמות קושי. מתחילים בזיהוי משפט החפיפה, עוברים להוכחות ישירות, להוכחות שצריך בהן צעד ביניים, להוכחות בשני שלבים, ומסיימים בשאלות אתגר. בכל פתרון יש את התשובה, הסבר איך מתחילים לחשוב על השאלה, והוכחה מלאה בטבלת טענה ונימוק. נסו לפתור לבד לפני שפותחים את הפתרון. ההסבר על המשפטים נמצא בדף חפיפת משולשים.

טיפ להוכחות: (1) סמנו בשרטוט את כל הנתונים. (2) מצאו את שני המשולשים שמכילים את מה שצריך להוכיח. (3) חפשו שלושה שוויונות: נתון, צלע או זווית משותפת, זוויות קודקודיות, זוויות בין מקבילים, זוויות בסיס במשולש שווה שוקיים. (4) אם חסר שוויון, אולי צריך קודם חפיפה אחרת.

רמה 1 ●○○○○

זיהוי משפט החפיפה

1. במשולשים \(ABC\) ו־\(DEF\) נתון \(AB = DE\), \(\angle B = \angle E\), \(BC = EF\). האם המשולשים חופפים? אם כן, לפי איזה משפט, ואילו שוויונות נוספים נובעים מכך?

פתרון
תשובה

כן, לפי צלע זווית צלע. \(AC = DF\), \(\angle A = \angle D\), \(\angle C = \angle F\).

דרך הפתרון:

הזווית \(\angle B\) כלואה בין \(AB\) ו־\(BC\), והזווית \(\angle E\) כלואה בין \(DE\) ו־\(EF\). אלה שתי צלעות והזווית שביניהן.

ההתאמה: \(A \leftrightarrow D,\ B \leftrightarrow E,\ C \leftrightarrow F\), ולכן \(\triangle ABC \cong \triangle DEF\).

מהחפיפה נובע שגם הצלע השלישית והזוויות האחרות שוות, כל אחת לזו שמתאימה לה.

2. נתון \(\angle A = \angle D\), \(\angle B = \angle E\), \(AB = DE\). לפי איזה משפט \(\triangle ABC \cong \triangle DEF\)?

פתרון
תשובה

זווית צלע זווית.

דרך הפתרון:

הצלע \(AB\) נמצאת בין הזוויות \(A\) ו־\(B\), וכך גם \(DE\) בין \(D\) ו־\(E\). זו צלע ושתי הזוויות שלידה.

3. נתון \(AB = DE = 7\), \(BC = EF = 5\), \(\angle A = \angle D = 30^\circ\). האם אפשר להסיק ש־\(\triangle ABC \cong \triangle DEF\)?

פתרון
תשובה

לא.

דרך הפתרון:

הזווית \(A\) לא כלואה בין \(AB\) ל־\(BC\), ולכן זה לא צלע זווית צלע. זה המבנה צלע צלע זווית.

צלע צלע זווית מספיק רק כשהזווית נמצאת מול הצלע הגדולה מבין השתיים. כאן \(\angle A\) נמצאת מול \(BC = 5\), הצלע הקטנה.

במקרה כזה אפשר לבנות שני משולשים שונים עם אותם נתונים (ראו את הסימולציה של צלע צלע זווית). לכן אי אפשר להסיק חפיפה.

4. נתון \(AB = DE\), \(AC = DF\), \(\angle C = \angle F\), וידוע ש־\(AB > AC\). האם המשולשים \(ABC\) ו־\(DEF\) חופפים?

פתרון
תשובה

כן, לפי משפט החפיפה הרביעי (צלע צלע זווית).

דרך הפתרון:

הזווית \(\angle C\) לא נמצאת בין \(AB\) ל־\(AC\). היא נמצאת מול \(AB\).

\(AB\) היא הגדולה מבין שתי הצלעות הנתונות, ולכן הזווית נמצאת מול הצלע הגדולה. זה בדיוק התנאי של משפט החפיפה הרביעי.

השוו לשאלה 3: שם הזווית הייתה מול הצלע הקטנה, ולכן לא היה מספיק.

5. נתון \(\triangle ABC \cong \triangle PQR\), \(\angle P = 40^\circ\), \(\angle Q = 75^\circ\), \(QR = 6\), \(PR = 8\). מצאו את \(\angle C\), את \(BC\) ואת \(AC\).

פתרון
תשובה

\(\angle C = 65^\circ\), \(BC = 6\), \(AC = 8\).

דרך הפתרון:

סדר האותיות קובע את ההתאמה: \(A \leftrightarrow P\), \(B \leftrightarrow Q\), \(C \leftrightarrow R\).

\(\angle R = 180^\circ - 40^\circ - 75^\circ = 65^\circ\), ולכן \(\angle C = 65^\circ\).

\(BC\) מתאימה ל־\(QR\), ולכן \(BC = 6\). \(AC\) מתאימה ל־\(PR\), ולכן \(AC = 8\).

6. נתון \(\angle A = \angle D\), \(\angle C = \angle F\) ו־\(BC = EF\). הצלע הנתונה לא נמצאת בין שתי הזוויות. האם המשולשים חופפים?

פתרון
תשובה

כן. אחרי שמחשבים את הזווית השלישית, זה זווית צלע זווית.

דרך הפתרון:

סכום הזוויות בכל משולש הוא \(180^\circ\), ולכן גם \(\angle B = 180^\circ - \angle A - \angle C = 180^\circ - \angle D - \angle F = \angle E\).

עכשיו יש לנו את הצלע \(BC\) ושתי הזוויות שלידה, \(\angle B\) ו־\(\angle C\), וכך גם \(EF\) עם \(\angle E\) ו־\(\angle F\). זה זווית צלע זווית.

כלל: שתי זוויות וצלע מתאימה תמיד מספיקות, בתנאי שהצלע נמצאת מול אותה זווית בשני המשולשים.

רמה 2 ●●○○○

הוכחה ישירה

7. במרובע \(ABCD\) נתון \(AB = AD\) ו־\(BC = DC\). הוכיחו ש־\(\angle B = \angle D\).

פתרון
תשובה

\(\triangle ABC \cong \triangle ADC\) לפי צלע צלע צלע, ולכן \(\angle B = \angle D\).

איך מתחילים: הזוויות \(\angle B\) ו־\(\angle D\) נמצאות במשולשים \(ABC\) ו־\(ADC\). לשני המשולשים יש צלע משותפת, \(AC\).

דרך הפתרון:

#טענהנימוק
1\(AB = AD\)נתון
2\(BC = DC\)נתון
3\(AC = AC\)צלע משותפת
4\(\triangle ABC \cong \triangle ADC\)צלע צלע צלע (טענות 1–3)
5\(\angle B = \angle D\)זוויות מתאימות במשולשים חופפים

8. הקטעים \(AC\) ו־\(BD\) נחתכים בנקודה \(O\), ו־\(O\) אמצע של שניהם. הוכיחו ש־\(AB = CD\).

פתרון
תשובה

\(\triangle AOB \cong \triangle COD\) לפי צלע זווית צלע, ולכן \(AB = CD\).

איך מתחילים: \(AB\) ו־\(CD\) נמצאות במשולשים \(AOB\) ו־\(COD\). את הזווית שבין הצלעות נותנות הזוויות הקודקודיות ב־\(O\).

דרך הפתרון:

#טענהנימוק
1\(AO = OC\)\(O\) אמצע \(AC\)
2\(\angle AOB = \angle COD\)זוויות קודקודיות
3\(BO = OD\)\(O\) אמצע \(BD\)
4\(\triangle AOB \cong \triangle COD\)צלע זווית צלע (טענות 1–3)
5\(AB = CD\)צלעות מתאימות במשולשים חופפים

9. במרובע \(ABCD\) האלכסון \(AC\) חוצה את הזווית \(A\) ואת הזווית \(C\). הוכיחו ש־\(AB = AD\).

פתרון
תשובה

\(\triangle ABC \cong \triangle ADC\) לפי זווית צלע זווית, ולכן \(AB = AD\).

איך מתחילים: יש שתי זוויות שוות בקצות הצלע המשותפת \(AC\). זה המבנה של זווית צלע זווית.

דרך הפתרון:

#טענהנימוק
1\(\angle BAC = \angle DAC\)\(AC\) חוצה את \(\angle A\)
2\(AC = AC\)צלע משותפת
3\(\angle BCA = \angle DCA\)\(AC\) חוצה את \(\angle C\)
4\(\triangle ABC \cong \triangle ADC\)זווית צלע זווית (טענות 1–3)
5\(AB = AD\)צלעות מתאימות במשולשים חופפים

10. במשולש \(ABC\) הקטע \(AD\) מאונך ל־\(BC\), ו־\(D\) אמצע \(BC\). הוכיחו שהמשולש שווה שוקיים: \(AB = AC\).

פתרון
תשובה

\(\triangle ABD \cong \triangle ACD\) לפי צלע זווית צלע, ולכן \(AB = AC\).

איך מתחילים: הגובה מחלק את המשולש לשני משולשים ישרי זווית עם צלע משותפת.

דרך הפתרון:

#טענהנימוק
1\(BD = DC\)\(D\) אמצע \(BC\)
2\(\angle ADB = \angle ADC = 90^\circ\)\(AD\) מאונך ל־\(BC\)
3\(AD = AD\)צלע משותפת
4\(\triangle ABD \cong \triangle ACD\)צלע זווית צלע (טענות 1–3)
5\(AB = AC\)צלעות מתאימות במשולשים חופפים

11. במרובע \(ABCD\) נתון \(AB \parallel DC\) ו־\(AB = DC\). הוכיחו ש־\(BC = AD\).

פתרון
תשובה

\(\triangle ABC \cong \triangle CDA\) לפי צלע זווית צלע, ולכן \(BC = DA\).

איך מתחילים: מהמקבילים מקבלים זוויות מתחלפות. הזווית \(\angle BAC\) כלואה בין \(AB\) ל־\(AC\), ו־\(\angle DCA\) בין \(DC\) ל־\(CA\).

דרך הפתרון:

#טענהנימוק
1\(AB = CD\)נתון
2\(\angle BAC = \angle DCA\)זוויות מתחלפות בין המקבילים \(AB \parallel DC\)
3\(AC = CA\)צלע משותפת
4\(\triangle ABC \cong \triangle CDA\)צלע זווית צלע (טענות 1–3)
5\(BC = DA\)צלעות מתאימות במשולשים חופפים

12. הנקודות \(A\) ו־\(D\) נמצאות באותו צד של \(BC\), ונתון \(AB = DC\) ו־\(AC = DB\). הוכיחו ש־\(\angle BAC = \angle CDB\).

פתרון
תשובה

\(\triangle ABC \cong \triangle DCB\) לפי צלע צלע צלע, ולכן \(\angle BAC = \angle CDB\).

איך מתחילים: המשולשים חופפים ״חלקית״ זה על זה. מחפשים אותם לפי הזוויות שצריך להוכיח: \(\angle BAC\) במשולש \(ABC\), ו־\(\angle CDB\) במשולש \(DCB\).

דרך הפתרון:

#טענהנימוק
1\(AB = DC\)נתון
2\(AC = DB\)נתון
3\(BC = CB\)צלע משותפת
4\(\triangle ABC \cong \triangle DCB\)צלע צלע צלע (טענות 1–3)
5\(\angle BAC = \angle CDB\)זוויות מתאימות במשולשים חופפים: שתיהן מול הצלע BC
רמה 3 ●●●○○

הוכחה עם צעד ביניים

13. הנקודות \(A, B, C, D\) נמצאות על ישר בסדר הזה, ו־\(AB = CD\). מעל הישר: \(AE = DF\) ו־\(\angle EAD = \angle FDA\). הוכיחו ש־\(EC = FB\).

פתרון
תשובה

\(AC = DB\), ולכן \(\triangle EAC \cong \triangle FDB\) לפי צלע זווית צלע, ו־\(EC = FB\).

איך מתחילים: המשולשים הם \(EAC\) ו־\(FDB\). הצלעות \(AC\) ו־\(DB\) לא נתונות כשוות. צריך להוסיף לשני הקטעים השווים \(AB\) ו־\(CD\) את הקטע המשותף \(BC\).

דרך הפתרון:

#טענהנימוק
1\(AB = CD\)נתון
2\(AC = AB + BC = CD + BC = DB\)הוספת הקטע המשותף \(BC\) (טענה 1)
3\(AE = DF\)נתון
4\(\angle EAC = \angle FDB\)נתון
5\(\triangle EAC \cong \triangle FDB\)צלע זווית צלע (טענות 2–4)
6\(EC = FB\)צלעות מתאימות במשולשים חופפים

14. במשולש \(ABC\) נתון \(AB = AC\). הנקודות \(D\) ו־\(E\) על \(BC\) כך ש־\(BD = CE\). הוכיחו ש־\(AD = AE\).

פתרון
תשובה

\(\triangle ABD \cong \triangle ACE\) לפי צלע זווית צלע, ולכן \(AD = AE\).

איך מתחילים: צעד הביניים: במשולש שווה שוקיים זוויות הבסיס שוות. כך מקבלים את הזווית שבין הצלעות.

דרך הפתרון:

#טענהנימוק
1\(AB = AC\)נתון
2\(\angle B = \angle C\)זוויות בסיס במשולש שווה שוקיים
3\(BD = CE\)נתון
4\(\triangle ABD \cong \triangle ACE\)צלע זווית צלע (טענות 1–3)
5\(AD = AE\)צלעות מתאימות במשולשים חופפים

15. נתון \(AC \parallel BD\). הקטעים \(AB\) ו־\(CD\) נחתכים בנקודה \(M\), ו־\(M\) אמצע \(AB\). הוכיחו ש־\(AC = BD\).

פתרון
תשובה

\(\triangle AMC \cong \triangle BMD\) לפי זווית צלע זווית, ולכן \(AC = BD\).

איך מתחילים: יש שני מקורות לזוויות שוות: זוויות מתחלפות בין המקבילים, וזוויות קודקודיות ב־\(M\).

דרך הפתרון:

#טענהנימוק
1\(\angle CAM = \angle DBM\)זוויות מתחלפות בין המקבילים \(AC \parallel BD\) (החותך \(AB\))
2\(AM = MB\)\(M\) אמצע \(AB\)
3\(\angle AMC = \angle BMD\)זוויות קודקודיות
4\(\triangle AMC \cong \triangle BMD\)זווית צלע זווית (טענות 1–3): הצלע והזוויות שלידה
5\(AC = BD\)צלעות מתאימות במשולשים חופפים

16. נתון \(AB = AD\), \(AC = AE\) ו־\(\angle BAD = \angle CAE\). הוכיחו ש־\(BC = DE\).

פתרון
תשובה

\(\angle BAC = \angle DAE\), ולכן \(\triangle ABC \cong \triangle ADE\) לפי צלע זווית צלע, ו־\(BC = DE\).

איך מתחילים: הזוויות הנתונות \(\angle BAD\) ו־\(\angle CAE\) לא נמצאות בתוך המשולשים. מוסיפים לשתיהן את הזווית המשותפת \(\angle DAC\).

דרך הפתרון:

#טענהנימוק
1\(\angle BAD = \angle CAE\)נתון
2\(\angle BAC = \angle BAD + \angle DAC = \angle CAE + \angle DAC = \angle DAE\)הוספת הזווית המשותפת \(\angle DAC\)
3\(AB = AD,\ AC = AE\)נתון
4\(\triangle ABC \cong \triangle ADE\)צלע זווית צלע (טענות 2–3)
5\(BC = DE\)צלעות מתאימות במשולשים חופפים

17. הנקודה \(P\) נמצאת על חוצה הזווית \(A\). מ־\(P\) מורידים אנכים לשוקי הזווית: \(PB \perp AB\) ו־\(PC \perp AC\). הוכיחו ש־\(PB = PC\).

פתרון
תשובה

\(\triangle ABP \cong \triangle ACP\) לפי זווית צלע זווית (אחרי חישוב הזווית השלישית), ולכן \(PB = PC\).

איך מתחילים: יש שתי זוויות שוות (חוצה הזווית והזוויות הישרות) וצלע משותפת \(AP\). אבל \(AP\) לא נמצאת בין שתי הזוויות הישרות והזוויות ב־\(A\). לכן מחשבים קודם את הזווית השלישית, כמו בשאלה 6.

דרך הפתרון:

#טענהנימוק
1\(\angle BAP = \angle CAP\)\(AP\) חוצה זווית
2\(\angle ABP = \angle ACP = 90^\circ\)אנכים (נתון)
3\(\angle APB = \angle APC\)סכום הזוויות במשולש (טענות 1–2)
4\(AP = AP\)צלע משותפת
5\(\triangle ABP \cong \triangle ACP\)זווית צלע זווית (טענות 1, 3, 4): הצלע \(AP\) והזוויות שלידה
6\(PB = PC\)צלעות מתאימות במשולשים חופפים

18. במשולש שווה שוקיים \(ABC\) (\(AB = AC\)) הנקודה \(M\) אמצע הבסיס \(BC\). מ־\(M\) מורידים אנכים \(MD \perp AB\) ו־\(ME \perp AC\). הוכיחו ש־\(MD = ME\).

פתרון
תשובה

\(\triangle BDM \cong \triangle CEM\), ולכן \(MD = ME\).

איך מתחילים: שני צעדי ביניים: זוויות הבסיס שוות (שווה שוקיים), והזווית השלישית שווה (סכום זוויות). אחר כך זווית צלע זווית על הצלע \(BM = MC\).

דרך הפתרון:

#טענהנימוק
1\(\angle B = \angle C\)זוויות בסיס במשולש שווה שוקיים
2\(\angle BDM = \angle CEM = 90^\circ\)אנכים (נתון)
3\(\angle BMD = \angle CME\)סכום הזוויות במשולש (טענות 1–2)
4\(BM = MC\)\(M\) אמצע \(BC\)
5\(\triangle BDM \cong \triangle CEM\)זווית צלע זווית (טענות 1, 3, 4)
6\(MD = ME\)צלעות מתאימות במשולשים חופפים
רמה 4 ●●●●○

הוכחה בשני שלבים

19. במרובע \(ABCD\) נתון \(AB = AD\) ו־\(CB = CD\) (דלתון). האלכסונים נחתכים בנקודה \(O\). הוכיחו ש־\(BO = OD\) וש־\(AC \perp BD\).

פתרון
תשובה

קודם \(\triangle ABC \cong \triangle ADC\), ומזה \(\triangle ABO \cong \triangle ADO\).

איך מתחילים: במשולשים \(ABO\) ו־\(ADO\) יש רק שתי צלעות שוות (\(AB = AD\) ו־\(AO\) משותפת). חסרה הזווית שביניהן. מקבלים אותה מחפיפה ראשונה של המשולשים הגדולים.

דרך הפתרון:

#טענהנימוק
1\(\triangle ABC \cong \triangle ADC\)צלע צלע צלע: AB = AD, CB = CD, AC משותפת
2\(\angle BAO = \angle DAO\)זוויות מתאימות במשולשים חופפים
3\(\triangle ABO \cong \triangle ADO\)צלע זווית צלע: AB = AD, טענה 2, AO משותפת
4\(BO = OD\)צלעות מתאימות במשולשים חופפים
5\(\angle AOB = \angle AOD\)זוויות מתאימות במשולשים חופפים
6\(\angle AOB = \angle AOD = 90^\circ\)זוויות צמודות ושוות (טענה 5)

20. במשולש שווה צלעות \(ABC\) הנקודות \(D, E, F\) נמצאות על הצלעות \(AB, BC, CA\) כך ש־\(AD = BE = CF\). הוכיחו שגם המשולש \(DEF\) שווה צלעות.

פתרון
תשובה

\(\triangle ADF \cong \triangle BED \cong \triangle CFE\) לפי צלע זווית צלע, ולכן \(DF = ED = FE\).

איך מתחילים: כל צלע של המשולש הפנימי היא צלע במשולש קטן אחד בפינה. מספיק להראות ששלושת המשולשים בפינות חופפים.

דרך הפתרון:

#טענהנימוק
1\(AD = BE = CF\)נתון
2\(AF = AC - CF = BA - AD = BD\)הצלעות שוות, ומחסירים קטעים שווים
3\(BD = CE\)באותו אופן
4\(\angle A = \angle B = \angle C = 60^\circ\)משולש שווה צלעות
5\(\triangle ADF \cong \triangle BED \cong \triangle CFE\)צלע זווית צלע: לכל אחד צלע אחת מהצורה AD, זווית של 60°, וצלע מהצורה AF
6\(DF = ED = FE\)צלעות מתאימות (מול הזוויות של \(60^\circ\)) במשולשים חופפים

21. במרובע \(ABCD\) נתון \(AB = CD\) ו־\(AD = CB\). הוכיחו ש־\(\angle A = \angle C\) וש־\(AB \parallel CD\).

פתרון
תשובה

\(\triangle ABD \cong \triangle CDB\) לפי צלע צלע צלע. מכאן \(\angle A = \angle C\), ומהזוויות המתחלפות \(AB \parallel CD\).

איך מתחילים: האלכסון \(BD\) יוצר שני משולשים עם צלע משותפת. אחרי החפיפה משתמשים בזוויות המתאימות פעמיים: פעם למסקנה הראשונה ופעם למשפט ההפוך על מקבילים.

דרך הפתרון:

#טענהנימוק
1\(AB = CD,\ AD = CB\)נתון
2\(BD = DB\)צלע משותפת
3\(\triangle ABD \cong \triangle CDB\)צלע צלע צלע (טענות 1–2)
4\(\angle A = \angle C\)זוויות מתאימות במשולשים חופפים (מול BD)
5\(\angle ABD = \angle CDB\)זוויות מתאימות במשולשים חופפים
6\(AB \parallel CD\)זוויות מתחלפות שוות (טענה 5), החותך \(BD\): המשפט ההפוך

22. במשולש \(ABC\) נתון \(AB = AC\). \(BD\) ו־\(CE\) תיכונים לשוקיים, והם נחתכים בנקודה \(O\). הוכיחו ש־\(OB = OC\).

פתרון
תשובה

\(\triangle ABD \cong \triangle ACE\), ולכן \(\angle OBC = \angle OCB\) ו־\(OB = OC\).

איך מתחילים: כדי להראות \(OB = OC\) מספיק להראות שבמשולש \(OBC\) יש שתי זוויות שוות. אותן מקבלים מהפרש בין זוויות שוות.

דרך הפתרון:

#טענהנימוק
1\(\triangle ABD \cong \triangle ACE\)צלע זווית צלע: \(AB = AC\), \(\angle A\) משותפת, \(AD = AE\) (מחציות של שוקיים שוות)
2\(\angle ABD = \angle ACE\)זוויות מתאימות במשולשים חופפים
3\(\angle ABC = \angle ACB\)זוויות בסיס במשולש שווה שוקיים
4\(\angle OBC = \angle OCB\)חיסור זוויות שוות (טענה 3 פחות טענה 2)
5\(OB = OC\)מול זוויות שוות במשולש נמצאות צלעות שוות

23. במשולש \(ABC\) נתון \(AB = AC\). הנקודה \(D\) על \(AB\) והנקודה \(E\) על \(AC\), כך ש־\(AD = AE\). הקטעים \(BE\) ו־\(CD\) נחתכים בנקודה \(O\). הוכיחו ש־\(\triangle DOB \cong \triangle EOC\).

פתרון
תשובה

קודם \(\triangle ABE \cong \triangle ACD\), ואז \(\triangle DOB \cong \triangle EOC\) לפי זווית צלע זווית.

איך מתחילים: במשולשים הקטנים \(DOB\) ו־\(EOC\) חסרים נתונים. מוצאים אותם מחפיפה של המשולשים הגדולים \(ABE\) ו־\(ACD\), שחופפים ״חלקית״ זה על זה.

דרך הפתרון:

#טענהנימוק
1\(\triangle ABE \cong \triangle ACD\)צלע זווית צלע: \(AB = AC\), \(\angle A\) משותפת, \(AE = AD\)
2\(\angle ABE = \angle ACD\)זוויות מתאימות במשולשים חופפים
3\(DB = AB - AD = AC - AE = EC\)חיסור קטעים שווים
4\(\angle DOB = \angle EOC\)זוויות קודקודיות
5\(\angle BDO = \angle CEO\)סכום הזוויות במשולש (טענות 2 ו־4)
6\(\triangle DOB \cong \triangle EOC\)זווית צלע זווית (טענות 2, 3, 5): הצלע \(DB\) והזוויות שלידה

אתגר

24. \(ABCD\) ריבוע. הנקודה \(E\) על \(BC\) והנקודה \(F\) על \(CD\) כך ש־\(BE = CF\). הקטעים \(AE\) ו־\(BF\) נחתכים בנקודה \(G\). הוכיחו ש־\(AE = BF\) וש־\(AE \perp BF\).

פתרון
תשובה

\(\triangle ABE \cong \triangle BCF\) לפי צלע זווית צלע. מכאן \(AE = BF\), ומהזוויות \(\angle AGB = 90^\circ\).

איך מתחילים: לשני הקטעים יש משולשים ישרי זווית ״מסובבים״ זה ביחס לזה. אחרי החפיפה, את האנך מוכיחים בעזרת סכום זוויות במשולש \(ABG\).

דרך הפתרון:

#טענהנימוק
1\(AB = BC\)צלעות הריבוע
2\(\angle ABE = \angle BCF = 90^\circ\)זוויות הריבוע
3\(BE = CF\)נתון
4\(\triangle ABE \cong \triangle BCF\)צלע זווית צלע (טענות 1–3)
5\(AE = BF\)צלעות מתאימות במשולשים חופפים
6\(\angle BAE = \angle CBF\)זוויות מתאימות במשולשים חופפים
7\(\angle BAG + \angle ABG = \angle CBF + \angle ABG = \angle ABC = 90^\circ\)טענה 6, ו־∠ABG + ∠CBF היא זווית הריבוע
8\(\angle AGB = 180^\circ - 90^\circ = 90^\circ\)סכום הזוויות במשולש \(ABG\), ולכן \(AE \perp BF\)

25. \(ABC\) משולש כלשהו. על הצלעות \(AB\) ו־\(AC\) בונים כלפי חוץ משולשים שווי צלעות \(ABD\) ו־\(ACE\). הוכיחו ש־\(DC = BE\).

פתרון
תשובה

\(\triangle DAC \cong \triangle BAE\) לפי צלע זווית צלע, ולכן \(DC = BE\).

איך מתחילים: הקטעים \(DC\) ו־\(BE\) נמצאים במשולשים \(DAC\) ו־\(BAE\). שתי הצלעות שוות כי המשולשים שווי צלעות. את הזווית שבין הצלעות מקבלים כמו בשאלה 16: מוסיפים זווית משותפת לזוויות של \(60^\circ\).

דרך הפתרון:

#טענהנימוק
1\(AD = AB\)צלעות המשולש שווה הצלעות \(ABD\)
2\(AC = AE\)צלעות המשולש שווה הצלעות \(ACE\)
3\(\angle DAC = 60^\circ + \angle BAC = \angle BAE\)\(\angle DAB = \angle CAE = 60^\circ\), ומוסיפים לשתיהן את \(\angle BAC\)
4\(\triangle DAC \cong \triangle BAE\)צלע זווית צלע (טענות 1–3)
5\(DC = BE\)צלעות מתאימות במשולשים חופפים

26. במשולש \(ABC\) הקטע \(AD\) הוא תיכון. ממשיכים את \(AD\) מעבר ל־\(D\) עד נקודה \(E\) כך ש־\(DE = AD\). הוכיחו ש־\(ABEC\) מקבילית.

פתרון
תשובה

\(\triangle ABD \cong \triangle ECD\), ולכן \(AB = EC\) ו־\(AB \parallel EC\). מרובע עם זוג צלעות נגדיות שוות ומקבילות הוא מקבילית.

איך מתחילים: כדי להוכיח מקבילית בוחרים משפט זיהוי. כאן הכי נוח: זוג צלעות נגדיות שוות ומקבילות. את שתי התכונות של \(AB\) ו־\(EC\) מקבלים מחפיפה אחת. (דרך קצרה יותר: האלכסונים \(AE\) ו־\(BC\) חוצים זה את זה.)

דרך הפתרון:

#טענהנימוק
1\(BD = DC\)\(AD\) תיכון
2\(\angle ADB = \angle EDC\)זוויות קודקודיות
3\(AD = DE\)נתון
4\(\triangle ABD \cong \triangle ECD\)צלע זווית צלע (טענות 1–3)
5\(AB = EC\)צלעות מתאימות במשולשים חופפים
6\(\angle BAD = \angle CED\)זוויות מתאימות במשולשים חופפים
7\(AB \parallel EC\)זוויות מתחלפות שוות, החותך \(AE\)
8\(ABEC\) מקביליתזוג צלעות נגדיות שוות ומקבילות (משפט זיהוי)
