הסבר ונוסחאות

מה זה טור הנדסי אינסופי? זה הסכום של כל איברי סדרה הנדסית: a₁ + a₁q + a₁q² + … בלי סוף. אי אפשר "לחבר אינסוף מספרים" בפועל, ולכן מגדירים את הסכום כגבול הסכומים החלקיים: מסתכלים על S₁, S₂, S₃, … ובודקים אם הם מתקרבים למספר מסוים.

המשמעות האינטואיטיבית: הולכים חצי מהדרך אל קיר, אחר כך חצי מהדרך שנותרה, וכן הלאה. בשום שלב לא מגיעים לקיר, אבל סך כל הצעדים הוא בדיוק המרחק: ½ + ¼ + ⅛ + … = 1. כאשר האיברים קטנים מספיק מהר, הסכום האינסופי הוא מספר סופי.

מתי זה עובד? רק כאשר |q| < 1, כלומר −1 < q < 1 (ו־q ≠ 0). אז qⁿ שואף ל־0, ומנוסחת הסכום הרגילה Sₙ = a₁(1 − qⁿ)/(1 − q) מקבלים S = a₁/(1 − q). אם |q| ≥ 1 האיברים לא קטנים, והסכום לא מתכנס.

תנאי התכנסות−1 < q < 1, q ≠ 0
סכום הטורS = a₁/(1 − q)
טור האיברים במקומות האי־זוגייםa₁/(1 − q²)
טור הריבועיםa₁²/(1 − q²)

שברים עשרוניים מחזוריים: כל שבר מחזורי הוא טור הנדסי אינסופי. למשל 0.454545… = 0.45 + 0.0045 + … עם q = 0.01. כך מוכיחים ש־0.999… = 1 בדיוק.

טורים נגזרים: אם לוקחים את הריבועים של איברי טור מתכנס, מתקבל טור עם איבר ראשון a₁² ומנה q². גם הוא מתכנס, כי q² < 1. באותו אופן, האיברים במקומות האי־זוגיים יוצרים טור עם מנה q².

טור עם משתנה: כשהמנה תלויה ב־x, שאלה כמו "לאילו ערכי x הטור מתכנס" היא אי־שוויון |q(x)| < 1. לפני שמשתמשים בנוסחה, חובה לבדוק את התנאי ולפסול פתרונות שאינם מקיימים אותו.

יישומים גאומטריים: צורות שהולכות וקטנות באותו יחס (ריבועים חסומים, משולשי אמצעים, כדור קופץ) נותנות טורים הנדסיים של שטחים, היקפים או מרחקים.

טעויות נפוצות: להשתמש בנוסחה כש־|q| ≥ 1; לשכוח לבדוק את תנאי ההתכנסות אחרי שפותרים משוואה ב־q או ב־x; בכדור קופץ לשכוח שכל גובה (חוץ מהראשון) נעשה פעמיים, למעלה ולמטה.

רמה א׳: בסיס שאלות 1–10

בדיקת התכנסות וחישוב סכום.

  1. חשבו: 1 + ½ + ¼ + ⅛ + …
    הצג פתרון

    q = ½: S = 1/(1 − ½) = 2

  2. חשבו: 9 + 3 + 1 + ⅓ + …
    הצג פתרון

    q = ⅓: S = 9/(2/3) = 13.5

  3. חשבו: 20 − 10 + 5 − 2.5 + …
    הצג פתרון

    q = −½: S = 20/(1.5) = 40/3

  4. האם הטור 2 + 3 + 4.5 + … מתכנס?
    הצג פתרון

    q = 1.5 > 1, האיברים גדלים. הטור אינו מתכנס.

  5. חשבו את סכום הטור עם a₁ = 6, q = −⅓.
    הצג פתרון

    S = 6/(1 + ⅓) = 6/(4/3) = 4.5

  6. סכום טור הנדסי אינסופי הוא 10, ו־q = 0.4. מצאו את a₁.
    הצג פתרון

    a₁ = S(1 − q) = 10·0.6 = 6

  7. סכום טור הנדסי אינסופי הוא 15, ו־a₁ = 5. מצאו את q.
    הצג פתרון

    5/(1 − q) = 15 ⇒ 1 − q = ⅓ ⇒ q = ⅔

  8. כתבו את 0.333… כשבר פשוט בעזרת טור.
    הצג פתרון

    0.3 + 0.03 + …: S = 0.3/0.9 = 1/3

  9. כתבו את 0.272727… כשבר פשוט.
    הצג פתרון

    a₁ = 0.27, q = 0.01: S = 0.27/0.99 = 27/99 = 3/11

  10. כתבו את 1.2333… כשבר פשוט.
    הצג פתרון

    1.2 + (0.03 + 0.003 + …) = 1.2 + 0.03/0.9 = 1.2 + 1/30 = 37/30

רמה ב׳: ביסוס שאלות 11–22

טורים עם פרמטר, טורים נגזרים ויישומים גאומטריים.

  1. כתבו את 2.454545… כשבר פשוט.
    הצג פתרון

    2 + 0.45/0.99 = 2 + 5/11 = 27/11

  2. לאילו ערכי x מתכנס הטור 1 + x/3 + (x/3)² + …? מהו סכומו?
    הצג פתרון

    |x/3| < 1 ⇒ −3 < x < 3

    S = 1/(1 − x/3) = 3/(3 − x)

  3. לאילו ערכי x מתכנס הטור 1 + 2x + 4x² + …? מצאו את x שעבורו סכום הטור הוא 4.
    הצג פתרון

    |2x| < 1 ⇒ −½ < x < ½

    1/(1 − 2x) = 4 ⇒ x = 3/8 (בתחום ✓)

  4. בטור הנדסי אינסופי a₂ = 2 וסכום הטור 9. מצאו את a₁ ואת q.
    הצג פתרון

    a₁ = 2/q, ולכן 2/(q(1 − q)) = 9 ⇒ 9q² − 9q + 2 = 0

    q = ⅓, a₁ = 6 או q = ⅔, a₁ = 3

  5. סכום טור הנדסי אינסופי גדול פי 3 מהאיבר הראשון. מצאו את q.
    הצג פתרון

    a₁/(1 − q) = 3a₁ ⇒ q = ⅔

  6. בטור עם a₁ = 4, q = ½ חשבו את סכום האיברים במקומות האי־זוגיים ואת סכום האיברים במקומות הזוגיים.
    הצג פתרון

    אי־זוגיים: 4 + 1 + ¼ + … = 4/(1 − ¼) = 16/3

    זוגיים: 2 + ½ + … = 2/(¾) = 8/3

    בדיקה: 16/3 + 8/3 = 8 = 4/(1 − ½) ✓

  7. בטור הנדסי אינסופי מתכנס, כל איבר גדול פי 3 מסכום כל האיברים שאחריו. מצאו את q.
    הצג פתרון

    סכום האיברים שאחרי aₙ הוא aₙq/(1 − q).

    aₙ = 3aₙq/(1 − q) ⇒ 1 − q = 3q ⇒ q = ¼

  8. בטור עם a₁ = 8, q = ½ חשבו את סכום ריבועי האיברים.
    הצג פתרון

    64/(1 − ¼) = 256/3

  9. כדור נופל מגובה 8 מ׳, ואחרי כל פגיעה הוא קופץ ל־¾ מהגובה הקודם. מהו המרחק הכולל שהכדור עובר עד שהוא נעצר?
    הצג פתרון

    ירידה ראשונה: 8 מ׳. כל קפיצה נעשית פעמיים (עלייה וירידה):

    8 + 2(6 + 4.5 + …) = 8 + 2·6/(1 − ¾) = 8 + 48 = 56 מ׳

  10. בריבוע שצלעו 4 ס״מ חוסמים ריבוע שקודקודיו באמצעי הצלעות, וכך הלאה בלי סוף. חשבו את סכום השטחים של כל הריבועים.
    הצג פתרון

    כל ריבוע חסום שטחו חצי מהקודם.

    16 + 8 + 4 + … = 16/(1 − ½) = 32 סמ״ר

  11. במשולש שווה צלעות שצלעו 6 מחברים את אמצעי הצלעות, ובמשולש האמצעים חוזרים על הפעולה בלי סוף. חשבו את סכום שטחי כל המשולשים (כולל הראשון).
    הצג פתרון

    שטח הראשון: (√3/4)·36 = 9√3. כל משולש אמצעים שטחו רבע מהקודם.

    S = 9√3/(1 − ¼) = 12√3

  12. סכום טור הנדסי אינסופי הוא 12, וסכום ריבועי איבריו 48. מצאו את a₁ ואת q.
    הצג פתרון

    a₁/(1−q) = 12, a₁²/(1−q²) = 48

    מעלים את הראשונה בריבוע ומחלקים: (1−q)/(1+q) = ⅓ ⇒ q = ½

    a₁ = 6

רמה ג׳: רמת בגרות שאלות 23–30

משוואות עם טורים, תנאי התכנסות ושילובים.

  1. סכום טור הנדסי אינסופי הוא 6, וסכום הטור של חזקות שלישיות של איבריו הוא 216/7. מצאו את a₁ ואת q.
    הצג פתרון

    a₁ = 6(1 − q), וטור החזקות השלישיות: a₁³/(1 − q³) = 216/7

    216(1−q)³/(1−q³) = 216/7 ⇒ 7(1−q)² = 1 + q + q²

    6q² − 15q + 6 = 0 ⇒ q = ½ (q = 2 נפסל)

    a₁ = 3

  2. עבור 0° < x < 90°, הטור 1 + cos x + cos²x + … מתכנס. מצאו את x שעבורו סכום הטור הוא 2.
    הצג פתרון

    0 < cos x < 1, לכן הטור מתכנס.

    1/(1 − cos x) = 2 ⇒ cos x = ½ ⇒ x = 60°

  3. סכום טור הנדסי אינסופי הוא 8, וסכום שני האיברים הראשונים הוא 6. מצאו את כל האפשרויות ל־a₁ ול־q.
    הצג פתרון

    a₁ = 8(1 − q), a₁(1 + q) = 6 ⇒ 8(1 − q²) = 6 ⇒ q² = ¼

    q = ½, a₁ = 4 או q = −½, a₁ = 12

  4. בטור הנדסי אינסופי יורד a₁ + a₃ = 10 ו־a₂ + a₄ = 5. חשבו את סכום הטור.
    הצג פתרון

    q = 5/10 = ½

    a₁(1 + ¼) = 10 ⇒ a₁ = 8

    S = 8/(½) = 16

  5. פתרו את המשוואה x + x² + x³ + … = 3.
    הצג פתרון

    נדרש |x| < 1. x/(1 − x) = 3 ⇒ x = ¾ (בתחום ✓)

  6. פתרו: 1 + (2x−1) + (2x−1)² + … = 2x + 1.
    הצג פתרון

    תנאי: |2x − 1| < 1 ⇒ 0 < x < 1

    1/(2 − 2x) = 2x + 1 ⇒ 4x² − 2x − 1 = 0 ⇒ x = (1 ± √5)/4

    רק x = (1 + √5)/4 ≈ 0.81 בתחום.

  7. סכום טור הנדסי אינסופי הוא 20, וסכום האיברים במקומות האי־זוגיים הוא 15. מצאו את a₁ ואת q.
    הצג פתרון

    a₁/(1 − q) = 20, a₁/(1 − q²) = 15

    מחלקים: 1/(1 + q) = ¾ ⇒ q = ⅓

    a₁ = 20·⅔ = 40/3

  8. הוכיחו בעזרת טור הנדסי ש־0.999… = 1, והסבירו מדוע אין כאן סתירה.
    הצג פתרון

    0.9 + 0.09 + … = 0.9/(1 − 0.1) = 1

    אין סתירה: 0.999… אינו "מספר שקטן במעט מ־1", אלא הגבול של 0.9, 0.99, 0.999, …, והגבול הזה הוא בדיוק 1.

הפתרונות מוסתרים כדי לאפשר תרגול עצמי. לחצו על "הצג פתרון" כדי לבדוק.
