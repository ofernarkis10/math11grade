הסבר ונוסחאות

מה זה טור הנדסי אינסופי? זה הסכום של כל איברי סדרה הנדסית: \(a_{1} + a_{1}q + a_{1}q^{2} + \ldots\) בלי סוף. אי אפשר "לחבר אינסוף מספרים" בפועל, ולכן מגדירים את הסכום כגבול הסכומים החלקיים: מסתכלים על \(S_{1}, S_{2}, S_{3}, \ldots\) ובודקים אם הם מתקרבים למספר מסוים.

המשמעות האינטואיטיבית: הולכים חצי מהדרך אל קיר, אחר כך חצי מהדרך שנותרה, וכן הלאה. בשום שלב לא מגיעים לקיר, אבל סך כל הצעדים הוא בדיוק המרחק: \({\dfrac{1}{2}} + {\dfrac{1}{4}} + {\dfrac{1}{8}} + \ldots = 1\). כאשר האיברים קטנים מספיק מהר, הסכום האינסופי הוא מספר סופי.

מתי זה עובד? רק כאשר \(|q| \lt 1\), כלומר \(- 1 \lt q \lt 1\) (ו־\(q \neq 0\)). אז \(q^{n}\) שואף ל־0, ומנוסחת הסכום הרגילה \(S_{n} = \dfrac{a_{1}(1 - q^{n})}{1 - q}\) מקבלים \(S = \dfrac{a_{1}}{1 - q}\). אם \(|q| \ge 1\) האיברים לא קטנים, והסכום לא מתכנס.

תנאי התכנסות\(- 1 \lt q \lt 1, q \neq 0\)
סכום הטור\(S = \dfrac{a_{1}}{1 - q}\)
טור האיברים במקומות האי־זוגיים\(\dfrac{a_{1}}{1 - q^{2}}\)
טור הריבועים\(\dfrac{a_{1}^{2}}{1 - q^{2}}\)

שברים עשרוניים מחזוריים: כל שבר מחזורי הוא טור הנדסי אינסופי. למשל \(0.454545 \ldots = 0.45 + 0.0045 + \ldots\) עם \(q = 0.01\). כך מוכיחים ש־\(0.999 \ldots = 1\) בדיוק.

טורים נגזרים: אם לוקחים את הריבועים של איברי טור מתכנס, מתקבל טור עם איבר ראשון \(a_{1}^{2}\) ומנה \(q^{2}\). גם הוא מתכנס, כי \(q^{2} \lt 1\). באותו אופן, האיברים במקומות האי־זוגיים יוצרים טור עם מנה \(q^{2}\).

טור עם משתנה: כשהמנה תלויה ב־x, שאלה כמו "לאילו ערכי x הטור מתכנס" היא אי־שוויון \(|q(x)| \lt 1\). לפני שמשתמשים בנוסחה, חובה לבדוק את התנאי ולפסול פתרונות שאינם מקיימים אותו.

יישומים גאומטריים: צורות שהולכות וקטנות באותו יחס (ריבועים חסומים, משולשי אמצעים, כדור קופץ) נותנות טורים הנדסיים של שטחים, היקפים או מרחקים.

טעויות נפוצות: להשתמש בנוסחה כש־\(|q| \ge 1\); לשכוח לבדוק את תנאי ההתכנסות אחרי שפותרים משוואה ב־q או ב־x; בכדור קופץ לשכוח שכל גובה (חוץ מהראשון) נעשה פעמיים, למעלה ולמטה.

רמה א׳: בסיס שאלות 1–10

בדיקת התכנסות וחישוב סכום.

  1. חשבו: \(1 + {\dfrac{1}{2}} + {\dfrac{1}{4}} + {\dfrac{1}{8}} + \ldots\)
    הצג פתרון

    \(q = {\dfrac{1}{2}}\): \(S = \dfrac{1}{1 - {\frac{1}{2}}} = 2\)

  2. חשבו: \(9 + 3 + 1 + {\dfrac{1}{3}} + \ldots\)
    הצג פתרון

    \(q = {\dfrac{1}{3}}\): \(S = \dfrac{9}{\frac{2}{3}} = 13.5\)

  3. חשבו: \(20 - 10 + 5 - 2.5 + \ldots\)
    הצג פתרון

    \(q = - {\dfrac{1}{2}}\): \(S = \dfrac{20}{1.5} = \dfrac{40}{3}\)

  4. האם הטור \(2 + 3 + 4.5 + \ldots\) מתכנס?
    הצג פתרון

    \(q = 1.5 \gt 1\), האיברים גדלים. הטור אינו מתכנס.

  5. חשבו את סכום הטור עם \(a_{1} = 6\), \(q = - {\dfrac{1}{3}}\).
    הצג פתרון

    \(S = \dfrac{6}{1 + {\frac{1}{3}}} = \dfrac{6}{\frac{4}{3}} = 4.5\)

  6. סכום טור הנדסי אינסופי הוא 10, ו־\(q = 0.4\). מצאו את \(a_{1}\).
    הצג פתרון

    \(a_{1} = S(1 - q) = 10 \cdot 0.6 = 6\)

  7. סכום טור הנדסי אינסופי הוא 15, ו־\(a_{1} = 5\). מצאו את \(q\).
    הצג פתרון

    \(\dfrac{5}{1 - q} = 15 \Rightarrow 1 - q = {\dfrac{1}{3}} \Rightarrow q = {\dfrac{2}{3}}\)

  8. כתבו את \(0.333 \ldots\) כשבר פשוט בעזרת טור.
    הצג פתרון

    \(0.3 + 0.03 + \ldots\): \(S = \dfrac{0.3}{0.9} = \dfrac{1}{3}\)

  9. כתבו את \(0.272727 \ldots\) כשבר פשוט.
    הצג פתרון

    \(a_{1} = 0.27\), \(q = 0.01\): \(S = \dfrac{0.27}{0.99} = \dfrac{27}{99} = \dfrac{3}{11}\)

  10. כתבו את \(1.2333 \ldots\) כשבר פשוט.
    הצג פתרון

    \(1.2 + (0.03 + 0.003 + \ldots ) = 1.2 + \dfrac{0.03}{0.9} = 1.2 + \dfrac{1}{30} = \dfrac{37}{30}\)

רמה ב׳: ביסוס שאלות 11–22

טורים עם פרמטר, טורים נגזרים ויישומים גאומטריים.

  1. כתבו את \(2.454545 \ldots\) כשבר פשוט.
    הצג פתרון

    \(2 + \dfrac{0.45}{0.99} = 2 + \dfrac{5}{11} = \dfrac{27}{11}\)

  2. לאילו ערכי x מתכנס הטור \(1 + \dfrac{x}{3} + \left(\dfrac{x}{3}\right)^{2} + \ldots\)? מהו סכומו?
    הצג פתרון

    \(\left|\dfrac{x}{3}\right| \lt 1 \Rightarrow - 3 \lt x \lt 3\)

    \(S = \dfrac{1}{1 - \frac{x}{3}} = \dfrac{3}{3 - x}\)

  3. לאילו ערכי x מתכנס הטור \(1 + 2x + 4x^{2} + \ldots\)? מצאו את x שעבורו סכום הטור הוא 4.
    הצג פתרון

    \(|2x| \lt 1 \Rightarrow - {\dfrac{1}{2}} \lt x \lt {\dfrac{1}{2}}\)

    \(\dfrac{1}{1 - 2x} = 4 \Rightarrow x = \dfrac{3}{8}\) (בתחום ✓)

  4. בטור הנדסי אינסופי \(a_{2} = 2\) וסכום הטור 9. מצאו את \(a_{1}\) ואת \(q\).
    הצג פתרון

    \(a_{1} = \dfrac{2}{q}\), ולכן \(\dfrac{2}{q(1 - q)} = 9 \Rightarrow 9q^{2} - 9q + 2 = 0\)

    \(q = {\dfrac{1}{3}}\), \(a_{1} = 6\) או \(q = {\dfrac{2}{3}}\), \(a_{1} = 3\)

  5. סכום טור הנדסי אינסופי גדול פי 3 מהאיבר הראשון. מצאו את \(q\).
    הצג פתרון

    \(\dfrac{a_{1}}{1 - q} = 3a_{1} \Rightarrow q = {\dfrac{2}{3}}\)

  6. בטור עם \(a_{1} = 4\), \(q = {\dfrac{1}{2}}\) חשבו את סכום האיברים במקומות האי־זוגיים ואת סכום האיברים במקומות הזוגיים.
    הצג פתרון

    אי־זוגיים: \(4 + 1 + {\dfrac{1}{4}} + \ldots = \dfrac{4}{1 - {\frac{1}{4}}} = \dfrac{16}{3}\)

    זוגיים: \(2 + {\dfrac{1}{2}} + \ldots = \dfrac{2}{{\frac{3}{4}}} = \dfrac{8}{3}\)

    בדיקה: \(\dfrac{16}{3} + \dfrac{8}{3} = 8 = \dfrac{4}{1 - {\frac{1}{2}}}\) ✓

  7. בטור הנדסי אינסופי מתכנס, כל איבר גדול פי 3 מסכום כל האיברים שאחריו. מצאו את \(q\).
    הצג פתרון

    סכום האיברים שאחרי \(a_{n}\) הוא \(\dfrac{a_{n}q}{1 - q}\).

    \(a_{n} = \dfrac{3a_{n}q}{1 - q} \Rightarrow 1 - q = 3q \Rightarrow q = {\dfrac{1}{4}}\)

  8. בטור עם \(a_{1} = 8\), \(q = {\dfrac{1}{2}}\) חשבו את סכום ריבועי האיברים.
    הצג פתרון

    \(\dfrac{64}{1 - {\frac{1}{4}}} = \dfrac{256}{3}\)

  9. כדור נופל מגובה 8 מ׳, ואחרי כל פגיעה הוא קופץ ל־¾ מהגובה הקודם. מהו המרחק הכולל שהכדור עובר עד שהוא נעצר?
    הצג פתרון

    ירידה ראשונה: 8 מ׳. כל קפיצה נעשית פעמיים (עלייה וירידה):

    \(8 + 2(6 + 4.5 + \ldots ) = 8 + \dfrac{2 \cdot 6}{1 - {\frac{3}{4}}} = 8 + 48 = 56\) מ׳

  10. בריבוע שצלעו 4 ס״מ חוסמים ריבוע שקודקודיו באמצעי הצלעות, וכך הלאה בלי סוף. חשבו את סכום השטחים של כל הריבועים.
    הצג פתרון

    כל ריבוע חסום שטחו חצי מהקודם.

    \(16 + 8 + 4 + \ldots = \dfrac{16}{1 - {\frac{1}{2}}} = 32\) סמ״ר

  11. במשולש שווה צלעות שצלעו 6 מחברים את אמצעי הצלעות, ובמשולש האמצעים חוזרים על הפעולה בלי סוף. חשבו את סכום שטחי כל המשולשים (כולל הראשון).
    הצג פתרון

    שטח הראשון: \(\left(\dfrac{\sqrt{3}}{4}\right) \cdot 36 = 9\sqrt{3}\). כל משולש אמצעים שטחו רבע מהקודם.

    \(S = \dfrac{9\sqrt{3}}{1 - {\frac{1}{4}}} = 12\sqrt{3}\)

  12. סכום טור הנדסי אינסופי הוא 12, וסכום ריבועי איבריו 48. מצאו את \(a_{1}\) ואת \(q\).
    הצג פתרון

    \(\dfrac{a_{1}}{1 - q} = 12\), \(\dfrac{a_{1}^{2}}{1 - q^{2}} = 48\)

    מעלים את הראשונה בריבוע ומחלקים: \(\dfrac{1 - q}{1+q} = {\dfrac{1}{3}} \Rightarrow q = {\dfrac{1}{2}}\)

    \(a_{1} = 6\)

רמה ג׳: רמת בגרות שאלות 23–30

משוואות עם טורים, תנאי התכנסות ושילובים.

  1. סכום טור הנדסי אינסופי הוא 6, וסכום הטור של חזקות שלישיות של איבריו הוא \(\dfrac{216}{7}\). מצאו את \(a_{1}\) ואת \(q\).
    הצג פתרון

    \(a_{1} = 6(1 - q)\), וטור החזקות השלישיות: \(\dfrac{a_{1}^{3}}{1 - q^{3}} = \dfrac{216}{7}\)

    \(\dfrac{216(1 - q)^{3}}{1 - q^{3}} = \dfrac{216}{7} \Rightarrow 7(1 - q)^{2} = 1 + q + q^{2}\)

    \(6q^{2} - 15q + 6 = 0 \Rightarrow q = {\dfrac{1}{2}}\) (\(q = 2\) נפסל)

    \(a_{1} = 3\)

  2. עבור \(0^{\circ} \lt x \lt 90^{\circ}\), הטור \(1 + {\cos x} + {\cos^{2} x} + \ldots\) מתכנס. מצאו את x שעבורו סכום הטור הוא 2.
    הצג פתרון

    \(0 \lt {\cos x} \lt 1\), לכן הטור מתכנס.

    \(\dfrac{1}{1 - {\cos x}} = 2 \Rightarrow {\cos x} = {\dfrac{1}{2}} \Rightarrow x = 60^{\circ}\)

  3. סכום טור הנדסי אינסופי הוא 8, וסכום שני האיברים הראשונים הוא 6. מצאו את כל האפשרויות ל־\(a_{1}\) ול־\(q\).
    הצג פתרון

    \(a_{1} = 8(1 - q)\), \(a_{1}(1 + q) = 6 \Rightarrow 8(1 - q^{2}) = 6 \Rightarrow q^{2} = {\dfrac{1}{4}}\)

    \(q = {\dfrac{1}{2}}\), \(a_{1} = 4\) או \(q = - {\dfrac{1}{2}}\), \(a_{1} = 12\)

  4. בטור הנדסי אינסופי יורד \(a_{1} + a_{3} = 10\) ו־\(a_{2} + a_{4} = 5\). חשבו את סכום הטור.
    הצג פתרון

    \(q = \dfrac{5}{10} = {\dfrac{1}{2}}\)

    \(a_{1}\left(1 + {\dfrac{1}{4}}\right) = 10 \Rightarrow a_{1} = 8\)

    \(S = \dfrac{8}{{\frac{1}{2}}} = 16\)

  5. פתרו את המשוואה \(x + x^{2} + x^{3} + \ldots = 3\).
    הצג פתרון

    נדרש \(|x| \lt 1\). \(\dfrac{x}{1 - x} = 3 \Rightarrow x = {\dfrac{3}{4}}\) (בתחום ✓)

  6. פתרו: \(1 + (2x - 1) + (2x - 1)^{2} + \ldots = 2x + 1\).
    הצג פתרון

    תנאי: \(|2x - 1| \lt 1 \Rightarrow 0 \lt x \lt 1\)

    \(\dfrac{1}{2 - 2x} = 2x + 1 \Rightarrow 4x^{2} - 2x - 1 = 0 \Rightarrow x = \dfrac{1 \pm \sqrt{5}}{4}\)

    רק \(x = \dfrac{1 + \sqrt{5}}{4} \approx 0.81\) בתחום.

  7. סכום טור הנדסי אינסופי הוא 20, וסכום האיברים במקומות האי־זוגיים הוא 15. מצאו את \(a_{1}\) ואת \(q\).
    הצג פתרון

    \(\dfrac{a_{1}}{1 - q} = 20\), \(\dfrac{a_{1}}{1 - q^{2}} = 15\)

    מחלקים: \(\dfrac{1}{1 + q} = {\dfrac{3}{4}} \Rightarrow q = {\dfrac{1}{3}}\)

    \(a_{1} = 20 \cdot {\dfrac{2}{3}} = \dfrac{40}{3}\)

  8. הוכיחו בעזרת טור הנדסי ש־\(0.999 \ldots = 1\), והסבירו מדוע אין כאן סתירה.
    הצג פתרון

    \(0.9 + 0.09 + \ldots = \dfrac{0.9}{1 - 0.1} = 1\)

    אין סתירה: \(0.999 \ldots\) אינו "מספר שקטן במעט מ־1", אלא הגבול של \(0.9, 0.99, 0.999, \ldots\), והגבול הזה הוא בדיוק 1.

הפתרונות מוסתרים כדי לאפשר תרגול עצמי. לחצו על "הצג פתרון" כדי לבדוק.
