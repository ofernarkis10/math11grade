שיעור שלישי - נוסחת הסכום

בדף הדוגמאות של שיעור שלישי חישבנו כמה יש בסך הכול – מזון לדולפינים, חיסכון עם הפקדה שנתית ותרופה שלוקחים כל יום. חישבנו שלב אחרי שלב. עכשיו נראה מה משותף לדוגמאות, נכיר נוסחה שנותנת את הסך הכול בבת אחת, ונשתמש בה.

1. מה משותף לכל הדוגמאות?

בכל הדוגמאות הסך הכול הוא סכום של מחוברים, שכל אחד מהם גדול פי b מהקודם: S = a + a · b + a · b2 + … + a · bn − 1 אלה בדיוק הערכים של הפונקציה f(t) = a · bt בזמנים t = 0, 1, 2, …, n − 1. יש n מחוברים, והמעריך האחרון הוא n − 1 (בדוגמאות: 8 מחוברים, המעריך האחרון 7).

2. נוסחת הסכום

כדי לא לחבר את כל המחוברים אחד אחד, משתמשים בנוסחה שנותנת את הסכום בבת אחת:

Sn = a · (bn − 1) / (b − 1)
  • a – המחובר הראשון (המזון של השנה הראשונה, ההפקדה החדשה, המנה של היום).
  • b – המספר שמכפילים בו בכל שלב (b ≠ 1).
  • n – מספר המחוברים (מספר השנים, ההפקדות או המנות).
כאשר 0 < b < 1 (דעיכה) נוח לכתוב את אותה נוסחה כך, כדי לא לעבוד עם מספרים שליליים: Sn = a · (1 − bn) / (1 − b)

3. בודקים את הנוסחה על דוגמת הדולפינים

בדף הדוגמאות חיברנו את המזון שנה אחרי שנה וקיבלנו 12,610 טון אחרי 8 שנים. נבדוק שהנוסחה נותנת אותו דבר.

מזהים את a, b ו-n (בניית נוסחה)
a = 256 b = 1.5 n = 8
מציבים בנוסחה ומחשבים במחשבון (בדיקה)

4. משתמשים בנוסחה

דוגמה א – כל לוח השחמט

לפי האגדה, ממציא השחמט ביקש מהמלך פרס: גרגיר אורז אחד במשבצת הראשונה, 2 בשנייה, 4 בשלישית – ובכל משבצת פי 2 מהקודמת. כמה גרגירי אורז יש בכל 64 המשבצות?

מזהים את a, b ו-n (בניית נוסחה)
a = 1 b = 2 n = 64
מציבים בנוסחת הסכום (חישוב סכום)
Sn = a · (bn − 1) / (b − 1) S64 = 1 · (264 − 1) / (2 − 1) S64 = 264 − 1 S64 ≈ 1.8447 · 1019

בערך 18 מיליארד מיליארד גרגירים. אם גרגיר אורז שוקל כ-0.025 גרם, זה יותר מ-460 מיליארד טון אורז.

דוגמה ב – שמועה

ביום הראשון 2 אנשים שמעו שמועה. בכל יום מספר האנשים החדשים ששומעים אותה גדל פי 3. כמה אנשים שמעו את השמועה בסך הכול ב-6 הימים הראשונים?

מזהים את a, b ו-n (בניית נוסחה)
a = 2 b = 3 n = 6
מציבים בנוסחת הסכום (חישוב סכום)
Sn = a · (bn − 1) / (b − 1) S6 = 2 · (36 − 1) / (3 − 1) S6 = 2 · 728 / 2 S6 = 728

בדיקה: 2 + 6 + 18 + 54 + 162 + 486 = 728 ✓

דוגמה ג – תרופה לאורך זמן רב

בדוגמת התרופה (100 מ"ג כל בוקר, נשארת חצי) ראינו שהכמות מתקרבת ל-200. למה?

מציבים בצורה הנוחה לדעיכה (חישוב סכום)
Sn = a · (1 − bn) / (1 − b) Sn = 100 · (1 − 0.5n) / (1 − 0.5) Sn = 200 · (1 − 0.5n)
בודקים מה קורה כש-n גדל

ככל ש-n גדל, 0.5n קטן ומתקרב ל-0. לכן 1 − 0.5n מתקרב ל-1, והכמות מתקרבת ל-200 – אבל אף פעם לא מגיעה אליו בדיוק.

S8 = 200 · (1 − 0.58) = 200 · 0.99609375 = 199.21875 S20 = 200 · (1 − 0.520) ≈ 199.9998

הסכום של אינסוף מחוברים כאלה נלמד בדף טור הנדסי אינסופי מתכנס.

5. בשפת הסדרות

כשרושמים את הערכים של f(t) = a · bt אחד אחרי השני – a, a · b, a · b2, … – מקבלים סדרה שבה כל איבר גדול פי מספר קבוע מהאיבר הקודם. סדרה כזו נקראת סדרה הנדסית.

בשיעורים שלנובשפת הסדרות
הערך הראשוןa = f(0)a1
המספר שמכפילים בוbq (המנה)
הערך במקום nf(n − 1) = a · bn − 1an = a1 · qn − 1
סכום של n ערכיםSn = a · (bn − 1) / (b − 1)Sn = a1 · (qn − 1) / (q − 1)

שימו לב: אצלנו הזמן מתחיל ב-t = 0, ובסדרה המספור מתחיל ב-n = 1. לכן האיבר ה-n הוא f(n − 1), והמעריך בנוסחת האיבר הכללי הוא n − 1. המשך הנושא בדף סדרה הנדסית.

6. עץ החלטה: מתי ואיך משתמשים בנוסחת הסכום

7. סיכום

  • סך הכול של כמות שגדלה או קטנה בכל שלב פי b הוא סכום: a + a · b + … + a · bn − 1.
  • נוסחת הסכום: Sn = a · (bn − 1) / (b − 1), ובדעיכה נוח: a · (1 − bn) / (1 − b).
  • n הוא מספר המחוברים, והמעריך האחרון בסכום הוא n − 1.
  • בדעיכה הסכום מתקרב ל-a / (1 − b) ולא עובר אותו.
