שיעור שלישי - מציאת הפונקציה משתי נקודות

במצגת הדוגמאות של שיעור שלישי ידענו רק שני ערכים – שתי נקודות על הגרף – ומצאנו מהם את כל הפונקציה. בדף הזה נסכם איך עושים את זה.

1. כשאחת הנקודות היא ב־t = 0

  1. הערך ב־t = 0 הוא a, כי f(0) = a · b0 = a.
  2. מציבים את הנקודה השנייה (t, y): a · bt = y, ולכן bt = y : a.
  3. מוצאים איזה מספר חיובי בחזקת t נותן את המנה. זה b.

דוגמה – נקודה אחת ב־t = 0

הפונקציה f(t) = a · bt עוברת בנקודות (0, 3) ו־(2, 48). מצאו את a ואת b, וקבעו אם זו פונקציית גדילה או דעיכה.

מציבים את הנקודה (0, 3) כדי למצוא את a (מציאת פרמטר)
f(0) = a · b0 3 = a · 1 a = 3
מציבים את הנקודה (2, 48) ואת a = 3 כדי למצוא את b (מציאת פרמטר)
f(2) = a · b2 48 = 3 · b2 b2 = 16 b = 4

הפתרון b = −4 נפסל, כי בסיס חייב להיות חיובי.

כותבים את הפונקציה וקובעים את סוגה לפי הבסיס
f(t) = 3 · 4t

מכיוון ש־b = 4 > 1, זו פונקציית גדילה.

דוגמה – דעיכה

בבריכה היו 500 ליטר מים. בגלל דליפה נשארו בה אחרי שעתיים 320 ליטר. כמות המים מתאימה לפונקציה f(t) = a · bt. מצאו את הפונקציה, ובכמה אחוזים קטנה הכמות בכל שעה.

מציבים את שתי הנקודות (0, 500) ו־(2, 320) (מציאת פרמטר)
a = 500 500 · b2 = 320 b2 = 0.64 b = 0.8
כותבים את הפונקציה ומתרגמים את b לאחוזים (בניית פונקציה)
f(t) = 500 · 0.8t p = (1 − b) · 100 = (1 − 0.8) · 100 = 20

הכמות קטנה ב־20% בכל שעה.

2. כשאין נקודה ב־t = 0

מציבים את שתי הנקודות, ומחלקים את המשוואות זו בזו. a מתבטל, ונשאר b בחזקת ההפרש בין הזמנים. אחר כך מוצאים את a.

דוגמה – שתי נקודות בלי t = 0

הפונקציה f(t) = a · bt עוברת בנקודות (2, 45) ו־(4, 405). מצאו את הפונקציה.

מציבים את שתי הנקודות (מציאת פרמטר)
a · b2 = 45 a · b4 = 405
מחלקים את המשוואה השנייה בראשונה: a מתבטל, ונשאר b בחזקת ההפרש בין הזמנים (מציאת פרמטר)
b4 − 2 = 405 : 45 b2 = 9 b = 3
מציבים את b באחת המשוואות ומוצאים את a (מציאת פרמטר)
a · 32 = 45 9a = 45 a = 5
כותבים את הפונקציה ובודקים בנקודה השנייה (בדיקה)
f(t) = 5 · 3t f(4) = 5 · 81 = 405 ✓

3. איך ניגשים לשאלה

בצע את התהליך המתאים לסוג השאלה:

אחת הנקודות ב־t = 0

  1. מהנקודה שבה t = 0 מקבלים את a.
  2. מציבים את הנקודה השנייה בפונקציה.
  3. מבודדים את bt.
  4. מוצאים את b. מתאים רק מספר חיובי.
  5. כותבים את הפונקציה:f(t) = a · bt

אין נקודה ב־t = 0

  1. מציבים את שתי הנקודות ומקבלים שתי משוואות.
  2. מחלקים את המשוואות זו בזו:bt2 − t1 = f(t2) : f(t1)
  3. מוצאים את b.
  4. מציבים את b באחת המשוואות ומוצאים את a.
  5. בודקים בנקודה השנייה.

משלימים ערכים חסרים

  1. קדימה: מכפילים ב־b.
  2. אחורה: מחלקים ב־b.
  3. או מציבים ישר בפונקציה את הזמן המבוקש.

4. סיכום

  • נקודה ב־t = 0 נותנת ישר את a.
  • מהנקודה השנייה: bt = y : a. רק b חיובי מתאים.
  • בלי נקודה ב־t = 0: מחלקים את שני הערכים ומקבלים bt2 − t1, ואז מוצאים את a.
  • ערכים חסרים: קדימה מכפילים ב־b, אחורה מחלקים ב־b.
