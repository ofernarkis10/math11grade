\(x(t) = \color{#1f6f8b}{x_A + v_x t} + R\cos(\color{#b4561e}{\theta_0 + \omega t})\)
\(y(t) = \color{#1f6f8b}{y_A + v_y t} + R\sin(\color{#b4561e}{\theta_0 + \omega t})\)
כלים לדף: כל הרכיבים נתונים. סדר ההצבה: (1) המרכז \((x_A + v_x t,\ y_A + v_y t)\) (2) הזווית \(\theta_0 + \omega t\) (3) ההזזה \((R\cos\theta,\ R\sin\theta)\) (4) מחברים. ערכים שכדאי לזכור: \(\cos 0^\circ = 1,\ \cos 90^\circ = 0,\ \cos 180^\circ = -1,\ \sin 90^\circ = 1,\ \sin 270^\circ = -1\)

רמה א׳: חלק אחד של הנוסחה שאלות 1–8

מציבים רק במשוואת המרכז, רק במשוואת הסיבוב, או רק בהזזה מהמרכז.

  1. משוואות המרכז הן \(x_C = 2 + 3t,\ y_C = 1 + 2t\). איפה המרכז ב־\(t = 4\)?
    הצג פתרון
    דרך החשיבה

    המשוואות כבר כתובות, ולא צריך למצוא שום רכיב. מציבים 4 במקום t בכל משוואה בנפרד.

    1. הצבה ב־xשאלת מרחק
      \(x_C = x_A + v_x t = 2 + 3\cdot 4 = 14\)
    2. הצבה ב־yשאלת מרחק
      \(y_C = y_A + v_y t = 1 + 2\cdot 4 = 9\)
    תשובה:
    \((14, 9)\)
    בדיקה:
    בכל שנייה x גדל ב־3, ובארבע שניות ב־12
    \(2+12 = 14\)✓
  2. משוואת הסיבוב היא \(\theta(t) = 30 + 45t\). מה הזווית ב־\(t = 2\) וב־\(t = 6\)?
    הצג פתרון
    דרך החשיבה

    מציבים את הזמן במשוואת הסיבוב. אם יוצאת זווית גדולה מ־360, אפשר להחסיר 360 כדי לראות איפה הנקודה על הגלגל.

    1. t = 2שאלת מרחק זוויתי
      \(\theta = \theta_0 + \omega t = 30 + 90 = 120^\circ\)
    2. t = 6שאלת מרחק זוויתי
      \(\theta = \theta_0 + \omega t = 30 + 270 = 300^\circ\)
    תשובה:
    \(120^\circ\)
    \(300^\circ\)
    בדיקה:
    \(300^\circ\)
    ברביע הרביעי: הגלגל הסתובב 270 מעלות מ־30 ✓
  3. גלגל שלא זז, מרכזו בראשית ורדיוסו 5. הנקודה בזווית \(60^\circ\). מה הקואורדינטות שלה?
    הצג פתרון
    דרך החשיבה

    נקודה על מעגל סביב הראשית: x הוא הרדיוס כפול קוסינוס הזווית, ו־y הוא הרדיוס כפול סינוס הזווית. את הערכים של 60 מעלות יודעים בעל פה.

    1. נוסחהשאלת מיקום
      \((R\cos\theta,\ R\sin\theta)\)
    2. xשאלת מיקום
      \(x = R\cos\theta = 5\cos 60^\circ = 5\cdot\tfrac12 = 2.5\)
    3. yשאלת מיקום
      \(y = R\sin\theta = 5\sin 60^\circ = 5\cdot\tfrac{\sqrt3}{2} \approx 4.33\)
    תשובה:
    \((2.5,\ 2.5\sqrt3) \approx (2.5,\ 4.33)\)
    בדיקה:
    \(2.5^2 + 4.33^2 \approx 6.25 + 18.75 = 25 = R^2\)✓
  4. מרכז הגלגל ב־\((3, 2)\), הרדיוס 2, והנקודה בזווית \(180^\circ\). מה הקואורדינטות שלה?
    הצג פתרון
    דרך החשיבה

    כשהמרכז לא בראשית, מוסיפים למרכז את ההזזה \((R\cos\theta, R\sin\theta)\).

    1. הזזהשאלת מיקום
      \((R\cos\theta,\ R\sin\theta) = (2\cos 180^\circ,\ 2\sin 180^\circ) = (-2,\ 0)\)
    2. הוספה למרכזשאלת מיקום
      \(P = C + (R\cos\theta,\ R\sin\theta) = (3-2,\ 2+0) = (1, 2)\)
    תשובה:
    \((1, 2)\)
    בדיקה:
    זווית 180 היא צד שמאל: 2 יחידות שמאלה מהמרכז ✓
  5. משוואות המרכז הן \(x_C = -3 + 4t,\ y_C = 5 - t\). איפה המרכז ב־\(t = 3\)?
    הצג פתרון
    דרך החשיבה

    מציבים 3 במקום t בכל משוואה. שימו לב למינוס במשוואת y: המרכז יורד עם הזמן.

    1. הצבה ב־xשאלת מרחק
      \(x_C = x_A + v_x t = -3 + 4\cdot 3 = 9\)
    2. הצבה ב־yשאלת מרחק
      \(y_C = y_A + v_y t = 5 - 3 = 2\)
    תשובה:
    \((9, 2)\)
    בדיקה:
    ב־3 שניות x גדל ב־12 ו־y קטן ב־3
    \((-3+12,\ 5-3)\)✓
  6. משוואת הסיבוב היא \(\theta(t) = 200 - 60t\). מה הזווית ב־\(t = 5\), ובאיזה רביע הנקודה?
    הצג פתרון
    דרך החשיבה

    מציבים. יוצאת זווית שלילית, ולכן מוסיפים 360 כדי לקבל זווית בין 0 ל־360 ולזהות את הרביע.

    1. הצבהשאלת מרחק זוויתי
      \(\theta = \theta_0 + \omega t = 200 - 300 = -100^\circ\)
    2. זווית שקולהשאלת מרחק זוויתי
      \(\theta + 360^\circ = -100 + 360 = 260^\circ\)
    3. רביע
      \(180^\circ \lt 260^\circ \lt 270^\circ\)
      רביע שלישי
    תשובה:
    \(-100^\circ\)
    (כלומר
    \(260^\circ\)
    ), רביע שלישי
    בדיקה:
    הגלגל הסתובב 300 מעלות עם השעון מ־200
    \(200 - 300 = -100\)✓
  7. גלגל שלא זז, מרכזו בראשית ורדיוסו 4. הנקודה בזווית \(135^\circ\). מה הקואורדינטות שלה?
    הצג פתרון
    דרך החשיבה

    אותה נוסחה כמו בשאלה 3, בזווית ברביע השני: הקוסינוס שלילי והסינוס חיובי.

    1. xשאלת מיקום
      \(x = R\cos\theta = 4\cos 135^\circ = 4\cdot\left(-\tfrac{\sqrt2}{2}\right) = -2\sqrt2 \approx -2.83\)
    2. yשאלת מיקום
      \(y = R\sin\theta = 4\sin 135^\circ = 4\cdot\tfrac{\sqrt2}{2} = 2\sqrt2 \approx 2.83\)
    תשובה:
    \((-2\sqrt2,\ 2\sqrt2) \approx (-2.83,\ 2.83)\)
    בדיקה:
    \(8 + 8 = 16 = R^2\)✓
  8. מרכז הגלגל ב־\((-1, 4)\), הרדיוס 3, והנקודה בזווית \(270^\circ\). מה הקואורדינטות שלה?
    הצג פתרון
    דרך החשיבה

    270 מעלות היא תחתית הגלגל. מחשבים את ההזזה ומוסיפים למרכז.

    1. הזזהשאלת מיקום
      \((R\cos\theta,\ R\sin\theta) = (3\cos 270^\circ,\ 3\sin 270^\circ) = (0,\ -3)\)
    2. הוספה למרכזשאלת מיקום
      \(P = C + (R\cos\theta,\ R\sin\theta) = (-1+0,\ 4-3) = (-1, 1)\)
    תשובה:
    \((-1, 1)\)
    בדיקה:
    3 יחידות מתחת למרכז ✓

רמה ב׳: הנוסחה המלאה שאלות 9–18

כל שבעת הרכיבים נתונים, וזוויות עגולות.

  1. נתון: \(x_A=1,\ y_A=2,\ v_x=2,\ v_y=1,\ R=3,\ \theta_0=0^\circ,\ \omega=90^\circ/\text{s}\). רשמו את הנוסחה ומצאו את הנקודה ב־\(t=1\).
    הצג פתרון
    דרך החשיבה

    כל שבעת הרכיבים נתונים. משבצים אותם בנוסחה הכללית, ואז מציבים t: קודם המרכז, אחר כך הזווית, ובסוף ההזזה מהמרכז.

    1. נוסחהשאלת מרחק זוויתישאלת מיקום
      \(x = x_A + v_x t + R\cos(\theta_0 + \omega t) = 1 + 2t + 3\cos(90t)\)
      \(y = y_A + v_y t + R\sin(\theta_0 + \omega t) = 2 + t + 3\sin(90t)\)
    2. מרכזשאלת מרחק
      \(C = (x_A + v_x t,\ y_A + v_y t) = (1+2,\ 2+1) = (3, 3)\)
    3. זוויתשאלת מרחק זוויתי
      \(\theta = \theta_0 + \omega t = 90\cdot 1 = 90^\circ\)
    4. נקודהשאלת מיקום
      \(x = x_C + R\cos\theta = 3 + 3\cos 90^\circ = 3\)
      \(y = y_C + R\sin\theta = 3 + 3\sin 90^\circ = 6\)
    תשובה:
    \((3, 6)\)
    בדיקה:
    90 מעלות היא ראש הגלגל: 3 יחידות מעל המרכז ✓
  2. באותו גלגל כמו בשאלה הקודמת, מצאו את הנקודה ב־\(t=2\).
    הצג פתרון
    דרך החשיבה

    אותה נוסחה, זמן אחר. מציבים מחדש: המרכז זז עוד, והזווית גדלה עוד 90 מעלות.

    1. מרכזשאלת מרחק
      \(C = (x_A + v_x t,\ y_A + v_y t) = (1+4,\ 2+2) = (5, 4)\)
    2. זוויתשאלת מרחק זוויתי
      \(\theta = \theta_0 + \omega t = 90\cdot 2 = 180^\circ\)
    3. נקודהשאלת מיקום
      \(x = x_C + R\cos\theta = 5 + 3\cos 180^\circ = 2\)
      \(y = y_C + R\sin\theta = 4 + 3\sin 180^\circ = 4\)
    תשובה:
    \((2, 4)\)
    בדיקה:
    180 מעלות היא צד שמאל: 3 יחידות שמאלה מהמרכז ✓
  3. נתון: \(x_A=0,\ y_A=4,\ v_x=3,\ v_y=0,\ R=1,\ \theta_0=90^\circ,\ \omega=-90^\circ/\text{s}\). מצאו את הנקודה ב־\(t=3\).
    הצג פתרון
    דרך החשיבה

    ω שלילית, ולכן הזווית קטנה עם הזמן. מציבים כרגיל, וזווית שלילית בודקים על המעגל: −180 זה אותו מקום כמו 180.

    1. נוסחהשאלת מרחק זוויתישאלת מיקום
      \(x = x_A + v_x t + R\cos(\theta_0 + \omega t) = 3t + \cos(90 - 90t)\)
      \(y = y_A + v_y t + R\sin(\theta_0 + \omega t) = 4 + \sin(90 - 90t)\)
    2. מרכזשאלת מרחק
      \(C = (x_A + v_x t,\ y_A + v_y t) = (9, 4)\)
    3. זוויתשאלת מרחק זוויתי
      \(\theta = \theta_0 + \omega t = 90 - 270 = -180^\circ\)
    4. נקודהשאלת מיקום
      \(x = x_C + R\cos\theta = 9 + \cos(-180^\circ) = 8\)
      \(y = y_C + R\sin\theta = 4 + \sin(-180^\circ) = 4\)
    תשובה:
    \((8, 4)\)
    בדיקה:
    צד שמאל של המרכז
    \((9,4)\)✓
  4. נתונה הנוסחה \(x(t) = 4 + 2t + 2\cos(30 + 30t),\ y(t) = 1 + t + 2\sin(30 + 30t)\). מצאו את הנקודה ב־\(t=2\).
    הצג פתרון
    דרך החשיבה

    הנוסחה כבר מלאה, ונשאר רק להציב. מחשבים את מה שבתוך הסוגריים לפני הקוסינוס והסינוס.

    1. מרכזשאלת מרחק
      \(C = (x_A + v_x t,\ y_A + v_y t) = (4+4,\ 1+2) = (8, 3)\)
    2. זוויתשאלת מרחק זוויתי
      \(\theta = \theta_0 + \omega t = 30 + 60 = 90^\circ\)
    3. נקודהשאלת מיקום
      \(x = x_C + R\cos\theta = 8 + 2\cdot 0 = 8\)
      \(y = y_C + R\sin\theta = 3 + 2\cdot 1 = 5\)
    תשובה:
    \((8, 5)\)
    בדיקה:
    המרחק מהמרכז הוא 2 = R ✓
  5. נתון: \(x_A=-2,\ y_A=0,\ v_x=1,\ v_y=2,\ R=4,\ \theta_0=45^\circ,\ \omega=45^\circ/\text{s}\). מצאו את הנקודה ב־\(t=1\).
    הצג פתרון
    דרך החשיבה

    מרכז שמתחיל ב־x שלילי: מציבים בזהירות עם הסימנים.

      \(y = y_C + R\sin\theta = 2 + 4\sin 90^\circ = 6\)
    תשובה:
    \((-1, 6)\)
    בדיקה:
    ראש הגלגל: 4 יחידות מעל המרכז ✓
  6. נתון: \(x_A=2,\ y_A=1,\ v_x=1,\ v_y=3,\ R=2,\ \theta_0=90^\circ,\ \omega=90^\circ/\text{s}\). רשמו את הנוסחה ומצאו את הנקודה ב־\(t=1\).
    הצג פתרון
    דרך החשיבה

    משבצים את שבעת הרכיבים בנוסחה הכללית, ומציבים t = 1 לפי הסדר: מרכז, זווית, הזזה.

    1. נוסחהשאלת מרחק זוויתישאלת מיקום

      \(C = (x_A + v_x t,\ y_A + v_y t) = (3, 4)\)
    3. זוויתשאלת מרחק זוויתי

    בדיקה:

  7. באותו גלגל כמו בשאלה הקודמת, מצאו את הנקודה ב־\(t=3\).
    הצג פתרון

    בדיקה:

רמה ג׳: גלגל מתגלגל ומחשבון שאלות 19–24

π בנוסחה, זווית לא עגולה וזמנים בשברים.

  1. גלגל מתגלגל: \(x(t) = \pi t + 2\cos(270 - 90t),\ y(t) = 2 + 2\sin(270 - 90t)\). מצאו את הנקודה ב־\(t=1\) וב־\(t=2\).
    הצג פתרון
    דרך החשיבה

    זו נוסחה של גלגל מתגלגל, אבל הכול נתון. מציבים כמו קודם; π נשאר π, ובסוף מחשבים ערך מקורב.

    1. t = 1שאלת מרחק זוויתישאלת מיקום
      זווית
      \(\theta = \theta_0 + \omega t = 180^\circ\)
      \(x = x_C + R\cos\theta = \pi - 2 \approx 1.14\)
      \(y = y_C + R\sin\theta = 2\)
    2. t = 2שאלת מרחק זוויתישאלת מיקום
      זווית
      \(\theta = \theta_0 + \omega t = 90^\circ\)
      \(x = x_C + R\cos\theta = 2\pi \approx 6.28\)
      \(y = y_C + R\sin\theta = 4\)
    תשובה:
    \((\pi - 2,\ 2) \approx (1.14, 2)\)
    \((2\pi,\ 4) \approx (6.28, 4)\)
    בדיקה:
    ב־t = 2 הגובה 4 = 2R: ראש הגלגל ✓
  2. נתונה הנוסחה \(x(t) = 1 + 2t + 3\cos(20 + 50t),\ y(t) = 2 + t + 3\sin(20 + 50t)\). מצאו את הנקודה ב־\(t=1\) (בעזרת מחשבון).
    הצג פתרון
    דרך החשיבה

    הזווית יוצאת לא עגולה, ולכן משתמשים במחשבון. חשוב לוודא שהמחשבון במצב מעלות (DEG).

    1. מרכזשאלת מרחק
      \(C = (x_A + v_x t,\ y_A + v_y t) = (3, 3)\)
    2. זוויתשאלת מרחק זוויתי
      \(\theta = \theta_0 + \omega t = 20 + 50 = 70^\circ\)
    3. מחשבוןשאלת מיקום
      \(\cos 70^\circ \approx 0.342\)
      \(\sin 70^\circ \approx 0.940\)
    4. נקודהשאלת מיקום
      \(x = x_C + R\cos\theta \approx 3 + 1.026 = 4.03\)
      \(y = y_C + R\sin\theta \approx 3 + 2.819 = 5.82\)
    תשובה:
    \((4.03,\ 5.82)\)
    בדיקה:
    אם יצא
    \(\cos 70 \approx 0.63\)
    המחשבון ברדיאנים ✓
  3. גלגל מתגלגל: \(x(t) = 2\pi t + 0.5\cos(-720t),\ y(t) = 0.5 + 0.5\sin(-720t)\). מצאו את הנקודה ב־\(t = \tfrac18\) וב־\(t = \tfrac14\).
    הצג פתרון
    דרך החשיבה

    זמנים בשברים: כופלים את ω בשבר. 720 כפול שמינית הוא 90.

    1. t = 1/8שאלת מרחק זוויתישאלת מיקום
      זווית
      \(\theta = \theta_0 + \omega t = -90^\circ\)
      \(x = x_C + R\cos\theta = \tfrac{\pi}{4} + 0 \approx 0.785\)
      \(y = y_C + R\sin\theta = 0.5 - 0.5 = 0\)
    2. t = 1/4שאלת מרחק זוויתישאלת מיקום
      זווית
      \(\theta = \theta_0 + \omega t = -180^\circ\)
      \(x = x_C + R\cos\theta = \tfrac{\pi}{2} - 0.5 \approx 1.07\)
      \(y = y_C + R\sin\theta = 0.5\)
    תשובה:
    \((0.785,\ 0)\)
    \((1.07,\ 0.5)\)
    בדיקה:
    ב־t = 1/8 הגובה 0: הנקודה נוגעת בקרקע ✓
  4. גלגל מתגלגל: \(x(t) = \pi t + 3\cos(90 - 60t),\ y(t) = 3 + 3\sin(90 - 60t)\). מצאו את הנקודה ב־\(t=1.5\) וב־\(t=3\).
    הצג פתרון
    דרך החשיבה

    הכול נתון; מציבים ומחשבים ערך מקורב בסוף.

    1. t = 1.5שאלת מרחק זוויתישאלת מיקום
      זווית
      \(\theta = \theta_0 + \omega t = 90 - 90 = 0^\circ\)

    2. t = 3שאלת מרחק זוויתישאלת מיקום

      \(y = y_C + R\sin\theta = 0\)
    תשובה:
    \((7.71,\ 3)\)
    \((3\pi,\ 0) \approx (9.42,\ 0)\)
    בדיקה:
    ב־t = 3 הגובה 0: הנקודה נוגעת בקרקע ✓
  5. נתונה הנוסחה \(x(t) = 2 + t + 2\cos(10 + 35t),\ y(t) = 1 + 2t + 2\sin(10 + 35t)\). מצאו את הנקודה ב־\(t=2\) (בעזרת מחשבון).
    הצג פתרון

  6. גלגל מתגלגל: \(x(t) = \tfrac{4\pi}{3}t + \cos(90 - 240t),\ y(t) = 1 + \sin(90 - 240t)\). מצאו את הנקודה ב־\(t = \tfrac38\) וב־\(t = \tfrac34\).
    הצג פתרון
    דרך החשיבה
