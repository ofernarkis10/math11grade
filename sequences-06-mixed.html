הסבר ונוסחאות

מה הכוונה ב"סדרה מעורבת"? סדרה או בעיה שבה פועל יותר ממבנה אחד. בבגרות אלה בדרך כלל השאלות הקשות בפרק, אבל הרעיון פשוט: לפרק את המסובך לסדרות פשוטות שאנחנו כבר יודעים לטפל בהן.

המשמעות: סדרות חשבוניות והנדסיות הן אבני בניין. כמו שמספר מורכב בנוי מגורמים ראשוניים, סדרה מורכבת בנויה משילוב שלהן: חיבור, שזירה, הפעלת פונקציה על האיברים או מעבר בין סוגים.

שזורהמקומות אי־זוגיים: סדרה אחת. מקומות זוגיים: סדרה אחרת.
חשבונית ⇒ הנדסיתaₙ חשבונית ⇒ cᵃⁿ הנדסית עם מנה cᵈ
הנדסית ⇒ חשבוניתaₙ הנדסית חיובית ⇒ log aₙ חשבונית עם הפרש log q
סכום של שתי סדרותΣ(aₙ + bₙ) = Σaₙ + Σbₙ

סדרה שזורה: כותבים את האיברים במקומות האי־זוגיים a₁, a₃, a₅, … כסדרה בפני עצמה, ואת הזוגיים a₂, a₄, … כסדרה שנייה. ב־2n איברים יש n מכל סוג. ב־2n+1 איברים יש n+1 אי־זוגיים ו־n זוגיים.

סדרה נגזרת: לוגריתם הופך כפל לחיבור, וחזקה הופכת חיבור לכפל. לכן הם מעבירים בין סדרה הנדסית לחשבונית. גם תת־סדרה "כל איבר שלישי" של סדרה חשבונית (הנדסית) היא חשבונית (הנדסית), עם הפרש 3d (מנה q³).

חשבונית ־ הנדסית באותה שאלה: מתרגמים כל תנאי למשוואה. תנאי חשבוני הוא 2y = x + z; תנאי הנדסי הוא y² = xz. בחירה חכמה של משתנים חוסכת עבודה: לשלושה איברים חשבוניים a−d, a, a+d; להנדסיים a/q, a, aq.

סכומים של קבוצות איברים: בסדרה חשבונית, S₃, S₆ − S₃, S₉ − S₆ יוצרים סדרה חשבונית. בסדרה הנדסית הם יוצרים סדרה הנדסית עם מנה q³.

טעויות נפוצות: לספור לא נכון כמה איברים יש מכל סוג בסדרה שזורה; לשכוח ש־log מוגדר רק לסדרה חיובית; לפתור משוואה ריבועית ולהשאיר פתרון שנותן סדרה קבועה כשהשאלה דורשת d ≠ 0 או q ≠ 1.

רמה א׳: בסיס שאלות 1–10

תכונות האמצע והמעבר בין סוגי סדרות.

  1. הוכיחו שאם שלושה מספרים הם גם סדרה חשבונית וגם סדרה הנדסית, הם שווים זה לזה.
    הצג פתרון

    2y = x + z ו־y² = xz

    (x + z)²/4 = xz ⇒ (x − z)² = 0 ⇒ x = z, ולכן גם y = x.

  2. מצאו את x אם 2, x, 18 הם (א) סדרה חשבונית (ב) סדרה הנדסית.
    הצג פתרון

    א. 2x = 20 ⇒ x = 10

    ב. x² = 36 ⇒ x = ±6

  3. aₙ חשבונית עם a₁ = 1, d = 2, ו־bₙ = 3ᵃⁿ. הראו ש־bₙ הנדסית וחשבו את סכום חמשת האיברים הראשונים שלה.
    הצג פתרון

    bₙ₊₁/bₙ = 3^(aₙ₊₁ − aₙ) = 3² = 9

    b₁ = 3 ⇒ S₅ = 3(9⁵ − 1)/8 = 22,143

  4. aₙ הנדסית עם a₁ = 2, q = 4, ו־cₙ = log₂aₙ. הראו ש־cₙ חשבונית וחשבו c₁ + … + c₁₀.
    הצג פתרון

    cₙ = log₂(2·4ⁿ⁻¹) = 2n − 1, חשבונית עם d = 2

    S₁₀ = 10(1 + 19)/2 = 100

  5. bₙ הנדסית עם b₁ = 81, q = ⅓, ו־cₙ = log₃bₙ. מצאו את cₙ ואת סכום עשרת איבריה הראשונים.
    הצג פתרון

    cₙ = 4 − (n − 1) = 5 − n, חשבונית עם d = −1

    S₁₀ = 10(4 + (−5))/2 = −5

  6. נתון aₙ = 2n + 2ⁿ. חשבו את S₁₀.
    הצג פתרון

    Σ2n = 2·55 = 110, Σ2ⁿ = 2¹¹ − 2 = 2046

    S₁₀ = 2156

  7. חשבו: 2 − 4 + 6 − 8 + … − 100.
    הצג פתרון

    25 זוגות, כל זוג שווה −2: S = −50

  8. חשבו: Σ_(n=1)^∞ (1/2ⁿ + 1/3ⁿ).
    הצג פתרון

    Σ1/2ⁿ = 1, Σ1/3ⁿ = ½

    הסכום: 3/2

  9. נתון aₙ = n + (−1)ⁿ. כתבו את האיברים הראשונים וחשבו את S₂₀.
    הצג פתרון

    0, 3, 2, 5, 4, 7, …

    S₂₀ = (1 + … + 20) + 0 = 210 (סכום ה־(−1)ⁿ מתאפס).

  10. חשבו את סכום מאה האיברים הראשונים בסדרה aₙ = (−1)ⁿ·n.
    הצג פתרון

    (−1 + 2) + (−3 + 4) + …: 50 זוגות ששווים 1 כל אחד.

    S₁₀₀ = 50

רמה ב׳: ביסוס שאלות 11–22

סדרות שזורות ובעיות של שלושה מספרים.

  1. בסדרה 1, 2, 4, 4, 7, 8, 10, 16, … המקומות האי־זוגיים יוצרים סדרה חשבונית והזוגיים סדרה הנדסית. חשבו את S₂₀.
    הצג פתרון

    אי־זוגיים: 10 איברים, 1, 4, 7, …: S = 10(1 + 28)/2 = 145

    זוגיים: 10 איברים, 2, 4, 8, …: S = 2(2¹⁰ − 1) = 2046

    S₂₀ = 2191

  2. בסדרה a₂ₖ₋₁ = 3k, a₂ₖ = 2ᵏ. כתבו את האיברים הראשונים וחשבו S₁₂.
    הצג פתרון

    3, 2, 6, 4, 9, 8, …

    אי־זוגיים: 3(1 + … + 6) = 63. זוגיים: 2 + … + 64 = 126

    S₁₂ = 189

  3. בסדרה שזורה, המקומות האי־זוגיים הם סדרה חשבונית עם איבר ראשון 10 והפרש −2, והזוגיים הם סדרה הנדסית 1, −2, 4, …. חשבו את S₁₆.
    הצג פתרון

    אי־זוגיים (8): 8(20 + 7·(−2))/2 = 24

    זוגיים (8): (1 − (−2)⁸)/(1 − (−2)) = −255/3 = −85

    S₁₆ = −61

  4. המספרים 4, x, y הם סדרה חשבונית, והמספרים x, y, 18 הם סדרה הנדסית. מצאו את x ו־y.
    הצג פתרון

    x = (4 + y)/2, y² = 18x = 9(4 + y) ⇒ y² − 9y − 36 = 0

    y = 12, x = 8 או y = −3, x = ½

  5. שלושה מספרים יוצרים סדרה חשבונית שסכומה 15. אם מוסיפים להם 1, 4 ו־19 בהתאמה, מתקבלת סדרה הנדסית. מצאו אותם.
    הצג פתרון

    5−d, 5, 5+d → 6−d, 9, 24+d

    (6−d)(24+d) = 81 ⇒ d² + 18d − 63 = 0 ⇒ d = 3 או −21

    2, 5, 8 או 26, 5, −16

  6. שלושה מספרים יוצרים סדרה הנדסית שסכומה 26. אם מוסיפים להם 1, 6 ו־3 בהתאמה, מתקבלת סדרה חשבונית. מצאו אותם.
    הצג פתרון

    2(aq + 6) = (a + 1) + (aq² + 3) ⇒ a + aq² = 2aq + 8

    מהסכום: 3aq + 8 = 26 ⇒ aq = 6, ולכן a + 36/a = 20 ⇒ a = 2 או 18

    2, 6, 18 או 18, 6, 2

  7. בסדרה חשבונית חיובית a₁ = 2, d = 3. חשבו 1/(a₁a₂) + 1/(a₂a₃) + … + 1/(a₁₀a₁₁).
    הצג פתרון

    1/(aₙaₙ₊₁) = (1/d)(1/aₙ − 1/aₙ₊₁), סכום טלסקופי.

    (1/3)(1/2 − 1/32) = 5/32

  8. בסדרה חשבונית לא קבועה, a₂, a₅, a₁₄ יוצרים סדרה הנדסית. מצאו את מנתה.
    הצג פתרון

    (a₁ + 4d)² = (a₁ + d)(a₁ + 13d) ⇒ 3d² = 6a₁d ⇒ d = 2a₁

    q = a₅/a₂ = 9a₁/3a₁ = 3

  9. בסדרה הנדסית עם q ≠ 1, האיברים a₁, a₃, a₂ (בסדר הזה) יוצרים סדרה חשבונית. מצאו את q.
    הצג פתרון

    2a₁q² = a₁ + a₁q ⇒ 2q² − q − 1 = 0

    q = −½ (הפתרון q = 1 נפסל)

  10. נתונות הסדרות aₙ = 4n − 1 ו־bₙ = 5n + 2, כל אחת עם 100 איברים. כמה איברים משותפים יש להן ומה סכומם?
    הצג פתרון

    האיבר המשותף הראשון: 7. המשותפים חשבוניים עם הפרש 20.

    הגבול: a₁₀₀ = 399. 7 + 20(k−1) ≤ 399 ⇒ k = 20

    סכום: 20(7 + 387)/2 = 3940

  11. סדרה חשבונית וסדרה הנדסית מתחילות שתיהן ב־3, האיבר השני שלהן שווה, והאיבר הרביעי של החשבונית שווה לאיבר השלישי של ההנדסית. מצאו את שתי הסדרות (לא קבועות).
    הצג פתרון

    3 + d = 3q, 3 + 3d = 3q² ⇒ q² − 3q + 2 = 0 ⇒ q = 2

    חשבונית: 3, 6, 9, 12, … הנדסית: 3, 6, 12, …

  12. aₙ = 3n + 1 ו־bₙ = a₂ₙ. הוכיחו ש־bₙ חשבונית וחשבו את סכום עשרת איבריה הראשונים.
    הצג פתרון

    bₙ = 6n + 1, חשבונית עם הפרש 6 (פעמיים ההפרש המקורי)

    S₁₀ = 6·55 + 10 = 340

רמה ג׳: רמת בגרות שאלות 23–30

בעיות מילוליות ושאלות מורכבות.

  1. aₙ הנדסית עם a₁ = 1, q = 2, ו־bₙ = a₃ₙ₋₂. הוכיחו ש־bₙ הנדסית וחשבו את סכום ארבעת איבריה הראשונים.
    הצג פתרון

    bₙ₊₁/bₙ = a₃ₙ₊₁/a₃ₙ₋₂ = q³ = 8

    1 + 8 + 64 + 512 = 585

  2. רון חוסך 100 ₪ בחודש הראשון ומוסיף 50 ₪ בכל חודש. טל חוסך 10 ₪ בחודש הראשון ומכפיל את הסכום בכל חודש. מאיזה חודש החיסכון הכולל של טל גדול מזה של רון?
    הצג פתרון

    רון: Sₙ = 25n² + 75n. טל: Tₙ = 10(2ⁿ − 1)

    n = 7: רון 1750, טל 1270. n = 8: רון 2200, טל 2550.

    מהחודש השמיני.

  3. הוכיחו שבסדרה חשבונית S₃, S₆ − S₃, S₉ − S₆ יוצרים סדרה חשבונית, ומצאו את הפרשה.
    הצג פתרון

    כל קבוצה של שלושה איברים עוקבים גדולה מהקודמת ב־3·3d:

    (S₆ − S₃) − S₃ = (a₄ − a₁) + (a₅ − a₂) + (a₆ − a₃) = 9d, וכן הלאה.

    ההפרש: 9d

  4. בסדרה הנדסית S₃ = 7 ו־S₆ = 63. חשבו את S₉ בלי למצוא את a₁.
    הצג פתרון

    S₃, S₆ − S₃, S₉ − S₆ הנדסית עם מנה q³: q³ = 56/7 = 8

    S₉ − S₆ = 56·8 = 448 ⇒ S₉ = 511

  5. נתון a₁ = 0 ו־aₙ₊₁ = aₙ + bₙ, כאשר bₙ = 2ⁿ⁻¹. מצאו את aₙ.
    הצג פתרון

    aₙ = b₁ + … + bₙ₋₁ = 1 + 2 + … + 2ⁿ⁻² = 2ⁿ⁻¹ − 1

  6. חשבו את 1 + 11 + 111 + … (n איברים) ובדקו עבור n = 5.
    הצג פתרון

    האיבר ה־k: (10ᵏ − 1)/9

    Sₙ = (1/9)[(10 + … + 10ⁿ) − n] = (10ⁿ⁺¹ − 10 − 9n)/81

    n = 5: (10⁶ − 55)/81 = 12,345 ✓

  7. שלושה מספרים שונים הם האיבר הראשון, הרביעי והשישה־עשר של סדרה חשבונית, והם גם שלושה איברים עוקבים בסדרה הנדסית. סכומם 42. מצאו אותם.
    הצג פתרון

    (a₁ + 3d)² = a₁(a₁ + 15d) ⇒ 9d² = 9a₁d ⇒ d = a₁

    q = a₄/a₁ = 4, ולכן a₁(1 + 4 + 16) = 42 ⇒ a₁ = 2

    2, 8, 32

  8. חשבו את 0.5 + 0.55 + 0.555 + … (n איברים).
    הצג פתרון

    האיבר ה־k: (5/9)(1 − 10⁻ᵏ)

    Sₙ = (5/9)[n − (1 − 10⁻ⁿ)/9]

הפתרונות מוסתרים כדי לאפשר תרגול עצמי. לחצו על "הצג פתרון" כדי לבדוק.
