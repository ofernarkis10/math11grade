הסבר ונוסחאות

מה הכוונה ב"סדרה מעורבת"? סדרה או בעיה שבה פועל יותר ממבנה אחד. בבגרות אלה בדרך כלל השאלות הקשות בפרק, אבל הרעיון פשוט: לפרק את המסובך לסדרות פשוטות שאנחנו כבר יודעים לטפל בהן.

המשמעות: סדרות חשבוניות והנדסיות הן אבני בניין. כמו שמספר מורכב בנוי מגורמים ראשוניים, סדרה מורכבת בנויה משילוב שלהן: חיבור, שזירה, הפעלת פונקציה על האיברים או מעבר בין סוגים.

שזורהמקומות אי־זוגיים: סדרה אחת. מקומות זוגיים: סדרה אחרת.
חשבונית ⇒ הנדסית\(a_{n}\) חשבונית ⇒ \(c^{an}\) הנדסית עם מנה \(c^{d}\)
הנדסית ⇒ חשבונית\(a_{n}\) הנדסית חיובית ⇒ \({\log a_{n}}\) חשבונית עם הפרש \({\log q}\)
סכום של שתי סדרות\(\sum (a_{n} + b_{n}) = \sum a_{n} + \sum b_{n}\)

סדרה שזורה: כותבים את האיברים במקומות האי־זוגיים \(a_{1}, a_{3}, a_{5}, \ldots\) כסדרה בפני עצמה, ואת הזוגיים \(a_{2}, a_{4}, \ldots\) כסדרה שנייה. ב־2n איברים יש n מכל סוג. ב־\(2n+1\) איברים יש \(n+1\) אי־זוגיים ו־n זוגיים.

סדרה נגזרת: לוגריתם הופך כפל לחיבור, וחזקה הופכת חיבור לכפל. לכן הם מעבירים בין סדרה הנדסית לחשבונית. גם תת־סדרה "כל איבר שלישי" של סדרה חשבונית (הנדסית) היא חשבונית (הנדסית), עם הפרש \(3d\) (מנה \(q^{3}\)).

חשבונית ־ הנדסית באותה שאלה: מתרגמים כל תנאי למשוואה. תנאי חשבוני הוא \(2y = x + z\); תנאי הנדסי הוא \(y^{2} = xz\). בחירה חכמה של משתנים חוסכת עבודה: לשלושה איברים חשבוניים \(a - d, a, a+d\); להנדסיים \(\dfrac{a}{q}, a, aq\).

סכומים של קבוצות איברים: בסדרה חשבונית, \(S_{3}, S_{6} - S_{3}, S_{9} - S_{6}\) יוצרים סדרה חשבונית. בסדרה הנדסית הם יוצרים סדרה הנדסית עם מנה \(q^{3}\).

טעויות נפוצות: לספור לא נכון כמה איברים יש מכל סוג בסדרה שזורה; לשכוח ש־log מוגדר רק לסדרה חיובית; לפתור משוואה ריבועית ולהשאיר פתרון שנותן סדרה קבועה כשהשאלה דורשת \(d \neq 0\) או \(q \neq 1\).

רמה א׳: בסיס שאלות 1–10

תכונות האמצע והמעבר בין סוגי סדרות.

  1. הוכיחו שאם שלושה מספרים הם גם סדרה חשבונית וגם סדרה הנדסית, הם שווים זה לזה.
    הצג פתרון

    \(2y = x + z\) ו־\(y^{2} = xz\)

    \(\dfrac{(x + z)^{2}}{4} = xz \Rightarrow (x - z)^{2} = 0 \Rightarrow x = z\), ולכן גם \(y = x\).

  2. מצאו את x אם \(2, x, 18\) הם (א) סדרה חשבונית (ב) סדרה הנדסית.
    הצג פתרון

    א. \(2x = 20 \Rightarrow x = 10\)

    ב. \(x^{2} = 36 \Rightarrow x = \pm 6\)

  3. \(a_{n}\) חשבונית עם \(a_{1} = 1\), \(d = 2\), ו־\(b_{n} = 3^{an}\). הראו ש־\(b_{n}\) הנדסית וחשבו את סכום חמשת האיברים הראשונים שלה.
    הצג פתרון

    \(\dfrac{b_{n+1}}{b_{n}} = 3^{a_{n+1} - a_{n}} = 3^{2} = 9\)

    \(b_{1} = 3 \Rightarrow S_{5} = \dfrac{3(9^{5} - 1)}{8} = 22{,}143\)

  4. \(a_{n}\) הנדסית עם \(a_{1} = 2\), \(q = 4\), ו־\(c_{n} = {\log_{2} a_{n}}\). הראו ש־\(c_{n}\) חשבונית וחשבו \(c_{1} + \ldots + c_{10}\).
    הצג פתרון

    \(c_{n} = {\log_{2}(2 \cdot 4^{n-1})} = 2n - 1\), חשבונית עם \(d = 2\)

    \(S_{10} = \dfrac{10(1 + 19)}{2} = 100\)

  5. \(b_{n}\) הנדסית עם \(b_{1} = 81\), \(q = {\dfrac{1}{3}}\), ו־\(c_{n} = {\log_{3} b_{n}}\). מצאו את \(c_{n}\) ואת סכום עשרת איבריה הראשונים.
    הצג פתרון

    \(c_{n} = 4 - (n - 1) = 5 - n\), חשבונית עם \(d = - 1\)

    \(S_{10} = \dfrac{10(4 + ( - 5))}{2} = - 5\)

  6. נתון \(a_{n} = 2n + 2^{n}\). חשבו את \(S_{10}\).
    הצג פתרון

    \(\sum 2n = 2 \cdot 55 = 110\), \(\sum 2^{n} = 2^{11} - 2 = 2046\)

    \(S_{10} = 2156\)

  7. חשבו: \(2 - 4 + 6 - 8 + \ldots - 100\).
    הצג פתרון

    25 זוגות, כל זוג שווה \(- 2\): \(S = - 50\)

  8. חשבו: \(\sum _{n=1}^{\infty} \left(\dfrac{1}{2^{n}} + \dfrac{1}{3^{n}}\right)\).
    הצג פתרון

    \(\sum \dfrac{1}{2^{n}} = 1\), \(\sum \dfrac{1}{3^{n}} = {\dfrac{1}{2}}\)

    הסכום: \(\dfrac{3}{2}\)

  9. נתון \(a_{n} = n + ( - 1)^{n}\). כתבו את האיברים הראשונים וחשבו את \(S_{20}\).
    הצג פתרון

    \(0, 3, 2, 5, 4, 7, \ldots\)

    \(S_{20} = (1 + \ldots + 20) + 0 = 210\) (סכום ה־\(( - 1)^{n}\) מתאפס).

  10. חשבו את סכום מאה האיברים הראשונים בסדרה \(a_{n} = ( - 1)^{n} \cdot n\).
    הצג פתרון

    \(( - 1 + 2) + ( - 3 + 4) + \ldots\): 50 זוגות ששווים 1 כל אחד.

    \(S_{100} = 50\)

רמה ב׳: ביסוס שאלות 11–22

סדרות שזורות ובעיות של שלושה מספרים.

  1. בסדרה \(1, 2, 4, 4, 7, 8, 10, 16, \ldots\) המקומות האי־זוגיים יוצרים סדרה חשבונית והזוגיים סדרה הנדסית. חשבו את \(S_{20}\).
    הצג פתרון

    אי־זוגיים: 10 איברים, \(1, 4, 7, \ldots\): \(S = \dfrac{10(1 + 28)}{2} = 145\)

    זוגיים: 10 איברים, \(2, 4, 8, \ldots\): \(S = 2(2^{10} - 1) = 2046\)

    \(S_{20} = 2191\)

  2. בסדרה \(a_{2k-1} = 3k\), \(a_{2k} = 2^{k}\). כתבו את האיברים הראשונים וחשבו \(S_{12}\).
    הצג פתרון

    \(3, 2, 6, 4, 9, 8, \ldots\)

    אי־זוגיים: \(3(1 + \ldots + 6) = 63\). זוגיים: \(2 + \ldots + 64 = 126\)

    \(S_{12} = 189\)

  3. בסדרה שזורה, המקומות האי־זוגיים הם סדרה חשבונית עם איבר ראשון 10 והפרש \(- 2\), והזוגיים הם סדרה הנדסית \(1, - 2, 4, \ldots\). חשבו את \(S_{16}\).
    הצג פתרון

    אי־זוגיים (8): \(\dfrac{8(20 + 7 \cdot ( - 2))}{2} = 24\)

    זוגיים (8): \(\dfrac{1 - ( - 2)^{8}}{1 - ( - 2)} = - \dfrac{255}{3} = - 85\)

    \(S_{16} = - 61\)

  4. המספרים \(4, x, y\) הם סדרה חשבונית, והמספרים \(x, y, 18\) הם סדרה הנדסית. מצאו את x ו־y.
    הצג פתרון

    \(x = \dfrac{4 + y}{2}\), \(y^{2} = 18x = 9(4 + y) \Rightarrow y^{2} - 9y - 36 = 0\)

    \(y = 12, x = 8\) או \(y = - 3, x = {\dfrac{1}{2}}\)

  5. שלושה מספרים יוצרים סדרה חשבונית שסכומה 15. אם מוסיפים להם 1, 4 ו־19 בהתאמה, מתקבלת סדרה הנדסית. מצאו אותם.
    הצג פתרון

    \(5 - d, 5, 5+d\) → \(6 - d, 9, 24+d\)

    \((6 - d)(24+d) = 81 \Rightarrow d^{2} + 18d - 63 = 0 \Rightarrow d = 3\) או \(- 21\)

    \(2, 5, 8\) או \(26, 5, - 16\)

  6. שלושה מספרים יוצרים סדרה הנדסית שסכומה 26. אם מוסיפים להם 1, 6 ו־3 בהתאמה, מתקבלת סדרה חשבונית. מצאו אותם.
    הצג פתרון

    \(2(aq + 6) = (a + 1) + (aq^{2} + 3) \Rightarrow a + aq^{2} = 2aq + 8\)

    מהסכום: \(3aq + 8 = 26 \Rightarrow aq = 6\), ולכן \(a + \dfrac{36}{a} = 20 \Rightarrow a = 2\) או \(18\)

    \(2, 6, 18\) או \(18, 6, 2\)

  7. בסדרה חשבונית חיובית \(a_{1} = 2\), \(d = 3\). חשבו \(\dfrac{1}{a_{1}a_{2}} + \dfrac{1}{a_{2}a_{3}} + \ldots + \dfrac{1}{a_{10}a_{11}}\).
    הצג פתרון

    \(\dfrac{1}{a_{n}a_{n+1}} = \dfrac{1}{d}\left(\dfrac{1}{a_{n}} - \dfrac{1}{a_{n+1}}\right)\), סכום טלסקופי.

    \(\dfrac{1}{3}\left(\dfrac{1}{2} - \dfrac{1}{32}\right) = \dfrac{5}{32}\)

  8. בסדרה חשבונית לא קבועה, \(a_{2}, a_{5}, a_{14}\) יוצרים סדרה הנדסית. מצאו את מנתה.
    הצג פתרון

    \((a_{1} + 4d)^{2} = (a_{1} + d)(a_{1} + 13d) \Rightarrow 3d^{2} = 6a_{1}d \Rightarrow d = 2a_{1}\)

    \(q = \dfrac{a_{5}}{a_{2}} = \dfrac{9a_{1}}{3a_{1}} = 3\)

  9. בסדרה הנדסית עם \(q \neq 1\), האיברים \(a_{1}, a_{3}, a_{2}\) (בסדר הזה) יוצרים סדרה חשבונית. מצאו את \(q\).
    הצג פתרון

    \(2a_{1}q^{2} = a_{1} + a_{1}q \Rightarrow 2q^{2} - q - 1 = 0\)

    \(q = - {\dfrac{1}{2}}\) (הפתרון \(q = 1\) נפסל)

  10. נתונות הסדרות \(a_{n} = 4n - 1\) ו־\(b_{n} = 5n + 2\), כל אחת עם 100 איברים. כמה איברים משותפים יש להן ומה סכומם?
    הצג פתרון

    האיבר המשותף הראשון: 7. המשותפים חשבוניים עם הפרש 20.

    הגבול: \(a_{100} = 399\). \(7 + 20(k - 1) \le 399 \Rightarrow k = 20\)

    סכום: \(\dfrac{20(7 + 387)}{2} = 3940\)

  11. סדרה חשבונית וסדרה הנדסית מתחילות שתיהן ב־3, האיבר השני שלהן שווה, והאיבר הרביעי של החשבונית שווה לאיבר השלישי של ההנדסית. מצאו את שתי הסדרות (לא קבועות).
    הצג פתרון

    \(3 + d = 3q\), \(3 + 3d = 3q^{2} \Rightarrow q^{2} - 3q + 2 = 0 \Rightarrow q = 2\)

    חשבונית: \(3, 6, 9, 12, \ldots\) הנדסית: \(3, 6, 12, \ldots\)

  12. \(a_{n} = 3n + 1\) ו־\(b_{n} = a_{2n}\). הוכיחו ש־\(b_{n}\) חשבונית וחשבו את סכום עשרת איבריה הראשונים.
    הצג פתרון

    \(b_{n} = 6n + 1\), חשבונית עם הפרש 6 (פעמיים ההפרש המקורי)

    \(S_{10} = 6 \cdot 55 + 10 = 340\)

רמה ג׳: רמת בגרות שאלות 23–30

בעיות מילוליות ושאלות מורכבות.

  1. \(a_{n}\) הנדסית עם \(a_{1} = 1\), \(q = 2\), ו־\(b_{n} = a_{3n-2}\). הוכיחו ש־\(b_{n}\) הנדסית וחשבו את סכום ארבעת איבריה הראשונים.
    הצג פתרון

    \(\dfrac{b_{n+1}}{b_{n}} = \dfrac{a_{3n+1}}{a_{3n-2}} = q^{3} = 8\)

    \(1 + 8 + 64 + 512 = 585\)

  2. רון חוסך 100 ₪ בחודש הראשון ומוסיף 50 ₪ בכל חודש. טל חוסך 10 ₪ בחודש הראשון ומכפיל את הסכום בכל חודש. מאיזה חודש החיסכון הכולל של טל גדול מזה של רון?
    הצג פתרון

    רון: \(S_{n} = 25n^{2} + 75n\). טל: \(T_{n} = 10(2^{n} - 1)\)

    \(n = 7\): רון 1750, טל 1270. \(n = 8\): רון 2200, טל 2550.

    מהחודש השמיני.

  3. הוכיחו שבסדרה חשבונית \(S_{3}, S_{6} - S_{3}, S_{9} - S_{6}\) יוצרים סדרה חשבונית, ומצאו את הפרשה.
    הצג פתרון

    כל קבוצה של שלושה איברים עוקבים גדולה מהקודמת ב־\(3 \cdot 3d\):

    \((S_{6} - S_{3}) - S_{3} = (a_{4} - a_{1}) + (a_{5} - a_{2}) + (a_{6} - a_{3}) = 9d\), וכן הלאה.

    ההפרש: \(9d\)

  4. בסדרה הנדסית \(S_{3} = 7\) ו־\(S_{6} = 63\). חשבו את \(S_{9}\) בלי למצוא את \(a_{1}\).
    הצג פתרון

    \(S_{3}, S_{6} - S_{3}, S_{9} - S_{6}\) הנדסית עם מנה \(q^{3}\): \(q^{3} = \dfrac{56}{7} = 8\)

    \(S_{9} - S_{6} = 56 \cdot 8 = 448 \Rightarrow S_{9} = 511\)

  5. נתון \(a_{1} = 0\) ו־\(a_{n+1} = a_{n} + b_{n}\), כאשר \(b_{n} = 2^{n-1}\). מצאו את \(a_{n}\).
    הצג פתרון

    \(a_{n} = b_{1} + \ldots + b_{n-1} = 1 + 2 + \ldots + 2^{n-2} = 2^{n-1} - 1\)

  6. חשבו את \(1 + 11 + 111 + \ldots\) (n איברים) ובדקו עבור \(n = 5\).
    הצג פתרון

    האיבר ה־k: \(\dfrac{10^{k} - 1}{9}\)

    \(S_{n} = \dfrac{1}{9}[(10 + \ldots + 10^{n}) - n] = \dfrac{10^{n+1} - 10 - 9n}{81}\)

    \(n = 5\): \(\dfrac{10^{6} - 55}{81} = 12{,}345\) ✓

  7. שלושה מספרים שונים הם האיבר הראשון, הרביעי והשישה־עשר של סדרה חשבונית, והם גם שלושה איברים עוקבים בסדרה הנדסית. סכומם 42. מצאו אותם.
    הצג פתרון

    \((a_{1} + 3d)^{2} = a_{1}(a_{1} + 15d) \Rightarrow 9d^{2} = 9a_{1}d \Rightarrow d = a_{1}\)

    \(q = \dfrac{a_{4}}{a_{1}} = 4\), ולכן \(a_{1}(1 + 4 + 16) = 42 \Rightarrow a_{1} = 2\)

    \(2, 8, 32\)

  8. חשבו את \(0.5 + 0.55 + 0.555 + \ldots\) (n איברים).
    הצג פתרון

    האיבר ה־k: \(\dfrac{5}{9}(1 - 10^{-k})\)

    \(S_{n} = \dfrac{5}{9}\left[n - \dfrac{1 - 10^{-n}}{9}\right]\)

הפתרונות מוסתרים כדי לאפשר תרגול עצמי. לחצו על "הצג פתרון" כדי לבדוק.
