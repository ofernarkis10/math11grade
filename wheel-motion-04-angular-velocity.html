תרגול: מהירות זוויתית במעלות

20 שאלות על משוואת הסיבוב \(\theta(t) = \theta_0 + \omega t\): איך מוצאים את הזווית ההתחלתית ואת המהירות הזוויתית במעלות לשנייה, כולל הסימן. ההסבר בדף התאוריה.

רמה א׳: מהירות זוויתית ישירה שאלות 1–8

סיבובים לשנייה, זמן מחזור, סל״ד, וזיהוי רכיבים מהמשוואה.

  1. גלגל מבצע 2 סיבובים בשנייה נגד כיוון השעון. מהי \(\omega\) במעלות לשנייה?
    הצג פתרון
    דרך החשיבה

    סיבוב מלא הוא 360 מעלות. כמה סיבובים בשנייה כפול 360 נותן מעלות בשנייה. הכיוון קובע את הסימן: נגד השעון הוא חיובי.

    1. נוסחהשאלת מרחק זוויתי
      \(\omega = 360n\)
    2. הצבהשאלת מרחק זוויתי
      \(\omega = 360n = 360\cdot 2 = 720\)
    3. סימן
      נגד השעון
      \(\Rightarrow +\)
    תשובה:
    \(\omega = 720^\circ/\text{s}\)
    בדיקה:
    בחצי שנייה הגלגל מסתובב
    \(360^\circ\)
    כלומר סיבוב אחד, ואכן 2 סיבובים בשנייה ✓
  2. גלגל משלים סיבוב מלא כל 8 שניות, עם כיוון השעון. מהי \(\omega\)?
    הצג פתרון
    דרך החשיבה

    נתון זמן מחזור, כלומר כמה שניות לוקח סיבוב אחד. מחלקים 360 מעלות בזמן הזה. עם כיוון השעון ולכן הסימן שלילי.

    1. נוסחהשאלת מרחק זוויתי
      \(|\omega| = \dfrac{360}{T}\)
    2. הצבהשאלת מרחק זוויתי
      \(|\omega| = \dfrac{360}{T} = \dfrac{360}{8} = 45\)
    3. סימן
      עם השעון
      \(\Rightarrow \omega = -45\)
    תשובה:
    \(\omega = -45^\circ/\text{s}\)
    בדיקה:
    \(45\cdot 8 = 360\)✓
  3. גלגל מסתובב ב־30 סיבובים לדקה (סל״ד) נגד כיוון השעון. כמה סיבובים בשנייה, ומהי \(\omega\)?
    הצג פתרון
    דרך החשיבה

    היחידה נתונה בדקות, ו־ω במעלות לשנייה. קודם ממירים לסיבובים בשנייה (מחלקים ב־60), ואז כופלים ב־360. אפשר גם לזכור: ω = 6 · סל״ד.

    1. המרהשאלת מרחק זוויתי
      \(n = \dfrac{\text{rpm}}{60} = \dfrac{30}{60} = 0.5\)
    2. חישובשאלת מרחק זוויתי
      \(\omega = 360n = 360\cdot 0.5 = 180\)
    3. קיצורשאלת מרחק זוויתי
      \(\omega = 6\cdot\text{rpm} = 6\cdot 30 = 180\)
    תשובה:
    0.5 סיבוב לשנייה
    \(\omega = 180^\circ/\text{s}\)
    בדיקה:
    שתי הדרכים נותנות 180 ✓
  4. משוואת הסיבוב היא \(\theta(t) = 45 + 60t\). מה הזווית ההתחלתית ובאיזה רביע הנקודה מתחילה? באיזה כיוון מסתובב הגלגל? מהו זמן המחזור, וכמה סיבובים לדקה?
    הצג פתרון
    דרך החשיבה

    מזהים את הרכיבים: המספר החופשי הוא \(\theta_0\) והמקדם של t הוא \(\omega\). הסימן של ω נותן את הכיוון, ומ־ω מחשבים את זמן המחזור.

    1. זיהוי
      \(\theta_0 = 45^\circ\)
      \(\omega = 60^\circ/\text{s}\)
    2. רביע
      \(0^\circ \lt 45^\circ \lt 90^\circ\)
      רביע ראשון
    3. כיוון
      \(\omega \gt 0\)
      נגד השעון
    4. מחזורשאלת מרחק זוויתי
      \(T = \dfrac{360}{|\omega|} = \dfrac{360}{60} = 6\)שניות
    5. סל״דשאלת מרחק זוויתי
      \(\text{rpm} = \dfrac{60}{T} = \dfrac{60}{6} = 10\)
    תשובה:
    מתחילה
    \(45^\circ\)
    (רביע ראשון), נגד השעון
    \(T = 6\)
    שניות, 10 סל״ד
    בדיקה:
    \(6\cdot 10 = 60\)✓
  5. גלגל מבצע 3 סיבובים בשנייה עם כיוון השעון. מהי \(\omega\)?
    הצג פתרון
    דרך החשיבה

    סיבובים לשנייה כפול 360. עם השעון — סימן שלילי.

    1. נוסחהשאלת מרחק זוויתי
      \(|\omega| = 360n = 360\cdot 3 = 1080\)
    2. סימן
      עם השעון
      \(\Rightarrow \omega = -1080\)
    תשובה:
    \(\omega = -1080^\circ/\text{s}\)
    בדיקה:
    \(1080 / 360 = 3\)✓
  6. גלגל משלים סיבוב כל 20 שניות נגד כיוון השעון. מהי \(\omega\)?
    הצג פתרון
    דרך החשיבה

    360 מעלות חלקי זמן המחזור. נגד השעון — חיובי.

    1. הצבהשאלת מרחק זוויתי
      \(\omega = \dfrac{360}{T} = \dfrac{360}{20} = 18\)
    תשובה:
    \(\omega = 18^\circ/\text{s}\)
    בדיקה:
    \(18\cdot 20 = 360\)✓
  7. גלגל מסתובב ב־45 סל״ד עם כיוון השעון. כמה סיבובים בשנייה, ומהי \(\omega\)?
    הצג פתרון
    דרך החשיבה

    ממירים מדקה לשנייה, כופלים ב־360, ושמים סימן שלילי.

    1. המרהשאלת מרחק זוויתי
      \(n = \dfrac{\text{rpm}}{60} = \dfrac{45}{60} = 0.75\)
    2. חישובשאלת מרחק זוויתי
      \(|\omega| = 360n = 360\cdot 0.75 = 270\)
    3. קיצורשאלת מרחק זוויתי
      \(|\omega| = 6\cdot\text{rpm} = 6\cdot 45 = 270\)
    תשובה:
    0.75 סיבוב לשנייה
    \(\omega = -270^\circ/\text{s}\)
    בדיקה:
    שתי הדרכים נותנות 270 ✓
  8. משוואת הסיבוב היא \(\theta(t) = 300 - 30t\). מה הזווית ההתחלתית ובאיזה רביע? באיזה כיוון מסתובב הגלגל? מהו זמן המחזור, וכמה סל״ד?
    הצג פתרון
    דרך החשיבה

    מזהים את \(\theta_0\) ואת \(\omega\) מהמשוואה. ω שלילית — עם השעון.

    1. זיהוי
      \(\theta_0 = 300^\circ\)
      \(\omega = -30\)
    2. רביע
      \(270^\circ \lt 300^\circ \lt 360^\circ\)
      רביע רביעי
    3. מחזורשאלת מרחק זוויתי
      \(T = \dfrac{360}{|\omega|} = \dfrac{360}{30} = 12\)
    4. סל״דשאלת מרחק זוויתי
      \(\text{rpm} = \dfrac{60}{T} = \dfrac{60}{12} = 5\)
    תשובה:
    רביע רביעי, עם השעון
    \(T = 12\)
    שניות, 5 סל״ד
    בדיקה:
    \(6\cdot 5 = 30\)✓

רמה ב׳: מוצאים ω ו־θ₀ מתיאור שאלות 9–16

שתי זוויות, תיאור מילולי, רבע סיבוב וחזרה לאותה נקודה.

  1. ב־\(t=0\) הנקודה בזווית \(20^\circ\), וב־\(t=3\) בזווית \(110^\circ\). הגלגל מסתובב נגד השעון והשלים פחות מסיבוב. מצאו את \(\omega\), רשמו את \(\theta(t)\), ומצאו מתי הנקודה תגיע לראשונה לתחתית הגלגל.
    הצג פתרון
    דרך החשיבה

    שתי זוויות בשני זמנים: בדיוק כמו מהירות משתי נקודות, רק עם זוויות. ״פחות מסיבוב״ אומר שאין להוסיף 360. התחתית היא 270 מעלות, ופותרים משוואה ב־t.

    1. מהירות זוויתיתשאלת מרחק זוויתי
      \(\omega = \dfrac{\Delta\theta}{\Delta t} = \dfrac{110-20}{3} = 30\)
    2. משוואהשאלת מרחק זוויתי
      \(\theta(t) = \theta_0 + \omega t = 20 + 30t\)
    3. תחתיתשאלת מרחק זוויתי
      \(\theta_0 + \omega t = \theta:\ \ 20 + 30t = 270 \Rightarrow t = \dfrac{250}{30} \approx 8.33\)
    תשובה:
    \(\omega = 30^\circ/\text{s}\)
    \(\theta(t) = 20 + 30t\)
    בתחתית לראשונה אחרי כ־8.33 שניות
    בדיקה:
    \(\theta(3) = 110\)✓
  2. נקודה מתחילה בראש הגלגל. הגלגל מסתובב עם כיוון השעון ומשלים סיבוב כל 4 שניות. רשמו את \(\theta(t)\) ומצאו איפה הנקודה ב־\(t=1\) וב־\(t=3\).
    הצג פתרון
    דרך החשיבה

    מתרגמים את התיאור המילולי: ״ראש הגלגל״ הוא 90 מעלות. ״עם כיוון השעון״ נותן ω שלילי. אחר כך מציבים ומפרשים את הזווית כמקום על הגלגל.

    1. זווית התחלה
      \(\theta_0 = 90^\circ\)
    2. מהירות זוויתיתשאלת מרחק זוויתי
      \(\omega = -\dfrac{360}{T} = -\dfrac{360}{4} = -90\)
    3. משוואהשאלת מרחק זוויתי
      \(\theta(t) = \theta_0 + \omega t = 90 - 90t\)
    4. t = 1שאלת מרחק זוויתי
      \(\theta = \theta_0 + \omega t = 90 - 90\cdot 1 = 0^\circ\)
      צד ימין
    5. t = 3שאלת מרחק זוויתי
      \(\theta = \theta_0 + \omega t = 90 - 90\cdot 3 = -180^\circ\)
      צד שמאל
    תשובה:
    \(\theta(t) = 90 - 90t\)
    ב־t = 1 בצד ימין, ב־t = 3 בצד שמאל
    בדיקה:
    עם השעון מהראש מגיעים קודם לימין (רבע סיבוב, שנייה אחת) ✓
  3. ב־\(t=0\) הנקודה בצד ימין של הגלגל. אחרי 2 שניות, כשהגלגל השלים רבע סיבוב בדיוק, היא מגיעה לתחתית. באיזה כיוון הגלגל מסתובב? מצאו את \(\omega\) ורשמו את \(\theta(t)\).
    הצג פתרון
    דרך החשיבה

    הכיוון לא נתון במפורש, אבל אפשר להסיק אותו. מימין (0°) לתחתית (270° או −90°) אפשר להגיע ברבע סיבוב עם השעון, או בשלושה רבעים נגד השעון. השאלה אומרת רבע סיבוב, ולכן הכיוון הוא עם השעון.

    1. כיוון
      \(0^\circ\)
      \(-90^\circ\)
      ברבע סיבוב — עם השעון
    2. מהירות זוויתיתשאלת מרחק זוויתי
      \(\omega = \dfrac{\Delta\theta}{\Delta t} = \dfrac{-90-0}{2} = -45\)
    3. משוואהשאלת מרחק זוויתי
      \(\theta(t) = \theta_0 + \omega t = -45t\)
    תשובה:
    עם כיוון השעון
    \(\omega = -45^\circ/\text{s}\)
    \(\theta(t) = -45t\)
    בדיקה:
    \(\theta(2) = -90^\circ\)
    תחתית, אחרי רבע סיבוב ✓
  4. ב־\(t=0\) הנקודה בזווית \(30^\circ\). ב־\(t=5\) היא חוזרת לזווית הזו בפעם הראשונה. הגלגל מסתובב נגד השעון. מהו זמן המחזור? רשמו את \(\theta(t)\).
    הצג פתרון
    דרך החשיבה

    ״חוזרת לאותה זווית בפעם הראשונה״ פירושו שהגלגל השלים בדיוק סיבוב אחד. לכן הזמן הזה הוא זמן המחזור.

    1. מחזור
      \(T = 5\)
    2. מהירות זוויתיתשאלת מרחק זוויתי
      \(\omega = \dfrac{360}{T} = \dfrac{360}{5} = 72\)
    3. משוואהשאלת מרחק זוויתי
      \(\theta(t) = \theta_0 + \omega t = 30 + 72t\)
    תשובה:
    \(T = 5\)שניות
    \(\theta(t) = 30 + 72t\)
    בדיקה:
    \(\theta(5) = 390^\circ = 30^\circ + 360^\circ\)✓
  5. ב־\(t=0\) הנקודה בזווית \(150^\circ\), וב־\(t=4\) בזווית \(50^\circ\). הגלגל מסתובב עם השעון והשלים פחות מסיבוב. מצאו את \(\omega\), רשמו את \(\theta(t)\), ומצאו מתי הנקודה תגיע לראשונה לצד ימין.
    הצג פתרון
    דרך החשיבה

    הזווית קטנה — מתאים לסיבוב עם השעון. צד ימין הוא 0 מעלות.

    1. מהירות זוויתיתשאלת מרחק זוויתי
      \(\omega = \dfrac{\Delta\theta}{\Delta t} = \dfrac{50-150}{4} = -25\)
    2. משוואהשאלת מרחק זוויתי
      \(\theta(t) = \theta_0 + \omega t = 150 - 25t\)
    3. צד ימיןשאלת מרחק זוויתי
      \(\theta_0 + \omega t = \theta:\ \ 150 - 25t = 0 \Rightarrow t = 6\)
    תשובה:
    \(\omega = -25^\circ/\text{s}\)
    צד ימין
    \(t=6\)
    בדיקה:
    \(\theta(4) = 50\)✓
  6. נקודה מתחילה בתחתית הגלגל. הגלגל מסתובב נגד השעון ומשלים סיבוב כל 6 שניות. רשמו את \(\theta(t)\) ומצאו איפה הנקודה ב־\(t=1.5\) וב־\(t=3\).
    הצג פתרון
    דרך החשיבה

    ״תחתית״ היא 270 מעלות. נגד השעון — ω חיובית. מזווית גדולה מ־360 מחסירים 360.

    1. רכיבים
      \(\theta_0 = 270^\circ\)
      \(\omega = 60\)
    2. משוואהשאלת מרחק זוויתי
      \(\theta(t) = \theta_0 + \omega t = 270 + 60t\)
    3. t = 1.5שאלת מרחק זוויתי
      \(\theta = \theta_0 + \omega t = 270 + 60\cdot 1.5 = 360^\circ = 0^\circ\)
      צד ימין
    4. t = 3שאלת מרחק זוויתי
      \(\theta = \theta_0 + \omega t = 270 + 60\cdot 3 = 450^\circ = 90^\circ\)
      ראש הגלגל
    תשובה:
    ב־1.5 בצד ימין, ב־3 בראש הגלגל
    בדיקה:
    חצי מחזור (3 שניות) מהתחתית מגיע לראש ✓
  7. נקודה מתחילה בראש הגלגל. אחרי 3 שניות, כשהגלגל השלים רבע סיבוב בדיוק, היא בצד שמאל. באיזה כיוון הגלגל מסתובב? מצאו את \(\omega\) ורשמו את \(\theta(t)\).
    הצג פתרון
    דרך החשיבה

    מהראש (90) לצד שמאל (180) ברבע סיבוב — הזווית גדלה, כלומר נגד השעון.

    1. כיוון
      \(90^\circ \to 180^\circ\)
      נגד השעון
    2. מהירות זוויתיתשאלת מרחק זוויתי
      \(\omega = \dfrac{\Delta\theta}{\Delta t} = \dfrac{90}{3} = 30\)
    3. משוואהשאלת מרחק זוויתי
      \(\theta(t) = \theta_0 + \omega t = 90 + 30t\)
    תשובה:
    נגד השעון
    \(\omega = 30^\circ/\text{s}\)
    בדיקה:
    \(\theta(3) = 180\)✓
  8. נקודה מתחילה בזווית \(0^\circ\). אחרי 4 שניות היא שוב ב־\(0^\circ\), אחרי שהגלגל השלים בדיוק 2 סיבובים עם כיוון השעון. מהו זמן המחזור? מצאו את \(\omega\).
    הצג פתרון
    דרך החשיבה

    שני סיבובים ב־4 שניות: סיבוב כל 2 שניות. עם השעון — ω שלילית.

    1. מחזורשאלת מרחק זוויתי
      \(T = \dfrac{t}{N} = \dfrac{4}{2} = 2\)
    2. מהירות זוויתיתשאלת מרחק זוויתי
      \(\omega = -\dfrac{360}{T} = -\dfrac{360}{2} = -180\)
    3. משוואהשאלת מרחק זוויתי
      \(\theta(t) = \theta_0 + \omega t = -180t\)
    תשובה:
    \(T = 2\)שניות
    \(\omega = -180^\circ/\text{s}\)
    בדיקה:
    \(\theta(4) = -720^\circ\)
    שני סיבובים שלמים ✓

רמה ג׳: θ₀ מקואורדינטות שאלות 17–20

הזווית ההתחלתית מתוך מיקום המרכז ומיקום הנקודה.

  1. מרכז הגלגל ב־\(t=0\) ב־\((3,2)\), והנקודה P ב־\((3,-2)\). הגלגל מבצע 3 סיבובים בדקה עם כיוון השעון. מצאו את R, את \(\theta_0\) ואת \(\omega\).
    הצג פתרון
    דרך החשיבה

    הרדיוס הוא המרחק בין P למרכז. הזווית ההתחלתית היא הזווית של הווקטור מהמרכז אל P: מחשבים את ההפרשים, מחלקים ב־R ומקבלים cos ו־sin של הזווית.

    1. הפרשיםשאלת מרחקשאלת מיקום
      \(x_P - x_C = 0\)
      \(y_P - y_C = -4\)
    2. רדיוסשאלת מיקום
      \(R = |P - C| = \sqrt{0^2 + (-4)^2} = 4\)
    3. זוויתשאלת מיקום
      \(\cos\theta_0 = \dfrac{x_P - x_C}{R} = 0\)
      \(\sin\theta_0 = \dfrac{y_P - y_C}{R} = -1 \Rightarrow \theta_0 = 270^\circ\)
    4. מהירות זוויתיתשאלת מרחק זוויתי
      \(\omega = -6\cdot\text{rpm} = -6\cdot 3 = -18\)
    תשובה:
    \(R = 4\)
    \(\theta_0 = 270^\circ\)
    \(\omega = -18^\circ/\text{s}\)
    בדיקה:
    P מתחת למרכז בדיוק — תחתית הגלגל, 270 מעלות ✓
  2. מרכז הגלגל ב־\(t=0\) ב־\((0,0)\), והנקודה P ב־\((-1,\sqrt3)\). הגלגל משלים סיבוב כל 12 שניות נגד השעון. מצאו את R ואת \(\theta_0\). מתי P תגיע לראשונה לצד שמאל של הגלגל?
    הצג פתרון
    דרך החשיבה

    כמו בשאלה הקודמת, אבל הזווית לא על ציר. cos שלילי ו־sin חיובי: רביע שני. מזהים את הזווית לפי הערכים המוכרים (cos = −½). צד שמאל הוא 180 מעלות.

    1. רדיוסשאלת מיקום
      \(R = \sqrt{(x_P - x_C)^2 + (y_P - y_C)^2} = \sqrt{1+3} = 2\)
    2. זוויתשאלת מיקום
      \(\cos\theta_0 = \dfrac{x_P - x_C}{R} = -\tfrac12\)
      \(\sin\theta_0 = \dfrac{y_P - y_C}{R} = \tfrac{\sqrt3}{2} \Rightarrow \theta_0 = 120^\circ\)
    3. מהירות זוויתיתשאלת מרחק זוויתי
      \(\omega = \dfrac{360}{T} = \dfrac{360}{12} = 30\)
    4. זמןשאלת מרחק זוויתי
      \(\theta_0 + \omega t = \theta:\ \ 120 + 30t = 180 \Rightarrow t = 2\)
    תשובה:
    \(R = 2\)
    \(\theta_0 = 120^\circ\)
    צד שמאל
    \(t=2\)
    בדיקה:
    \(2\cos 120^\circ = -1\)
    \(2\sin 120^\circ = \sqrt3\)✓
  3. מרכז הגלגל ב־\(t=0\) ב־\((-2,1)\), והנקודה P ב־\((1,1)\). הגלגל מסתובב ב־10 סל״ד נגד השעון. מצאו את R, את \(\theta_0\) ואת \(\omega\).
    הצג פתרון
    דרך החשיבה

    ההפרש P פחות המרכז נותן את הרדיוס ואת הכיוון של P.

    1. הפרשיםשאלת מיקום
      \(P - C = (x_P - x_C,\ y_P - y_C) = (1-(-2),\ 1-1) = (3, 0)\)
    2. רדיוס וזוויתשאלת מיקום
      \(R = |P - C| = 3\)
      \(\theta_0 = 0^\circ\)
    3. מהירות זוויתיתשאלת מרחק זוויתי
      \(\omega = 6\cdot\text{rpm} = 6\cdot 10 = 60\)
    תשובה:
    \(R = 3\)
    \(\theta_0 = 0^\circ\)
    \(\omega = 60^\circ/\text{s}\)
    בדיקה:
    P מימין למרכז בדיוק ✓
  4. מרכז הגלגל ב־\(t=0\) ב־\((1,1)\), והנקודה P ב־\((1-\sqrt2,\ 1+\sqrt2)\). הגלגל משלים סיבוב כל 8 שניות עם השעון. מצאו את R ואת \(\theta_0\). מתי P תגיע לראשונה לראש הגלגל?
    הצג פתרון
    דרך החשיבה

    ההפרש \((-\sqrt2, \sqrt2)\): cos שלילי ו־sin חיובי, רביע שני. עם השעון הזווית קטנה, ולכן מ־135 מגיעים קודם ל־90.

    1. רדיוסשאלת מיקום
      \(R = \sqrt{(x_P - x_C)^2 + (y_P - y_C)^2} = \sqrt{2+2} = 2\)
    2. זוויתשאלת מיקום
      \(\cos\theta_0 = \dfrac{x_P - x_C}{R} = -\tfrac{\sqrt2}{2}\)
      \(\sin\theta_0 = \dfrac{y_P - y_C}{R} = \tfrac{\sqrt2}{2} \Rightarrow \theta_0 = 135^\circ\)
    3. מהירות זוויתיתשאלת מרחק זוויתי
      \(\omega = -\dfrac{360}{T} = -\dfrac{360}{8} = -45\)
    4. זמןשאלת מרחק זוויתי
      \(\theta_0 + \omega t = \theta:\ \ 135 - 45t = 90 \Rightarrow t = 1\)
    תשובה:
    \(R = 2\)
    \(\theta_0 = 135^\circ\)
    ראש הגלגל
    \(t=1\)
    בדיקה:
    \(2\cos 135^\circ = -\sqrt2\)✓
