תרגול חזרה: נקודה על גלגל

12 שאלות חזרה. שאלות 1–10 על גלגל שהמרכז שלו קבוע: הצבה בנוסחת תנועה, ביטוי לגובה בגלגל ענק, בעיה הפוכה (מהגובה לזמן), זווית התחלה מתוך נקודה, ושאלות מסכמות על שתי קרוניות. שאלות 11–12 על גלגל של עגלה בתנועה, שהמרכז שלו נע בקו ישר. בפתרון של כל שאלה יש אנימציה של הגלגל. ההסבר על הבעיה ההפוכה בדף מהגובה לזווית ולזמן.

תוכן
  1. רמה א׳: הצבה וביטוי לגובה (1–4)
  2. רמה ב׳: בעיה הפוכה וזווית התחלה (5–7)
  3. רמה ג׳: רמת בגרות (8–10)
  4. רמה ד׳: גלגל של עגלה בתנועה (11–12)
\(x = x_C + R\cos(\theta_0 + \omega t)\)
\(y = y_C + R\sin(\theta_0 + \omega t)\)

רמה א׳: הצבה וביטוי לגובה שאלות 1–4

  1. נקודה P על גלגל נעה כך שבזמן \(t\) (בשניות) המיקום שלה הוא:
    \(x(t) = 4 + 10\cos(30^\circ + 45t)\)
    \(y(t) = 6 + 10\sin(30^\circ + 45t)\)
    מצאו את מיקום P אחרי 2 שניות ואחרי 8 שניות.
    הצג פתרון
    דרך החשיבה

    הנוסחה כבר כתובה, ולכן כל העבודה היא הצבה: קודם מחשבים את הזווית, ורק אחר כך cos ו־sin. זווית גדולה מ־360° מקטינים בסיבוב שלם.

    אנימציה: הנקודה P על הגלגל. הפעילו, גררו את הזמן, או קפצו לזמנים שבשאלה
    1. נתונים
      \(x_C = 4,\ y_C = 6,\ R = 10\)
      \(\theta_0 = 30^\circ,\ \omega = 45^\circ/\text{s}\)
    2. הצבה \(t = 2\)שאלת מרחק זוויתישאלת מיקום
      זווית
      \(\theta = \theta_0 + \omega t = 30^\circ + 45\cdot2 = 120^\circ\)
      \(x = x_C + R\cos\theta = 4 + 10\cos120^\circ = 4 - 5 = -1\)
      \(y = y_C + R\sin\theta = 6 + 10\sin120^\circ = 6 + 5\sqrt3 \approx 14.66\)
    3. הצבה \(t = 8\)שאלת מרחק זוויתישאלת מיקום
      זווית
      \(\theta = \theta_0 + \omega t = 30^\circ + 45\cdot8 = 390^\circ \equiv 30^\circ\)
      \(x = x_C + R\cos\theta = 4 + 10\cos30^\circ = 4 + 5\sqrt3 \approx 12.66\)
      \(y = y_C + R\sin\theta = 6 + 10\sin30^\circ = 11\)
    תשובה:
    \(t = 2:\ P(-1,\ 14.66)\)
    \(t = 8:\ P(12.66,\ 11)\)
    בדיקה:
    המרחק של P מהמרכז שווה לרדיוס:
    \(\sqrt{(-1-4)^2 + (14.66-6)^2} = \sqrt{25 + 75} = 10\ \checkmark\)
  2. נקודה P על גלגל נעה לפי:
    \(x(t) = -3 + 8\cos(180^\circ - 60t)\)
    \(y(t) = 5 + 8\sin(180^\circ - 60t)\)
    מצאו את מיקום P אחרי שנייה אחת ואחרי 4.5 שניות.
    הצג פתרון
    דרך החשיבה

    המינוס לפני 60t אומר שהזווית קטנה עם הזמן: הגלגל מסתובב עם כיוון השעון. זווית שלילית היא חוקית, ואפשר להציב אותה כמו שהיא.

    אנימציה: הנקודה P על הגלגל. הפעילו, גררו את הזמן, או קפצו לזמנים שבשאלה
    1. נתונים
      \(x_C = -3,\ y_C = 5,\ R = 8\)
      \(\theta_0 = 180^\circ,\ \omega = -60^\circ/\text{s}\)
    2. הצבה \(t = 1\)שאלת מרחק זוויתישאלת מיקום
      זווית
      \(\theta = \theta_0 + \omega t = 180^\circ - 60\cdot1 = 120^\circ\)
      \(x = x_C + R\cos\theta = -3 + 8\cos120^\circ = -7\)
      \(y = y_C + R\sin\theta = 5 + 8\sin120^\circ = 5 + 4\sqrt3 \approx 11.93\)
    3. הצבה \(t = 4.5\)שאלת מרחק זוויתישאלת מיקום
      זווית
      \(\theta = \theta_0 + \omega t = 180^\circ - 60\cdot4.5 = -90^\circ\)
      \(x = x_C + R\cos\theta = -3 + 8\cos(-90^\circ) = -3\)
      \(y = y_C + R\sin\theta = 5 + 8\sin(-90^\circ) = -3\)
    תשובה:
    \(t = 1:\ P(-7,\ 11.93)\)
    \(t = 4.5:\ P(-3,\ -3)\)
    בדיקה:
    ב־t = 4.5 הזווית −90°, הנקודה הנמוכה: x כמו המרכז, ו־y נמוך ממנו ברדיוס:
    \(y = 5 - 8 = -3\ \checkmark\)
  3. מרכז C של גלגל ענק נמצא בגובה 30 מ׳ מעל הקרקע, וקוטר הגלגל 50 מ׳. הגלגל משלים סיבוב בכל 4 דקות, נגד כיוון השעון. קרונית P עולה בנקודה הנמוכה ביותר. כתבו ביטוי לגובה של P אחרי \(t\) שניות, ומצאו את הגובה שלה אחרי דקה ואחרי 100 שניות. מה המרחק האופקי של P מהציר אחרי 100 שניות?
    הצג פתרון
    דרך החשיבה

    מתרגמים שלושה נתונים: קוטר ← רדיוס, זמן מחזור בדקות ← ω בשניות, "הנקודה הנמוכה" ← זווית התחלה. אחר כך כל סעיף הוא הצבה. "מרחק אופקי מהציר" הוא \(|x - x_C|\).

    אנימציה: הקרונית P על הגלגל. הפעילו, גררו את הזמן, או קפצו לזמנים שבשאלה
    1. נתונים
      \(y_C = 30\)מ׳
      \(d = 50\)מ׳
      \(R = \tfrac{d}{2} = 25\)מ׳
      \(\theta_0 = 270^\circ\)
    2. זמן מחזורהמרת יחידותשאלת מרחק זוויתי
      \(T = 4\cdot60 = 240\)שניות
      \(\omega = \tfrac{360^\circ}{T} = \tfrac{360^\circ}{240} = 1.5^\circ/\text{s}\)
    3. ביטוי לגובהשאלת מרחק זוויתישאלת מיקום
      \(y = y_C + R\sin(\theta_0 + \omega t)\)
      \(h(t) = 30 + 25\sin(270^\circ + 1.5t)\)
    4. הצבה \(t = 60\)שאלת מרחק זוויתישאלת מיקום
      \(\theta = 270^\circ + 1.5\cdot60 = 360^\circ\)
      \(h = 30 + 25\sin360^\circ = 30\)מ׳
    5. הצבה \(t = 100\)שאלת מרחק זוויתישאלת מיקום
      \(\theta = 270^\circ + 1.5\cdot100 = 420^\circ \equiv 60^\circ\)
      \(h = 30 + 25\sin60^\circ \approx 51.65\)מ׳
      מרחק אופקי
      \(|x - x_C| = |R\cos\theta| = 25\cos60^\circ = 12.5\)מ׳
    תשובה:
    \(h(t) = 30 + 25\sin(270^\circ + 1.5t)\)
    \(h(60) = 30,\ h(100) \approx 51.65\)מ׳
    \(|x - x_C| = 12.5\)מ׳
    בדיקה:
    אחרי דקה עבר רבע סיבוב, והקרונית עלתה מהתחתית לגובה המרכז:
    \(h(60) = y_C = 30\ \checkmark\)
  4. הנקודה הנמוכה של גלגל ענק נמצאת בגובה 2 מ׳ מעל הקרקע, וקוטר הגלגל 36 מ׳. הגלגל משלים סיבוב בכל 3 דקות, נגד כיוון השעון. בהתחלה קרונית P נמצאת בראש הגלגל. כתבו ביטוי לגובה של P, ומצאו את הגובה שלה אחרי 30 שניות ואחרי 105 שניות. מה המרחק האופקי של P מהציר אחרי 30 שניות?
    הצג פתרון
    דרך החשיבה

    המלכודת: הגובה הנתון הוא של הנקודה הנמוכה ולא של המרכז. המרכז גבוה ממנה ברדיוס אחד. "בראש הגלגל" ← 90°.

    אנימציה: הקרונית P על הגלגל. הפעילו, גררו את הזמן, או קפצו לזמנים שבשאלה
    1. נתונים
      \(d = 36\)מ׳
      \(R = \tfrac{d}{2} = 18\)מ׳
      \(y_C = 2 + R = 2 + 18 = 20\)מ׳
      \(\theta_0 = 90^\circ\)
    2. זמן מחזורהמרת יחידותשאלת מרחק זוויתי
      \(T = 3\cdot60 = 180\)שניות
      \(\omega = \tfrac{360^\circ}{T} = \tfrac{360^\circ}{180} = 2^\circ/\text{s}\)
    3. ביטוי לגובהשאלת מרחק זוויתישאלת מיקום
      \(y = y_C + R\sin(\theta_0 + \omega t)\)
      \(h(t) = 20 + 18\sin(90^\circ + 2t)\)
    4. הצבה \(t = 30\)שאלת מרחק זוויתישאלת מיקום
      \(\theta = 90^\circ + 2\cdot30 = 150^\circ\)
      \(h = 20 + 18\sin150^\circ = 29\)מ׳
      מרחק אופקי
      \(|x - x_C| = |R\cos\theta| = 18|\cos150^\circ| = 9\sqrt3 \approx 15.59\)מ׳
    5. הצבה \(t = 105\)שאלת מרחק זוויתישאלת מיקום
      \(\theta = 90^\circ + 2\cdot105 = 300^\circ\)
      \(h = 20 + 18\sin300^\circ \approx 4.41\)מ׳
    תשובה:
    \(h(t) = 20 + 18\sin(90^\circ + 2t)\)
    \(h(30) = 29,\ h(105) \approx 4.41\)מ׳
    \(|x - x_C| \approx 15.59\)מ׳
    בדיקה:
    ב־t = 0 הקרונית בראש, בגובה של הנקודה הגבוהה:
    \(h(0) = 20 + 18 = 38 = 2 + 36\ \checkmark\)

רמה ב׳: בעיה הפוכה וזווית התחלה שאלות 5–7

  1. כנף של טחנת רוח באורך 10 מ׳ מסתובבת סביב ציר C בגובה 25 מ׳, ‏15 סיבובים לדקה עם כיוון השעון. בהתחלה הכנף פונה אופקית שמאלה. מצאו את המהירות הזוויתית ואת זמן המחזור. מתי לראשונה קצה הכנף P בגובה 30 מ׳, ומתי בפעם השנייה? כמה זמן בכל סיבוב הוא מעל 30 מ׳? מצאו את כל הזמנים שבהם הוא בגובה 30 מ׳.
    הצג פתרון
    דרך החשיבה

    זו בעיה הפוכה: נתון גובה ומחפשים זמן. מבודדים את sinθ, מוצאים את שתי הזוויות בסיבוב, ובוחרים לפי כיוון הסיבוב איזו מגיעה קודם. עם כיוון השעון הזווית יורדת.

    אנימציה: הקרונית P על הגלגל. הפעילו, גררו את הזמן, או קפצו לזמנים שבשאלה
    1. נתונים
      \(R = 10\)מ׳
      \(y_C = 25\)מ׳
      \(\theta_0 = 180^\circ\)
    2. מהירות זוויתיתהמרת יחידותשאלת מרחק זוויתי
      \(\omega = -\tfrac{15\cdot360^\circ}{60\ \text{s}} = -90^\circ/\text{s}\)
      \(T = \tfrac{360^\circ}{|\omega|} = \tfrac{360^\circ}{90^\circ} = 4\)שניות
    3. מהגובה לזוויתשאלת מיקום
      \(y = y_C + R\sin\theta\)
      \(25 + 10\sin\theta = 30\)
      \(\sin\theta = \tfrac{30 - 25}{10} = \tfrac12\)
      \(\theta = 30^\circ\ \ \text{or}\ \ \theta = 150^\circ\)
    4. מהזווית לזמןשאלת מרחק זוויתי
      מ־180° הזווית יורדת, ולכן מגיעים קודם ל־150° ואחר כך ל־30°
      \(\theta = \theta_0 + \omega t:\ 180 - 90t = 150 \Rightarrow t = \tfrac13\)
      \(180 - 90t = 30 \Rightarrow t = \tfrac53\)
    5. מעל 30 מ׳שאלת מרחק זוויתי
      \(\tfrac53 - \tfrac13 = \tfrac43\)שניות
    6. כל הזמניםשאלת מרחק זוויתי
      \(t = \tfrac13 + 4k\ \ \text{or}\ \ t = \tfrac53 + 4k,\quad k = 0, 1, 2, \dots\)
    תשובה:
    \(\omega = -90^\circ/\text{s},\ T = 4\)שניות
    \(t = \tfrac13,\ t = \tfrac53\)שניות
    \(\tfrac43\)שניות מעל 30 מ׳ בכל סיבוב
    \(t = \tfrac13 + 4k,\ \ t = \tfrac53 + 4k\)
    בדיקה:
    הצבה של t = ⅓:
    \(\theta = 180^\circ - 30^\circ = 150^\circ,\quad y = 25 + 10\cdot\tfrac12 = 30\ \checkmark\)
  2. מרכז C של גלגל ענק נמצא בגובה 15 מ׳, ורדיוס הגלגל 12 מ׳. הגלגל מסתובב עם כיוון השעון, סיבוב בכל דקה. בהתחלה קרונית P נמצאת מימין לציר, בגובה הציר. מתי לראשונה P בגובה 9 מ׳, ומתי בפעם השנייה? כמה זמן בכל סיבוב היא נמוך מ־9 מ׳? מצאו את כל הזמנים שבהם היא בגובה 9 מ׳.
    הצג פתרון
    דרך החשיבה

    הגובה 9 נמוך מהמרכז, ולכן sinθ שלילי. הקרונית מתחילה ב־0° ויורדת מיד (עם כיוון השעון), ולכן מגיעה לגובה הזה מהר.

    אנימציה: הקרונית P על הגלגל. הפעילו, גררו את הזמן, או קפצו לזמנים שבשאלה
    1. נתונים
      \(y_C = 15\)מ׳
      \(R = 12\)מ׳
      \(\theta_0 = 0^\circ\)
    2. מהירות זוויתיתהמרת יחידותשאלת מרחק זוויתי
      \(T = 60\)שניות
      \(\omega = -\tfrac{360^\circ}{T} = -\tfrac{360^\circ}{60} = -6^\circ/\text{s}\)
    3. מהגובה לזוויתשאלת מיקום
      \(y = y_C + R\sin\theta\)
      \(15 + 12\sin\theta = 9\)
      \(\sin\theta = \tfrac{9 - 15}{12} = -\tfrac12\)
      \(\theta = -30^\circ\ \ \text{or}\ \ \theta = -150^\circ\)
    4. מהזווית לזמןשאלת מרחק זוויתי
      \(\theta = \theta_0 + \omega t:\ -6t = -30 \Rightarrow t = 5\)
      \(-6t = -150 \Rightarrow t = 25\)
    5. נמוך מ־9 מ׳שאלת מרחק זוויתי
      \(25 - 5 = 20\)שניות
    6. כל הזמניםשאלת מרחק זוויתי
      \(t = 5 + 60k\ \ \text{or}\ \ t = 25 + 60k,\quad k = 0, 1, 2, \dots\)
    תשובה:
    \(t = 5,\ t = 25\)שניות
    \(20\)שניות מתחת ל־9 מ׳ בכל סיבוב
    \(t = 5 + 60k,\ \ t = 25 + 60k\)
    בדיקה:
    הצבה של t = 5:
    \(y = 15 + 12\sin(-30^\circ) = 15 - 6 = 9\ \checkmark\)
  3. מרכז הגלגל C, רדיוסו 4, ונקודה P על הגלגל נמצאת בהתחלה בנקודה A:
    \(C(-2,\ 4)\)
    \(A(-2+2\sqrt2,\ 4-2\sqrt2)\)
    הגלגל מסתובב נגד כיוון השעון, 10 סיבובים לדקה. מצאו את זווית ההתחלה, את המהירות הזוויתית ואת זמן המחזור. איפה P אחרי 2 שניות? מתי לראשונה P בראש הגלגל, ומתי בפעם השנייה?
    הצג פתרון
    דרך החשיבה

    כשנקודת ההתחלה נתונה בקואורדינטות, מחסירים את המרכז ומחלקים ברדיוס כדי לקבל cos ו־sin של זווית ההתחלה. הסימנים שלהם קובעים את הרביע.

    אנימציה: הנקודה P על הגלגל. הפעילו, גררו את הזמן, או קפצו לזמנים שבשאלה
    1. נתונים
      \(C(-2,\ 4),\ R = 4\)
      \(A(-2+2\sqrt2,\ 4-2\sqrt2),\ t_A = 0\)
    2. זווית התחלהשאלת מיקום
      \(\cos\theta_0 = \tfrac{x_A - x_C}{R} = \tfrac{2\sqrt2}{4} = \tfrac{\sqrt2}{2}\)
      \(\sin\theta_0 = \tfrac{y_A - y_C}{R} = \tfrac{-2\sqrt2}{4} = -\tfrac{\sqrt2}{2}\)
      cos חיובי ו־sin שלילי: רביע IV
      \(\theta_0 = 315^\circ\)
    3. מהירות זוויתיתהמרת יחידותשאלת מרחק זוויתי
      \(\omega = \tfrac{10\cdot360^\circ}{60\ \text{s}} = 60^\circ/\text{s}\)
      \(T = \tfrac{360^\circ}{60^\circ} = 6\)שניות
    4. הצבה \(t = 2\)שאלת מרחק זוויתישאלת מיקום
      \(\theta = \theta_0 + \omega t = 315^\circ + 60\cdot2 = 435^\circ \equiv 75^\circ\)
      \(x = x_C + R\cos\theta = -2 + 4\cos75^\circ \approx -0.97\)
      \(y = y_C + R\sin\theta = 4 + 4\sin75^\circ \approx 7.86\)
    5. בראש הגלגלשאלת מרחק זוויתי
      הזווית עולה מ־315° עד 450° (≡ 90°)
      \(\theta_0 + \omega t = 450^\circ:\ 315 + 60t = 450 \Rightarrow t = 2.25\)
      \(t = 2.25 + T = 8.25\)שניות
    תשובה:
    \(\theta_0 = 315^\circ,\ \omega = 60^\circ/\text{s},\ T = 6\)
    \(t = 2:\ P(-0.97,\ 7.86)\)
    \(t = 2.25,\ t = 8.25\)שניות
    בדיקה:
    ב־t = 2 הזווית 75°, קרוב ל־90°, ובאמת P קרובה לראש (גובה הראש y_C + R = 8) ✓

רמה ג׳: רמת בגרות שאלות 8–10

  1. מרכז הגלגל C, רדיוסו 10, ונקודה P על הגלגל נמצאת בהתחלה בנקודה A:
    \(C(1,\ -3)\)
    \(A(-4,\ -3+5\sqrt3)\)
    הגלגל מסתובב עם כיוון השעון, 2 סיבובים לדקה. מצאו את זווית ההתחלה, את המהירות הזוויתית ואת זמן המחזור. איפה P אחרי 5 שניות? מתי לראשונה P בנקודה הימנית ביותר של הגלגל, ומתי בפעם השנייה?
    הצג פתרון
    דרך החשיבה

  1. עגלה נוסעת ימינה על כביש ישר במהירות קבועה. רדיוס הגלגל של העגלה 0.3 מ׳, הגלגל מתגלגל בלי החלקה ומשלים סיבוב בכל 1.2 שניות. בהתחלה מרכז הגלגל C נמצא בנקודה \(A(0,\ 0.3)\), והוונטיל P נמצא בראש הגלגל. הכביש הוא הציר \(y = 0\). באיזה כיוון מסתובב הגלגל? מצאו את המהירות הזוויתית ואת מהירות העגלה. כתבו את משוואות התנועה של הוונטיל. איפה הוונטיל אחרי 0.3 שניות ואחרי 0.9 שניות? מתי לראשונה הוונטיל נוגע בכביש, כמה נסעה העגלה עד אז, ומתי הוא נוגע בכביש בפעם השנייה?
    הצג פתרון
    דרך החשיבה

    שתי תנועות מתחברות: המרכז נע בקו ישר (שאלת מרחק), והוונטיל מסתובב סביב המרכז (שאלת מרחק זוויתי ושאלת מיקום). בלי החלקה, בכל סיבוב העגלה נוסעת היקף אחד של הגלגל, ומזה מקבלים את המהירות. עגלה שנוסעת ימינה מסובבת את הגלגל עם כיוון השעון, ולכן ω שלילית.

    אנימציה: הוונטיל P על גלגל העגלה, והמסלול שהוא משרטט. הפעילו, גררו את הזמן, או קפצו לזמנים שבשאלה
    1. נתונים
      \(R = 0.3\)מ׳
      \(A(0,\ 0.3):\ x_A = 0,\ y_A = 0.3\)
      \(T = 1.2\)שניות

    2. כיוון ומהירות זוויתיתשאלת מרחק זוויתי
      נוסעת ימינה ← הגלגל מסתובב עם כיוון השעון
      \(\omega = -\tfrac{360^\circ}{T} = -\tfrac{360^\circ}{1.2} = -300^\circ/\text{s}\)
    3. מהירות העגלהשאלת מרחק
      בסיבוב אחד העגלה נוסעת היקף אחד
      \(L = 2\pi R = 2\pi\cdot0.3 = 0.6\pi \approx 1.885\)מ׳
      \(v_x = \tfrac{L}{T} = \tfrac{0.6\pi}{1.2} = 0.5\pi \approx 1.571\)מ׳/ש׳
      \(v_y = 0\)
    4. משוואות התנועהשאלת מרחקשאלת מרחק זוויתישאלת מיקום
      \(x = x_A + v_x t + R\cos(\theta_0 + \omega t)\)
      \(x(t) = 0.5\pi t + 0.3\cos(90^\circ - 300t)\)
      \(y = y_A + v_y t + R\sin(\theta_0 + \omega t)\)
      \(y(t) = 0.3 + 0.3\sin(90^\circ - 300t)\)
    5. הצבה \(t = 0.3\)שאלת מרחקשאלת מרחק זוויתישאלת מיקום
      מרכז
      \(x_C = x_A + v_x t = 0.5\pi\cdot0.3 = 0.15\pi \approx 0.471\)
      זווית
      \(\theta = 90^\circ - 300\cdot0.3 = 0^\circ\)
      \(x = x_C + R\cos\theta = 0.15\pi + 0.3 \approx 0.77\)
      \(y = y_C + R\sin\theta = 0.3 + 0 = 0.3\)
    6. הצבה \(t = 0.9\)שאלת מרחקשאלת מרחק זוויתישאלת מיקום
      מרכז
      \(x_C = 0.5\pi\cdot0.9 = 0.45\pi \approx 1.414\)
      זווית
      \(\theta = 90^\circ - 300\cdot0.9 = -180^\circ\)
      \(x = x_C + R\cos\theta = 0.45\pi - 0.3 \approx 1.11\)
      \(y = 0.3 + 0.3\sin(-180^\circ) = 0.3\)
    7. נגיעה בכביששאלת מרחק זוויתישאלת מרחק
      הוונטיל בכביש כשהוא בתחתית הגלגל
      \(\theta_0 + \omega t = -90^\circ:\ 90 - 300t = -90 \Rightarrow t = 0.6\)
      \(\Delta x = v_x t = 0.5\pi\cdot0.6 = 0.3\pi \approx 0.94\)מ׳
      \(t = 0.6 + T = 1.8\)שניות
    תשובה:
    עם כיוון השעון
    \(\omega = -300^\circ/\text{s}\)
    \(v_x = 0.5\pi \approx 1.57\)מ׳/ש׳
    \(x(t) = 0.5\pi t + 0.3\cos(90^\circ - 300t)\)
    \(y(t) = 0.3 + 0.3\sin(90^\circ - 300t)\)
