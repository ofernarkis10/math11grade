תרגול משולב: בונים את הנוסחה

18 שאלות שמחברות את שתי המשוואות לשאלה אחת. בכל שאלה: מוצאים קודם את כל 7 הרכיבים, רושמים את הנוסחה המלאה, ורק אז מציבים. ההסבר והשיטה בדף התאוריה.

תוכן
  1. רמה א׳: גלגל חופשי (1–8)
  2. רמה ב׳: גלגל מתגלגל (9–14)
  3. רמה ג׳: רמת בגרות (15–18)
רכיב\(x_0\)\(y_0\)\(v_x\)\(v_y\)\(R\)\(\theta_0\)\(\omega\)
ערך

טבלת עבודה: מעתיקים למחברת וממלאים בכל שאלה לפני שרושמים את הנוסחה.

\(x(t) = \color{#1f6f8b}{x_0 + v_x t} + R\cos(\color{#b4561e}{\theta_0 + \omega t})\)
\(y(t) = \color{#1f6f8b}{y_0 + v_y t} + R\sin(\color{#b4561e}{\theta_0 + \omega t})\)

רמה א׳: גלגל חופשי שאלות 1–8

מוצאים את 7 הרכיבים, רושמים את הנוסחה ומציבים; גם קריאה הפוכה של נוסחה.

  1. גלגל ברדיוס 2. המרכז מתחיל ב־\((0,5)\) עם \(v_x = 3,\ v_y = 1\). הגלגל מסתובב נגד השעון ב־\(90^\circ\) לשנייה. ב־\(t=0\) הנקודה P בצד ימין של הגלגל. (א) מלאו את טבלת הרכיבים ורשמו את הנוסחה. (ב) מצאו את P ב־\(t=1\) וב־\(t=2\).
    הצג פתרון
    דרך החשיבה

    כל הרכיבים נתונים כמעט ישירות; צריך רק לתרגם ״צד ימין״ לזווית 0. אחרי שהנוסחה כתובה, בכל זמן מחשבים קודם את המרכז ואת הזווית, ואז מוסיפים את ההזזה מהמרכז.

    1. רכיבים: \(x_0=0,\ y_0=5,\ v_x=3,\ v_y=1,\ R=2,\ \theta_0=0^\circ,\ \omega=90\)
    2. נוסחה: \(x(t) = 3t + 2\cos(90t),\ y(t) = 5 + t + 2\sin(90t)\)
    3. t = 1: מרכז \((3,6)\), זווית \(90^\circ\) — \(P = (3, 6+2) = (3,8)\)
    4. t = 2: מרכז \((6,7)\), זווית \(180^\circ\) — \(P = (6-2, 7) = (4,7)\)

    תשובה: \(P(1) = (3,8),\ P(2) = (4,7)\)

    בדיקה: המרחק של P מהמרכז בשני המקרים הוא 2 = R ✓

  2. מרכז גלגל ברדיוס 3 עובר מ־\((1,1)\) ל־\((11,6)\) תוך 5 שניות. ב־\(t=0\) הנקודה P בראש הגלגל. הגלגל משלים סיבוב כל 12 שניות עם כיוון השעון. רשמו את הנוסחה ומצאו את P ב־\(t=3\) וב־\(t=6\).
    הצג פתרון
    דרך החשיבה

    שני רכיבים צריך לחשב: את מהירות המרכז משתי נקודות, ואת ω מזמן המחזור עם סימן שלילי. ״ראש הגלגל״ הוא 90 מעלות.

    1. מרכז: \(v_x = \dfrac{10}{5} = 2,\ v_y = \dfrac{5}{5} = 1\)
    2. סיבוב: \(\theta_0 = 90^\circ,\ \omega = -\dfrac{360}{12} = -30\)
    3. נוסחה: \(x(t) = 1 + 2t + 3\cos(90-30t),\ y(t) = 1 + t + 3\sin(90-30t)\)
    4. t = 3: מרכז \((7,4)\), זווית \(0^\circ\) — \(P = (10,4)\)
    5. t = 6: מרכז \((13,7)\), זווית \(-90^\circ\) — \(P = (13,4)\)

    תשובה: \(P(3) = (10,4),\ P(6) = (13,4)\)

    בדיקה: עם השעון, מהראש עוברים לימין (אחרי רבע מחזור, 3 שניות) ואז לתחתית (6 שניות) ✓

  3. נתונה הנוסחה \(x(t) = 4 + 3t + 2\cos(60 + 45t),\ y(t) = -1 + 4t + 2\sin(60 + 45t)\). מהו מיקום ההתחלה של המרכז ומהו גודל מהירותו? מהו הרדיוס ומהי הזווית ההתחלתית? באיזה כיוון מסתובב הגלגל ומהו זמן המחזור? איפה הנקודה ב־\(t=0\)?
    הצג פתרון
    דרך החשיבה

    קוראים את הנוסחה ״הפוך״: משווים אותה לנוסחה הכללית ומזהים כל רכיב לפי מקומו. אחר כך מחשבים ממנו את מה שנשאל.

    1. זיהוי: \(x_0=4,\ y_0=-1,\ v_x=3,\ v_y=4,\ R=2,\ \theta_0=60^\circ,\ \omega=45\)
    2. גודל המהירות: \(|v| = \sqrt{9+16} = 5\)
    3. כיוון ומחזור: \(\omega \gt 0\) נגד השעון; \(T = \dfrac{360}{45} = 8\)
    4. t = 0: \(x = 4 + 2\cos 60^\circ = 5,\ y = -1 + 2\sin 60^\circ = -1+\sqrt3 \approx 0.73\)

    תשובה: מרכז מתחיל ב־\((4,-1)\), \(|v|=5\), \(R=2,\ \theta_0=60^\circ\), נגד השעון, \(T=8\); \(P(0) = (5,\ -1+\sqrt3)\)

    בדיקה: המרחק של \((5, -1+\sqrt3)\) מ־\((4,-1)\): \(\sqrt{1+3} = 2\) ✓

  4. ב־\(t=0\) מרכז הגלגל ב־\((3,3)\) והנקודה P ב־\((5,3)\). ב־\(t=2\) המרכז ב־\((9,5)\) והנקודה ב־\((9,7)\). הגלגל מסתובב נגד השעון והשלים פחות מסיבוב. מצאו את כל הרכיבים, רשמו את הנוסחה ומצאו את P ב־\(t=4\).
    הצג פתרון
    דרך החשיבה

    הכול נתון כמיקומים. מהמרכז בשני הזמנים: מהירות המרכז. מההפרש בין P למרכז בכל זמן: הרדיוס והזווית באותו רגע. משתי הזוויות: ω.

    1. רדיוס וזווית התחלה: \(P - C = (2,0) \Rightarrow R = 2,\ \theta_0 = 0^\circ\)
    2. מהירות המרכז: \(v_x = \dfrac{6}{2} = 3,\ v_y = \dfrac{2}{2} = 1\)
    3. זווית ב־t = 2: \(P - C = (0,2) \Rightarrow \theta = 90^\circ\)
    4. מהירות זוויתית: \(\omega = \dfrac{90-0}{2} = 45\)
    5. נוסחה: \(x(t) = 3 + 3t + 2\cos(45t),\ y(t) = 3 + t + 2\sin(45t)\)
    6. t = 4: מרכז \((15,7)\), זווית \(180^\circ\) — \(P = (13,7)\)

    תשובה: \(P(4) = (13,7)\)

    בדיקה: הצבת t = 2 בנוסחה: \((3+6+0,\ 3+2+2) = (9,7)\) ✓

  5. גלגל ברדיוס 1. המרכז מתחיל ב־\((2,0)\) עם \(v_x = 1,\ v_y = 2\). הגלגל מסתובב עם השעון ב־\(90^\circ\) לשנייה, ו־P מתחילה בראש הגלגל. רשמו את הנוסחה ומצאו את P ב־\(t=1\) וב־\(t=2\).
    הצג פתרון
    דרך החשיבה

    מתרגמים: ״ראש הגלגל״ 90 מעלות, ״עם השעון״ ω שלילית. שאר הרכיבים נתונים.

    1. רכיבים: \(x_0=2,\ y_0=0,\ v_x=1,\ v_y=2,\ R=1,\ \theta_0=90^\circ,\ \omega=-90\)
    2. נוסחה: \(x = 2 + t + \cos(90 - 90t),\ y = 2t + \sin(90 - 90t)\)
    3. t = 1: מרכז \((3,2)\), זווית \(0^\circ\) — \(P = (4,2)\)
    4. t = 2: מרכז \((4,4)\), זווית \(-90^\circ\) — \(P = (4,3)\)

    תשובה: \(P(1) = (4,2),\ P(2) = (4,3)\)

    בדיקה: עם השעון מהראש: ימין ואז תחתית ✓

  6. מרכז גלגל ברדיוס 2 עובר מ־\((0,2)\) ל־\((12,8)\) תוך 6 שניות. P מתחילה בצד שמאל. הגלגל משלים סיבוב כל 8 שניות נגד השעון. רשמו את הנוסחה ומצאו את P ב־\(t=2\) וב־\(t=4\).
    הצג פתרון
    דרך החשיבה

    מהירות המרכז משתי נקודות, ω מזמן המחזור (חיובית), ו״צד שמאל״ 180 מעלות.

    1. מרכז: \(v_x = 2,\ v_y = 1\)
    2. סיבוב: \(\theta_0 = 180^\circ,\ \omega = 45\)
    3. נוסחה: \(x = 2t + 2\cos(180+45t),\ y = 2 + t + 2\sin(180+45t)\)
    4. t = 2: מרכז \((4,4)\), זווית \(270^\circ\) — \(P = (4,2)\)
    5. t = 4: מרכז \((8,6)\), זווית \(360^\circ\) — \(P = (10,6)\)

    תשובה: \(P(2) = (4,2),\ P(4) = (10,6)\)

    בדיקה: נגד השעון משמאל: תחתית ואז ימין ✓

  7. נתונה הנוסחה \(x(t) = -2 + 5t + 3\cos(120 - 30t),\ y(t) = 6 - t + 3\sin(120 - 30t)\). מהו מיקום ההתחלה של המרכז וגודל מהירותו? מהו הרדיוס והזווית ההתחלתית? כיוון הסיבוב וזמן המחזור? איפה P ב־\(t=0\)?
    הצג פתרון
    דרך החשיבה

    מזהים רכיבים לפי מקומם בנוסחה הכללית, ושמים לב לסימנים.

    1. זיהוי: \(x_0=-2,\ y_0=6,\ v_x=5,\ v_y=-1,\ R=3,\ \theta_0=120^\circ,\ \omega=-30\)
    2. גודל המהירות: \(|v| = \sqrt{26} \approx 5.10\)
    3. כיוון ומחזור: עם השעון, \(T = 12\)
    4. t = 0: \(x = -2 + 3\cos 120^\circ = -3.5,\ y = 6 + 3\sin 120^\circ \approx 8.60\)

    תשובה: מרכז \((-2,6)\), \(|v| \approx 5.10\), \(R = 3,\ \theta_0 = 120^\circ\), עם השעון, \(T=12\); \(P(0) \approx (-3.5,\ 8.60)\)

    בדיקה: \(1.5^2 + 2.6^2 \approx 9\) ✓

  8. ב־\(t=0\) המרכז ב־\((0,0)\) ו־P ב־\((0,3)\). ב־\(t=3\) המרכז ב־\((6,-3)\) ו־P ב־\((3,-3)\). הגלגל מסתובב נגד השעון והשלים פחות מסיבוב. מצאו את כל הרכיבים ואת P ב־\(t=6\).
    הצג פתרון
    דרך החשיבה

    מההפרש P פחות המרכז בכל זמן: רדיוס וזווית. מהמרכזים: מהירות. משתי הזוויות: ω.

    1. התחלה: \(P - C = (0,3) \Rightarrow R = 3,\ \theta_0 = 90^\circ\)
    2. מרכז: \(v_x = 2,\ v_y = -1\)
    3. זווית ב־t = 3: \(P - C = (-3, 0) \Rightarrow 180^\circ\)
    4. מהירות זוויתית: \(\omega = \dfrac{90}{3} = 30\)
    5. t = 6: מרכז \((12,-6)\), זווית \(270^\circ\) — \(P = (12,-9)\)

    תשובה: \(P(6) = (12,-9)\)

    בדיקה: הצבת t = 3 בנוסחה נותנת \((3,-3)\) ✓

רמה ב׳: גלגל מתגלגל שאלות 9–14

מהירות המרכז מתוך הסיבוב, מתי נקודה נוגעת בקרקע, ותנאי אי־ההחלקה.

  1. גלגל ברדיוס 1 מתגלגל ימינה על ציר x בלי החלקה ומשלים סיבוב כל 4 שניות. ב־\(t=0\) המרכז ב־\((0,1)\) והנקודה P נוגעת בקרקע. מצאו את מהירות המרכז מתוך הסיבוב, רשמו את הנוסחה, ומצאו את P ב־\(t=2\) וב־\(t=4\).
    הצג פתרון
    דרך החשיבה

    בגלגל מתגלגל מהירות המרכז לא נתונה: מחשבים אותה מהסיבוב (היקף לכל סיבוב). ״נוגעת בקרקע״ היא 270 מעלות, וימינה פירושו ω שלילית.

    1. מהירות המרכז: \(v_x = \dfrac{2\pi\cdot 1}{4} = \dfrac{\pi}{2},\ v_y = 0\)
    2. סיבוב: \(\theta_0 = 270^\circ,\ \omega = -90\)
    3. נוסחה: \(x(t) = \tfrac{\pi}{2}t + \cos(270-90t),\ y(t) = 1 + \sin(270-90t)\)
    4. t = 2: זווית \(90^\circ\) — \(P = (\pi, 2)\)
    5. t = 4: זווית \(-90^\circ\) — \(P = (2\pi, 0)\)

    תשובה: \(P(2) = (\pi,2)\) (ראש הגלגל), \(P(4) = (2\pi,0)\) (שוב בקרקע)

    בדיקה: אחרי סיבוב שלם P חזרה לקרקע במרחק \(2\pi\) — היקף אחד ✓

  2. גלגל ברדיוס 0.5 מתגלגל ימינה ב־2 סיבובים לשנייה. ב־\(t=0\) המרכז ב־\((0,0.5)\) והנקודה P בצד ימין של הגלגל. רשמו את הנוסחה. מתי P נוגעת בקרקע לראשונה, ומה x שלה אז?
    הצג פתרון
    דרך החשיבה

    ״נוגעת בקרקע״ פירושו y = 0, כלומר הזווית −90 מעלות (התחתית). מתחילים מ־0 מעלות ומסתובבים עם השעון, ולכן מגיעים לשם אחרי רבע סיבוב.

    1. מהירות המרכז: \(v_x = 2\pi\cdot 0.5\cdot 2 = 2\pi\)
    2. סיבוב: \(\theta_0 = 0^\circ,\ \omega = -720\)
    3. נוסחה: \(x(t) = 2\pi t + 0.5\cos(-720t),\ y(t) = 0.5 + 0.5\sin(-720t)\)
    4. זמן: \(-720t = -90 \Rightarrow t = \tfrac18\)
    5. מיקום: \(x = 2\pi\cdot\tfrac18 + 0 = \tfrac{\pi}{4} \approx 0.785\)

    תשובה: ב־\(t = \tfrac18\) שנייה, ב־\(x = \tfrac{\pi}{4}\)

    בדיקה: ברגע המגע P מתחת למרכז בדיוק: המרכז ב־\(x = \tfrac{\pi}{4}\) ✓

  3. נתונה התנועה \(x(t) = 6t + 3\cos(90 - kt),\ y(t) = 3 + 3\sin(90 - kt)\). זהו את R, את מהירות המרכז ואת \(\theta_0\), ומצאו את k כך שהגלגל יתגלגל בלי החלקה.
    הצג פתרון
    דרך החשיבה

    מזהים רכיבים מהנוסחה, ובודקים שזה באמת גלגל על הקרקע (גובה המרכז = R). תנאי אי־ההחלקה קושר את ω למהירות המרכז, ולכן k נקבע.

    1. זיהוי: \(R = 3,\ v_x = 6,\ v_y = 0,\ y_0 = 3 = R,\ \theta_0 = 90^\circ\)
    2. תנאי: \(|\omega| = \dfrac{180|v|}{\pi R} = \dfrac{180\cdot 6}{3\pi} = \dfrac{360}{\pi}\)
    3. k: \(k = \dfrac{360}{\pi} \approx 114.6\)

    תשובה: \(k = \tfrac{360}{\pi} \approx 114.6^\circ/\text{s}\)

    בדיקה: סיבוב לוקח \(\tfrac{360}{k} = \pi\) שניות, ובזמן זה המרכז עובר \(6\pi = 2\pi\cdot 3\) — היקף ✓

  4. גלגל ברדיוס 2 מתגלגל ימינה בלי החלקה ומשלים סיבוב כל 6 שניות. המרכז מתחיל ב־\((0,2)\) ו־P בראש הגלגל. רשמו את הנוסחה ומצאו את P ב־\(t=1.5\) וב־\(t=3\).
    הצג פתרון
    דרך החשיבה

    מהירות המרכז מהסיבוב, ω שלילית, וזווית התחלה 90.

    1. מהירות: \(v_x = \dfrac{4\pi}{6} = \dfrac{2\pi}{3}\)
    2. סיבוב: \(\theta_0 = 90^\circ,\ \omega = -60\)
    3. נוסחה: \(x = \tfrac{2\pi}{3}t + 2\cos(90-60t),\ y = 2 + 2\sin(90-60t)\)
    4. t = 1.5: זווית \(0^\circ\): \(x = \pi + 2 \approx 5.14,\ y = 2\)
    5. t = 3: זווית \(-90^\circ\): \(x = 2\pi \approx 6.28,\ y = 0\)

    תשובה: \((5.14,\ 2)\) ו־\((2\pi,\ 0)\)

    בדיקה: אחרי חצי סיבוב הנקודה עברה מהראש לקרקע ✓

  5. גלגל ברדיוס 1 מתגלגל ימינה, סיבוב כל 2 שניות. המרכז מתחיל ב־\((0,1)\) ו־P בצד שמאל. מתי P נוגעת בקרקע לראשונה, ומה x שלה אז?
    הצג פתרון
    דרך החשיבה

    מצד שמאל (180) עם השעון מגיעים לתחתית (−90) אחרי שלושה רבעי סיבוב: הזווית יורדת 270 מעלות.

    1. רכיבים: \(v_x = \pi,\ \theta_0 = 180^\circ,\ \omega = -180\)
    2. זמן: \(180 - 180t = -90 \Rightarrow t = 1.5\)
    3. מיקום: \(x = 1.5\pi + \cos(-90^\circ) = 1.5\pi \approx 4.71\)

    תשובה: ב־\(t = 1.5\), ב־\(x = 1.5\pi \approx 4.71\)

    בדיקה: ברגע המגע P מתחת למרכז, שנמצא ב־\(1.5\pi\) ✓

  6. נתונה התנועה \(x(t) = 3\pi t + 1.5\cos(270 - kt),\ y(t) = 1.5 + 1.5\sin(270 - kt)\). זהו את R ואת מהירות המרכז, ומצאו את k כך שאין החלקה.
    הצג פתרון
    דרך החשיבה

    גובה המרכז שווה ל־R, ולכן זה גלגל על הקרקע. תנאי אי־ההחלקה נותן את ω.

    1. זיהוי: \(R = 1.5,\ v_x = 3\pi,\ \theta_0 = 270^\circ\)
    2. תנאי: \(|\omega| = \dfrac{180\cdot 3\pi}{\pi\cdot 1.5} = 360\)
    3. k: \(k = 360\)

    תשובה: \(k = 360^\circ/\text{s}\)

    בדיקה: סיבוב בשנייה, והמרכז עובר \(3\pi = 2\pi\cdot 1.5\) בשנייה ✓

רמה ג׳: רמת בגרות שאלות 15–18

מספרים מהחיים וגלגול שמאלה.

  1. השסתום של גלגל אופניים (רדיוס 0.35 מ׳) בראש הגלגל ב־\(t=0\). האופניים נוסעים ימינה במהירות 7 מ׳/ש׳, והמרכז מתחיל ב־\((0,0.35)\). מצאו את מספר הסיבובים בשנייה ואת \(\omega\), רשמו את הנוסחה, ומצאו את גובה השסתום אחרי 0.1 שניות.
    הצג פתרון
    דרך החשיבה

    שאלה מהחיים עם מספרים לא עגולים: מחשבים ω מהמהירות והרדיוס, מציבים ומחשבים במחשבון במצב מעלות (DEG).

    1. סיבובים: \(n = \dfrac{7}{0.7\pi} = \dfrac{10}{\pi} \approx 3.18\)
    2. מהירות זוויתית: \(\omega = -360n = -\dfrac{3600}{\pi} \approx -1145.9\)
    3. נוסחה: \(y(t) = 0.35 + 0.35\sin(90 - 1145.9t)\)
    4. זווית: \(90 - 114.59 \approx -24.6^\circ\)
    5. גובה: \(y \approx 0.35 + 0.35\cdot(-0.416) \approx 0.204\) מ׳

    תשובה: כ־3.18 סיבובים בשנייה, \(\omega \approx -1145.9^\circ/\text{s}\), גובה כ־0.20 מ׳ (20 ס״מ)

    בדיקה: הזווית שלילית, ולכן השסתום כבר מתחת לגובה המרכז (0.35 מ׳) ועדיין מעל הקרקע: \(0 \lt 0.204 \lt 0.35\) ✓

  2. גלגל ברדיוס 2 מתגלגל שמאלה בלי החלקה. המרכז מתחיל ב־\((20,2)\) ונע במהירות \(\pi\) יחידות לשנייה. ב־\(t=0\) הנקודה P בצד שמאל של הגלגל. מצאו את כל 7 הרכיבים ואת P ב־\(t=2\).
    הצג פתרון
    דרך החשיבה

    כל הסימנים הפוכים מהרגיל: שמאלה פירושו \(v_x \lt 0\) ו־ω חיובית. ״צד שמאל״ הוא 180 מעלות.

    1. מרכז: \(x_0=20,\ y_0=2,\ v_x=-\pi,\ v_y=0\)
    2. גלגל: \(R = 2,\ \theta_0 = 180^\circ\)
    3. מהירות זוויתית: \(|\omega| = \dfrac{180\pi}{2\pi} = 90\), שמאלה \(\Rightarrow \omega = +90\)
    4. נוסחה: \(x(t) = 20 - \pi t + 2\cos(180+90t),\ y(t) = 2 + 2\sin(180+90t)\)
    5. t = 2: מרכז \((20-2\pi, 2) \approx (13.72, 2)\), זווית \(360^\circ\) — \(P \approx (15.72, 2)\)

    תשובה: \(P(2) = (22 - 2\pi,\ 2) \approx (15.72, 2)\)

    בדיקה: אחרי חצי סיבוב P עברה מצד שמאל לצד ימין, והמרכז זז חצי היקף, \(2\pi\) ✓

  3. השסתום של צמיג מכונית (רדיוס 0.3 מ׳) בתחתית הגלגל ב־\(t=0\). המכונית נוסעת ימינה במהירות 15 מ׳/ש׳, והמרכז מתחיל ב־\((0,0.3)\). מצאו את \(\omega\) ואת גובה השסתום אחרי 0.01 שניות.
    הצג פתרון
    דרך החשיבה

    מחשבים ω מהמהירות והרדיוס, ומציבים במחשבון במצב מעלות.

    1. סיבובים: \(n = \dfrac{15}{0.6\pi} \approx 7.96\)
    2. מהירות זוויתית: \(\omega \approx -2864.8\)
    3. זווית: \(270 - 28.65 \approx 241.35^\circ\)
    4. גובה: \(y \approx 0.3 + 0.3\cdot(-0.877) \approx 0.037\) מ׳

    תשובה: \(\omega \approx -2865^\circ/\text{s}\), גובה כ־3.7 ס״מ

    בדיקה: השסתום רק התחיל לעלות מהקרקע: גובה קטן וחיובי ✓

  4. גלגל ברדיוס 1 מתגלגל שמאלה בלי החלקה. המרכז מתחיל ב־\((10,1)\) ונע במהירות \(\tfrac{\pi}{2}\). P מתחילה בראש הגלגל. מצאו את כל הרכיבים ואת P ב־\(t=1\) וב־\(t=2\).
    הצג פתרון
    דרך החשיבה

    שמאלה: v_x שלילי ו־ω חיובית. ״ראש הגלגל״ 90 מעלות.

    1. רכיבים: \(x_0=10,\ y_0=1,\ v_x=-\tfrac{\pi}{2},\ v_y=0,\ R=1,\ \theta_0=90^\circ\)
    2. מהירות זוויתית: \(|\omega| = \dfrac{180\cdot\frac{\pi}{2}}{\pi} = 90\), שמאלה \(\Rightarrow \omega = +90\)
    3. t = 1: זווית \(180^\circ\): \(x = 10 - \tfrac{\pi}{2} - 1 \approx 7.43,\ y = 1\)
    4. t = 2: זווית \(270^\circ\): \(x = 10 - \pi \approx 6.86,\ y = 0\)

    תשובה: \((7.43,\ 1)\) ו־\((10-\pi,\ 0) \approx (6.86,\ 0)\)

    בדיקה: אחרי חצי סיבוב הנקודה בקרקע, מתחת למרכז ✓
