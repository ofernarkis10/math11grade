תרגול משולב: בונים את הנוסחה

18 שאלות שמחברות את שתי המשוואות לשאלה אחת. בכל שאלה: מוצאים קודם את כל 7 הרכיבים, רושמים את הנוסחה המלאה, ורק אז מציבים. ההסבר והשיטה בדף התאוריה.

תוכן

רכיב\(x_A\)\(y_A\)\(v_x\)\(v_y\)\(R\)\(\theta_0\)\(\omega\)
ערך

טבלת עבודה: מעתיקים למחברת וממלאים בכל שאלה לפני שרושמים את הנוסחה.

\(x(t) = \color{#1f6f8b}{x_A + v_x t} + R\cos(\color{#b4561e}{\theta_0 + \omega t})\)
\(y(t) = \color{#1f6f8b}{y_A + v_y t} + R\sin(\color{#b4561e}{\theta_0 + \omega t})\)

רמה א׳: גלגל חופשי שאלות 1–8

מוצאים את 7 הרכיבים, רושמים את הנוסחה ומציבים; גם קריאה הפוכה של נוסחה.

  1. גלגל ברדיוס 2. המרכז מתחיל ב־\((0,5)\) עם \(v_x = 3,\ v_y = 1\). הגלגל מסתובב נגד השעון ב־\(90^\circ\) לשנייה. ב־\(t=0\) הנקודה P בצד ימין של הגלגל. (א) מלאו את טבלת הרכיבים ורשמו את הנוסחה. (ב) מצאו את P ב־\(t=1\) וב־\(t=2\).
    הצג פתרון
    דרך החשיבה

    כל הרכיבים נתונים כמעט ישירות; צריך רק לתרגם ״צד ימין״ לזווית 0. אחרי שהנוסחה כתובה, בכל זמן מחשבים קודם את המרכז ואת הזווית, ואז מוסיפים את ההזזה מהמרכז.

    1. רכיבים
      \(x_A=0\)
      \(y_A=5\)
      \(v_x=3\)
      \(v_y=1\)
      \(R=2\)
      \(\theta_0=0^\circ\)
      \(\omega=90\)
    2. נוסחהשאלת מרחק זוויתישאלת מיקום
      \(x(t) = x_A + v_x t + R\cos(\theta_0 + \omega t) = 3t + 2\cos(90t)\)
      \(y(t) = y_A + v_y t + R\sin(\theta_0 + \omega t) = 5 + t + 2\sin(90t)\)
    3. t = 1שאלת מרחקשאלת מרחק זוויתישאלת מיקום
      מרכז
      \(C = (x_A + v_x t,\ y_A + v_y t) = (3,6)\)
      זווית
      \(\theta = \theta_0 + \omega t = 90^\circ\)
      \(P = C + (R\cos\theta,\ R\sin\theta) = (3, 6+2) = (3,8)\)
    4. t = 2שאלת מרחקשאלת מרחק זוויתישאלת מיקום
      מרכז
      \(C = (x_A + v_x t,\ y_A + v_y t) = (6,7)\)
      זווית
      \(\theta = \theta_0 + \omega t = 180^\circ\)
      \(P = C + (R\cos\theta,\ R\sin\theta) = (6-2, 7) = (4,7)\)
    תשובה:
    \(P(1) = (3,8)\)
    \(P(2) = (4,7)\)
    בדיקה:
    המרחק של P מהמרכז בשני המקרים הוא 2 = R ✓
  2. מרכז גלגל ברדיוס 3 עובר מהנקודה \(A(1,1)\) לנקודה \(B(11,6)\) תוך 5 שניות. ב־\(t=0\) הנקודה P בראש הגלגל. הגלגל משלים סיבוב כל 12 שניות עם כיוון השעון. רשמו את הנוסחה ומצאו את P ב־\(t=3\) וב־\(t=6\).
    הצג פתרון
    דרך החשיבה

    שני רכיבים צריך לחשב: את מהירות המרכז משתי נקודות, ואת ω מזמן המחזור עם סימן שלילי. ״ראש הגלגל״ הוא 90 מעלות.

    1. נתונים
      \(A(1,1)\)
      \(t_A = 0\)
      \(B(11,6)\)
      \(t_B = 5\)
      \(R = 3\)
    2. מרכזשאלת מרחק
      \(v_x = \dfrac{x_B - x_A}{t_B - t_A} = \dfrac{11-1}{5-0} = 2\)
      \(v_y = \dfrac{y_B - y_A}{t_B - t_A} = \dfrac{6-1}{5-0} = 1\)
    3. סיבובשאלת מרחק זוויתי
      \(\theta_0 = 90^\circ\)
      \(\omega = -\dfrac{360}{T} = -\dfrac{360}{12} = -30\)
    4. נוסחהשאלת מרחק זוויתישאלת מיקום
      \(x(t) = x_A + v_x t + R\cos(\theta_0 + \omega t) = 1 + 2t + 3\cos(90-30t)\)
      \(y(t) = y_A + v_y t + R\sin(\theta_0 + \omega t) = 1 + t + 3\sin(90-30t)\)
    5. t = 3שאלת מרחקשאלת מרחק זוויתישאלת מיקום
      מרכז
      \(C = (x_A + v_x t,\ y_A + v_y t) = (7,4)\)
      זווית
      \(\theta = \theta_0 + \omega t = 0^\circ\)
      \(P = C + (R\cos\theta,\ R\sin\theta) = (10,4)\)
    6. t = 6שאלת מרחקשאלת מרחק זוויתישאלת מיקום
      מרכז
      \(C = (x_A + v_x t,\ y_A + v_y t) = (13,7)\)
      זווית
      \(\theta = \theta_0 + \omega t = -90^\circ\)
      \(P = C + (R\cos\theta,\ R\sin\theta) = (13,4)\)
    תשובה:
    \(P(3) = (10,4)\)
    \(P(6) = (13,4)\)
    בדיקה:
    עם השעון, מהראש עוברים לימין (אחרי רבע מחזור, 3 שניות) ואז לתחתית (6 שניות) ✓
  3. נתונה הנוסחה \(x(t) = 4 + 3t + 2\cos(60 + 45t),\ y(t) = -1 + 4t + 2\sin(60 + 45t)\). מהו מיקום ההתחלה של המרכז ומהו גודל מהירותו? מהו הרדיוס ומהי הזווית ההתחלתית? באיזה כיוון מסתובב הגלגל ומהו זמן המחזור? איפה הנקודה ב־\(t=0\)?
    הצג פתרון
    דרך החשיבה

    קוראים את הנוסחה ״הפוך״: משווים אותה לנוסחה הכללית ומזהים כל רכיב לפי מקומו. אחר כך מחשבים ממנו את מה שנשאל.

    1. זיהוי
      \(x_A=4\)
      \(y_A=-1\)
      \(v_x=3\)
      \(v_y=4\)
      \(R=2\)
      \(\theta_0=60^\circ\)
      \(\omega=45\)
    2. גודל המהירותשאלת מרחק
      \(|v| = \sqrt{v_x^2 + v_y^2} = \sqrt{9+16} = 5\)
    3. כיוון ומחזורשאלת מרחק זוויתי
      \(\omega \gt 0\)
      נגד השעון
      \(T = \dfrac{360}{|\omega|} = \dfrac{360}{45} = 8\)
    4. t = 0שאלת מיקום
      \(x = x_C + R\cos\theta = 4 + 2\cos 60^\circ = 5\)
      \(y = y_C + R\sin\theta = -1 + 2\sin 60^\circ = -1+\sqrt3 \approx 0.73\)
    תשובה:
    מרכז מתחיל
    \((4,-1)\)
    \(|v|=5\)
    \(R=2\)
    \(\theta_0=60^\circ\)
    נגד השעון
    \(T=8\)
    \(P(0) = (5,\ -1+\sqrt3)\)
    בדיקה:
    המרחק של
    \((5, -1+\sqrt3)\)
    \((4,-1)\)
    \(\sqrt{1+3} = 2\)✓
  4. ב־\(t=0\) מרכז הגלגל בנקודה \(A(3,3)\) והנקודה P ב־\((5,3)\). ב־\(t=2\) המרכז בנקודה \(B(9,5)\) והנקודה P ב־\((9,7)\). הגלגל מסתובב נגד השעון והשלים פחות מסיבוב. מצאו את כל הרכיבים, רשמו את הנוסחה ומצאו את P ב־\(t=4\).
    הצג פתרון
    דרך החשיבה

    הכול נתון כמיקומים. מהמרכז בשני הזמנים: מהירות המרכז. מההפרש בין P למרכז בכל זמן: הרדיוס והזווית באותו רגע. משתי הזוויות: ω.

    1. נתונים
      \(A(3,3)\)
      \(t_A = 0\)
      \(B(9,5)\)
      \(t_B = 2\)
      \(P(t_A) = (5,3)\)
      \(P(t_B) = (9,7)\)
    2. רדיוס וזווית התחלהשאלת מיקום
      \(P - C = (5-3,\ 3-3) = (2,0) \Rightarrow R = |P - C| = 2\)
      \(\theta_0 = 0^\circ\)
    3. מהירות המרכזשאלת מרחק
      \(v_x = \dfrac{x_B - x_A}{t_B - t_A} = \dfrac{9-3}{2-0} = 3\)
      \(v_y = \dfrac{y_B - y_A}{t_B - t_A} = \dfrac{5-3}{2-0} = 1\)
    4. זווית ב־t = 2שאלת מיקום
      \(P - C = (9-9,\ 7-5) = (0,2) \Rightarrow \theta = 90^\circ\)
    5. מהירות זוויתיתשאלת מרחק זוויתי
      \(\omega = \dfrac{\Delta\theta}{\Delta t} = \dfrac{90-0}{2} = 45\)
    6. נוסחהשאלת מרחק זוויתישאלת מיקום
      \(x(t) = x_A + v_x t + R\cos(\theta_0 + \omega t) = 3 + 3t + 2\cos(45t)\)
      \(y(t) = y_A + v_y t + R\sin(\theta_0 + \omega t) = 3 + t + 2\sin(45t)\)
    7. t = 4שאלת מרחקשאלת מרחק זוויתישאלת מיקום
      מרכז
      \(C = (x_A + v_x t,\ y_A + v_y t) = (15,7)\)
      זווית
      \(\theta = \theta_0 + \omega t = 180^\circ\)
      \(P = C + (R\cos\theta,\ R\sin\theta) = (13,7)\)
    תשובה:
    \(P(4) = (13,7)\)
    בדיקה:
    הצבת t = 2 בנוסחה
    \((3+6+0,\ 3+2+2) = (9,7)\)✓
  5. גלגל ברדיוס 1. המרכז מתחיל ב־\((2,0)\) עם \(v_x = 1,\ v_y = 2\). הגלגל מסתובב עם השעון ב־\(90^\circ\) לשנייה, ו־P מתחילה בראש הגלגל. רשמו את הנוסחה ומצאו את P ב־\(t=1\) וב־\(t=2\).
    הצג פתרון
    דרך החשיבה

    מתרגמים: ״ראש הגלגל״ 90 מעלות, ״עם השעון״ ω שלילית. שאר הרכיבים נתונים.

    1. רכיבים
      \(x_A=2\)
      \(y_A=0\)
      \(v_x=1\)
      \(v_y=2\)
      \(R=1\)
      \(\theta_0=90^\circ\)
      \(\omega=-90\)
    2. נוסחהשאלת מרחק זוויתישאלת מיקום
      \(x = x_A + v_x t + R\cos(\theta_0 + \omega t) = 2 + t + \cos(90 - 90t)\)
      \(y = y_A + v_y t + R\sin(\theta_0 + \omega t) = 2t + \sin(90 - 90t)\)
    3. t = 1שאלת מרחקשאלת מרחק זוויתישאלת מיקום
      מרכז
      \(C = (x_A + v_x t,\ y_A + v_y t) = (3,2)\)
      זווית

    4. t = 2שאלת מרחקשאלת מרחק זוויתישאלת מיקום
      מרכז
      \(C = (x_A + v_x t,\ y_A + v_y t) = (4,4)\)
      זווית

    תשובה:

    \(P(2) = (4,3)\)
    בדיקה:
    עם השעון מהראש: ימין ואז תחתית ✓
  6. מרכז גלגל ברדיוס 2 עובר מהנקודה \(A(0,2)\) לנקודה \(B(12,8)\) תוך 6 שניות. P מתחילה בצד שמאל. הגלגל משלים סיבוב כל 8 שניות נגד השעון. רשמו את הנוסחה ומצאו את P ב־\(t=2\) וב־\(t=4\).
    הצג פתרון
    דרך החשיבה

    מהירות המרכז משתי נקודות, ω מזמן המחזור (חיובית), ו״צד שמאל״ 180 מעלות.

    3. סיבובשאלת מרחק זוויתי

    4. נוסחהשאלת מרחק זוויתישאלת מיקום

  7. נתונה הנוסחה \(x(t) = -2 + 5t + 3\cos(120 - 30t),\ y(t) = 6 - t + 3\sin(120 - 30t)\). מהו מיקום ההתחלה של המרכז וגודל מהירותו? מהו הרדיוס והזווית ההתחלתית? כיוון הסיבוב וזמן המחזור? איפה P ב־\(t=0\)?
    הצג פתרון
    דרך החשיבה

    4. t = 0שאלת מיקום

    מרכז

  8. ב־\(t=0\) המרכז בנקודה \(A(0,0)\) ו־P ב־\((0,3)\). ב־\(t=3\) המרכז בנקודה \(B(6,-3)\) ו־P ב־\((3,-3)\). הגלגל מסתובב נגד השעון והשלים פחות מסיבוב. מצאו את כל הרכיבים ואת P ב־\(t=6\).

רמה ב׳: גלגל מתגלגל שאלות 9–14

מהירות המרכז מתוך הסיבוב, מתי נקודה נוגעת בקרקע, ותנאי אי־ההחלקה.

  1. גלגל ברדיוס 1 מתגלגל ימינה על ציר x בלי החלקה ומשלים סיבוב כל 4 שניות. ב־\(t=0\) המרכז ב־\((0,1)\) והנקודה P נוגעת בקרקע. מצאו את מהירות המרכז מתוך הסיבוב, רשמו את הנוסחה, ומצאו את P ב־\(t=2\) וב־\(t=4\).
    הצג פתרון
    דרך החשיבה

    בגלגל מתגלגל מהירות המרכז לא נתונה: מחשבים אותה מהסיבוב (היקף לכל סיבוב). ״נוגעת בקרקע״ היא 270 מעלות, וימינה פירושו ω שלילית.

    1. מהירות המרכזשאלת מרחק
      \(v_x = \dfrac{2\pi R}{T} = \dfrac{2\pi\cdot 1}{4} = \dfrac{\pi}{2}\)
