מהירות העגלה מתוך תנועת הגלגל

איך מחשבים את מהירות העגלה (אופניים, מכונית, צעצוע) מתוך מה שיודעים על הגלגל שלה: רדיוס או קוטר, היקף, מספר סיבובים, סל״ד, זמן מחזור או מהירות סיבוב במעלות. הרעיון: בכל סיבוב העגלה מתקדמת היקף אחד. התרגול בדף הבא.

הרעיון

עגלה (אופניים, מכונית, רכבת צעצוע) נוסעת על גלגלים. הגלגלים מחוברים לציר של העגלה, ולכן מרכז הגלגל נע בדיוק כמו העגלה: מהירות העגלה היא מהירות מרכז הגלגל.

כשהגלגל מתגלגל בלי להחליק, בכל סיבוב מלא הוא ״פורש״ על הכביש את כל ההיקף שלו. לכן בכל סיבוב העגלה מתקדמת היקף אחד. מזה נובעות כל הנוסחאות בדף.

הגלגל מחובר לציר של העגלה. בכל סיבוב מלא, בלי החלקה, העגלה מתקדמת היקף אחד של הגלגל.

הגדלים והיחידות

גודלסימוןיחידההערה
רדיוס / קוטר\(R,\ d\)מ׳\(d = 2R\). לשים לב לס״מ: מחלקים ב־100
היקף\(L\)מ׳\(L = 2\pi R = \pi d\) — המרחק שהעגלה עוברת בסיבוב אחד. מסמנים L (אורך ההיקף); האות C שמורה למרכז הגלגל, והאות P לנקודה על הגלגל
סיבובים בשנייה\(n\)סיבובים לשנייה\(n = \dfrac{\text{rpm}}{60} = \dfrac{1}{T}\)
סיבובים לדקה (סל״ד)\(\text{rpm}\)סיבובים לדקה\(\text{rpm} = 60n\)
זמן מחזור\(T\)שניותזמן של סיבוב אחד
מהירות סיבוב\(\omega\)מעלות לשנייה\(|\omega| = 360n\)
מהירות העגלה\(v\)מ׳/ש׳ או קמ״ש\(1\ \text{m/s} = 3.6\ \text{km/h}\)

הנוסחאות: מתנועת הגלגל למהירות העגלה

\(v = L\cdot n = 2\pi R\cdot n\)מהירות העגלה = היקף × מספר הסיבובים בשנייה
מה נתון על הגלגלהנוסחה למהירות העגלה
רדיוס וסיבובים בשנייה\(v = 2\pi R\, n\)
קוטר וסיבובים בשנייה\(v = \pi d\, n\)
היקף וסיבובים בשנייה\(v = L\, n\)
רדיוס וזמן מחזור\(v = \dfrac{2\pi R}{T}\)
רדיוס וסל״ד\(v = \dfrac{2\pi R\cdot\text{rpm}}{60}\)
רדיוס ומהירות סיבוב במעלות לשנייה\(v = \dfrac{|\omega|\,\pi R}{180}\)
רדיוס ומהירות זוויתית ברדיאנים לשנייה\(v = \omega R\)
למה זה עובד: בשנייה אחת הגלגל מבצע \(n\) סיבובים, ובכל סיבוב העגלה מתקדמת \(L\). לכן בשנייה העגלה מתקדמת \(L\cdot n\) — וזו המהירות.

בכיוון ההפוך: ממהירות העגלה לתנועת הגלגל

סיבובים בשנייה\(n = \dfrac{v}{L} = \dfrac{v}{2\pi R}\)
סל״ד\(\text{rpm} = 60\cdot\dfrac{v}{2\pi R}\)
מהירות סיבוב במעלות\(|\omega| = \dfrac{180\,v}{\pi R}\)
רדיוס מתוך המהירות והסיבוב\(R = \dfrac{v}{2\pi n}\)
מרחק מתוך מספר סיבובים\(s = L\cdot N\)
מספר סיבובים לאורך דרך\(N = \dfrac{s}{L}\)
שני גלגלים באותה עגלה: כל הגלגלים של העגלה נעים באותה מהירות \(v\). גלגל קטן צריך להסתובב מהר יותר מגלגל גדול: \(n = \dfrac{v}{2\pi R}\), ולכן פי 2 ברדיוס פירושו חצי ממספר הסיבובים.

דוגמה פתורה 1: אופניים

השאלה

קוטר גלגל אופניים 70 ס״מ, והגלגל מבצע 2.5 סיבובים בשנייה. באיזו מהירות נוסעים האופניים, במ׳/ש׳ ובקמ״ש?

  1. נתונים
    \(d = 0.7\ \text{m}\)
    \(n = 2.5\ \text{rev/s}\)
  2. היקףשאלת מרחק
    \(L = \pi d = 0.7\pi \approx 2.199\ \text{m}\)
  3. מהירותשאלת מרחק
    \(v = L\cdot n = 0.7\pi\cdot 2.5 \approx 5.50\ \text{m/s}\)
  4. המרההמרת יחידות
    \(v_{\text{km/h}} = 3.6\,v = 5.50\cdot 3.6 \approx 19.8\ \text{km/h}\)
תשובה:
כ־5.5 מ׳/ש׳, כלומר כ־19.8 קמ״ש

דוגמה פתורה 2: סל״ד

השאלה

רדיוס צמיג 0.3 מ׳, והצמיג מסתובב ב־600 סל״ד. מהי מהירות המכונית?

  1. סיבובים בשנייהשאלת מרחק זוויתי
    \(n = \dfrac{\text{rpm}}{60} = \dfrac{600}{60} = 10\)
  2. היקףשאלת מרחק
    \(L = 2\pi R = 2\pi\cdot 0.3 = 0.6\pi \approx 1.885\ \text{m}\)
  3. מהירותשאלת מרחק
    \(v = L\cdot n = 0.6\pi\cdot 10 = 6\pi \approx 18.85\ \text{m/s}\)
  4. המרההמרת יחידות
    \(v_{\text{km/h}} = 3.6\,v = 18.85\cdot 3.6 \approx 67.9\ \text{km/h}\)
תשובה:
כ־18.85 מ׳/ש׳, כלומר כ־68 קמ״ש

דוגמה פתורה 3: מעלות לשנייה

השאלה

גלגל של עגלת צעצוע ברדיוס 5 ס״מ מסתובב ב־\(540^\circ/\text{s}\). מהי מהירות העגלה?

  1. המרה
    \(R = 0.05\ \text{m}\)
  2. סיבובים בשנייהשאלת מרחק זוויתי
    \(n = \dfrac{|\omega|}{360} = \dfrac{540}{360} = 1.5\)
  3. מהירותשאלת מרחק
    \(v = L\cdot n = 2\pi\cdot 0.05\cdot 1.5 = 0.15\pi \approx 0.47\ \text{m/s}\)
  4. בנוסחה הישירהשאלת מרחקשאלת מרחק זוויתי
    \(v = \dfrac{|\omega|\pi R}{180} = \dfrac{540\cdot\pi\cdot 0.05}{180} \approx 0.47\)
תשובה:
כ־0.47 מ׳/ש׳

דוגמה פתורה 4: ממספר סיבובים למרחק

השאלה

מונה סיבובים על גלגל ברדיוס 0.3 מ׳ ספר 1500 סיבובים. כמה מטרים עברה העגלה?

  1. היקףשאלת מרחק
    \(L = 2\pi R = 0.6\pi \approx 1.885\ \text{m}\)
  2. מרחקשאלת מרחק
    \(s = L\cdot N = 1500\cdot 1.885 \approx 2827\ \text{m}\)
תשובה:
כ־2.83 ק״מ

טעויות נפוצות

  • מציבים קוטר במקום רדיוס ב־\(2\pi R\), ומקבלים מהירות כפולה.
  • שוכחים להמיר ס״מ למטרים, או סל״ד לסיבובים בשנייה (מחלקים ב־60).
  • מכפילים מעלות לשנייה ברדיוס (\(v = \omega R\) נכון רק ברדיאנים!). במעלות: \(v = \dfrac{|\omega|\pi R}{180}\).
  • מערבבים מ׳/ש׳ וקמ״ש: מ־מ׳/ש׳ לקמ״ש כופלים ב־3.6, ובכיוון ההפוך מחלקים.
