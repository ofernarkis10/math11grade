הסבר ונוסחאות

מה זו אינדוקציה? שיטת הוכחה לטענות שתלויות במספר טבעי n, כמו "1 + 2 + … + n = n(n+1)/2 לכל n". אי אפשר לבדוק אינסוף מקרים, אבל אפשר להוכיח שני דברים שיחד מכסים את כולם.

המשמעות: אפקט הדומינו. מעמידים שורה אינסופית של אבני דומינו. אם (1) האבן הראשונה נופלת, ו־(2) כל אבן שנופלת מפילה את זו שאחריה, אז כל האבנים נופלות. בהוכחה: (1) הטענה נכונה עבור n = 1; (2) אם היא נכונה עבור מספר כלשהו k, היא נכונה גם עבור k + 1.

למה זה חשוב בסדרות? הרבה נוסחאות בסדרות "מנחשים" מכמה איברים ראשונים. אינדוקציה הופכת את הניחוש להוכחה. היא מתאימה במיוחד לסדרות בכלל נסיגה, כי כלל הנסיגה הוא בדיוק "איך עוברים מ־k ל־k+1".

שלב 1: בסיסבודקים שהטענה נכונה עבור n = 1 (או הערך ההתחלתי)
שלב 2: הנחהמניחים שהטענה נכונה עבור n = k
שלב 3: צעדמוכיחים בעזרת ההנחה שהיא נכונה עבור n = k+1

נוסחאות סכום: בצעד כותבים S(k+1) = S(k) + aₖ₊₁, מציבים את ההנחה במקום S(k), ומפשטים עד שמגיעים לנוסחה עם k+1. כדאי לכתוב מראש מה רוצים לקבל, כדי לדעת לאן לכוון את הפישוט (לרוב: להוציא גורם משותף (k+1)).

התחלקות: כותבים את הביטוי עבור k+1 כך שיופיע בו הביטוי עבור k. למשל 7ᵏ⁺¹ − 1 = 7(7ᵏ − 1) + 6. החלק הראשון מתחלק לפי ההנחה, והשני מתחלק בבירור.

אי־שוויונות: מתחילים מהאגף של k+1, משתמשים בהנחה כדי להגיע לביטוי ביניים, ואז מראים שביטוי הביניים גדול (או קטן) מהאגף השני. לפעמים הבסיס אינו n = 1, למשל 2ⁿ > n² נכון רק מ־n = 5.

כלל נסיגה: כדי להוכיח ש־aₙ = f(n), מציבים בכלל: aₖ₊₁ = g(aₖ) = g(f(k)), ומראים שזה שווה ל־f(k+1).

טעויות נפוצות: לדלג על הבסיס (בלעדיו ה"הוכחה" יכולה "להוכיח" טענות שגויות); להניח את מה שצריך להוכיח, כלומר להתחיל מהשוויון עבור k+1 ולהגיע ל־0 = 0; לא להשתמש בהנחה בכלל (אז זו לא הוכחה באינדוקציה).

רמה א׳: נוסחאות סכום שאלות 1–12

הוכיחו באינדוקציה לכל n טבעי. בכל פתרון מוצגים הבסיס והצעד.

  1. 1 + 2 + … + n = n(n+1)/2
    הצג פתרון

    בסיס: 1 = 1·2/2 ✓

    צעד: k(k+1)/2 + (k+1) = (k+1)(k+2)/2 ✓

  2. 1 + 3 + 5 + … + (2n−1) = n²
    הצג פתרון

    בסיס: 1 = 1² ✓

    צעד: k² + (2k + 1) = (k+1)² ✓

  3. 2 + 4 + … + 2n = n(n+1)
    הצג פתרון

    בסיס: 2 = 1·2 ✓

    צעד: k(k+1) + 2(k+1) = (k+1)(k+2) ✓

  4. 1² + 2² + … + n² = n(n+1)(2n+1)/6
    הצג פתרון

    בסיס: 1 = 1·2·3/6 ✓

    צעד: k(k+1)(2k+1)/6 + (k+1)² = (k+1)(2k² + 7k + 6)/6 = (k+1)(k+2)(2k+3)/6 ✓

  5. 1³ + 2³ + … + n³ = [n(n+1)/2]²
    הצג פתרון

    בסיס: 1 = 1² ✓

    צעד: k²(k+1)²/4 + (k+1)³ = (k+1)²(k² + 4k + 4)/4 = [(k+1)(k+2)/2]² ✓

  6. 1 + 2 + 4 + … + 2ⁿ⁻¹ = 2ⁿ − 1
    הצג פתרון

    בסיס: 1 = 2 − 1 ✓

    צעד: 2ᵏ − 1 + 2ᵏ = 2ᵏ⁺¹ − 1 ✓

  7. 1 + 3 + 9 + … + 3ⁿ⁻¹ = (3ⁿ − 1)/2
    הצג פתרון

    בסיס: 1 = (3 − 1)/2 ✓

    צעד: (3ᵏ − 1)/2 + 3ᵏ = (3·3ᵏ − 1)/2 = (3ᵏ⁺¹ − 1)/2 ✓

  8. 1·2 + 2·3 + … + n(n+1) = n(n+1)(n+2)/3
    הצג פתרון

    בסיס: 2 = 1·2·3/3 ✓

    צעד: k(k+1)(k+2)/3 + (k+1)(k+2) = (k+1)(k+2)(k+3)/3 ✓

  9. 1/(1·2) + 1/(2·3) + … + 1/(n(n+1)) = n/(n+1)
    הצג פתרון

    בסיס: ½ = ½ ✓

    צעד: k/(k+1) + 1/((k+1)(k+2)) = (k² + 2k + 1)/((k+1)(k+2)) = (k+1)/(k+2) ✓

  10. 1/(1·3) + 1/(3·5) + … + 1/((2n−1)(2n+1)) = n/(2n+1)
    הצג פתרון

    בסיס: ⅓ = ⅓ ✓

    צעד: k/(2k+1) + 1/((2k+1)(2k+3)) = (2k² + 3k + 1)/((2k+1)(2k+3)) = (k+1)/(2k+3) ✓

  11. 1 + 4 + 7 + … + (3n−2) = n(3n−1)/2
    הצג פתרון

    בסיס: 1 = 1·2/2 ✓

    צעד: k(3k−1)/2 + (3k+1) = (3k² + 5k + 2)/2 = (k+1)(3k+2)/2 ✓

  12. 1·2⁰ + 2·2¹ + 3·2² + … + n·2ⁿ⁻¹ = (n−1)·2ⁿ + 1
    הצג פתרון

    בסיס: 1 = 0·2 + 1 ✓

    צעד: (k−1)2ᵏ + 1 + (k+1)2ᵏ = 2k·2ᵏ + 1 = k·2ᵏ⁺¹ + 1 ✓

רמה ב׳: התחלקות שאלות 13–20

הוכיחו באינדוקציה לכל n טבעי.

  1. 7ⁿ − 1 מתחלק ב־6.
    הצג פתרון

    בסיס: 6 ✓

    צעד: 7ᵏ⁺¹ − 1 = 7(7ᵏ − 1) + 6 ✓

  2. 5ⁿ − 1 מתחלק ב־4.
    הצג פתרון

    בסיס: 4 ✓

    צעד: 5ᵏ⁺¹ − 1 = 5(5ᵏ − 1) + 4 ✓

  3. 4ⁿ + 5 מתחלק ב־3.
    הצג פתרון

    בסיס: 9 ✓

    צעד: 4ᵏ⁺¹ + 5 = 4(4ᵏ + 5) − 15 ✓

  4. 3²ⁿ − 1 מתחלק ב־8.
    הצג פתרון

    בסיס: 8 ✓

    צעד: 9ᵏ⁺¹ − 1 = 9(9ᵏ − 1) + 8 ✓

  5. 11ⁿ − 6 מתחלק ב־5.
    הצג פתרון

    בסיס: 5 ✓

    צעד: 11ᵏ⁺¹ − 6 = 11(11ᵏ − 6) + 60 ✓

  6. n³ + 2n מתחלק ב־3.
    הצג פתרון

    בסיס: 3 ✓

    צעד: (k+1)³ + 2(k+1) = (k³ + 2k) + 3(k² + k + 1) ✓

  7. n³ − n מתחלק ב־6.
    הצג פתרון

    בסיס: 0 ✓

    צעד: (k+1)³ − (k+1) = (k³ − k) + 3k(k+1)

    k(k+1) זוגי (מכפלת שני מספרים עוקבים), לכן 3k(k+1) מתחלק ב־6 ✓

  8. 2ⁿ⁺² + 3²ⁿ⁺¹ מתחלק ב־7.
    הצג פתרון

    בסיס: 8 + 27 = 35 ✓

    צעד: 2ᵏ⁺³ + 3²ᵏ⁺³ = 2·2ᵏ⁺² + 9·3²ᵏ⁺¹ = 2(2ᵏ⁺² + 3²ᵏ⁺¹) + 7·3²ᵏ⁺¹ ✓

רמה ג׳: אי־שוויונות וסדרות שאלות 21–30

שימו לב לבסיס בכל שאלה.

  1. 2ⁿ ≥ n + 1 לכל n טבעי.
    הצג פתרון

    בסיס: 2 ≥ 2 ✓

    צעד: 2ᵏ⁺¹ = 2·2ᵏ ≥ 2(k + 1) = 2k + 2 ≥ k + 2 ✓

  2. 3ⁿ > n² לכל n טבעי.
    הצג פתרון

    בסיס: n = 1: 3 > 1; n = 2: 9 > 4 ✓

    צעד (עבור k ≥ 2): 3ᵏ⁺¹ > 3k² ≥ (k+1)², כי 2k² − 2k − 1 ≥ 0 עבור k ≥ 2 ✓

  3. 2ⁿ > n² לכל n ≥ 5.
    הצג פתרון

    בסיס: 32 > 25 ✓

    צעד: 2ᵏ⁺¹ > 2k² ≥ (k+1)², כי k² − 2k − 1 ≥ 0 עבור k ≥ 3 ✓

  4. (אי־שוויון ברנולי) (1 + x)ⁿ ≥ 1 + nx לכל n טבעי ולכל x > −1.
    הצג פתרון

    בסיס: שוויון ✓

    צעד: (1+x)ᵏ⁺¹ ≥ (1 + kx)(1 + x) = 1 + (k+1)x + kx² ≥ 1 + (k+1)x ✓

    (השתמשנו ב־1 + x > 0 כדי לכפול את אי־השוויון.)

  5. נתון a₁ = 3, aₙ₊₁ = 2aₙ + 1. הוכיחו ש־aₙ = 2ⁿ⁺¹ − 1.
    הצג פתרון

    בסיס: 2² − 1 = 3 ✓

    צעד: aₖ₊₁ = 2(2ᵏ⁺¹ − 1) + 1 = 2ᵏ⁺² − 1 ✓

  6. נתון a₁ = 1, aₙ₊₁ = aₙ + 2n + 1. הוכיחו ש־aₙ = n².
    הצג פתרון

    בסיס: 1 = 1² ✓

    צעד: aₖ₊₁ = k² + 2k + 1 = (k+1)² ✓

  7. נתון a₁ = 2, aₙ₊₁ = 2 − 1/aₙ. הוכיחו ש־aₙ = (n+1)/n.
    הצג פתרון

    בסיס: 2/1 = 2 ✓

    צעד: aₖ₊₁ = 2 − k/(k+1) = (k+2)/(k+1) ✓

  8. נתון a₁ = 1, aₙ₊₁ = (aₙ + 4)/3. הוכיחו ש־aₙ < 2 לכל n, ושהסדרה עולה.
    הצג פתרון

    חסם: בסיס 1 < 2 ✓. צעד: אם aₖ < 2 אז aₖ₊₁ < (2 + 4)/3 = 2 ✓

    עלייה: aₙ₊₁ − aₙ = (4 − 2aₙ)/3 > 0, כי aₙ < 2 ✓

  9. הוכיחו: 1·1! + 2·2! + … + n·n! = (n+1)! − 1.
    הצג פתרון

    בסיס: 1 = 2! − 1 ✓

    צעד: (k+1)! − 1 + (k+1)(k+1)! = (k+1)!(k+2) − 1 = (k+2)! − 1 ✓

  10. מצאו את השגיאה: "נוכיח ש־n = n + 1. נניח k = k + 1; מוסיפים 1 לשני האגפים ומקבלים k + 1 = k + 2. הוכחנו."
    הצג פתרון

    הצעד עצמו נכון, אבל אין בסיס: עבור n = 1 מקבלים 1 = 2, וזה שקר.

    בלי האבן הראשונה, אף אבן דומינו לא נופלת.
