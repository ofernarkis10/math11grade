תאוריה: שתי משוואות ונוסחה אחת

איך מתארים את המיקום של נקודה על גלגל שזז ומסתובב: משוואה לינארית למרכז, משוואת סיבוב במעלות, והנוסחה הכללית שמחברת אותן. אחר כך גלגל שמתגלגל בלי החלקה, ושתי דוגמאות פתורות. לתרגול: הדפים הבאים בנושא.

הרעיון

גלגל שהמרכז שלו נע בקו ישר, ובאותו זמן הוא מסתובב. רוצים לדעת איפה נמצאת נקודה P על השפה שלו בכל רגע.

המיקום של P הוא המיקום של המרכז (משוואה לינארית) ועוד המיקום של P ביחס למרכז (סיבוב לפי מעלות). לכן מתחילים משתי משוואות, ובסוף מחברים אותן לנוסחה אחת.

C – מרכז הגלגל · P – הנקודה על השפה · θ – הזווית של P ביחס למרכז · v – מהירות המרכז · ω – מהירות הסיבוב

נושאמוסכמה בכל הדפים של הנושא
זווית \(\theta\)במעלות, נמדדת מהכיוון החיובי של ציר x, נגד כיוון השעון חיובי.
\(\omega\)מהירות זוויתית במעלות לשנייה. חיובית: נגד כיוון השעון. שלילית: עם כיוון השעון.
נקודות מיוחדות על הגלגלימין \(0^\circ\), למעלה \(90^\circ\), שמאל \(180^\circ\), למטה \(270^\circ\) (או \(-90^\circ\)).
זמן\(t\) בשניות; \(t=0\) הוא רגע ההתחלה.
גלגל מתגלגלמתגלגל על ציר x בלי להחליק. נע ימינה: מסתובב עם כיוון השעון (\(\omega \lt 0\)).

משוואה 1: תנועת המרכז (לינארית)

המרכז נע בקו ישר במהירות קבועה: בכל שנייה x גדל ב־\(v_x\) ו־y גדל ב־\(v_y\).

\(x_C(t) = x_A + v_x t \qquad y_C(t) = y_A + v_y t\)
סימון נקודות: \(A\) — נקודת ההתחלה של המרכז (\(t_A = 0\)), \(B\) — נקודת הסיום או נקודה בזמן מאוחר \(t_B\), ו־\(D, E\) — נקודות נוספות לפי הצורך. בנתונים רושמים את הנקודות עם הקואורדינטות, למשל \(A(1,4),\ B(7,8)\), ובביטויים כותבים \(x_A, y_A, x_B, t_B\) — האות של הנקודה קטנה, למטה. האות \(C\) שמורה למרכז הגלגל, \(P\) לנקודה על הגלגל ו־\(L\) להיקף.
רכיבמשמעותאיך מוצאים אותו מהנתונים
\(A(x_A, y_A)\)נקודת ההתחלה של המרכז, ב־\(t_A = 0\)נתון ישירות, או חוזרים אחורה מנקודה בזמן אחר: \(x_A = x_B - v_x t_B\), \(y_A = y_B - v_y t_B\)
\(v_x, v_y\)מהירות המרכז בכל צירמשתי נקודות: \(v_x = \dfrac{{x_B - x_A}}{{t_B - t_A}},\ v_y = \dfrac{{y_B - y_A}}{{t_B - t_A}}\)
מגודל וזווית: \(v_x = |v|\cos\alpha,\ v_y = |v|\sin\alpha\)
\(|v|\)גודל מהירות המרכז\(|v| = \sqrt{{v_x^2 + v_y^2}}\)
\(\alpha\)כיוון התנועה\(\tan\alpha = \dfrac{{v_y}}{{v_x}}\) — ובודקים ברביע לפי הסימנים

משוואה 2: הסיבוב (לפי מעלות)

הגלגל מסתובב במהירות זוויתית קבועה, ולכן הזווית של P משתנה באופן לינארי בזמן.

\(\theta(t) = \theta_0 + \omega t\)
רכיבמשמעותאיך מוצאים אותו מהנתונים
\(\theta_0\)הזווית של P ב־\(t=0\)מתיאור: "בראש הגלגל" \(90^\circ\), "נוגעת בקרקע" \(270^\circ\), "בצד ימין" \(0^\circ\).
מקואורדינטות: \(\cos\theta_0 = \dfrac{{x_P - x_C}}{{R}},\ \sin\theta_0 = \dfrac{{y_P - y_C}}{{R}}\)
\(\omega\)מעלות לשנייה, הסימן הוא הכיווןn סיבובים לשנייה: \(\omega = 360n\) · זמן מחזור: \(\omega = \dfrac{{360}}{{T}}\) · סל״ד: \(\omega = \dfrac{{360\cdot\text{{rpm}}}}{{60}} = 6\cdot\text{{rpm}}\) · משתי זוויות: \(\omega = \dfrac{{\Delta\theta}}{{\Delta t}}\)
שימו לב לסימן: עם כיוון השעון \(\Rightarrow \omega \lt 0\). נגד כיוון השעון \(\Rightarrow \omega \gt 0\).

הנוסחה הכללית

נקודה על מעגל ברדיוס R סביב הראשית נמצאת ב־\((R\cos\theta, R\sin\theta)\). כשהמרכז הוא C, מזיזים: \(P = C + (R\cos\theta, R\sin\theta)\). מציבים את שתי המשוואות:

\(x(t) = \color{#1f6f8b}{x_A + v_x t} + R\cos(\color{#b4561e}{\theta_0 + \omega t})\)
\(y(t) = \color{#1f6f8b}{y_A + v_y t} + R\sin(\color{#b4561e}{\theta_0 + \omega t})\)בכחול: המשוואה הלינארית של המרכז · בכתום: משוואת הסיבוב
שיטת עבודה לכל שאלה
  1. רושמים את הנוסחה הכללית עם 7 מקומות ריקים: \(x_A, y_A, v_x, v_y, R, \theta_0, \omega\).
  2. מרכז: מוצאים \(x_A, y_A, v_x, v_y\).
  3. גלגל: מוצאים \(R\).
  4. סיבוב: מוצאים \(\theta_0\) ו־\(\omega\), כולל הסימן.
  5. רושמים את הנוסחה המלאה, ורק אז מציבים \(t\).

סוגי השאלות

בכל שלב בפתרון כתוב איזה סוג תרגיל פותרים בו. יש שני סוגים עיקריים:

סוגמה מחפשיםדוגמאות לנוסחאות
שאלת מרחקזמן, מהירות או מרחק. גם תנועת המרכז, כשמפרקים אותה ל־x ול־y ומוצאים את מיקום המרכז, היא שאלת מרחק — זו תנועה לינארית.\(v_x = \dfrac{x_B - x_A}{t_B - t_A}\), \(x_C = x_A + v_x t\), \(v = L\cdot n\), \(s = v\cdot t\)
שאלת מרחק זוויתיאותו רעיון בסיבוב: זווית = מהירות זוויתית × זמן.\(\theta = \theta_0 + \omega t\), \(\omega = \dfrac{360}{T}\), \(t = \dfrac{\theta - \theta_0}{\omega}\)
שאלת מיקוםהקואורדינטות של נקודה מסוימת על הגלגל, או הזווית שלה מתוך הקואורדינטות או הגובה.\(x = x_C + R\cos\theta\), \(\sin\theta = \dfrac{y - y_C}{R}\), \(\cos\theta_0 = \dfrac{x_P - x_C}{R}\)

שלב שמשנה רק יחידות (למשל קמ״ש למ׳/ש׳) מסומן „המרת יחידות״.

גלגל מתגלגל בלי החלקה

כשהגלגל מתגלגל על הקרקע בלי להחליק, בכל סיבוב מלא המרכז מתקדם בדיוק היקף אחד, \(2\pi R\). כאן שתי המשוואות כבר תלויות זו בזו: את מהירות המרכז מחשבים מתוך הסיבוב, ולהפך.

מהירות המרכז מתוך מספר הסיבובים בשנייה\(|v| = 2\pi R\cdot n\)
מהירות זוויתית מתוך מספר הסיבובים\(|\omega| = 360 n\)
מ־ω למהירות המרכז\(|v| = \dfrac{|\omega|\,\pi R}{180}\)
ממהירות המרכז ל־ω\(|\omega| = \dfrac{180\,|v|}{\pi R}\)
רכיבבגלגל שמתגלגל על ציר x
\(y_A\)תמיד \(R\): המרכז בגובה הרדיוס
\(v_y\)\(0\)
\(v_x\)\(\pm 2\pi R n\): חיובי כשנע ימינה
\(\omega\)נע ימינה: \(\omega = -360n\). נע שמאלה: \(\omega = +360n\)
\(x(t) = x_A + v t + R\cos(\theta_0 + \omega t)\)
\(y(t) = R + R\sin(\theta_0 + \omega t)\)המסלול של נקודה על גלגל מתגלגל נקרא ציקלואידה (אפשר לראות אותו בסימולטור)
  • שוכחים את הסימן של \(\omega\): גלגל שנוסע ימינה מסתובב עם כיוון השעון.
  • מבלבלים קוטר ורדיוס: ההיקף הוא \(2\pi R = \pi d\).
  • מציבים מהירות בקמ״ש ורדיוס במטרים: קודם ממירים ליחידות אחידות.

דוגמה פתורה 1: גלגל חופשי

השאלה

מרכז גלגל ברדיוס 2 נמצא ב־\(t=0\) בנקודה \(A(1,4)\) וב־\(t=2\) בנקודה \(B(7,8)\). הגלגל מסתובב נגד כיוון השעון ומשלים סיבוב כל 8 שניות. ב־\(t=0\) הנקודה P בראש הגלגל. מצאו את מיקום P ב־\(t=2\).

  1. נתונים
    \(A(1,4)\)
    \(t_A = 0\)
    \(B(7,8)\)
    \(t_B = 2\)
    \(R = 2\)
  2. מרכזשאלת מרחק
    \(v_x = \dfrac{x_B - x_A}{t_B - t_A} = \dfrac{7-1}{2-0} = 3\)
    \(v_y = \dfrac{y_B - y_A}{t_B - t_A} = \dfrac{8-4}{2-0} = 2\)
  3. רדיוס
    \(R = 2\)
  4. סיבובשאלת מרחק זוויתי
    "בראש הגלגל"
    \(\Rightarrow \theta_0 = 90^\circ\)
    סיבוב כל 8 שניות נגד השעון
    \(\Rightarrow \omega = \dfrac{360}{T} = \dfrac{360}{8} = 45^\circ/\text{s}\)
  5. נוסחהשאלת מרחק זוויתישאלת מיקום
    \(x(t) = x_A + v_x t + R\cos(\theta_0 + \omega t) = 1 + 3t + 2\cos(90^\circ + 45^\circ t)\)
    \(y(t) = y_A + v_y t + R\sin(\theta_0 + \omega t) = 4 + 2t + 2\sin(90^\circ + 45^\circ t)\)
  6. הצבה \(t=2\)שאלת מרחקשאלת מרחק זוויתישאלת מיקום
    \(\theta = \theta_0 + \omega t = 90 + 45\cdot 2 = 180^\circ\)
    \(x = x_A + v_x t + R\cos\theta = 1 + 6 + 2\cdot(-1) = 5\)
    \(y = y_A + v_y t + R\sin\theta = 4 + 4 + 0 = 8\)
תשובה:
\(P(5,8)\)
בצד שמאל של המרכז
\((7,8)\)
כמו שמצפים מזווית
\(180^\circ\)

דוגמה פתורה 2: גלגל מתגלגל

השאלה

גלגל ברדיוס 1 מתגלגל ימינה על ציר x בלי החלקה ומשלים סיבוב כל 4 שניות. ב־\(t=0\) המרכז בנקודה \(A(0,1)\) והנקודה P נוגעת בקרקע. מצאו את P ב־\(t=1\) וב־\(t=2\).

  1. מרכזשאלת מרחק
    \(x_A = 0\)
    \(y_A = R = 1\)
    \(v_y = 0\)
  2. מהירות המרכז מתוך הסיבובשאלת מרחק
    בסיבוב אחד (4 שניות) המרכז עובר
    \(2\pi\cdot 1 = 2\pi\)
    ולכן
    \(v_x = \dfrac{2\pi R}{T} = \dfrac{2\pi}{4} = \dfrac{\pi}{2} \approx 1.571\)
  3. סיבובשאלת מרחק זוויתי
    נוגעת בקרקע
    \(\Rightarrow \theta_0 = 270^\circ\)
    נע ימינה
    \(\Rightarrow\)
    עם השעון
    \(\Rightarrow \omega = -\dfrac{360}{T} = -\dfrac{360}{4} = -90^\circ/\text{s}\)
  4. נוסחהשאלת מרחק זוויתישאלת מיקום
    \(x(t) = x_A + v_x t + R\cos(\theta_0 + \omega t) = \tfrac{\pi}{2}t + \cos(270^\circ - 90^\circ t)\)
    \(y(t) = y_A + v_y t + R\sin(\theta_0 + \omega t) = 1 + \sin(270^\circ - 90^\circ t)\)
  5. \(t=1\)שאלת מרחקשאלת מרחק זוויתישאלת מיקום
    \(\theta = \theta_0 + \omega t = 270 - 90 = 180^\circ\)
    \(x = v_x t + R\cos\theta = \tfrac{\pi}{2} - 1 \approx 0.571\)
    \(y = R + R\sin\theta = 1 + 0 = 1\)
  6. \(t=2\)שאלת מרחקשאלת מרחק זוויתישאלת מיקום
    \(\theta = \theta_0 + \omega t = 270 - 180 = 90^\circ\)
    \(x = v_x t + R\cos\theta = \pi + 0 \approx 3.14\)
    \(y = R + R\sin\theta = 1 + 1 = 2\)
תשובה:
\(P(1) \approx (0.571, 1)\)
\(P(2) = (\pi, 2)\)
