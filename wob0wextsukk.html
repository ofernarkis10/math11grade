פתרונות שיעור 1: נגזרת של פולינום במונה ובמכנה

פתרונות מלאים לדף העבודה של שיעור 1: בכל שאלה הנגזרת, מפורקת לגורמים, והנקודות שבהן היא מתאפסת. את סוג הנקודות (מקסימום, מינימום או לא קיצון) קובעים בשיעור 2.

המתכון שבו פותרים את כל השאלות של חלק ב׳
  1. מפרקים את המונה ואת המכנה. אם יש גורם משותף, מצמצמים לפני שגוזרים.
  2. מסמנים את המונה \(g(x)\) ואת המכנה \(h(x)\), ורושמים בנפרד את \(g(x),\ g'(x),\ h(x),\ h'(x)\).
  3. מציבים בכלל המנה \(f'(x) = \dfrac{g'(x)\cdot h(x) - g(x)\cdot h'(x)}{h(x)^{2}}\), עם סוגריים סביב כל גורם.
  4. פותחים סוגריים רק במונה, כל מכפלה בנפרד, ומכנסים.
  5. מפרקים את מונה הנגזרת, ומצמצמים עם המכנה אם אפשר.
  6. משווים את מונה הנגזרת ל־0, ומציבים כל \(x\) בפונקציה כדי למצוא את \(y\).

שאלה 1

פולינום · גזירה איבר איבר
נתון

נתונה הפונקציה \(f(x) = -x^{3} - 6x^{2} - 9x\).

דרך החשיבה

זה פולינום רגיל, ולכן גוזרים כל איבר לפי כלל החזקה. אחר כך מוציאים גורם משותף ומפרקים טרינום, משווים ל־0, ומציבים בפונקציה.

  1. גוזרים כל איבר לפי כלל החזקה
    \((x^{n})' = n\cdot x^{n-1}\)
    \(f'(x) = -3x^{2} - 12x - 9\)
  2. מוציאים גורם משותף \(-3\) ומפרקים את הטרינום
    \(f'(x) = -3(x^{2} + 4x + 3)\)
    \(f'(x) = -3(x+1)(x+3)\)
  3. משווים את הנגזרת ל־0 ופותרים
    \(-3(x+1)(x+3) = 0\)
    \(x = -1,\quad x = -3\)
  4. מציבים כל \(x\) בפונקציה כדי למצוא את \(y\)
    \(f(-1) = -(-1)^{3} - 6(-1)^{2} - 9(-1) = 1 - 6 + 9 = 4\)
    \(f(-3) = -(-3)^{3} - 6(-3)^{2} - 9(-3) = 27 - 54 + 27 = 0\)
תשובה:
\(f'(x) = -3(x+1)(x+3)\)
x\(-3\)\(-1\)
y = f(x)\(0\)\(4\)

שאלה 2

פולינום בחזקה · כלל השרשרת
נתון

נתונה הפונקציה \(f(x) = (x^{2}-9)^{2}\).

דרך החשיבה

הפונקציה היא סוגריים בחזקה. לא פותחים את הסוגריים: גוזרים בכלל השרשרת, כך שהנגזרת יוצאת כבר מפורקת.

  1. רושמים את כלל השרשרת לחזקה של פולינום
    \(\left[g(x)^{n}\right]' = n\cdot g(x)^{n-1}\cdot g'(x)\)
  2. מציבים: החזקה יורדת, הסוגריים נשארים, וכופלים בנגזרת הפנימית
    \(g(x) = x^{2}-9\qquad g'(x) = 2x\)
    \(f'(x) = 2(x^{2}-9)\cdot 2x\)
    \(f'(x) = 4x(x^{2}-9)\)
  3. מפרקים את הפרש הריבועים
    \(f'(x) = 4x(x-3)(x+3)\)
  4. משווים את הנגזרת ל־0 ופותרים
    \(4x(x-3)(x+3) = 0\)
    \(x = 0,\quad x = 3,\quad x = -3\)
  5. מציבים כל \(x\) בפונקציה
    \(f(0) = (0-9)^{2} = 81\)
    \(f(3) = (9-9)^{2} = 0\)
    \(f(-3) = (9-9)^{2} = 0\)
תשובה:
\(f'(x) = 4x(x-3)(x+3)\)
x\(-3\)\(0\)\(3\)
y = f(x)\(0\)\(81\)\(0\)

שאלה 3

מכפלה · כלל המכפלה ושרשרת
נתון

נתונה הפונקציה \(f(x) = (x-2)(x+2)^{3}\).

דרך החשיבה

הפונקציה היא מכפלה של שני גורמים, ולכן גוזרים בכלל המכפלה. בגורם \((x+2)^{3}\) משתמשים בכלל השרשרת. בסוף מוציאים את \((x+2)^{2}\) כגורם משותף, בלי לפתוח סוגריים.

  1. רושמים את כלל המכפלה
    \((u\cdot v)' = u'\cdot v + u\cdot v'\)
  2. רושמים בנפרד את \(u, u', v, v'\)
    \(u = x-2\qquad u' = 1\)
    \(v = (x+2)^{3}\qquad v' = 3(x+2)^{2}\)
  3. מציבים בכלל המכפלה
    \(f'(x) = 1\cdot(x+2)^{3} + (x-2)\cdot 3(x+2)^{2}\)
  4. מוציאים גורם משותף \((x+2)^{2}\) ומכנסים בסוגריים
    \(f'(x) = (x+2)^{2}\left[(x+2) + 3(x-2)\right]\)
    \(f'(x) = (x+2)^{2}(4x - 4)\)
    \(f'(x) = 4(x-1)(x+2)^{2}\)
  5. משווים את הנגזרת ל־0 ופותרים
    \(4(x-1)(x+2)^{2} = 0\)
    \(x = 1,\quad x = -2\)
  6. מציבים כל \(x\) בפונקציה
    \(f(1) = (1-2)(1+2)^{3} = -1\cdot 27 = -27\)
    \(f(-2) = (-2-2)(-2+2)^{3} = -4\cdot 0 = 0\)
תשובה:
\(f'(x) = 4(x-1)(x+2)^{2}\)
x\(-2\)\(1\)
y = f(x)\(0\)\(-27\)

שאלה 4

מונה ומכנה ממעלה שנייה
נתון

נתונה הפונקציה \(f(x) = \dfrac{x^{2} - 5x + 4}{x^{2} + 5x + 4}\).

דרך החשיבה

פונקציה עם פולינום במונה ובמכנה: עובדים לפי המתכון. מפרקים קודם כדי לבדוק אם יש גורם משותף, ואחר כך גוזרים בכלל המנה ופותחים סוגריים רק במונה.

  1. מפרקים את המונה ואת המכנה ובודקים אם יש גורם משותף
    \(f(x) = \dfrac{(x-1)(x-4)}{(x+1)(x+4)}\)
    אין גורם משותף, ולכן גוזרים את הפונקציה כמו שהיא.
  2. רושמים בנפרד את \(g(x),\ g'(x),\ h(x),\ h'(x)\)
    \(g(x) = x^{2} - 5x + 4\qquad g'(x) = 2x - 5\)
    \(h(x) = x^{2} + 5x + 4\qquad h'(x) = 2x + 5\)
  3. מציבים בכלל המנה, עם סוגריים סביב כל גורם
    \(f'(x) = \dfrac{g'(x)\cdot h(x) - g(x)\cdot h'(x)}{h(x)^{2}}\)
    \(f'(x) = \dfrac{(2x-5)(x^{2}+5x+4) - (x^{2}-5x+4)(2x+5)}{(x^{2}+5x+4)^{2}}\)
  4. פותחים סוגריים במונה, כל מכפלה בנפרד
    \((2x-5)(x^{2}+5x+4) = 2x^{3} + 5x^{2} - 17x - 20\)
    \((x^{2}-5x+4)(2x+5) = 2x^{3} - 5x^{2} - 17x + 20\)
  5. מחסרים את המכפלה השנייה מהראשונה ומכנסים איברים
    \((2x^{3} + 5x^{2} - 17x - 20) - (2x^{3} - 5x^{2} - 17x + 20) = 10x^{2} - 40\)
  6. מפרקים את מונה הנגזרת
    \(10x^{2} - 40 = 10(x^{2}-4) = 10(x-2)(x+2)\)
    \(f'(x) = \dfrac{10(x-2)(x+2)}{(x^{2}+5x+4)^{2}}\)
  7. משווים את מונה הנגזרת ל־0 ופותרים
    \(10(x-2)(x+2) = 0\)
    \(x = 2,\quad x = -2\)
  8. מציבים כל \(x\) בפונקציה
    \(f(2) = \dfrac{4 - 10 + 4}{4 + 10 + 4} = \dfrac{-2}{18} = -\dfrac{1}{9}\)
    \(f(-2) = \dfrac{4 + 10 + 4}{4 - 10 + 4} = \dfrac{18}{-2} = -9\)
תשובה:
\(f'(x) = \dfrac{10(x-2)(x+2)}{(x^{2}+5x+4)^{2}}\)
x\(-2\)\(2\)
y = f(x)\(-9\)\(-\dfrac19\)

שאלה 5

מכנה שהוא ריבוע שלם
נתון

נתונה הפונקציה \(f(x) = \dfrac{x^{2} - 3x}{x^{2} + 6x + 9}\).

דרך החשיבה

המכנה הוא ריבוע שלם, \((x+3)^{2}\). גוזרים לפי המתכון, ובסוף מונה הנגזרת מתפרק עם גורם \((x+3)\) שמצטמצם עם המכנה.

  1. מפרקים את המונה ואת המכנה ובודקים אם יש גורם משותף
    \(f(x) = \dfrac{x(x-3)}{(x+3)^{2}}\)
    אין גורם משותף.
  2. רושמים בנפרד את \(g(x),\ g'(x),\ h(x),\ h'(x)\)
    \(g(x) = x^{2} - 3x\qquad g'(x) = 2x - 3\)
    \(h(x) = x^{2} + 6x + 9\qquad h'(x) = 2x + 6\)
  3. מציבים בכלל המנה
    \(f'(x) = \dfrac{g'(x)\cdot h(x) - g(x)\cdot h'(x)}{h(x)^{2}}\)
    \(f'(x) = \dfrac{(2x-3)(x^{2}+6x+9) - (x^{2}-3x)(2x+6)}{(x^{2}+6x+9)^{2}}\)
  4. פותחים סוגריים במונה, כל מכפלה בנפרד
    \((2x-3)(x^{2}+6x+9) = 2x^{3} + 9x^{2} - 27\)
    \((x^{2}-3x)(2x+6) = 2x^{3} - 18x\)
  5. מחסרים ומכנסים איברים
    \((2x^{3} + 9x^{2} - 27) - (2x^{3} - 18x) = 9x^{2} + 18x - 27\)
  6. מפרקים את מונה הנגזרת ומצמצמים עם המכנה
    \(9x^{2} + 18x - 27 = 9(x^{2} + 2x - 3) = 9(x+3)(x-1)\)
    \(f'(x) = \dfrac{9(x+3)(x-1)}{(x+3)^{4}} = \dfrac{9(x-1)}{(x+3)^{3}}\)
  7. משווים את מונה הנגזרת ל־0 ופותרים
    \(9(x-1) = 0\)
    \(x = 1\)
  8. מציבים את \(x\) בפונקציה
    \(f(1) = \dfrac{1 - 3}{1 + 6 + 9} = \dfrac{-2}{16} = -\dfrac{1}{8}\)
תשובה:
\(f'(x) = \dfrac{9(x-1)}{(x+3)^{3}}\)
x\(1\)
y = f(x)\(-\dfrac18\)

שאלה 6

מונה ריבוע שלם, מכנה הפרש ריבועים
נתון

נתונה הפונקציה \(f(x) = \dfrac{x^{2} - 2x + 1}{x^{2} - 4}\).

דרך החשיבה

מפרקים ובודקים שאין גורם משותף, ואז גוזרים לפי המתכון. מונה הנגזרת יוצא טרינום שמתפרק לשורשים שלמים.

  1. מפרקים את המונה ואת המכנה ובודקים אם יש גורם משותף
    \(f(x) = \dfrac{(x-1)^{2}}{(x-2)(x+2)}\)
    אין גורם משותף.
  2. רושמים בנפרד את \(g(x),\ g'(x),\ h(x),\ h'(x)\)
    \(g(x) = x^{2} - 2x + 1\qquad g'(x) = 2x - 2\)
    \(h(x) = x^{2} - 4\qquad h'(x) = 2x\)
  3. מציבים בכלל המנה
    \(f'(x) = \dfrac{g'(x)\cdot h(x) - g(x)\cdot h'(x)}{h(x)^{2}}\)
    \(f'(x) = \dfrac{(2x-2)(x^{2}-4) - (x^{2}-2x+1)\cdot 2x}{(x^{2}-4)^{2}}\)
  4. פותחים סוגריים במונה, כל מכפלה בנפרד
    \((2x-2)(x^{2}-4) = 2x^{3} - 2x^{2} - 8x + 8\)
    \((x^{2}-2x+1)\cdot 2x = 2x^{3} - 4x^{2} + 2x\)
  5. מחסרים ומכנסים איברים
    \((2x^{3} - 2x^{2} - 8x + 8) - (2x^{3} - 4x^{2} + 2x) = 2x^{2} - 10x + 8\)
  6. מפרקים את מונה הנגזרת
    \(2x^{2} - 10x + 8 = 2(x^{2} - 5x + 4) = 2(x-1)(x-4)\)
    \(f'(x) = \dfrac{2(x-1)(x-4)}{(x^{2}-4)^{2}}\)
  7. משווים את מונה הנגזרת ל־0 ופותרים
    \(2(x-1)(x-4) = 0\)
    \(x = 1,\quad x = 4\)
  8. מציבים כל \(x\) בפונקציה
    \(f(1) = \dfrac{1 - 2 + 1}{1 - 4} = \dfrac{0}{-3} = 0\)
    \(f(4) = \dfrac{16 - 8 + 1}{16 - 4} = \dfrac{9}{12} = \dfrac{3}{4}\)
תשובה:
\(f'(x) = \dfrac{2(x-1)(x-4)}{(x^{2}-4)^{2}}\)
x\(1\)\(4\)
y = f(x)\(0\)\(\dfrac34\)

שאלה 7

הנגזרת לא מתאפסת
נתון

נתונה הפונקציה \(f(x) = \dfrac{x^{2} - 4x}{x^{2} - 4x + 4}\).

דרך החשיבה

כאן \(g'(x)\) ו־\(h'(x)\) שווים, ולכן במונה של כלל המנה אפשר להוציא את \((2x-4)\) כגורם משותף במקום לפתוח סוגריים. מונה הנגזרת יוצא מספר, ולכן הנגזרת לא מתאפסת אף פעם.

  1. מפרקים את המונה ואת המכנה ובודקים אם יש גורם משותף
    \(f(x) = \dfrac{x(x-4)}{(x-2)^{2}}\)
    אין גורם משותף.
  2. רושמים בנפרד את \(g(x),\ g'(x),\ h(x),\ h'(x)\)
    \(g(x) = x^{2} - 4x\qquad g'(x) = 2x - 4\)
    \(h(x) = x^{2} - 4x + 4\qquad h'(x) = 2x - 4\)
  3. מציבים בכלל המנה
    \(f'(x) = \dfrac{g'(x)\cdot h(x) - g(x)\cdot h'(x)}{h(x)^{2}}\)
    \(f'(x) = \dfrac{(2x-4)(x^{2}-4x+4) - (x^{2}-4x)(2x-4)}{(x^{2}-4x+4)^{2}}\)
  4. מוציאים גורם משותף \((2x-4)\) מהמונה ומכנסים בסוגריים
    \((2x-4)\left[(x^{2}-4x+4) - (x^{2}-4x)\right] = (2x-4)\cdot 4 = 8(x-2)\)
  5. כותבים את המכנה מפורק ומצמצמים
    \((x^{2}-4x+4)^{2} = (x-2)^{4}\)
    \(f'(x) = \dfrac{8(x-2)}{(x-2)^{4}} = \dfrac{8}{(x-2)^{3}}\)
  6. משווים את מונה הנגזרת ל־0
    \(8 \neq 0\)
    אין פתרון: המונה הוא המספר 8, והוא אף פעם לא 0.
תשובה:
\(f'(x) = \dfrac{8}{(x-2)^{3}}\)

אין נקודות שבהן הנגזרת מתאפסת.

שאלה 8

מונה ממעלה רביעית
נתון

נתונה הפונקציה \(f(x) = \dfrac{2x^{4}}{x^{2} + 2x + 1}\).

דרך החשיבה

המונה הוא חזקה אחת, ולכן \(g'(x)\) קל. אחרי פתיחת הסוגריים מוציאים גורם משותף \(4x^{3}\), ונשאר טרינום שמתפרק. גורם \((x+1)\) מצטמצם עם המכנה.

  1. מפרקים את המונה ואת המכנה ובודקים אם יש גורם משותף
    \(f(x) = \dfrac{2x^{4}}{(x+1)^{2}}\)
    אין גורם משותף.
  2. רושמים בנפרד את \(g(x),\ g'(x),\ h(x),\ h'(x)\)
    \(g(x) = 2x^{4}\qquad g'(x) = 8x^{3}\)
    \(h(x) = x^{2} + 2x + 1\qquad h'(x) = 2x + 2\)
  3. מציבים בכלל המנה
    \(f'(x) = \dfrac{g'(x)\cdot h(x) - g(x)\cdot h'(x)}{h(x)^{2}}\)
    \(f'(x) = \dfrac{8x^{3}(x^{2}+2x+1) - 2x^{4}(2x+2)}{(x^{2}+2x+1)^{2}}\)
  4. פותחים סוגריים במונה, כל מכפלה בנפרד
    \(8x^{3}(x^{2}+2x+1) = 8x^{5} + 16x^{4} + 8x^{3}\)
    \(2x^{4}(2x+2) = 4x^{5} + 4x^{4}\)
  5. מחסרים ומכנסים איברים
    \((8x^{5} + 16x^{4} + 8x^{3}) - (4x^{5} + 4x^{4}) = 4x^{5} + 12x^{4} + 8x^{3}\)
  6. מוציאים גורם משותף, מפרקים את הטרינום ומצמצמים עם המכנה
    \(4x^{5} + 12x^{4} + 8x^{3} = 4x^{3}(x^{2} + 3x + 2) = 4x^{3}(x+1)(x+2)\)
    \(f'(x) = \dfrac{4x^{3}(x+1)(x+2)}{(x+1)^{4}} = \dfrac{4x^{3}(x+2)}{(x+1)^{3}}\)
  7. משווים את מונה הנגזרת ל־0 ופותרים
    \(4x^{3}(x+2) = 0\)
    \(x = 0,\quad x = -2\)
  8. מציבים כל \(x\) בפונקציה
    \(f(0) = \dfrac{2\cdot 0}{1} = 0\)
    \(f(-2) = \dfrac{2\cdot 16}{4 - 4 + 1} = \dfrac{32}{1} = 32\)
תשובה:
\(f'(x) = \dfrac{4x^{3}(x+2)}{(x+1)^{3}}\)
x\(-2\)\(0\)
y = f(x)\(32\)\(0\)

שאלה 9

מונה ממעלה שלישית
נתון

נתונה הפונקציה \(f(x) = \dfrac{x^{3}}{x^{2} - 2x + 1}\).

דרך החשיבה

אותו מתכון: אחרי פתיחת הסוגריים מוציאים \(x^{2}\) כגורם משותף, מפרקים את הטרינום שנשאר, ומצמצמים \((x-1)\) עם המכנה.

  1. מפרקים את המונה ואת המכנה ובודקים אם יש גורם משותף
    \(f(x) = \dfrac{x^{3}}{(x-1)^{2}}\)
    אין גורם משותף.
  2. רושמים בנפרד את \(g(x),\ g'(x),\ h(x),\ h'(x)\)
    \(g(x) = x^{3}\qquad g'(x) = 3x^{2}\)
    \(h(x) = x^{2} - 2x + 1\qquad h'(x) = 2x - 2\)
  3. מציבים בכלל המנה
    \(f'(x) = \dfrac{g'(x)\cdot h(x) - g(x)\cdot h'(x)}{h(x)^{2}}\)
    \(f'(x) = \dfrac{3x^{2}(x^{2}-2x+1) - x^{3}(2x-2)}{(x^{2}-2x+1)^{2}}\)
  4. פותחים סוגריים במונה, כל מכפלה בנפרד
    \(3x^{2}(x^{2}-2x+1) = 3x^{4} - 6x^{3} + 3x^{2}\)

נתון

נתונה הפונקציה \(f(x) = \dfrac{x^{3} - 2x^{2} - 11x + 12}{x^{2} + 3x}\).

דרך החשיבה

כאן הצעד הראשון של המתכון חוסך הרבה עבודה: מפרקים את המונה (פולינום ממעלה שלישית) ואת המכנה, מגלים גורם משותף \((x+3)\), מצמצמים, ורק אז גוזרים פונקציה פשוטה יותר.

  1. מחפשים שורש שלם של המונה: מציבים מחלקים של 12
    \(1 - 2 - 11 + 12 = 0\)
    \(x=1\) הוא שורש, ולכן \((x-1)\) הוא גורם של המונה.
  2. מוצאים את הגורם השני בהשוואת מקדמים
    \(x^{3} - 2x^{2} - 11x + 12 = (x-1)(x^{2} + bx + c)\)
    \((x-1)(x^{2} + bx + c) = x^{3} + (b-1)x^{2} + (c-b)x - c\)
    \(b - 1 = -2 \;\Rightarrow\; b = -1\)
    \(-c = 12 \;\Rightarrow\; c = -12\)
    \(x^{3} - 2x^{2} - 11x + 12 = (x-1)(x^{2} - x - 12) = (x-1)(x-4)(x+3)\)
  3. מפרקים את המכנה ומצמצמים את הגורם המשותף
    \(x^{2} + 3x = x(x+3)\)
    \(f(x) = \dfrac{(x-1)(x-4)(x+3)}{x(x+3)} = \dfrac{x^{2} - 5x + 4}{x}\)
  4. רושמים בנפרד את \(g(x),\ g'(x),\ h(x),\ h'(x)\) של הפונקציה המצומצמת
    \(g(x) = x^{2} - 5x + 4\qquad g'(x) = 2x - 5\)
    \(h(x) = x\qquad h'(x) = 1\)
  5. מציבים בכלל המנה ומכנסים את המונה
    \(f'(x) = \dfrac{g'(x)\cdot h(x) - g(x)\cdot h'(x)}{h(x)^{2}}\)
    \(f'(x) = \dfrac{(2x-5)\cdot x - (x^{2}-5x+4)\cdot 1}{x^{2}}\)
    \(f'(x) = \dfrac{2x^{2} - 5x - x^{2} + 5x - 4}{x^{2}} = \dfrac{x^{2} - 4}{x^{2}}\)
  6. מפרקים את מונה הנגזרת
    \(f'(x) = \dfrac{(x-2)(x+2)}{x^{2}}\)
  7. משווים את מונה הנגזרת ל־0 ופותרים
    \((x-2)(x+2) = 0\)
    \(x = 2,\quad x = -2\)
  8. מציבים כל \(x\) בפונקציה המצומצמת
    \(f(2) = \dfrac{4 - 10 + 4}{2} = \dfrac{-2}{2} = -1\)
    \(f(-2) = \dfrac{4 + 10 + 4}{-2} = \dfrac{18}{-2} = -9\)
תשובה:
\(f'(x) = \dfrac{(x-2)(x+2)}{x^{2}}\)
