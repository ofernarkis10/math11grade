שיעור שני – חישוב הדוגמאות בנוסחה

בדף הדוגמאות של שיעור שני פתרנו את השאלות בטבלה – שנה אחרי שנה. עכשיו נפתור אותן בעזרת הנוסחה:

f(t) = a · bt

כותבים פונקציה לכל קבוצה, משווים ביניהן, ופותרים את המשוואה. בסוף כל שאלה טבלת בדיקה מראה שהתשובה נכונה.

סדר הפתרון בכל שאלה: מוצאים את b של כל קבוצה, כותבים פונקציה לכל קבוצה (את מה שלא ידוע מסמנים באות), משווים בין הפונקציות בזמן המתאים, פותרים, ובודקים בטבלה.

שאלה 1 – שתי שמורות דולפינים 🐬

בשמורה א' יש 1,728 דולפינים, ומספרם גדל ב-25% בכל שנה.
בשמורה ב' יש 1,000 דולפינים, ומספרם גדל ב-50% בכל שנה.
אחרי כמה שנים יהיה בשתי השמורות אותו מספר דולפינים? כמה דולפינים יהיו אז בכל שמורה?

מתרגמים את אחוזי הגידול של כל שמורה למספר שמכפילים בו (בניית פונקציה)
b = 1 + p/100 bA = 1 + 25/100 = 1.25 bB = 1 + 50/100 = 1.5
כותבים פונקציה לכל שמורה (בניית פונקציה)
f(t) = a · bt A(t) = 1728 · 1.25t B(t) = 1000 · 1.5t
משווים בין הפונקציות, כי מחפשים את השנה שבה מספר הדולפינים שווה (פתרון משוואה)
A(t) = B(t) 1728 · 1.25t = 1000 · 1.5t
מעבירים אגפים: החזקות לאגף אחד והמספרים לאגף השני
1.5t / 1.25t = 1728 / 1000 (1.5 / 1.25)t = 1.728 1.2t = 1.728

חילוק של שתי חזקות עם אותו מעריך: xt / yt = (x / y)t.

מוצאים איזו חזקה של 1.2 נותנת 1.728 (פתרון משוואה)
1.21 = 1.2 1.22 = 1.44 1.23 = 1.728 t = 3
מציבים t = 3 בשתי הפונקציות, כדי למצוא את מספר הדולפינים ולוודא שהוא שווה (חישוב ערך)
A(3) = 1728 · 1.253 = 1728 · 1.953125 = 3375 B(3) = 1000 · 1.53 = 1000 · 3.375 = 3375

תשובה: אחרי 3 שנים יהיו בכל שמורה 3,375 דולפינים.

שאלה 2 – שני עדרי כבשים 🐑

בעדר א' היו בהתחלה 500 כבשים, ומספרן גדל ב-20% בכל שנה.
בעדר ב' מספר הכבשים גדל ב-50% בכל שנה.
אחרי 3 שנים היה בשני העדרים אותו מספר כבשים. כמה כבשים היו בהתחלה בעדר ב'?

מתרגמים את אחוזי הגידול של כל עדר למספר שמכפילים בו (בניית פונקציה)
b = 1 + p/100 bA = 1 + 20/100 = 1.2 bB = 1 + 50/100 = 1.5
כותבים פונקציה לכל עדר; הערך ההתחלתי של עדר ב' לא ידוע, ומסמנים אותו a (בניית פונקציה)
f(t) = a · bt A(t) = 500 · 1.2t B(t) = a · 1.5t
מציבים t = 3 בפונקציה של עדר א' כדי למצוא כמה כבשים יש בו אחרי 3 שנים (חישוב ערך)
A(3) = 500 · 1.23 A(3) = 500 · 1.728 A(3) = 864
משווים: אחרי 3 שנים יש בעדר ב' אותו מספר כבשים, ומחלצים את a (מציאת פרמטר)
B(3) = A(3) a · 1.53 = 864 a · 3.375 = 864 a = 864 / 3.375 a = 256

תשובה: בהתחלה היו בעדר ב' 256 כבשים.

שאלה 3 – שתי בריכות דגים שהתחילו בזמנים שונים 🐟

בבריכה א' הכניסו 256 דגים, ומספרם גדל ב-50% בכל שנה.
שנתיים אחרי זה הכניסו דגים לבריכה ב', ושם מספר הדגים מוכפל בכל שנה.
5 שנים אחרי שהכניסו את הדגים לבריכה א', היה בשתי הבריכות אותו מספר דגים. כמה דגים הכניסו לבריכה ב'?

מתרגמים את קצב הגידול של כל בריכה למספר שמכפילים בו (בניית פונקציה)
b = 1 + p/100 bA = 1 + 50/100 = 1.5 bB = 2

בבריכה ב' מספר הדגים מוכפל בכל שנה – גידול של 100%.

כותבים פונקציה לכל בריכה; בבריכה ב' המעריך הוא מספר השנים מאז שהוכנסו אליה הדגים, t − 2 (בניית פונקציה)
f(t) = a · bt A(t) = 256 · 1.5t B(t) = a · 2t − 2 , t ≥ 2

t נמדד מהשנה שבה הכניסו דגים לבריכה א'. בבריכה ב' הדגים הוכנסו בשנה 2, ולכן בשנה t הם גדלו רק t − 2 שנים.

מציבים t = 5 בפונקציה של בריכה א' (חישוב ערך)
A(5) = 256 · 1.55 A(5) = 256 · 7.59375 A(5) = 1944
משווים: בשנה 5 יש בבריכה ב' אותו מספר דגים, ומחלצים את a (מציאת פרמטר)
B(5) = A(5) a · 25 − 2 = 1944 a · 23 = 1944 8a = 1944 a = 1944 / 8 a = 243

תשובה: לבריכה ב' הכניסו 243 דגים. אם היינו כותבים 25 במקום 23, היינו מקבלים 1944 / 32 = 60.75 – תשובה שגויה (ואפילו לא מספר שלם).

סיכום

  • כשמשווים שתי קבוצות, כותבים פונקציה לכל אחת ומשווים: A(t) = B(t).
  • כשהזמן לא ידוע – מעבירים אגפים ומגיעים למשוואה מהצורה ct = d, ומוצאים את החזקה המתאימה.
  • כשהערך ההתחלתי לא ידוע – מציבים את הזמן הידוע ומחלקים: a = d / bt.
  • כשקבוצה התחילה מאוחר יותר, המעריך שלה הוא מספר השנים שהיא גדלה, למשל t − 2.
