הסבר ונוסחאות

מה זו נוסחת איבר כללי? נוסחה שנותנת את aₙ ישירות כפונקציה של מקומו n. למשל aₙ = n² + 1 נותנת 2, 5, 10, 17, …, ואפשר לחשב את a₁₀₀ = 10,001 בלי לחשב את כל האיברים שלפניו.

המשמעות: סדרה היא פונקציה שהתחום שלה הוא המספרים הטבעיים 1, 2, 3, …. הגרף שלה הוא אוסף של נקודות בודדות, לא קו רציף. לכן הרבה ממה שיודעים על פונקציות עובד גם כאן (קודקוד של פרבולה, עלייה וירידה), אבל תמיד צריך לזכור ש־n חייב להיות מספר טבעי.

השוואה לכלל נסיגה: כלל נסיגה אומר "איך מתקדמים". נוסחת איבר כללי אומרת "איפה נמצאים". לכל סדרה חשבונית והנדסית יש גם וגם.

האם k איבר בסדרה?פותרים aₙ = k ובודקים ש־n טבעי
עולה / יורדתהסימן של aₙ₊₁ − aₙ
איבר מתוך סכומיםaₙ = Sₙ − Sₙ₋₁ עבור n ≥ 2
האיבר הראשוןa₁ = S₁

חקירת מונוטוניות: מחשבים aₙ₊₁ − aₙ ומפשטים. אם התוצאה חיובית לכל n, הסדרה עולה. בסדרות חיוביות אפשר גם לבדוק אם aₙ₊₁/aₙ גדול מ־1.

האיבר הגדול או הקטן ביותר: בנוסחה ריבועית מוצאים את קודקוד הפרבולה. אם הקודקוד אינו מספר שלם, בודקים את שני השלמים הסמוכים. אם הקודקוד בדיוק באמצע בין שני שלמים, יש שני איברים שווים קיצוניים.

מ־Sₙ ל־aₙ: הסכום של n איברים פחות הסכום של n−1 איברים הוא בדיוק האיבר ה־n. הנוסחה נכונה רק מ־n = 2, ולכן תמיד בודקים בנפרד אם a₁ = S₁ מתאים לאותה נוסחה. אם Sₙ ריבועי בלי מקדם חופשי, הסדרה חשבונית; אם יש מקדם חופשי, היא חשבונית רק החל מהאיבר השני.

סכום טלסקופי: כשאפשר לכתוב aₙ = f(n) − f(n+1), בסכום כמעט הכול מתבטל: Sₙ = f(1) − f(n+1).

טעויות נפוצות: לקבל n שלילי או שבר ולא לפסול; להשתמש ב־aₙ = Sₙ − Sₙ₋₁ גם עבור n = 1; לבלבל בין "הסדרה עולה" לבין "הפונקציה עולה בקטע" כשהקודקוד נמצא בין 1 ל־2.

רמה א׳: בסיס שאלות 1–10

חישוב איברים, זיהוי נוסחה ושאלת "האם זה איבר".

  1. נתון aₙ = 3n − 2. כתבו את חמשת האיברים הראשונים ואת a₂₀.
    הצג פתרון

    1, 4, 7, 10, 13

    a₂₀ = 58

  2. נתון aₙ = n² + 1. כתבו את חמשת האיברים הראשונים ואת a₁₀.
    הצג פתרון

    2, 5, 10, 17, 26

    a₁₀ = 101

  3. נתון aₙ = (−1)ⁿ·n. כתבו את חמשת האיברים הראשונים.
    הצג פתרון

    −1, 2, −3, 4, −5

  4. נתון aₙ = (n+1)/n. כתבו את ארבעת האיברים הראשונים. לאיזה מספר הם מתקרבים?
    הצג פתרון

    2, 3/2, 4/3, 5/4

    aₙ = 1 + 1/n, ולכן הם מתקרבים ל־1.

  5. האם 58 הוא איבר בסדרה aₙ = 3n + 1?
    הצג פתרון

    3n + 1 = 58 ⇒ n = 19. כן, a₁₉ = 58.

  6. האם 50 הוא איבר בסדרה aₙ = n² + n?
    הצג פתרון

    n² + n − 50 = 0, הדיסקרימיננטה 201 אינה ריבוע שלם, ולכן אין פתרון טבעי.

    (a₆ = 42, a₇ = 56.) 50 אינו איבר.

  7. אילו איברים בסדרה aₙ = n² − 7n + 10 שווים לאפס?
    הצג פתרון

    (n − 2)(n − 5) = 0 ⇒ a₂ = a₅ = 0

  8. כתבו נוסחת איבר כללי לכל אחת מהסדרות:
    א. 2, 4, 6, 8, … ב. 1, 4, 9, 16, … ג. 3, 9, 27, … ד. ½, ⅔, ¾, …
    הצג פתרון

    א. aₙ = 2n ב. aₙ = n² ג. aₙ = 3ⁿ ד. aₙ = n/(n+1)

  9. נתון aₙ = 2ⁿ − 1. חשבו את a₁₀. מהו האיבר הראשון שגדול מ־1000?
    הצג פתרון

    a₁₀ = 1023, ו־a₉ = 511. לכן a₁₀ הוא הראשון.

  10. נתון aₙ = 5 − 2n. הוכיחו שהסדרה יורדת.
    הצג פתרון

    aₙ₊₁ − aₙ = (3 − 2n) − (5 − 2n) = −2 < 0

רמה ב׳: ביסוס שאלות 11–22

איבר קיצון, מונוטוניות ומעבר מ־Sₙ ל־aₙ.

  1. מצאו את האיבר הקטן ביותר בסדרה aₙ = n² − 10n + 30.
    הצג פתרון

    קודקוד ב־n = 5: a₅ = 25 − 50 + 30 = 5

  2. מצאו את האיבר הקטן ביותר בסדרה aₙ = n² − 9n + 25.
    הצג פתרון

    הקודקוד ב־n = 4.5, בודקים את 4 ו־5:

    a₄ = 16 − 36 + 25 = 5, a₅ = 25 − 45 + 25 = 5

    יש שני איברים מינימליים, a₄ = a₅ = 5.

  3. כמה איברים בסדרה aₙ = n² − 12n + 20 שליליים?
    הצג פתרון

    (n − 2)(n − 10) < 0 ⇒ 2 < n < 10

    n = 3, …, 9: שבעה איברים.

  4. הוכיחו שהסדרה aₙ = (3n+1)/(n+2) עולה, ושכל איבריה קטנים מ־3.
    הצג פתרון

    aₙ₊₁ − aₙ = (3n+4)/(n+3) − (3n+1)/(n+2) = 5/[(n+2)(n+3)] > 0

    aₙ = 3 − 5/(n+2) < 3

  5. מצאו את האיבר הקטן ביותר בסדרה aₙ = n + 20/n.
    הצג פתרון

    a₃ = 3 + 6.67 ≈ 9.67, a₄ = 4 + 5 = 9, a₅ = 5 + 4 = 9, a₆ ≈ 9.33

    האיבר המינימלי הוא 9 (מתקבל ב־n = 4 וב־n = 5).

  6. נתון Sₙ = n² + 4n. מצאו את aₙ וקבעו את סוג הסדרה.
    הצג פתרון

    aₙ = Sₙ − Sₙ₋₁ = 2n + 3, ו־a₁ = S₁ = 5 ✓

    סדרה חשבונית עם d = 2.

  7. נתון Sₙ = 3ⁿ − 1. מצאו את aₙ וקבעו את סוג הסדרה.
    הצג פתרון

    aₙ = 3ⁿ − 3ⁿ⁻¹ = 2·3ⁿ⁻¹, ו־a₁ = S₁ = 2 ✓

    סדרה הנדסית עם q = 3.

  8. נתון Sₙ = 2n² − n + 1. מצאו את aₙ. האם הסדרה חשבונית?
    הצג פתרון

    עבור n ≥ 2: aₙ = 4n − 3. אבל a₁ = S₁ = 2 ≠ 1.

    הסדרה 2, 5, 9, 13, … חשבונית רק החל מהאיבר השני.

  9. נתון aₙ = 2n + 1. חשבו את סכום 20 האיברים הראשונים.
    הצג פתרון

    חשבונית עם a₁ = 3, a₂₀ = 41

    S₂₀ = 20(3 + 41)/2 = 440

  10. נתון aₙ = n(n+1). חשבו את aₙ₊₁ − aₙ. איזה איבר שווה ל־110?
    הצג פתרון

    (n+1)(n+2) − n(n+1) = 2(n+1)

    n(n+1) = 110 ⇒ n = 10

  11. נתון aₙ = (n − 3)/(n + 1). אילו איברים שליליים? האם יש איבר ששווה 1?
    הצג פתרון

    שלילי כאשר n < 3: a₁ = −1, a₂ = −⅓

    aₙ = 1 ⇒ n − 3 = n + 1, אין פתרון. אין איבר כזה.

  12. נתון aₙ = (−1)ⁿ + 1. כתבו את האיברים הראשונים וחשבו את S₁₀₁.
    הצג פתרון

    0, 2, 0, 2, …

    50 זוגות שסכום כל אחד 2, ועוד a₁₀₁ = 0: S₁₀₁ = 100

רמה ג׳: רמת בגרות שאלות 23–30

פרמטרים, סכומים טלסקופיים ושילובים.

  1. עבור אילו n האיבר aₙ = (n² + 6)/n הוא מספר שלם?
    הצג פתרון

    aₙ = n + 6/n, שלם כאשר n מחלק את 6.

    n = 1, 2, 3, 6

  2. נתון aₙ = 1/(n(n+1)). מצאו נוסחה ל־Sₙ וחשבו את S₉₉.
    הצג פתרון

    1/(n(n+1)) = 1/n − 1/(n+1), והסכום טלסקופי:

    Sₙ = 1 − 1/(n+1) = n/(n+1)

    S₉₉ = 99/100

  3. נתון Sₙ = n/(n+1). מצאו את aₙ.
    הצג פתרון

    aₙ = n/(n+1) − (n−1)/n = 1/(n(n+1))

    a₁ = S₁ = ½ ✓

  4. נתון aₙ = 2ⁿ + 3n. מצאו נוסחה ל־Sₙ וחשבו את S₁₀.
    הצג פתרון

    מפרקים לשני סכומים: הנדסי וחשבוני.

    Sₙ = (2ⁿ⁺¹ − 2) + 3n(n+1)/2

    S₁₀ = 2046 + 165 = 2211

  5. נתון aₙ = n² − kn + 20. לאילו ערכי k האיבר a₃ הוא האיבר הקטן ביותר (ויחיד)?
    הצג פתרון

    צריך שהקודקוד k/2 יהיה קרוב ל־3 יותר מאשר ל־2 ול־4: 2.5 < k/2 < 3.5

    5 < k < 7

  6. בסדרה aₙ = An + B נתון a₃ = 7 ו־a₈ = 22. מצאו את A ו־B והסבירו מדוע הסדרה חשבונית.
    הצג פתרון

    5A = 15 ⇒ A = 3, B = −2

    aₙ₊₁ − aₙ = A = 3 קבוע, לכן הסדרה חשבונית.

  7. נתון aₙ = cos(nπ/2). כתבו את האיברים הראשונים וחשבו את S₂₀₂₆.
    הצג פתרון

    0, −1, 0, 1, 0, −1, …: מחזור באורך 4 שסכומו 0.

    2026 = 4·506 + 2 ⇒ S₂₀₂₆ = a₁ + a₂ = −1

  8. בסדרה Sₙ = An² + Bn נתון S₂ = 8 ו־S₄ = 28. מצאו את A, B ו־aₙ.
    הצג פתרון

    4A + 2B = 8, 16A + 4B = 28 ⇒ A = 1.5, B = 1

    aₙ = Sₙ − Sₙ₋₁ = 3n − 0.5 (ו־a₁ = S₁ = 2.5 ✓)

הפתרונות מוסתרים כדי לאפשר תרגול עצמי. לחצו על "הצג פתרון" כדי לבדוק.
