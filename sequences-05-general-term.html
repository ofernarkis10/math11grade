הסבר ונוסחאות

מה זו נוסחת איבר כללי? נוסחה שנותנת את \(a_{n}\) ישירות כפונקציה של מקומו n. למשל \(a_{n} = n^{2} + 1\) נותנת \(2, 5, 10, 17, \ldots\), ואפשר לחשב את \(a_{100} = 10{,}001\) בלי לחשב את כל האיברים שלפניו.

המשמעות: סדרה היא פונקציה שהתחום שלה הוא המספרים הטבעיים \(1, 2, 3, \ldots\). הגרף שלה הוא אוסף של נקודות בודדות, לא קו רציף. לכן הרבה ממה שיודעים על פונקציות עובד גם כאן (קודקוד של פרבולה, עלייה וירידה), אבל תמיד צריך לזכור ש־n חייב להיות מספר טבעי.

השוואה לכלל נסיגה: כלל נסיגה אומר "איך מתקדמים". נוסחת איבר כללי אומרת "איפה נמצאים". לכל סדרה חשבונית והנדסית יש גם וגם.

האם k איבר בסדרה?פותרים \(a_{n} = k\) ובודקים ש־n טבעי
עולה / יורדתהסימן של \(a_{n+1} - a_{n}\)
איבר מתוך סכומים\(a_{n} = S_{n} - S_{n-1}\) עבור \(n \ge 2\)
האיבר הראשון\(a_{1} = S_{1}\)

חקירת מונוטוניות: מחשבים \(a_{n+1} - a_{n}\) ומפשטים. אם התוצאה חיובית לכל n, הסדרה עולה. בסדרות חיוביות אפשר גם לבדוק אם \(\dfrac{a_{n+1}}{a_{n}}\) גדול מ־1.

האיבר הגדול או הקטן ביותר: בנוסחה ריבועית מוצאים את קודקוד הפרבולה. אם הקודקוד אינו מספר שלם, בודקים את שני השלמים הסמוכים. אם הקודקוד בדיוק באמצע בין שני שלמים, יש שני איברים שווים קיצוניים.

מ־\(S_{n}\) ל־\(a_{n}\): הסכום של n איברים פחות הסכום של \(n - 1\) איברים הוא בדיוק האיבר ה־n. הנוסחה נכונה רק מ־\(n = 2\), ולכן תמיד בודקים בנפרד אם \(a_{1} = S_{1}\) מתאים לאותה נוסחה. אם \(S_{n}\) ריבועי בלי מקדם חופשי, הסדרה חשבונית; אם יש מקדם חופשי, היא חשבונית רק החל מהאיבר השני.

סכום טלסקופי: כשאפשר לכתוב \(a_{n} = f(n) - f(n+1)\), בסכום כמעט הכול מתבטל: \(S_{n} = f(1) - f(n+1)\).

טעויות נפוצות: לקבל n שלילי או שבר ולא לפסול; להשתמש ב־\(a_{n} = S_{n} - S_{n-1}\) גם עבור \(n = 1\); לבלבל בין "הסדרה עולה" לבין "הפונקציה עולה בקטע" כשהקודקוד נמצא בין 1 ל־2.

רמה א׳: בסיס שאלות 1–10

חישוב איברים, זיהוי נוסחה ושאלת "האם זה איבר".

  1. נתון \(a_{n} = 3n - 2\). כתבו את חמשת האיברים הראשונים ואת \(a_{20}\).
    הצג פתרון

    \(1, 4, 7, 10, 13\)

    \(a_{20} = 58\)

    הסבר מפורט

    נוסחת איבר כללי היא "מכונה": מכניסים את מקום האיבר \(n\) ומקבלים את ערכו.

    \(a_{1} = 3 \cdot 1 - 2 = 1\), \(a_{2} = 4\), \(a_{3} = 7\), \(a_{4} = 10\), \(a_{5} = 13\).

    \(a_{20} = 3 \cdot 20 - 2 = 58\). אין צורך לחשב את כל האיברים שלפניו.

    הנוסחה לינארית ב־\(n\), ולכן הסדרה חשבונית עם \(d = 3\) (המקדם של \(n\)).

  2. נתון \(a_{n} = n^{2} + 1\). כתבו את חמשת האיברים הראשונים ואת \(a_{10}\).
    הצג פתרון

    \(2, 5, 10, 17, 26\)

    \(a_{10} = 101\)

    הסבר מפורט

    מציבים \(n = 1, \ldots, 5\) בנוסחה \(n^{2} + 1\): \(2, 5, 10, 17, 26\).

    \(a_{10} = 10^{2} + 1 = 101\).

    ההפרשים \(3, 5, 7, 9\) אינם קבועים, ולכן הסדרה אינה חשבונית.

  3. נתון \(a_{n} = ( - 1)^{n} \cdot n\). כתבו את חמשת האיברים הראשונים.
    הצג פתרון

    \(- 1, 2, - 3, 4, - 5\)

    הסבר מפורט

    \((-1)^{n}\) שווה \(-1\) כאשר \(n\) אי־זוגי, ו־\(1\) כאשר \(n\) זוגי. הוא קובע רק את הסימן.

    \(a_{1} = -1\), \(a_{2} = 2\), \(a_{3} = -3\), \(a_{4} = 4\), \(a_{5} = -5\).

    הערך המוחלט הוא \(n\), והסימנים מתחלפים.

  4. נתון \(a_{n} = \dfrac{n+1}{n}\). כתבו את ארבעת האיברים הראשונים. לאיזה מספר הם מתקרבים?
    הצג פתרון

    \(2, \dfrac{3}{2}, \dfrac{4}{3}, \dfrac{5}{4}\)

    \(a_{n} = 1 + \dfrac{1}{n}\), ולכן הם מתקרבים ל־1.

    הסבר מפורט

    \(a_{1} = \dfrac{2}{1} = 2\), \(a_{2} = \dfrac{3}{2}\), \(a_{3} = \dfrac{4}{3}\), \(a_{4} = \dfrac{5}{4}\).

    כדי לראות לאן הם הולכים, מפרקים את השבר: \(\dfrac{n + 1}{n} = \dfrac{n}{n} + \dfrac{1}{n} = 1 + \dfrac{1}{n}\).

    כש־\(n\) גדל, \(\dfrac{1}{n}\) הולך ומתקרב ל־0, ולכן האיברים מתקרבים ל־1. הם תמיד גדולים מ־1, ולא מגיעים אליו.

  5. האם 58 הוא איבר בסדרה \(a_{n} = 3n + 1\)?
    הצג פתרון

    \(3n + 1 = 58 \Rightarrow n = 19\). כן, \(a_{19} = 58\).

    הסבר מפורט

    מספר הוא איבר בסדרה אם יש \(n\) טבעי שעבורו \(a_{n}\) שווה לו.

    פותרים \(3n + 1 = 58\): \(3n = 57\), ולכן \(n = 19\).

    19 הוא מספר טבעי, ולכן 58 הוא האיבר ה־19.

  6. האם 50 הוא איבר בסדרה \(a_{n} = n^{2} + n\)?
    הצג פתרון

    \(n^{2} + n - 50 = 0\), הדיסקרימיננטה 201 אינה ריבוע שלם, ולכן אין פתרון טבעי.

    (\(a_{6} = 42\), \(a_{7} = 56\).) 50 אינו איבר.

    הסבר מפורט

    פותרים \(n^{2} + n = 50\), כלומר \(n^{2} + n - 50 = 0\).

    הדיסקרימיננטה \(1 + 200 = 201\) אינה ריבוע שלם, ולכן הפתרונות אינם שלמים: \(n = \dfrac{-1 \pm \sqrt{201}}{2}\), והפתרון החיובי בערך \(6.6\).

    אין \(n\) טבעי שמתאים, ולכן 50 אינו איבר. אפשר לראות זאת גם כך: \(a_{6} = 42\) ו־\(a_{7} = 56\), ו־50 נמצא ביניהם.

  7. אילו איברים בסדרה \(a_{n} = n^{2} - 7n + 10\) שווים לאפס?
    הצג פתרון

    \((n - 2)(n - 5) = 0 \Rightarrow a_{2} = a_{5} = 0\)

    הסבר מפורט

    פותרים \(n^{2} - 7n + 10 = 0\). מפרקים לגורמים: מחפשים שני מספרים שמכפלתם 10 וסכומם 7, כלומר 2 ו־5.

    \((n - 2)(n - 5) = 0\), ולכן \(n = 2\) או \(n = 5\). שניהם טבעיים.

    לכן \(a_{2} = 0\) ו־\(a_{5} = 0\). בדיקה: \(4 - 14 + 10 = 0\) ✓

  8. כתבו נוסחת איבר כללי לכל אחת מהסדרות:
    א. \(2, 4, 6, 8, \ldots\) ב. \(1, 4, 9, 16, \ldots\) ג. \(3, 9, 27, \ldots\) ד. \({\dfrac{1}{2}}, {\dfrac{2}{3}}, {\dfrac{3}{4}}, \ldots\)
    הצג פתרון

    א. \(a_{n} = 2n\) ב. \(a_{n} = n^{2}\) ג. \(a_{n} = 3^{n}\) ד. \(a_{n} = \dfrac{n}{n+1}\)

    הסבר מפורט

    מחפשים קשר בין המקום \(n\) לבין הערך.

    א. כל איבר הוא פי 2 ממקומו: \(a_{n} = 2n\). ב. כל איבר הוא ריבוע מקומו: \(a_{n} = n^{2}\).

    ג. חזקות של 3: \(a_{n} = 3^{n}\). ד. המונה הוא המקום והמכנה גדול ממנו ב־1: \(a_{n} = \dfrac{n}{n + 1}\).

    תמיד בודקים נוסחה על שני איברים לפחות. למשל בד׳: \(a_{3} = \dfrac{3}{4}\) ✓

  9. נתון \(a_{n} = 2^{n} - 1\). חשבו את \(a_{10}\). מהו האיבר הראשון שגדול מ־1000?
    הצג פתרון

    \(a_{10} = 1023\), ו־\(a_{9} = 511\). לכן \(a_{10}\) הוא הראשון.

    הסבר מפורט

    \(a_{10} = 2^{10} - 1 = 1024 - 1 = 1023\).

    הסדרה עולה, כי \(2^{n}\) גדל. לכן מספיק למצוא את האיבר הראשון שעובר את 1000.

    \(a_{9} = 512 - 1 = 511\) עוד קטן מ־1000, ו־\(a_{10} = 1023\) כבר גדול. לכן \(a_{10}\) הוא הראשון.

  10. נתון \(a_{n} = 5 - 2n\). הוכיחו שהסדרה יורדת.
    הצג פתרון

    \(a_{n+1} - a_{n} = (3 - 2n) - (5 - 2n) = - 2 \lt 0\)

    הסבר מפורט

    כדי לבדוק אם סדרה יורדת, מחשבים \(a_{n+1} - a_{n}\) ובודקים את הסימן לכל \(n\).

    \(a_{n+1} = 5 - 2(n + 1) = 3 - 2n\).

    \(a_{n+1} - a_{n} = (3 - 2n) - (5 - 2n) = -2\). ההפרש שלילי (וגם קבוע), ולכן כל איבר קטן מקודמו: הסדרה יורדת.

רמה ב׳: ביסוס שאלות 11–22

איבר קיצון, מונוטוניות ומעבר מ־\(S_{n}\) ל־\(a_{n}\).

  1. מצאו את האיבר הקטן ביותר בסדרה \(a_{n} = n^{2} - 10n + 30\).
    הצג פתרון

    קודקוד ב־\(n = 5\): \(a_{5} = 25 - 50 + 30 = 5\)

    הסבר מפורט

    \(a_{n} = n^{2} - 10n + 30\) היא פרבולה "מחייכת" ב־\(n\), ולכן יש לה מינימום בקודקוד.

    הקודקוד ב־\(n = -\dfrac{b}{2a} = \dfrac{10}{2} = 5\), וזה מספר טבעי.

    \(a_{5} = 25 - 50 + 30 = 5\). זה האיבר הקטן ביותר.

    בדיקה: \(a_{4} = a_{6} = 6\), שניהם גדולים מ־5 ✓

  2. מצאו את האיבר הקטן ביותר בסדרה \(a_{n} = n^{2} - 9n + 25\).
    הצג פתרון

    הקודקוד ב־\(n = 4.5\), בודקים את 4 ו־5:

    \(a_{4} = 16 - 36 + 25 = 5\), \(a_{5} = 25 - 45 + 25 = 5\)

    יש שני איברים מינימליים, \(a_{4} = a_{5} = 5\).

    הסבר מפורט

    הקודקוד ב־\(n = \dfrac{9}{2} = 4.5\). זה אינו מספר טבעי, ולכן אין איבר בקודקוד עצמו.

    בודקים את שני הטבעיים הקרובים: \(a_{4} = 16 - 36 + 25 = 5\) ו־\(a_{5} = 25 - 45 + 25 = 5\).

    שניהם שווים, כי 4.5 נמצא בדיוק באמצע ביניהם והפרבולה סימטרית. יש שני איברים מינימליים ששווים 5.

  3. כמה איברים בסדרה \(a_{n} = n^{2} - 12n + 20\) שליליים?
    הצג פתרון

    \((n - 2)(n - 10) \lt 0 \Rightarrow 2 \lt n \lt 10\)

    \(n = 3, \ldots , 9\): שבעה איברים.

    הסבר מפורט

    מחפשים \(n\) שעבורם \(n^{2} - 12n + 20 < 0\). מפרקים: \((n - 2)(n - 10) < 0\).

    מכפלה שלילית פירושה שהגורמים בסימנים שונים, וזה קורה בין השורשים: \(2 < n < 10\).

    הטבעיים בתחום: \(3, 4, 5, 6, 7, 8, 9\), כלומר שבעה איברים.

    שימו לב ש־\(n = 2\) ו־\(n = 10\) נותנים 0, ו־0 אינו שלילי.

  4. הוכיחו שהסדרה \(a_{n} = \dfrac{3n+1}{n+2}\) עולה, ושכל איבריה קטנים מ־3.
    הצג פתרון

    \(a_{n+1} - a_{n} = \dfrac{3n+4}{n+3} - \dfrac{3n+1}{n+2} = \dfrac{5}{(n+2)(n+3)} \gt 0\)

    \(a_{n} = 3 - \dfrac{5}{n+2} \lt 3\)

    הסבר מפורט

    מחשבים \(a_{n+1} - a_{n} = \dfrac{3n + 4}{n + 3} - \dfrac{3n + 1}{n + 2}\). מכנה משותף: \((n + 2)(n + 3)\).

    המונה: \((3n + 4)(n + 2) - (3n + 1)(n + 3) = (3n^{2} + 10n + 8) - (3n^{2} + 10n + 3) = 5\).

    \(a_{n+1} - a_{n} = \dfrac{5}{(n + 2)(n + 3)} > 0\) לכל \(n\) טבעי, ולכן הסדרה עולה.

    החסם: מפרקים \(\dfrac{3n + 1}{n + 2} = \dfrac{3(n + 2) - 5}{n + 2} = 3 - \dfrac{5}{n + 2}\). מחסירים מ־3 מספר חיובי, ולכן כל איבר קטן מ־3.

  5. מצאו את האיבר הקטן ביותר בסדרה \(a_{n} = n + \dfrac{20}{n}\).
    הצג פתרון

    \(a_{3} = 3 + 6.67 \approx 9.67\), \(a_{4} = 4 + 5 = 9\), \(a_{5} = 5 + 4 = 9\), \(a_{6} \approx 9.33\)

    האיבר המינימלי הוא 9 (מתקבל ב־\(n = 4\) וב־\(n = 5\)).

    הסבר מפורט

    זו לא פרבולה, ולכן אין קודקוד. מחשבים איברים ומחפשים איפה הסדרה מפסיקה לרדת.

    \(a_{1} = 21\), \(a_{2} = 12\), \(a_{3} \approx 9.67\), \(a_{4} = 9\), \(a_{5} = 9\), \(a_{6} \approx 9.33\), \(a_{7} \approx 9.86\).

    הסדרה יורדת עד \(n = 4\), נשארת ב־9 ב־\(n = 5\), ואחר כך עולה. המינימום הוא 9.

    אינטואיציה: \(n\) גדל ו־\(\dfrac{20}{n}\) קטן. הסכום קטן ביותר כשהם קרובים זה לזה, כלומר כש־\(n \approx \sqrt{20} \approx 4.5\).

  6. נתון \(S_{n} = n^{2} + 4n\). מצאו את \(a_{n}\) וקבעו את סוג הסדרה.
    הצג פתרון

    \(a_{n} = S_{n} - S_{n-1} = 2n + 3\), ו־\(a_{1} = S_{1} = 5\) ✓

    סדרה חשבונית עם \(d = 2\).

    הסבר מפורט

    \(S_{n}\) הוא סכום \(n\) האיברים הראשונים, ו־\(S_{n-1}\) הוא סכום \(n - 1\) הראשונים. ההפרש ביניהם הוא בדיוק האיבר האחרון, \(a_{n}\).

    \(S_{n-1} = (n - 1)^{2} + 4(n - 1) = n^{2} + 2n - 3\). לכן \(a_{n} = (n^{2} + 4n) - (n^{2} + 2n - 3) = 2n + 3\).

    הנוסחה נכונה רק עבור \(n \ge 2\), ולכן בודקים את \(a_{1}\) בנפרד: \(a_{1} = S_{1} = 5\), ו־\(2 \cdot 1 + 3 = 5\) ✓

    \(a_{n} = 2n + 3\) לינארי, ולכן הסדרה חשבונית עם \(d = 2\).

  7. נתון \(S_{n} = 3^{n} - 1\). מצאו את \(a_{n}\) וקבעו את סוג הסדרה.
    הצג פתרון

    \(a_{n} = 3^{n} - 3^{n-1} = 2 \cdot 3^{n-1}\), ו־\(a_{1} = S_{1} = 2\) ✓

    סדרה הנדסית עם \(q = 3\).

    הסבר מפורט

    \(a_{n} = S_{n} - S_{n-1} = (3^{n} - 1) - (3^{n-1} - 1) = 3^{n} - 3^{n-1}\).

    מוציאים גורם משותף: \(3^{n-1}(3 - 1) = 2 \cdot 3^{n-1}\).

    בודקים את \(a_{1}\): \(S_{1} = 3 - 1 = 2\), והנוסחה נותנת \(2 \cdot 3^{0} = 2\) ✓

    \(a_{n} = 2 \cdot 3^{n-1}\) היא סדרה הנדסית עם \(a_{1} = 2\) ו־\(q = 3\).

  8. נתון \(S_{n} = 2n^{2} - n + 1\). מצאו את \(a_{n}\). האם הסדרה חשבונית?
    הצג פתרון

    עבור \(n \ge 2\): \(a_{n} = 4n - 3\). אבל \(a_{1} = S_{1} = 2 \neq 1\).

    הסדרה \(2, 5, 9, 13, \ldots\) חשבונית רק החל מהאיבר השני.

    הסבר מפורט

    \(S_{n-1} = 2(n-1)^{2} - (n-1) + 1 = 2n^{2} - 5n + 4\). לכן עבור \(n \ge 2\): \(a_{n} = (2n^{2} - n + 1) - (2n^{2} - 5n + 4) = 4n - 3\).

    עכשיו הבדיקה החשובה: \(a_{1} = S_{1} = 2 - 1 + 1 = 2\). אבל הנוסחה \(4n - 3\) נותנת עבור \(n = 1\) את הערך 1. הם לא שווים!

    הסדרה היא \(2, 5, 9, 13, \ldots\). ההפרש בין \(a_{1}\) ל־\(a_{2}\) הוא 3, ומשם הוא 4. לכן היא חשבונית רק החל מהאיבר השני.

    הסיבה: ל־\(S_{n}\) יש מקדם חופשי (ה־\(+1\)). בסדרה חשבונית \(S_{0}\) חייב להיות 0.

  9. נתון \(a_{n} = 2n + 1\). חשבו את סכום 20 האיברים הראשונים.
    הצג פתרון

    חשבונית עם \(a_{1} = 3\), \(a_{20} = 41\)

    \(S_{20} = \dfrac{20(3 + 41)}{2} = 440\)

    הסבר מפורט

    \(a_{n} = 2n + 1\) לינארי, ולכן הסדרה חשבונית עם \(d = 2\). אפשר להשתמש בנוסחת הסכום.

    \(a_{1} = 3\) ו־\(a_{20} = 41\).

    \(S_{20} = \dfrac{20(3 + 41)}{2} = 10 \cdot 44 = 440\).

  10. נתון \(a_{n} = n(n+1)\). חשבו את \(a_{n+1} - a_{n}\). איזה איבר שווה ל־110?
    הצג פתרון

    \((n+1)(n+2) - n(n+1) = 2(n+1)\)

    \(n(n+1) = 110 \Rightarrow n = 10\)

    הסבר מפורט

    \(a_{n+1} = (n + 1)(n + 2)\), ולכן \(a_{n+1} - a_{n} = (n + 1)(n + 2) - n(n + 1)\). מוציאים את \((n + 1)\) כגורם משותף: \((n + 1)(n + 2 - n) = 2(n + 1)\).

    ההפרש חיובי וגדל, ולכן הסדרה עולה, אבל אינה חשבונית.

    \(n(n + 1) = 110\): מחפשים שני מספרים עוקבים שמכפלתם 110. \(10 \cdot 11 = 110\), ולכן \(n = 10\).

    בדרך אלגברית: \(n^{2} + n - 110 = 0\), כלומר \((n + 11)(n - 10) = 0\). הפתרון \(n = -11\) נפסל.

  11. נתון \(a_{n} = \dfrac{n - 3}{n + 1}\). אילו איברים שליליים? האם יש איבר ששווה 1?
    הצג פתרון

    שלילי כאשר \(n \lt 3\): \(a_{1} = - 1\), \(a_{2} = - {\dfrac{1}{3}}\)

    \(a_{n} = 1 \Rightarrow n - 3 = n + 1\), אין פתרון. אין איבר כזה.

    הסבר מפורט

    שבר שלילי כשהמונה והמכנה בסימנים שונים. המכנה \(n + 1\) תמיד חיובי, ולכן צריך מונה שלילי: \(n - 3 < 0\), כלומר \(n < 3\).

    האיברים השליליים: \(a_{1} = \dfrac{-2}{2} = -1\) ו־\(a_{2} = \dfrac{-1}{3}\).

    האם יש איבר ששווה 1? \(\dfrac{n - 3}{n + 1} = 1\) פירושו \(n - 3 = n + 1\), כלומר \(-3 = 1\). זו סתירה, ולכן אין איבר כזה.

    הסבר נוסף: המונה תמיד קטן מהמכנה ב־4, ולכן השבר תמיד קטן מ־1.

  12. נתון \(a_{n} = ( - 1)^{n} + 1\). כתבו את האיברים הראשונים וחשבו את \(S_{101}\).
    הצג פתרון

    \(0, 2, 0, 2, \ldots\)

    50 זוגות שסכום כל אחד 2, ועוד \(a_{101} = 0\): \(S_{101} = 100\)

    הסבר מפורט

    \((-1)^{n} + 1\): עבור \(n\) אי־זוגי \(-1 + 1 = 0\), ועבור \(n\) זוגי \(1 + 1 = 2\). הסדרה \(0, 2, 0, 2, \ldots\)

    ב־101 איברים יש 50 זוגות שלמים \((0, 2)\), ועוד איבר אחרון \(a_{101}\).

    101 אי־זוגי, ולכן \(a_{101} = 0\).

    \(S_{101} = 50 \cdot 2 + 0 = 100\).

רמה ג׳: רמת בגרות שאלות 23–30

פרמטרים, סכומים טלסקופיים ושילובים.

  1. עבור אילו n האיבר \(a_{n} = \dfrac{n^{2} + 6}{n}\) הוא מספר שלם?
    הצג פתרון

    \(a_{n} = n + \dfrac{6}{n}\), שלם כאשר n מחלק את 6.

    \(n = 1, 2, 3, 6\)

  2. נתון \(a_{n} = \dfrac{1}{n(n+1)}\). מצאו נוסחה ל־\(S_{n}\) וחשבו את \(S_{99}\).
    הצג פתרון

    \(\dfrac{1}{n(n+1)} = \dfrac{1}{n} - \dfrac{1}{n+1}\), והסכום טלסקופי:

    \(S_{n} = 1 - \dfrac{1}{n+1} = \dfrac{n}{n+1}\)

    \(S_{99} = \dfrac{99}{100}\)

  3. נתון \(S_{n} = \dfrac{n}{n+1}\). מצאו את \(a_{n}\).
    הצג פתרון

    \(a_{n} = \dfrac{n}{n+1} - \dfrac{n - 1}{n} = \dfrac{1}{n(n+1)}\)

    \(a_{1} = S_{1} = {\dfrac{1}{2}}\) ✓

  4. נתון \(a_{n} = 2^{n} + 3n\). מצאו נוסחה ל־\(S_{n}\) וחשבו את \(S_{10}\).
    הצג פתרון

    מפרקים לשני סכומים: הנדסי וחשבוני.

    \(S_{n} = (2^{n+1} - 2) + \dfrac{3n(n+1)}{2}\)

    \(S_{10} = 2046 + 165 = 2211\)

  5. נתון \(a_{n} = n^{2} - kn + 20\). לאילו ערכי k האיבר \(a_{3}\) הוא האיבר הקטן ביותר (ויחיד)?
    הצג פתרון

    צריך שהקודקוד \(\dfrac{k}{2}\) יהיה קרוב ל־3 יותר מאשר ל־2 ול־4: \(2.5 \lt \dfrac{k}{2} \lt 3.5\)

    \(5 \lt k \lt 7\)

  6. בסדרה \(a_{n} = An + B\) נתון \(a_{3} = 7\) ו־\(a_{8} = 22\). מצאו את A ו־B והסבירו מדוע הסדרה חשבונית.
    הצג פתרון

    \(5A = 15 \Rightarrow A = 3\), \(B = - 2\)

    \(a_{n+1} - a_{n} = A = 3\) קבוע, לכן הסדרה חשבונית.

  7. נתון \(a_{n} = {\cos\left(\dfrac{n{\pi}}{2}\right)}\). כתבו את האיברים הראשונים וחשבו את \(S_{2026}\).
    הצג פתרון

    \(0, - 1, 0, 1, 0, - 1, \ldots\): מחזור באורך 4 שסכומו 0.

    \(2026 = 4 \cdot 506 + 2 \Rightarrow S_{2026} = a_{1} + a_{2} = - 1\)

  8. בסדרה \(S_{n} = An^{2} + Bn\) נתון \(S_{2} = 8\) ו־\(S_{4} = 28\). מצאו את A, B ו־\(a_{n}\).
    הצג פתרון

    \(4A + 2B = 8\), \(16A + 4B = 28 \Rightarrow A = 1.5\), \(B = 1\)

    \(a_{n} = S_{n} - S_{n-1} = 3n - 0.5\) (ו־\(a_{1} = S_{1} = 2.5\) ✓)

הפתרונות מוסתרים כדי לאפשר תרגול עצמי. לחצו על "הצג פתרון" כדי לבדוק.
