שיעור חמישי – חישוב הדוגמאות בנוסחה

בדף הדוגמאות חישבנו את הסך הכול שלב אחרי שלב. בדף ההסבר הכרנו את נוסחת הסכום:

Sn = a · (bn − 1) / (b − 1)

עכשיו נפתור את אותן דוגמאות בעזרת הנוסחה, ובסוף כל דוגמה נבדוק בטבלה שהנוסחה נותנת בדיוק את אותו סכום כמו החישוב שלב אחרי שלב.

סדר הפתרון בכל דוגמה: מזהים את a (המחובר הראשון), את b (המספר שמכפילים בו) ואת n (מספר המחוברים), מציבים בנוסחה, ובודקים בטבלה.

דוגמה 1 – מזון לדולפינים 🐬

בשמורה יש 256 דולפינים, ומספרם גדל ב-50% בכל שנה. כל דולפין אוכל טון דגים בשנה. כמה מזון צריך בסך הכול ב-8 השנים הראשונות?

מזהים את a – המחובר הראשון (בניית נוסחה)
a = 256

המזון של השנה הראשונה: 256 דולפינים כפול טון.

מזהים את b – המספר שמכפילים בו (בניית נוסחה)
b = 1.5

מספר הדולפינים גדל פי 1.5 בכל שנה.

מזהים את n – מספר המחוברים (בניית נוסחה)
n = 8

8 שנים.

מציבים בנוסחת הסכום ומחשבים במחשבון (חישוב סכום)
Sn = a · (bn − 1) / (b − 1) S8 = 256 · (1.58 − 1) / (1.5 − 1) S8 = 256 · (25.62890625 − 1) / 0.5 S8 = 12,610

תשובה: בסך הכול צריך 12,610 טון מזון.

דוגמה 3 – תרופה שלוקחים כל יום 💊

כל בוקר לוקחים 100 מ"ג תרופה, ועד הבוקר הבא נשארת חצי. כמה תרופה יש בגוף מיד אחרי המנה ה-8?

מזהים את a – המחובר הראשון (בניית נוסחה)
a = 100

המנה של היום (עוד לא התפרקה).

מזהים את b – המספר שמכפילים בו (בניית נוסחה)
b = 0.5

מכל מנה נשארת חצי בכל יום.

מזהים את n – מספר המחוברים (בניית נוסחה)
n = 8

8 מנות.

מציבים בנוסחת הסכום ומחשבים במחשבון (חישוב סכום)
Sn = a · (1 − bn) / (1 − b) S8 = 100 · (1 − 0.58) / (1 − 0.5) S8 = 100 · (1 − 0.00390625) / 0.5 S8 = 199.21875

בדעיכה משתמשים בצורה (1 − bn) / (1 − b), כדי שהמונה והמכנה יהיו חיוביים.

דוגמה 4 – שאלה הפוכה: אחרי כמה שנים? 🐬

בשמורת הדולפינים (דוגמה 1) יש מחסן שמספיק ל-20,000 טון מזון בסך הכול. אחרי כמה שנים הסך הכול של המזון יעבור את 20,000 טון?

כותבים את נוסחת הסכום עם a = 256 ו-b = 1.5, ומפשטים (בניית נוסחה)
Sn = a · (bn − 1) / (b − 1) Sn = 256 · (1.5n − 1) / 0.5 Sn = 512 · (1.5n − 1)
כותבים את התנאי: הסכום גדול מ-20,000 (מציאת n)
512 · (1.5n − 1) > 20000 1.5n − 1 > 39.0625 1.5n > 40.0625
מוצאים את החזקה המתאימה – מנסים ערכים של n (מציאת n)
1.59 ≈ 38.44 < 40.0625 1.510 ≈ 57.67 > 40.0625 n = 10

תשובה: במהלך השנה ה-10 הסך הכול יעבור את 20,000 טון (אחרי 9 שנים הוא עוד מתחת).

סיכום

  • לפני שמציבים – מזהים שלושה דברים: a, b ו-n.
  • בגדילה (b > 1) משתמשים ב-a · (bn − 1) / (b − 1), ובדעיכה (0 < b < 1) ב-a · (1 − bn) / (1 − b).
  • את bn מחשבים במחשבון ומעגלים רק את התוצאה הסופית.
  • כשהסכום ידוע ו-n לא ידוע – מפשטים עד bn ומוצאים את החזקה המתאימה.
