הנגזרת, הפולינום ושיטת הנחש

איך הגרף של f′ "מספר" לנו מתי f עולה, מתי היא יורדת, ואיפה היא עוצרת.

למעלה: גרף הנגזרת f′(x). למטה: גרף הפונקציה f(x). הקו המקווקו עובר באותו x בשניהם.
שלב 1 · ערכי האינסוף

הקצוות נקבעים לפי החזקה הגבוהה

בפולינום f(x) = a·xⁿ + … מסתכלים רק על האיבר המוביל: המעלה n והסימן של a.
מעלה זוגית, a > 0: שני הקצוות למעלה. בשמאל הפונקציה יורדת, בימין עולה.
מעלה זוגית גבוהה יותר (x⁴): אותה התנהגות בקצוות, רק "שטוחה" יותר באמצע.
מעלה אי־זוגית, a > 0: מתחילה למטה ונגמרת למעלה. בשני הקצוות היא עולה.
a < 0 הופך הכול: הגרף מתהפך, וכל עלייה בקצה הופכת לירידה.
נסו בעצמכם: בחרו מעלה וסימן בכפתורים.
שלב 1 · למה רק האיבר המוביל?

מתרחקים מהגרף

הקו הכחול: f(x) = x⁴ − 4x³. הקו המקווקו: רק האיבר המוביל x⁴.
מקרוב הם שונים מאוד: ל־f יש מינימום ב־x = 3 והיא יורדת מתחת לאפס.
מתרחקים פי כמה: ההבדל כבר קטן ביחס לגודל הגרף.
ממש מרחוק אי אפשר להבחין ביניהם. בקצוות, האיבר המוביל "בולע" את כל השאר.
הקשר בין הגרפים

הנגזרת היא השיפוע

למטה f(x) = ½x² עם קו משיק שזז. למעלה הנגזרת f′(x) = x.
כש־f′ מעל הציר (ירוק), השיפוע חיובי: f עולה.
כש־f′ מתחת לציר (כתום), השיפוע שלילי: f יורדת.
כש־f′ = 0 המשיק אופקי. זה המקום היחיד שבו f יכולה לשנות כיוון.
גררו את המחוון ובדקו: הערך של f′ שווה לשיפוע של המשיק.
שלב 2 · שורש יחיד (פשוט)

הנגזרת חוצה את הציר

f(x) = x³ − 3x, ולכן f′(x) = 3(x + 1)(x − 1): שני שורשים פשוטים.
בשורש פשוט הגרף של f′ חוצה את הציר: הסימן מתחלף.
ב־x = −1: מ־+ ל־−. הפונקציה עולה ואז יורדת: מקסימום.
ב־x = 1: מ־− ל־+. הפונקציה יורדת ואז עולה: מינימום.
שורש פשוט של הנגזרת = נקודת קיצון.
שלב 2 · שורש כפול

הנגזרת נוגעת בציר וחוזרת

f(x) = x³, ולכן f′(x) = 3x²: השורש x = 0 הוא כפול.
הגרף של f′ רק נוגע בציר ב־0 וחוזר למעלה. הסימן לא מתחלף: + לפני ו־+ אחרי.
לכן f עולה, עוצרת לרגע (משיק אופקי) וממשיכה לעלות. זו עצירה והמשך, לא קיצון.
ואם f′(x) = −3x²: הנגזרת נוגעת בציר מלמטה. f יורדת, עוצרת וממשיכה לרדת.
שורש כפול של הנגזרת = עצירה והמשך (נקודת פיתול עם משיק אופקי).
שלב 2 · הריבוי קובע

זוגי או אי־זוגי?

ריבוי 1: f′ = x. חוצה: מינימום.
ריבוי 2: f′ = x². נוגעת: עצירה והמשך.
ריבוי 3: f′ = x³. שוב חוצה: מינימום, רק שטוח יותר.
ריבוי 4: f′ = x⁴. שוב נוגעת: עצירה והמשך.
ריבוי אי־זוגי ← הסימן מתחלף ← קיצון.
ריבוי זוגי ← הסימן נשאר ← עצירה והמשך.
שלב 3 · בונים את הנחש

הנחש של f′(x) = (x+2)·x²·(x−3)

מסמנים על ציר את שורשי הנגזרת לפי הסדר (לא בקנה מידה), וליד כל אחד את הריבוי.
מתחילים מימין. המקדם המוביל חיובי, ולכן הנחש מתחיל מעל הציר.
ב־3 שורש פשוט: הנחש חוצה את הציר.
ב־0 שורש כפול: הנחש נוגע בציר וחוזר לאותו צד.
ב־−2 שורש פשוט: שוב חוצה.
מתרגמים: מעל = ↗ עולה, מתחת = ↘ יורדת. ומזה סוג כל נקודה.
וזה הגרף האמיתי של f: בדיוק לפי החצים.
הסימולציה המרכזית

הנגזרת למעלה, הפולינום למטה

הנקודה זזה על שני הגרפים באותו x. למעלה רואים את הערך של f′, למטה את המשיק ל־f.
השטח הירוק (f′ > 0) מתאים לקטע הירוק של f: עלייה.
השטח הכתום (f′ < 0) מתאים לקטע הכתום: ירידה.
בכל מקום ש־f′ פוגשת את הציר, המשיק של f אופקי. אם היא חוצה: קיצון. אם היא נוגעת: עצירה.
בחרו פולינום מהרשימה: אלה ארבע הדוגמאות מדף ההסבר, ועוד אחת.
מעבדה

עולה, יורדת, זוגית, אי־זוגית

בונים את הנגזרת משורשים ב־−2, 0, 2, בוחרים לכל אחד ריבוי (0 = אין שורש) ואת הסימן.
המעלה של f גדולה ב־1 מסכום הריבויים. שימו לב איך הקצוות משתנים כשהמעלה מתחלפת בין זוגית לאי־זוגית.
מעלה 3 (שני שורשים פשוטים): מתחילה למטה, נגמרת למעלה, מקסימום ואז מינימום.
מוסיפים שורש פשוט, מעלה 4: שני הקצוות למעלה, ומספר הקיצונים אי־זוגי.
הופכים שורש לכפול: הקיצון שלו הופך לעצירה, ושני השכנים שלו מתאחדים לכיוון אחד.
מקדם שלילי: הנחש מתחיל מתחת לציר, והגרף כולו מתהפך.
סיכום

שיטת הנחש בארבעה שלבים

1. האינסוף: מעלה ומקדם מוביל ← הקצוות.
2. גוזרים ומפרקים את f′ עד הסוף, בלי לחלק ב־x.
3. הנחש: מימין לפי הסימן, חוצים בפשוט, נוגעים בכפול.
4. מציבים ב־f (לא ב־f′!) ומשרטטים משמאל לימין.
