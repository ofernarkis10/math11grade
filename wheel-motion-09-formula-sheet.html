עמוד A4 אחד: כל הנוסחאות של הנושא ואיך מוצאים כל רכיב. את טבלת הנתונים הריקה שממלאים בכל שאלה תמצאו בדף 10.

דף נוסחאות: נקודה על גלגל

מתמטיקה · כיתה י״א · 5 יח״ל · תנועה על גלגל ועל גלגל מתגלגל
שם:כיתה:תאריך:
\(x(t) = \color{#1f6f8b}{x_0 + v_x t} + R\cos(\color{#b4561e}{\theta_0 + \omega t})\)
\(y(t) = \color{#1f6f8b}{y_0 + v_y t} + R\sin(\color{#b4561e}{\theta_0 + \omega t})\)

משוואת המרכז (לינארית)

  • \(x_C = x_0 + v_x t,\ \ y_C = y_0 + v_y t\)
  • משתי נקודות: \(v_x = \dfrac{\Delta x}{\Delta t},\ v_y = \dfrac{\Delta y}{\Delta t}\)
  • מגודל וזווית: \(v_x = |v|\cos\alpha,\ v_y = |v|\sin\alpha\)
  • גודל וכיוון: \(|v| = \sqrt{v_x^2+v_y^2},\ \tan\alpha = \dfrac{v_y}{v_x}\) (לבדוק רביע)
  • חזרה ל־\(t=0\): \(x_0 = x_1 - v_x t_1,\ y_0 = y_1 - v_y t_1\)

משוואת הסיבוב (מעלות)

  • \(\theta(t) = \theta_0 + \omega t\) · נגד השעון \(\omega \gt 0\), עם השעון \(\omega \lt 0\)
  • \(|\omega| = 360n = \dfrac{360}{T} = 6\cdot\text{rpm}\) · \(\omega = \dfrac{\Delta\theta}{\Delta t}\)
  • ימין \(0^\circ\) · למעלה \(90^\circ\) · שמאל \(180^\circ\) · למטה \(270^\circ\)
  • מקואורדינטות: \(R = |P - C|,\ \cos\theta_0 = \dfrac{x_P - x_C}{R},\ \sin\theta_0 = \dfrac{y_P - y_C}{R}\)

גלגל מתגלגל בלי החלקה

  • סיבוב אחד = המרכז מתקדם היקף אחד: \(|v| = 2\pi R n\) · \(|v| = \dfrac{|\omega|\pi R}{180}\) · \(|\omega| = \dfrac{180|v|}{\pi R}\)
  • על ציר x: \(y_0 = R,\ v_y = 0\) · נע ימינה: \(v_x \gt 0,\ \omega \lt 0\) · נע שמאלה: \(v_x \lt 0,\ \omega \gt 0\)

סדר העבודה

  1. ממלאים את 7 הרכיבים בטבלת הנתונים (דף 10).
  2. רושמים את הנוסחה המלאה עם המספרים.
  3. מציבים \(t\): קודם המרכז, אחר כך הזווית, ואז ההזזה.
  4. בודקים: המרחק של P מהמרכז שווה ל־\(R\).

ערכים שכדאי לזכור
