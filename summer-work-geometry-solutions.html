ארגז כלים: המשפטים והתכונות

ז.זמשפט דמיון זווית־זווית

אם שתי זוויות במשולש אחד שוות לשתי זוויות במשולש אחר, המשולשים דומים.

צ.ז.צמשפט דמיון צלע־זווית־צלע

אם שתי צלעות במשולש אחד פרופורציוניות לשתי צלעות במשולש אחר, והזוויות שביניהן שוות, המשולשים דומים.

יחסיחסים במשולשים דומים

היחס בין כל שתי צלעות מתאימות שווה ליחס הדמיון \(k\). היחס בין השטחים הוא \(k^{2}\). זוויות מתאימות שוות.

תאלסמשפט תאלס המורחב וההפוך שלו

ישר המקביל לצלע במשולש יוצר משולש דומה ומחלק את שתי הצלעות האחרות לקטעים פרופורציוניים. ההפך: אם ישר מחלק שתי צלעות באותו יחס, הוא מקביל לצלע השלישית.

∥זוויות בין ישרים מקבילים

ישר שחותך שני ישרים מקבילים יוצר זוויות מתחלפות שוות וזוויות מתאימות שוות.

180°זוויות בסיסיות

סכום הזוויות במשולש הוא 180°. זוויות צמודות משלימות ל־180°. זוויות קודקודיות שוות. שני ישרים המאונכים לאותו ישר מקבילים זה לזה.

מקביליתתכונות ומשפטי מקבילית

במקבילית צלעות נגדיות שוות ומקבילות, זוויות נגדיות שוות, זוויות סמוכות משלימות ל־180°, והאלכסונים חוצים זה את זה. מרובע עם שני זוגות צלעות מקבילות, או עם זוג צלעות נגדיות שוות ומקבילות, הוא מקבילית.

מעויןתכונות מעוין

כל הצלעות שוות. האלכסונים מאונכים זה לזה, חוצים זה את זה וחוצים את זוויות המעוין.

ש״שמשולש שווה שוקיים

זוויות הבסיס שוות, ולהפך: אם שתי זוויות שוות, הצלעות שמולן שוות. התיכון לבסיס הוא גם גובה וגם חוצה זווית הראש.

2:1מפגש התיכונים

שלושת התיכונים נפגשים בנקודה אחת, שמחלקת כל תיכון ביחס \(2:1\) מהקדקוד. לכן נקודה על תיכון שמחלקת אותו ביחס \(2:1\) מהקדקוד היא מפגש התיכונים.

חוצהמשפט חוצה הזווית

חוצה זווית פנימית במשולש מחלק את הצלע שמולו ביחס של שתי הצלעות הכולאות את הזווית.

90°משולש ישר זווית

משפט פיתגורס. התיכון ליתר שווה למחצית היתר. ניצב שווה למחצית היתר אם ורק אם הזווית שמולו היא 30°.

שטחיחסי שטחים

למשולשים בעלי אותו גובה (קדקוד משותף ובסיסים על אותו ישר), יחס השטחים שווה ליחס הבסיסים. תיכון מחלק משולש לשני משולשים שווי שטח.

דמיון משולשים, יחס צלעות ומשולש ישר זווית
נתון

הנקודה \(E\) נמצאת על הצלע \(BC\) במשולש \(BCD\), ו־\(\measuredangle DBE = \measuredangle CDE\).

א.הוכחה: \(\triangle BCD \sim \triangle DCE\)

דרך החשיבה

כדי להוכיח דמיון מחפשים שתי זוויות שוות. לשני המשולשים יש את הזווית \(C\), והזווית השנייה נתונה. חשוב לכתוב את ההתאמה בין הקדקודים לפי הזוויות השוות, כי ממנה יוצאים היחסים שנצטרך בהמשך.

  1. זווית משותפת
    הזווית \(C\) משותפת לשני המשולשים:
    \(\measuredangle BCD = \measuredangle DCE\)
  2. זווית נתונה
    \(E\) על \(BC\), ולכן \(\measuredangle DBE\) היא \(\measuredangle DBC\). לפי הנתון:
    \(\measuredangle DBC = \measuredangle CDE\)
  3. מסקנה
    לפי משפט ז.ז:
    \(\triangle BCD \sim \triangle DCE\)
    ההתאמה:
    \(B \leftrightarrow D,\ C \leftrightarrow C,\ D \leftrightarrow E\)
    ומכאן היחסים:
    \(\dfrac{BC}{DC} = \dfrac{CD}{CE} = \dfrac{BD}{DE}\)
תשובה:
\(\triangle BCD \sim \triangle DCE\)
לפי ז.ז
בדיקה:
הזוויות המתאימות שוות: \(B\) מול \(D\) (הנתון), \(C\) מול \(C\) (משותפת).

ב.נתון \(\dfrac{BE}{CE} = \dfrac{7}{9}\)

השלמה: בקובץ נחתכה האות השנייה במונה. \(\dfrac{BE}{CE}\) היא הקריאה היחידה שמתאימה לשרטוט ונותנת תוצאות שלמות.

דרך החשיבה

כשנתון יחס בין קטעים מסמנים אותם בעזרת משתנה אחד: \(7k\) ו־\(9k\). מהדמיון בסעיף א יש פרופורציה שבה \(CD\) מופיע פעמיים, ולכן ממנה מקבלים את \(CD^{2}\).

  1. נתונים
    \(BE = 7k\)
    \(CE = 9k\)
    \(BC = BE + CE = 7k + 9k = 16k\)
  2. הצלע \(CD\) מהדמיון
    מסעיף א:
    \(\dfrac{BC}{CD} = \dfrac{CD}{CE}\)
    \(CD^{2} = BC\cdot CE = 16k\cdot 9k = 144k^{2}\)
    \(CD = 12k\)
  3. סעיף (1): היחס \(\dfrac{CD}{CE}\)
    \(\dfrac{CD}{CE} = \dfrac{12k}{9k} = \dfrac{4}{3}\)
  4. סעיף (2): היחס \(\dfrac{BD}{DE}\)
    \(BD\) ו־\(DE\) צלעות מתאימות, ולכן היחס שלהן שווה ליחס הדמיון:
    \(\dfrac{BD}{DE} = \dfrac{BC}{DC} = \dfrac{16k}{12k} = \dfrac{4}{3}\)
תשובה:
\(\dfrac{CD}{CE} = \dfrac{4}{3}\)
\(\dfrac{BD}{DE} = \dfrac{4}{3}\)
בדיקה:
כל זוגות הצלעות המתאימות נותנים אותו יחס:
\(\dfrac{BC}{DC} = \dfrac{16}{12} = \dfrac{4}{3},\quad \dfrac{CD}{CE} = \dfrac{12}{9} = \dfrac{4}{3}\ \checkmark\)

ג.נתון \(\measuredangle BDE = 90^{\circ}\). מצאו את \(\dfrac{BD}{BE}\)

דרך החשיבה

זה משולש ישר זווית שבו ידוע היחס בין הניצבים (מסעיף ב). מסמנים את הניצבים \(4m\) ו־\(3m\), ומפיתגורס מקבלים את היתר.

  1. נתונים
    \(\measuredangle BDE = 90^{\circ}\)
    מסעיף ב(2):
    \(\dfrac{BD}{DE} = \dfrac{4}{3}\)
    \(BD = 4m\)
    \(DE = 3m\)
  2. פיתגורס במשולש \(BDE\)
    \(BE^{2} = BD^{2} + DE^{2}\)
    \(BE^{2} = 16m^{2} + 9m^{2} = 25m^{2}\)
    \(BE = 5m\)
  3. היחס
    \(\dfrac{BD}{BE} = \dfrac{4m}{5m} = \dfrac{4}{5}\)
תשובה:
\(\dfrac{BD}{BE} = \dfrac{4}{5}\)
בדיקה:
3, 4, 5 היא שלשה פיתגורית:
\(3^{2} + 4^{2} = 9 + 16 = 25 = 5^{2}\ \checkmark\)

שימוש ב: פיתגורס

ד.\(EF \perp DC\), והנקודה \(F\) על \(DC\)

דרך החשיבה

שני המשולשים ישרי זווית, ולכן מספיקה עוד זווית חדה שווה. יחס הדמיון הוא היחס בין היתרים. כדי לחשב את \(DF:FC\) צריך לבטא את כל הקטעים באותו משתנה: מסעיף ג (\(m\)) עוברים ל־\(k\) של סעיף ב.

  1. סעיף (1): הוכחת הדמיון
    נתון בסעיף ג, ו־\(EF \perp DC\):
    \(\measuredangle BDE = \measuredangle DFE = 90^{\circ}\)
    \(\measuredangle FDE\) היא \(\measuredangle CDE\), ולפי הנתון:
    \(\measuredangle DBE = \measuredangle FDE\)
    לפי ז.ז:
    \(\triangle BDE \sim \triangle DFE\)
    \(B \leftrightarrow D,\ D \leftrightarrow F,\ E \leftrightarrow E\)
  2. סעיף (2): יחס הדמיון
    היתר \(BE\) מתאים ליתר \(DE\):
    \(\dfrac{BE}{DE} = \dfrac{5m}{3m} = \dfrac{5}{3}\)
  3. סעיף (3): מעבר למשתנה \(k\)
    מסעיף ב \(BE = 7k\), ומסעיף ג \(BE = 5m\):
    \(5m = 7k\)
    \(m = \dfrac{7k}{5}\)
    \(BD = 4m = \dfrac{28k}{5}\)
    \(DE = 3m = \dfrac{21k}{5}\)
  4. הקטע \(DF\)
    \(DF\) מתאים ל־\(BD\), ויחס הדמיון של \(\triangle DFE\) ל־\(\triangle BDE\) הוא \(\dfrac{3}{5}\):
    \(DF = \dfrac{3}{5}\cdot BD = \dfrac{3}{5}\cdot\dfrac{28k}{5} = \dfrac{84k}{25}\)
  5. הקטע \(FC\)
    מסעיף ב:
    \(DC = 12k = \dfrac{300k}{25}\)
    \(FC = DC - DF = \dfrac{300k}{25} - \dfrac{84k}{25} = \dfrac{216k}{25}\)
  6. היחס
    \(DF:FC = 84:216 = 7:18\)
תשובה:
יחס הדמיון:
\(5:3\)
\(DF:FC = 7:18\)
בדיקה:
את \(EF\) אפשר לחשב בפיתגורס משני המשולשים ישרי הזווית, ומקבלים אותו אורך:
\(EF^{2} = DE^{2} - DF^{2} = \dfrac{441k^{2}}{25} - \dfrac{7056k^{2}}{625} = \dfrac{3969k^{2}}{625}\)
\(EF^{2} = CE^{2} - FC^{2} = 81k^{2} - \dfrac{46656k^{2}}{625} = \dfrac{3969k^{2}}{625}\ \checkmark\)

שאלה 2

מקבילית, תאלס ומפגש התיכונים
נתון

\(ABCD\) מקבילית שאלכסוניה נפגשים בנקודה \(O\). הנקודה \(E\) על הקטע \(DO\), ו־\(DE = 2EO\).

א.מצאו את \(\dfrac{DE}{BE}\)

דרך החשיבה

נתון יחס על הקטע \(DO\), ולכן מסמנים \(EO = t\). התכונה של המקבילית שמשמשת כאן: האלכסונים חוצים זה את זה, ולכן \(OB = DO\).

  1. נתונים
    \(EO = t\)
    \(DE = 2EO = 2t\)
    \(DO = DE + EO = 3t\)
  2. אלכסוני המקבילית
    האלכסונים חוצים זה את זה:
    \(OB = DO = 3t\)
  3. הקטע \(BE\)
    \(BE = EO + OB = t + 3t = 4t\)
  4. היחס
    \(\dfrac{DE}{BE} = \dfrac{2t}{4t} = \dfrac{1}{2}\)
תשובה:
\(\dfrac{DE}{BE} = \dfrac{1}{2}\)
בדיקה:
כל האלכסון שווה לפעמיים חציו:
\(DB = DE + BE = 2t + 4t = 6t = 2\cdot DO\ \checkmark\)

שימוש ב: אלכסוני מקבילית

ב.\(EF \parallel AB\). מצאו את \(\dfrac{DF}{AD}\)

דרך החשיבה

קטע המקביל לצלע במשולש יוצר משולש דומה (תאלס המורחב). המשולש הוא \(DAB\), והקטע \(EF\) מקביל ל־\(AB\), ולכן היחס \(DF:DA\) שווה ל־\(DE:DB\).

  1. תאלס המורחב
    במשולש \(DAB\) מתקיים \(EF \parallel AB\):
    \(\triangle DFE \sim \triangle DAB\)
    \(\dfrac{DF}{DA} = \dfrac{DE}{DB}\)
  2. הקטע \(DB\)
    \(DB = 2\cdot DO = 6t\)
  3. הצבה
    \(\dfrac{DF}{DA} = \dfrac{2t}{6t} = \dfrac{1}{3}\)
תשובה:
\(\dfrac{DF}{AD} = \dfrac{1}{3}\)
בדיקה:
לפי משפט תאלס על הקטעים עצמם:
\(\dfrac{DF}{FA} = \dfrac{DE}{EB} = \dfrac{2t}{4t} = \dfrac{1}{2}\)
ולכן \(DF\) הוא שליש מ־\(DA\) ✓

ג.המשך \(AE\) חותך את \(DC\) בנקודה \(G\)

דרך החשיבה

קטעים על ישר שחוצה שני ישרים מקבילים יוצרים שני משולשים דומים ("פרפר"): זוויות קודקודיות וזוויות מתחלפות. לחלק (2) משתמשים בכך שמפגש התיכונים מחלק כל תיכון ביחס \(2:1\) מהקדקוד.

  1. סעיף (1): הוכחת הדמיון
    זוויות קודקודיות:
    \(\measuredangle AEB = \measuredangle GED\)
    זוויות מתחלפות, כי \(AB \parallel DC\):
    \(\measuredangle ABE = \measuredangle GDE\)
    לפי ז.ז:
    \(\triangle ABE \sim \triangle GDE\)
  2. היחס \(\dfrac{AE}{EG}\)
    \(\dfrac{AE}{EG} = \dfrac{BE}{DE} = \dfrac{4t}{2t} = 2\)
  3. סעיף (2): \(DO\) תיכון
    האלכסונים חוצים זה את זה, ולכן \(O\) אמצע \(AC\):
    \(AO = OC\)
    ולכן \(DO\) הוא תיכון במשולש \(ACD\).
  4. מפגש התיכונים
    \(E\) על התיכון \(DO\) ומחלקת אותו מהקדקוד ביחס:
    \(DE:EO = 2:1\)
    מפגש התיכונים הוא הנקודה היחידה על התיכון שמחלקת אותו כך, ולכן \(E\) היא מפגש התיכונים במשולש \(ACD\).
תשובה:
\(\dfrac{AE}{EG} = 2\)
\(E\) היא מפגש התיכונים במשולש \(ACD\).
בדיקה:
אם \(E\) מפגש התיכונים, גם \(AG\) תיכון ומחולק ביחס \(2:1\), וזה מתאים לסעיף (1):
\(AE:EG = 2:1\ \checkmark\)
וגם \(G\) אמצע \(DC\): מהדמיון
\(\dfrac{DG}{AB} = \dfrac{DE}{BE} = \dfrac{1}{2}\ \checkmark\)

ד.\(S_{\triangle DEF} = S\)

דרך החשיבה

משולשים עם קדקוד משותף ובסיסים על אותו ישר הם בעלי אותו גובה, ולכן יחס השטחים שלהם שווה ליחס הבסיסים. מחפשים בכל פעם קדקוד משותף כזה.

  1. כלל
    \(\dfrac{S_{1}}{S_{2}} = \dfrac{a_{1}}{a_{2}}\)
    כאשר לשני המשולשים אותו גובה (\(a\) הבסיסים).
  2. סעיף (1): \(S_{\triangle ADE}\)
    קדקוד משותף \(E\), בסיסים \(DA\) ו־\(DF\) על אותו ישר:
    \(\dfrac{S_{\triangle ADE}}{S_{\triangle DEF}} = \dfrac{DA}{DF} = 3\)
    \(S_{\triangle ADE} = 3S\)
  3. סעיף (2): \(S_{\triangle ADO}\)
    קדקוד משותף \(A\), בסיסים \(DO\) ו־\(DE\) על הישר \(DB\):
    \(\dfrac{S_{\triangle ADO}}{S_{\triangle ADE}} = \dfrac{DO}{DE} = \dfrac{3t}{2t} = \dfrac{3}{2}\)
    \(S_{\triangle ADO} = \dfrac{3}{2}\cdot 3S = \dfrac{9S}{2}\)
תשובה:
\(S_{\triangle ADE} = 3S\)
\(S_{\triangle ADO} = \dfrac{9S}{2}\)
בדיקה:

ב.נתון \(\measuredangle BAD = \measuredangle BCE\). הוכחה: \(\triangle ABD \sim \triangle CBE\)

דרך החשיבה

לדמיון צ.ז.צ צריך שתי צלעות פרופורציוניות (יש מסעיף א) והזווית שביניהן שווה (נתונה). בודקים שהזווית הנתונה היא באמת הזווית שבין הצלעות האלה.

  1. צלעות פרופורציוניות
    מסעיף א:
    \(\dfrac{AB}{CB} = \dfrac{AD}{CE}\)
  2. הזווית שביניהן
    הזווית שבין \(AB\) ל־\(AD\) היא \(\measuredangle BAD\), והזווית שבין \(CB\) ל־\(CE\) היא \(\measuredangle BCE\). נתון:
    \(\measuredangle BAD = \measuredangle BCE\)
  3. מסקנה
    לפי צ.ז.צ:
    \(\triangle ABD \sim \triangle CBE\)
    \(A \leftrightarrow C,\ B \leftrightarrow B,\ D \leftrightarrow E\)
תשובה:
\(\triangle ABD \sim \triangle CBE\)
לפי צ.ז.צ

שימוש ב: צ.ז.צ

ג.נתון \(AB \perp BE\). מצאו את \(\measuredangle ABD\)

דרך החשיבה

הזווית \(ABE\) מורכבת משלוש זוויות שוות: שתיים מחוצה הזווית ועוד אחת מהדמיון בסעיף ב. הזווית כולה ישרה, ולכן כל אחת היא שליש ממנה.

  1. סימון
    \(\measuredangle ABD = \beta\)
    \(BD\) חוצה זווית:
    \(\measuredangle DBC = \beta\)
  2. מהדמיון
    זוויות מתאימות בסעיף ב:
    \(\measuredangle CBE = \measuredangle ABD = \beta\)
  3. הזווית \(ABE\)
    \(\triangle BCE\) בנוי מחוץ ל־\(\triangle ABC\):
    \(\measuredangle ABE = \measuredangle ABD + \measuredangle DBC + \measuredangle CBE = 3\beta\)
  4. \(\beta\)
    \(AB \perp BE\):
    \(3\beta = 90^{\circ}\)
    \(\beta = 30^{\circ}\)
תשובה:
\(\measuredangle ABD = 30^{\circ}\)
בדיקה:
\(\measuredangle ABE = 3\cdot 30^{\circ} = 90^{\circ}\ \checkmark\)
