כללי הגזירה של פונקציה מורכבת

1. מה זו פונקציה מורכבת

פונקציה מורכבת היא "פונקציה בתוך פונקציה": מפעילים פונקציה אחת על x, ועל התוצאה מפעילים פונקציה שנייה. מסמנים y = f(g(x)), ובקיצור (f∘g)(x).

g היא הפונקציה הפנימית, זו שפועלת ראשונה על x. f היא הפונקציה החיצונית, זו שפועלת אחרונה.

x⟶ gפנימית⟶ g(x)⟶ fחיצונית⟶ f(g(x))

איך מזהים מה פנימי ומה חיצוני? שואלים: "אם הייתי מחשב את הערך במחשבון עבור x מסוים, מה הייתי לוחץ אחרון?" הפעולה האחרונה היא הפונקציה החיצונית, וכל מה שנמצא "בתוכה" הוא הפונקציה הפנימית.

2. כלל השרשרת

[ f(g(x)) ]′ = f′(g(x)) · g′(x) נגזרת החיצונית (כשהפנימית נשארת בתוכה כמו שהיא) כפול נגזרת הפנימית

במילים: גוזרים את הפונקציה החיצונית ו"לא נוגעים" במה שבתוכה, ואז כופלים בנגזרת של מה שבתוכה.

בכתיב של לייבניץ: אם u = g(x) ו־y = f(u), אז dy/dx = (dy/du) · (du/dx). נראה כמו "צמצום" של du, וזו דרך טובה לזכור את הכלל.

למה זה נכון? (אינטואיציה) נגזרת היא קצב שינוי. אם u משתנה פי 3 מהר יותר מ־x, ו־y משתנה פי 2 מהר יותר מ־u, אז y משתנה פי 2·3 = 6 מהר יותר מ־x. קצבי השינוי נכפלים לאורך השרשרת. דוגמה מוחשית: גלגל שיניים גדול מסובב גלגל בינוני פי 3, והבינוני מסובב קטן פי 2. הקטן מסתובב פי 6 מהר מהגדול.

דוגמה פתורה

גזרו את y = (x² + 3x)⁵.

פנימית: u = x² + 3x, ונגזרתה u′ = 2x + 3.

חיצונית: u⁵, ונגזרתה 5u⁴.

לכן y′ = 5(x² + 3x)⁴ · (2x + 3).

בדיקה עצמית: במקרה g(x) = x הנגזרת הפנימית היא 1, וכלל השרשרת נותן בדיוק את הנגזרת הרגילה. לכן הכלל מכליל את מה שכבר הכרתם, ולא מחליף אותו.

3. תזכורת: נגזרות בסיסיות

כדי להשתמש בכלל השרשרת צריך לדעת לגזור את הפונקציה החיצונית. אלה הנגזרות הבסיסיות של כיתה יא׳:

קבוע(c)′ = 0
חזקה (כל n ממשי)(xⁿ)′ = n·xⁿ⁻¹
שורש ריבועי(√x)′ = 1/(2√x)
הופכי(1/x)′ = −1/x²
סינוס(sin x)′ = cos x
קוסינוס(cos x)′ = −sin x
טנגנס(tan x)′ = 1/cos²x
מכפלה(u·v)′ = u′v + uv′
מנה(u/v)′ = (u′v − uv′)/v²
חשוב: נגזרות הפונקציות הטריגונומטריות נכונות רק כאשר x נמדד ברדיאנים.

4. טבלת הכללים לפונקציה מורכבת

כל שורה בטבלה היא כלל השרשרת שהופעל על פונקציה חיצונית מוכרת. f מסמנת כאן את הפונקציה הפנימית ו־f′ את נגזרתה.

[f(x)]ⁿn·[f(x)]ⁿ⁻¹ · f′(x)[(x²+1)³]′ = 3(x²+1)²·2x
√f(x)f′(x) / (2√f(x))[√(5x−1)]′ = 5/(2√(5x−1))
ⁿ√f(x) = f^(1/n)f′(x) / (n·ⁿ√[f(x)]ⁿ⁻¹)[∛(x²)]′ = 2x/(3∛x⁴)

מקרה חשוב: פנימית לינארית. כשהפונקציה הפנימית היא ax + b, נגזרתה היא פשוט a. לכן גוזרים כרגיל וכופלים במקדם של x: [sin(2x)]′ = 2cos 2x, [√(4x+1)]′ = 4/(2√(4x+1)) = 2/√(4x+1).

טיפ: הפכו שורשים ושברים לחזקות. √f = f^(1/2), 1/f³ = f⁻³, 1/√f = f^(−1/2). אז מספיק לזכור רק את כלל החזקה: [f^(−1/2)]′ = −½·f^(−3/2)·f′.

תחום הגזירות: לפונקציה √f(x) אין נגזרת בנקודות שבהן f(x) = 0, כי שם המכנה 2√f(x) מתאפס. תחום הנגזרת יכול להיות קטן מתחום הפונקציה.

דוגמה פתורה: שורש

גזרו את y = √(x² − 6x + 13).

y′ = (2x − 6) / (2√(x² − 6x + 13)) = (x − 3) / √(x² − 6x + 13)

שימו לב לצמצום ב־2. כדאי תמיד לפשט, כי בהמשך נחפש היכן הנגזרת מתאפסת.

דוגמה פתורה: טריגונומטריה

גזרו את y = cos²(3x).

שלוש שכבות: חזקה ⟵ קוסינוס ⟵ 3x.

y′ = 2cos(3x) · (−sin 3x) · 3 = −6 sin(3x)cos(3x) = −3 sin(6x)

(השתמשנו בזהות 2sin α cos α = sin 2α.)

5. שילוב עם כלל המכפלה וכלל המנה

בשאלות בגרות הפונקציה המורכבת מופיעה בדרך כלל כחלק ממכפלה או ממנה. הסדר: קודם מזהים את המבנה הכללי (מכפלה? מנה?), ורק כשגוזרים כל חלק מפעילים עליו את כלל השרשרת.

דוגמה פתורה: מכפלה

גזרו את y = x²·(1 − x)⁴.

y′ = 2x(1 − x)⁴ + x² · 4(1 − x)³·(−1)

מוציאים גורם משותף: y′ = 2x(1 − x)³ [ (1 − x) − 2x ] = 2x(1 − x)³(1 − 3x)

הצורה המפורקת מאפשרת למצוא מיד את נקודות האפס: x = 0, 1, 1/3.

דוגמה פתורה: מנה

גזרו את y = x / √(x² + 1).

y′ = [ 1·√(x²+1) − x · x/√(x²+1) ] / (x² + 1)

כופלים מונה ומכנה ב־√(x²+1): y′ = [ (x² + 1) − x² ] / (x² + 1)^(3/2) = 1 / (x² + 1)^(3/2)

טיפ לפישוט: אחרי גזירת מכפלה שבה מופיעה אותה סוגריים בחזקות שונות, הוציאו את החזקה הנמוכה כגורם משותף. כך מקבלים ביטוי מפורק שקל לבדוק את סימנו.

6. כמה שכבות של הרכבה

כשיש יותר משתי שכבות, כלל השרשרת פשוט ממשיך: גוזרים מבחוץ פנימה, שכבה אחרי שכבה, וכופלים את כל הנגזרות.

[ f(g(h(x))) ]′ = f′(g(h(x))) · g′(h(x)) · h′(x)

דוגמה פתורה

גזרו את y = √(sin(x²)).

השכבות מבחוץ פנימה: √ ⟵ sin ⟵ x².

y′ = 1/(2√(sin(x²))) · cos(x²) · 2x = x·cos(x²) / √(sin(x²))

דוגמה פתורה: נגזרת בנקודה

נתון g(x) = f(2x − 3), וידוע ש־f′(5) = 7. חשבו את g′(4).

g′(x) = f′(2x − 3) · 2

g′(4) = f′(5) · 2 = 14

שימו לב: מציבים x = 4 בתוך הפנימית, ולכן צריך את f′(5) ולא את f′(4).

7. טעויות נפוצות

  • לשכוח לכפול בנגזרת הפנימית. [(3x+1)⁴]′ ≠ 4(3x+1)³. התשובה הנכונה: 12(3x+1)³.
  • לגזור גם את הפנימית בתוך החיצונית. [sin(x²)]′ ≠ cos(2x). הפנימית נשארת כמו שהיא בתוך הקוסינוס: 2x·cos(x²).
  • לבלבל בין sin²x ל־sin(x²). (sin²x)′ = 2sin x·cos x, ואילו [sin(x²)]′ = 2x·cos(x²).
  • להוריד את החזקה גם בתוך הסוגריים. [(x²+1)³]′ ≠ 3(2x)². גוזרים את החזקה החיצונית ומשאירים את x²+1 כמו שהוא.
  • לשכוח את המינוס של קוסינוס. [cos(5x)]′ = −5 sin(5x).
  • טעות בחזקה שלילית. [(x−2)⁻³]′ = −3(x−2)⁻⁴: החזקה יורדת ב־1 ומגיעה ל־−4, לא ל־−2.
  • להשאיר את התשובה לא מפושטת ואז לא להצליח למצוא היכן היא מתאפסת. תמיד הוציאו גורמים משותפים וצמצמו.
