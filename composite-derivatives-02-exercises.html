תרגילים: נגזרות של פונקציות מורכבות

42 שאלות מדורגות עם פתרונות מלאים, בשלוש רמות. בכל פתרון יש קודם דרך החשיבה (איך מזהים את המבנה ואיזה כלל בוחרים), ואחריה השלבים אחד אחד והתשובה. הכללים וההסברים נמצאים בדף כללי הגזירה של פונקציה מורכבת.

תוכן
  1. רמה א׳: בסיס (1–15)
  2. רמה ב׳: ביסוס (16–30)
  3. רמה ג׳: רמת בגרות (31–42)
  4. חזרה לכללי הגזירה
לפני שמתחילים: בכל שאלה זהו קודם את הפונקציה הפנימית ואת החיצונית. אחר כך גזרו לפי כלל השרשרת: \([f(g(x))]' = f'(g(x)) \cdot g'(x)\), ופשטו את התשובה.

רמה א׳: בסיס שאלות 1–15

גזרו את הפונקציות. הפעלה ישירה של כלל אחד מהטבלה.

  1. \(y = (3x - 2)^{5}\)
    הצג פתרון
    דרך החשיבה

    יש כאן ביטוי שלם בסוגריים שמועלה בחזקה. כשהבסיס של החזקה הוא לא סתם \(x\) אלא ביטוי, זו פונקציה מורכבת: גוזרים את החזקה כרגיל ואז כופלים בנגזרת של מה שבתוך הסוגריים.

    1. זיהוי המבנה: פנימית \(u = 3x-2\), חיצונית \(u^{5}\).
    2. נגזרת החיצונית: \(5u^{4} = 5(3x-2)^{4}\). הסוגריים נשארים כמו שהם.
    3. נגזרת הפנימית: \((3x-2)' = 3\)
    4. כפל ופישוט: \(y' = 5(3x-2)^{4}\cdot 3 = 15(3x-2)^{4}\)

    תשובה: \(y' = 15(3x-2)^{4}\)

  2. \(y = (x^{2} + 1)^{4}\)
    הצג פתרון
    דרך החשיבה

    אותו מבנה כמו בשאלה 1: ביטוי בסוגריים בחזקה. ההבדל: הפנימית ריבועית, ולכן הנגזרת הפנימית היא \(2x\) ולא מספר. לא פותחים את הסוגריים — זה ארוך ומיותר.

    1. זיהוי המבנה: פנימית \(u = x^{2}+1\), חיצונית \(u^{4}\).
    2. נגזרת החיצונית: \(4(x^{2}+1)^{3}\)
    3. נגזרת הפנימית: \((x^{2}+1)' = 2x\)
    4. כפל ופישוט: \(y' = 4(x^{2}+1)^{3}\cdot 2x = 8x(x^{2}+1)^{3}\). מסדרים: המספרים וה־\(x\) מקדימה.

    תשובה: \(y' = 8x(x^{2}+1)^{3}\)

  3. \(y = \sqrt{4x + 1}\)
    הצג פתרון
    דרך החשיבה

    שורש של ביטוי. הכלל לשורש: \((\sqrt{u})' = \dfrac{u'}{2\sqrt{u}}\) — הנגזרת הפנימית עולה למונה, והשורש עצמו נשאר במכנה.

    1. זיהוי המבנה: פנימית \(u = 4x+1\), חיצונית \(\sqrt{u}\).
    2. נגזרת החיצונית: \(\dfrac{1}{2\sqrt{4x+1}}\)
    3. נגזרת הפנימית: \((4x+1)' = 4\)
    4. כפל ופישוט: \(y' = \dfrac{4}{2\sqrt{4x+1}} = \dfrac{2}{\sqrt{4x+1}}\) (מצמצמים 4 עם 2).

    תשובה: \(y' = \dfrac{2}{\sqrt{4x+1}}\)

  4. \(y = \dfrac{1}{(2x - 5)^{3}}\)
    הצג פתרון
    דרך החשיבה

    אחד חלקי ביטוי בחזקה. במקום כלל המנה, הדרך הקצרה היא להעלות את המכנה למונה עם חזקה שלילית, ואז זו חזקה רגילה של ביטוי.

    1. כתיבה כחזקה: \(y = (2x-5)^{-3}\)
    2. נגזרת החיצונית: \(-3(2x-5)^{-4}\) (החזקה יורדת באחד: \(-3-1=-4\)).
    3. נגזרת הפנימית: \((2x-5)' = 2\)
    4. כפל ופישוט: \(y' = -3(2x-5)^{-4}\cdot 2 = -\dfrac{6}{(2x-5)^{4}}\). מחזירים את החזקה השלילית למכנה.

    תשובה: \(y' = -\dfrac{6}{(2x-5)^{4}}\)

  5. \(y = {\sin(3x)}\)
    הצג פתרון
    דרך החשיבה

    סינוס של ביטוי. החיצונית היא \(\sin\), ונגזרתה \(\cos\) של אותו ביטוי. אחר כך כופלים בנגזרת של מה שבתוך הסינוס.

    1. זיהוי המבנה: פנימית \(u = 3x\), חיצונית \(\sin u\).
    2. נגזרת החיצונית: \(\cos(3x)\)
    3. נגזרת הפנימית: \((3x)' = 3\)
    4. כפל ופישוט: \(y' = 3\cos(3x)\)

    תשובה: \(y' = 3\cos(3x)\)

  6. \(y = {\cos(x^{2})}\)
    הצג פתרון
    דרך החשיבה

    קוסינוס של \(x^{2}\). שימו לב: \(\cos(x^{2})\) (הזווית בריבוע) שונה מ־\(\cos^{2}x\) (התוצאה בריבוע). כאן הריבוע בתוך הקוסינוס, ולכן הוא הפנימית.

    1. זיהוי המבנה: פנימית \(u = x^{2}\), חיצונית \(\cos u\).
    2. נגזרת החיצונית: \(-\sin(x^{2})\) — הנגזרת של קוסינוס היא מינוס סינוס.
    3. נגזרת הפנימית: \((x^{2})' = 2x\)
    4. כפל ופישוט: \(y' = -\sin(x^{2})\cdot 2x = -2x\sin(x^{2})\)

    תשובה: \(y' = -2x\sin(x^{2})\)

  7. \(y = {\sin^{2} x}\)
    הצג פתרון
    דרך החשיבה

    \(\sin^{2}x\) פירושו \((\sin x)^{2}\): קודם מחשבים סינוס, ואז מעלים בריבוע. מה שמחושב אחרון הוא החיצונית — כאן הריבוע.

    1. כתיבה כחזקה: \(y = (\sin x)^{2}\). פנימית \(u = \sin x\), חיצונית \(u^{2}\).
    2. נגזרת החיצונית: \(2\sin x\)
    3. נגזרת הפנימית: \((\sin x)' = \cos x\)
    4. כפל ופישוט: \(y' = 2\sin x\cos x = \sin(2x)\) (זהות הזווית הכפולה).

    תשובה: \(y' = 2\sin x\cos x = \sin(2x)\)

  8. \(y = (5 - 2x)^{6}\)
    הצג פתרון
    דרך החשיבה

    ביטוי בסוגריים בחזקה, כמו בשאלה 1. הפעם המקדם של \(x\) בפנימית שלילי, ולכן הנגזרת הפנימית שלילית. זו הטעות הנפוצה כאן: שוכחים את המינוס.

    1. זיהוי המבנה: פנימית \(u = 5-2x\), חיצונית \(u^{6}\).
    2. נגזרת החיצונית: \(6(5-2x)^{5}\)
    3. נגזרת הפנימית: \((5-2x)' = -2\)
    4. כפל ופישוט: \(y' = 6(5-2x)^{5}\cdot(-2) = -12(5-2x)^{5}\)

    תשובה: \(y' = -12(5-2x)^{5}\)

  9. \(y = \sqrt{x^{2} + 16}\)
    הצג פתרון
    דרך החשיבה

    שורש של ביטוי ריבועי. לפי כלל השורש, הנגזרת הפנימית \(2x\) עולה למונה, ובמכנה \(2\sqrt{\ldots}\). ה־2 מצטמצם.

    1. זיהוי המבנה: פנימית \(u = x^{2}+16\), חיצונית \(\sqrt{u}\).
    2. נגזרת החיצונית: \(\dfrac{1}{2\sqrt{x^{2}+16}}\)
    3. נגזרת הפנימית: \(2x\)
    4. כפל ופישוט: \(y' = \dfrac{2x}{2\sqrt{x^{2}+16}} = \dfrac{x}{\sqrt{x^{2}+16}}\)

    תשובה: \(y' = \dfrac{x}{\sqrt{x^{2}+16}}\)

  10. \(y = (x^{3} - 2x)^{4}\)
    הצג פתרון
    דרך החשיבה

    ביטוי בחזקה רביעית. לא פותחים — זה היה נותן פולינום ממעלה 12. הפנימית היא פולינום, ואת הנגזרת שלה כותבים בסוגריים כי היא סכום.

    1. זיהוי המבנה: פנימית \(u = x^{3}-2x\), חיצונית \(u^{4}\).
    2. נגזרת החיצונית: \(4(x^{3}-2x)^{3}\)
    3. נגזרת הפנימית: \(3x^{2}-2\)
    4. כפל ופישוט: \(y' = 4(x^{3}-2x)^{3}(3x^{2}-2)\). אין מה לצמצם, משאירים כך.

    תשובה: \(y' = 4(x^{3}-2x)^{3}(3x^{2}-2)\)

  11. \(y = \dfrac{1}{x^{2} + 1}\)
    הצג פתרון
    דרך החשיבה

    אחד חלקי ביטוי, כמו בשאלה 4: כותבים כחזקה \(-1\) וגוזרים כחזקה של ביטוי.

    1. כתיבה כחזקה: \(y = (x^{2}+1)^{-1}\)
    2. נגזרת החיצונית: \(-(x^{2}+1)^{-2}\)
    3. נגזרת הפנימית: \(2x\)
    4. כפל ופישוט: \(y' = -(x^{2}+1)^{-2}\cdot 2x = -\dfrac{2x}{(x^{2}+1)^{2}}\)

    תשובה: \(y' = -\dfrac{2x}{(x^{2}+1)^{2}}\)

  12. \(y = {\cos(5x - 1)}\)
    הצג פתרון
    דרך החשיבה

    קוסינוס של ביטוי לינארי. שני דברים לזכור: נגזרת קוסינוס היא מינוס סינוס, והזווית בתוך הסינוס נשארת \(5x-1\).

    1. זיהוי המבנה: פנימית \(u = 5x-1\), חיצונית \(\cos u\).
    2. נגזרת החיצונית: \(-\sin(5x-1)\)
    3. נגזרת הפנימית: \(5\)
    4. כפל ופישוט: \(y' = -5\sin(5x-1)\)

    תשובה: \(y' = -5\sin(5x-1)\)

  13. \(y = {\sin\left(\dfrac{x}{2}\right)}\)
    הצג פתרון
    דרך החשיבה

    סינוס של \(\tfrac{x}{2}\). כדאי לראות את \(\tfrac{x}{2}\) כ־\(\tfrac12 x\): ביטוי לינארי שהנגזרת שלו \(\tfrac12\).

    1. זיהוי המבנה: פנימית \(u = \tfrac{x}{2}\), חיצונית \(\sin u\).
    2. נגזרת החיצונית: \(\cos\left(\tfrac{x}{2}\right)\)
    3. נגזרת הפנימית: \(\tfrac12\)
    4. כפל ופישוט: \(y' = \tfrac12\cos\left(\tfrac{x}{2}\right)\)

    תשובה: \(y' = \tfrac12\cos\left(\tfrac{x}{2}\right)\)

  14. \(y = \sqrt[3]{3x + 2}\)
    הצג פתרון
    דרך החשיבה

    שורש שלישי — אין לו כלל משלו בטבלה, ולכן כותבים אותו כחזקה \(\tfrac13\) וגוזרים כחזקה של ביטוי.

    1. כתיבה כחזקה: \(y = (3x+2)^{1/3}\)
    2. נגזרת החיצונית: \(\tfrac13(3x+2)^{-2/3}\) (\(\tfrac13 - 1 = -\tfrac23\)).
    3. נגזרת הפנימית: \(3\)
    4. כפל ופישוט: \(y' = \tfrac13(3x+2)^{-2/3}\cdot 3 = (3x+2)^{-2/3} = \dfrac{1}{\sqrt[3]{(3x+2)^{2}}}\)

    תשובה: \(y' = \dfrac{1}{\sqrt[3]{(3x+2)^{2}}}\)

  15. \(y = {\tan(x^{2})}\)
    הצג פתרון
    דרך החשיבה

    טנגנס של \(x^{2}\). הנגזרת של \(\tan u\) היא \(\dfrac{1}{\cos^{2}u}\), ואת הנגזרת הפנימית מעלים למונה.

    1. זיהוי המבנה: פנימית \(u = x^{2}\), חיצונית \(\tan u\).
    2. נגזרת החיצונית: \(\dfrac{1}{\cos^{2}(x^{2})}\)
    3. נגזרת הפנימית: \(2x\)
    4. כפל ופישוט: \(y' = \dfrac{2x}{\cos^{2}(x^{2})}\)

    תשובה: \(y' = \dfrac{2x}{\cos^{2}(x^{2})}\)

רמה ב׳: ביסוס שאלות 16–30

שורשים עם פנימית ריבועית, שילוב עם מכפלה ומנה, ושתי שכבות של הרכבה. פשטו את התשובה.

  1. \(y = \sqrt{x^{2} - 6x + 10}\)
    הצג פתרון
    דרך החשיבה

    שורש של ביטוי ריבועי. אחרי הגזירה מופיע 2 גם במונה וגם במכנה — מוציאים 2 מהמונה כגורם משותף ומצמצמים.

    1. זיהוי המבנה: פנימית \(u = x^{2}-6x+10\), חיצונית \(\sqrt{u}\).
    2. נגזרת הפנימית: \(2x-6 = 2(x-3)\)
    3. כפל ופישוט: \(y' = \dfrac{2(x-3)}{2\sqrt{x^{2}-6x+10}} = \dfrac{x-3}{\sqrt{x^{2}-6x+10}}\)

    תשובה: \(y' = \dfrac{x-3}{\sqrt{x^{2}-6x+10}}\)

  2. \(y = \dfrac{5}{(x^{2} + 3)^{2}}\)
    הצג פתרון
    דרך החשיבה

    מספר חלקי ביטוי בחזקה. המספר 5 הוא סתם מקדם, הוא נשאר. את המכנה מעלים למונה עם חזקה שלילית.

    1. כתיבה כחזקה: \(y = 5(x^{2}+3)^{-2}\)
    2. נגזרת החיצונית: \(5\cdot(-2)(x^{2}+3)^{-3} = -10(x^{2}+3)^{-3}\)
    3. נגזרת הפנימית: \(2x\)
    4. כפל ופישוט: \(y' = -10(x^{2}+3)^{-3}\cdot 2x = -\dfrac{20x}{(x^{2}+3)^{3}}\)

    תשובה: \(y' = -\dfrac{20x}{(x^{2}+3)^{3}}\)

  3. \(y = x(2x + 1)^{3}\)
    הצג פתרון
    דרך החשיבה

    יש כאן מכפלה של שתי פונקציות: \(x\) ו־\((2x+1)^{3}\). לכן קודם כלל המכפלה, ורק את הגורם השני גוזרים בכלל השרשרת. בסוף מוציאים גורם משותף כדי לקבל תשובה מפושטת.

    1. זיהוי המבנה: \(f = x\), \(g = (2x+1)^{3}\). כלל המכפלה: \(y' = f'g + fg'\).
    2. הנגזרות של הגורמים: \(f' = 1\); \(g' = 3(2x+1)^{2}\cdot 2 = 6(2x+1)^{2}\) (שרשרת).
    3. הצבה בכלל המכפלה: \(y' = (2x+1)^{3} + x\cdot 6(2x+1)^{2}\)
    4. גורם משותף: \((2x+1)^{2}[(2x+1)+6x] = (2x+1)^{2}(8x+1)\)

    תשובה: \(y' = (2x+1)^{2}(8x+1)\)

  4. \(y = x\sqrt{1 - x}\)
    הצג פתרון
    דרך החשיבה

    מכפלה של \(x\) בשורש. כלל המכפלה, והשורש נגזר בשרשרת. התוצאה היא סכום של ביטוי רגיל ושבר עם שורש — מאחדים למכנה משותף \(2\sqrt{1-x}\).

    1. זיהוי המבנה: \(f = x\), \(g = \sqrt{1-x}\).
    2. הנגזרות של הגורמים: \(f' = 1\); \(g' = \dfrac{-1}{2\sqrt{1-x}}\) (הנגזרת הפנימית \(-1\)).
    3. הצבה בכלל המכפלה: \(y' = \sqrt{1-x} - \dfrac{x}{2\sqrt{1-x}}\)
    4. מכנה משותף: כופלים את \(\sqrt{1-x}\) ב־\(\dfrac{2\sqrt{1-x}}{2\sqrt{1-x}}\): \(\dfrac{2(1-x)-x}{2\sqrt{1-x}} = \dfrac{2-3x}{2\sqrt{1-x}}\)

    תשובה: \(y' = \dfrac{2-3x}{2\sqrt{1-x}}\)

  5. \(y = {\tan(2x)}\)
    הצג פתרון
    דרך החשיבה

    טנגנס של \(2x\): החיצונית \(\tan\) והפנימית לינארית. כמו בשאלה 15, רק שהנגזרת הפנימית היא מספר.

    1. זיהוי המבנה: פנימית \(u = 2x\), חיצונית \(\tan u\).
    2. נגזרת החיצונית: \(\dfrac{1}{\cos^{2}(2x)}\)
    3. נגזרת הפנימית: \(2\)
    4. כפל ופישוט: \(y' = \dfrac{2}{\cos^{2}(2x)}\)

    תשובה: \(y' = \dfrac{2}{\cos^{2}(2x)}\)

  6. \(y = \left( \dfrac{x + 1}{x - 1} \right)^{3}\)
    הצג פתרון
    דרך החשיבה

    שבר שלם בחזקה שלישית. החיצונית היא החזקה, והפנימית היא השבר — ואת השבר גוזרים בכלל המנה. כך כלל השרשרת "קורא" לכלל אחר בתוכו.

    1. זיהוי המבנה: פנימית \(u = \dfrac{x+1}{x-1}\), חיצונית \(u^{3}\).
    2. נגזרת החיצונית: \(3\left(\dfrac{x+1}{x-1}\right)^{2}\)
    3. נגזרת הפנימית (כלל המנה): \(\dfrac{1\cdot(x-1)-(x+1)\cdot 1}{(x-1)^{2}} = -\dfrac{2}{(x-1)^{2}}\)
    4. כפל ופישוט: \(y' = 3\cdot\dfrac{(x+1)^{2}}{(x-1)^{2}}\cdot\dfrac{-2}{(x-1)^{2}} = -\dfrac{6(x+1)^{2}}{(x-1)^{4}}\)

    תשובה: \(y' = -\dfrac{6(x+1)^{2}}{(x-1)^{4}}\)

  7. \(y = {\cos^{3}(2x)}\)
    הצג פתרון
    דרך החשיבה

    שלוש שכבות: \(x \to 2x \to \cos(2x) \to (\cos 2x)^{3}\). גוזרים מבחוץ פנימה, שכבה אחר שכבה, וכופלים את כל הנגזרות.

    1. זיהוי המבנה: חיצונית \(u^{3}\), אמצעית \(\cos v\), פנימית \(v = 2x\).
    2. שכבה חיצונית: \(3\cos^{2}(2x)\)
    3. שכבה אמצעית: \(-\sin(2x)\)
    4. שכבה פנימית: \(2\)
    5. כפל ופישוט: \(y' = 3\cos^{2}(2x)\cdot(-\sin 2x)\cdot 2 = -6\cos^{2}(2x)\sin(2x)\)

    תשובה: \(y' = -6\cos^{2}(2x)\sin(2x)\)

  8. \(y = (x - 1)^{2}(x + 2)^{3}\)
    הצג פתרון
    דרך החשיבה

    מכפלה של שני ביטויים בחזקה. כלל המכפלה, וכל גורם נגזר בשרשרת (כאן הנגזרות הפנימיות הן 1). בסוף מוציאים את הגורם המשותף הגדול ביותר: מכל סוג לוקחים את החזקה הנמוכה.

    1. זיהוי המבנה: \(f = (x-1)^{2}\), \(g = (x+2)^{3}\).
    2. הנגזרות של הגורמים: \(f' = 2(x-1)\); \(g' = 3(x+2)^{2}\)
    3. הצבה בכלל המכפלה: \(y' = 2(x-1)(x+2)^{3} + 3(x-1)^{2}(x+2)^{2}\)
    4. גורם משותף \((x-1)(x+2)^{2}\): \((x-1)(x+2)^{2}[2(x+2)+3(x-1)] = (x-1)(x+2)^{2}(5x+1)\)

    תשובה: \(y' = (x-1)(x+2)^{2}(5x+1)\)

  9. \(y = \dfrac{x}{(x^{2} + 1)^{2}}\)
    הצג פתרון
    דרך החשיבה

    מנה שבה המכנה הוא ביטוי בחזקה. כלל המנה, ואת המכנה גוזרים בשרשרת. בסוף יש \((x^{2}+1)\) בכל איברי המונה ובמכנה — מצמצמים אותו פעם אחת.

    1. כלל המנה: \(y' = \dfrac{1\cdot(x^{2}+1)^{2} - x\cdot[(x^{2}+1)^{2}]'}{(x^{2}+1)^{4}}\)
    2. נגזרת המכנה (שרשרת): \([(x^{2}+1)^{2}]' = 2(x^{2}+1)\cdot 2x = 4x(x^{2}+1)\)
    3. הצבה: \(y' = \dfrac{(x^{2}+1)^{2} - 4x^{2}(x^{2}+1)}{(x^{2}+1)^{4}}\)
    4. צמצום ב־\((x^{2}+1)\): \(\dfrac{(x^{2}+1) - 4x^{2}}{(x^{2}+1)^{3}} = \dfrac{1-3x^{2}}{(x^{2}+1)^{3}}\)

    תשובה: \(y' = \dfrac{1-3x^{2}}{(x^{2}+1)^{3}}\)

  10. \(y = \dfrac{1}{\sqrt{2x - 1}}\)
    הצג פתרון
    דרך החשיבה

    אחד חלקי שורש. שתי ההמרות יחד: שורש = חזקה \(\tfrac12\), ובמכנה = חזקה שלילית. מקבלים חזקה \(-\tfrac12\) של ביטוי.

    1. כתיבה כחזקה: \(y = (2x-1)^{-1/2}\)
    2. נגזרת החיצונית: \(-\tfrac12(2x-1)^{-3/2}\)
    3. נגזרת הפנימית: \(2\)
    4. כפל ופישוט: \(y' = -(2x-1)^{-3/2} = -\dfrac{1}{(2x-1)\sqrt{2x-1}}\) (כי \((2x-1)^{3/2} = (2x-1)\sqrt{2x-1}\)).

    תשובה: \(y' = -\dfrac{1}{(2x-1)\sqrt{2x-1}}\)

  11. \(y = \dfrac{2x + 1}{\sqrt{x^{2} + 2}}\)
    הצג פתרון
    דרך החשיבה

    מנה שבמכנה שלה שורש. כלל המנה, ואת השורש גוזרים בשרשרת. נוצר "שבר בתוך שבר", ולכן כופלים מונה ומכנה ב־\(\sqrt{x^{2}+2}\) כדי להיפטר ממנו.

    1. כלל המנה: \(y' = \dfrac{2\sqrt{x^{2}+2} - (2x+1)\cdot(\sqrt{x^{2}+2})'}{x^{2}+2}\)
    2. נגזרת השורש (שרשרת): \((\sqrt{x^{2}+2})' = \dfrac{x}{\sqrt{x^{2}+2}}\)
    3. כפל ב־\(\sqrt{x^{2}+2}\): \(y' = \dfrac{2(x^{2}+2) - x(2x+1)}{(x^{2}+2)\sqrt{x^{2}+2}}\)
    4. פישוט המונה: \(2x^{2}+4-2x^{2}-x = 4-x\), ולכן \(y' = \dfrac{4-x}{(x^{2}+2)^{3/2}}\)

    תשובה: \(y' = \dfrac{4-x}{(x^{2}+2)^{3/2}}\)

  12. \(y = x \cdot {\sin(2x)}\)
    הצג פתרון
    דרך החשיבה

    מכפלה של \(x\) בסינוס. כלל המכפלה, והסינוס של \(2x\) נגזר בשרשרת.

    1. זיהוי המבנה: \(f = x\), \(g = \sin(2x)\).
    2. הנגזרות של הגורמים: \(f' = 1\); \(g' = 2\cos(2x)\)
    3. הצבה בכלל המכפלה: \(y' = \sin(2x) + 2x\cos(2x)\)

    תשובה: \(y' = \sin(2x) + 2x\cos(2x)\)

  13. \(y = {\sin(3x)} \cdot {\cos(3x)}\)
    הצג פתרון
    דרך החשיבה

    מכפלה של סינוס בקוסינוס של אותה זווית. אפשר כלל מכפלה, אבל אם מזהים את הזהות \(\sin\alpha\cos\alpha = \tfrac12\sin 2\alpha\), הפונקציה הופכת לסינוס אחד והגזירה קצרה. כדאי תמיד לבדוק אם פישוט לפני הגזירה חוסך עבודה.

    1. דרך א׳: כלל המכפלה: \(y' = 3\cos 3x\cdot\cos 3x + \sin 3x\cdot(-3\sin 3x) = 3(\cos^{2}3x - \sin^{2}3x)\)
    2. זהות: \(\cos^{2}\alpha - \sin^{2}\alpha = \cos 2\alpha\), ולכן \(y' = 3\cos(6x)\)
    3. דרך ב׳: פישוט קודם: \(y = \tfrac12\sin(6x) \Rightarrow y' = \tfrac12\cdot 6\cos(6x) = 3\cos(6x)\)

    תשובה: \(y' = 3\cos(6x)\)

  14. \(y = \sqrt{1 + {\cos^{2} x}}\)
    הצג פתרון
    דרך החשיבה

    שלוש שכבות: שורש ← ריבוע ← קוסינוס. כלומר \(x \to \cos x \to 1+\cos^{2}x \to \sqrt{\ldots}\). גוזרים מבחוץ פנימה.

    1. שכבה חיצונית (שורש): \(\dfrac{1}{2\sqrt{1+\cos^{2}x}}\)
    2. שכבה אמצעית (\(1+u^{2}\)): \(2\cos x\)
    3. שכבה פנימית: \((\cos x)' = -\sin x\)
    4. כפל ופישוט: \(y' = \dfrac{2\cos x\cdot(-\sin x)}{2\sqrt{1+\cos^{2}x}} = -\dfrac{\sin x\cos x}{\sqrt{1+\cos^{2}x}}\)

    תשובה: \(y' = -\dfrac{\sin x\cos x}{\sqrt{1+\cos^{2}x}}\)

  15. \(y = \dfrac{1}{{\sin^{2} x}}\)
    הצג פתרון
    דרך החשיבה

    אחד חלקי סינוס בריבוע. כותבים \((\sin x)^{-2}\) — חזקה שלילית של סינוס — וגוזרים בשרשרת.

    1. כתיבה כחזקה: \(y = (\sin x)^{-2}\)
    2. נגזרת החיצונית: \(-2(\sin x)^{-3}\)
    3. נגזרת הפנימית: \(\cos x\)
    4. כפל ופישוט: \(y' = -2(\sin x)^{-3}\cos x = -\dfrac{2\cos x}{\sin^{3}x}\)

    תשובה: \(y' = -\dfrac{2\cos x}{\sin^{3}x}\)

רמה ג׳: רמת בגרות שאלות 31–42

כמה שכבות, משיק, נקודות קיצון ונגזרת בנקודה.

  1. גזרו את \(y = \sqrt{{\sin x}}\) ואת \(y = {\sin(\sqrt{x})}\). מה ההבדל?
    הצג פתרון
    דרך החשיבה

    שתי פונקציות עם אותם "חלקים" — שורש וסינוס — אבל בסדר הפוך. השאלה היא מה מחשבים אחרון: זו החיצונית. ב־\(\sqrt{\sin x}\) מחשבים סינוס ואז שורש; ב־\(\sin\sqrt{x}\) מחשבים שורש ואז סינוס.

    1. \(y = \sqrt{\sin x}\): חיצונית שורש, פנימית \(\sin x\): \(y' = \dfrac{\cos x}{2\sqrt{\sin x}}\)
    2. \(y = \sin(\sqrt{x})\): חיצונית סינוס, פנימית \(\sqrt{x}\): \(y' = \cos(\sqrt{x})\cdot\dfrac{1}{2\sqrt{x}} = \dfrac{\cos\sqrt{x}}{2\sqrt{x}}\)
    3. ההבדל: בראשונה הקוסינוס במונה והשורש של \(\sin x\) במכנה; בשנייה הקוסינוס הוא של \(\sqrt{x}\) ובמכנה שורש של \(x\). סדר ההרכבה משנה את התוצאה.

    תשובה: שתי הנגזרות שונות: \(\dfrac{\cos x}{2\sqrt{\sin x}}\) לעומת \(\dfrac{\cos\sqrt{x}}{2\sqrt{x}}\)

  2. גזרו את \(y = ({\sin x} + {\cos x})^{2}\) והראו שהתוצאה שווה ל־\(2{\cos(2x)}\).
    הצג פתרון
    דרך החשיבה

    ביטוי בסוגריים בריבוע — שרשרת. אחרי הגזירה מקבלים מכפלה של סכום בהפרש, שזה בדיוק המבנה \((a+b)(a-b) = a^{2}-b^{2}\), ואז זהות הזווית הכפולה.

    1. זיהוי המבנה: פנימית \(u = \sin x+\cos x\), חיצונית \(u^{2}\).
    2. גזירה: \(y' = 2(\sin x+\cos x)(\cos x-\sin x)\)
    3. נוסחת הכפל המקוצר: \((\cos x+\sin x)(\cos x-\sin x) = \cos^{2}x-\sin^{2}x = \cos 2x\)
    4. בדיקה בדרך אחרת: \(y = \sin^{2}x+2\sin x\cos x+\cos^{2}x = 1+\sin 2x \Rightarrow y' = 2\cos 2x\) ✓

    תשובה: \(y' = 2\cos(2x)\)

  3. מצאו את משוואת המשיק לגרף \(y = \sqrt{2x + 5}\) בנקודה שבה \(x = 2\).
    הצג פתרון
    דרך החשיבה

    משוואת משיק צריכה שני דברים: נקודה ושיפוע. את הנקודה מקבלים מהצבה בפונקציה, ואת השיפוע מהצבה בנגזרת (שנגזרת בשרשרת).

    1. הנקודה: \(y(2) = \sqrt{9} = 3\), כלומר \((2, 3)\).
    2. הנגזרת: \(y' = \dfrac{2}{2\sqrt{2x+5}} = \dfrac{1}{\sqrt{2x+5}}\)
    3. השיפוע: \(y'(2) = \tfrac13\)
    4. משוואת המשיק: \(y-3 = \tfrac13(x-2) \Rightarrow y = \tfrac13x+\tfrac73\)

    תשובה: \(y = \tfrac13x+\tfrac73\)

  4. מצאו את נקודות הקיצון של \(f(x) = (x^{2} - 4)^{3}\) וקבעו את סוגן.
    הצג פתרון
    דרך החשיבה

    נקודות קיצון: מאפסים את הנגזרת ובודקים אם היא מחליפה סימן. גורם בריבוע אף פעם לא שלילי, ולכן הוא לא משפיע על הסימן — רק \(6x\) קובע.

    1. הנגזרת (שרשרת): \(f'(x) = 3(x^{2}-4)^{2}\cdot 2x = 6x(x^{2}-4)^{2}\)
    2. איפוס: \(x = 0\) או \(x = \pm2\)
    3. סימן הנגזרת: שלילית ל־\(x \lt 0\) (חוץ מ־\(x=-2\) שבה היא 0), חיובית ל־\(x \gt 0\) (חוץ מ־\(x=2\)).
    4. מסקנה: ב־\(x=0\) הנגזרת עוברת ממינוס לפלוס: מינימום, \(f(0) = (-4)^{3} = -64\). ב־\(x=\pm2\) אין החלפת סימן: לא קיצון (נקודות פיתול עם משיק אופקי).

    תשובה: מינימום ב־\((0,-64)\); ב־\(x=\pm2\) אין קיצון.

  5. נתון \(g(x) = f(3x - 1)\), וידוע ש־\(f'(5) = 4\). חשבו את \(g'(2)\).
    הצג פתרון
    דרך החשיבה

    לא יודעים מהי \(f\), ולא צריך. כלל השרשרת אומר שהנגזרת של \(f(3x-1)\) היא \(f'\) של הפנימית כפול הנגזרת הפנימית. צריך רק לבדוק לאיזה ערך הפנימית שווה כש־\(x=2\).

    1. כלל השרשרת: \(g'(x) = f'(3x-1)\cdot 3\)
    2. הערך של הפנימית: ב־\(x=2\): \(3\cdot2-1 = 5\) — בדיוק הערך שעבורו נתון \(f'\).
    3. הצבה: \(g'(2) = 3f'(5) = 3\cdot 4 = 12\)

    תשובה: \(g'(2) = 12\)

  6. מצאו את תחום ההגדרה של \(f(x) = \sqrt{9 - x^{2}}\), את תחום הגזירות שלה ואת נקודת הקיצון הפנימית.
    הצג פתרון
    דרך החשיבה

    שורש מוגדר רק כשמה שבתוכו אינו שלילי. הנגזרת מכילה את השורש במכנה, ולכן היא לא מוגדרת גם כשהשורש מתאפס — בקצוות.

    1. תחום הגדרה: \(9-x^{2} \ge 0 \Rightarrow -3 \le x \le 3\)
    2. הנגזרת: \(f'(x) = \dfrac{-2x}{2\sqrt{9-x^{2}}} = -\dfrac{x}{\sqrt{9-x^{2}}}\); מוגדרת רק ב־\(-3 \lt x \lt 3\).
    3. איפוס וסימן: \(f'(x) = 0 \Rightarrow x = 0\). המכנה חיובי, ולכן הסימן הפוך לסימן של \(x\): חיובית משמאל ל־0, שלילית מימין.
    4. מסקנה: מקסימום ב־\((0,3)\). הגרף הוא חצי המעגל העליון \(x^{2}+y^{2} = 9\).

    תשובה: תחום הגדרה \([-3,3]\), גזירה ב־\((-3,3)\), מקסימום ב־\((0,3)\).

  7. מצאו את הנקודה על הגרף של \(y = \sqrt{x^{2} + 9}\) שבה שיפוע המשיק הוא \(\dfrac{4}{5}\).
    הצג פתרון
    דרך החשיבה

    "שיפוע המשיק" = הנגזרת. לכן משווים את הנגזרת ל־\(\tfrac45\) ופותרים משוואה עם שורש: מבודדים, מעלים בריבוע, ובודקים שהפתרון מתאים לסימן (העלאה בריבוע יכולה להוסיף פתרון זר).

    1. הנגזרת: \(y' = \dfrac{x}{\sqrt{x^{2}+9}}\)
    2. משוואה: \(\dfrac{x}{\sqrt{x^{2}+9}} = \dfrac45\). המכנה חיובי והשיפוע חיובי, ולכן \(x \gt 0\).
    3. פתרון: \(5x = 4\sqrt{x^{2}+9} \Rightarrow 25x^{2} = 16x^{2}+144 \Rightarrow x^{2} = 16\). מ־\(x \gt 0\): \(x = 4\) (הפתרון \(x=-4\) זר: שם השיפוע \(-\tfrac45\)).
    4. הנקודה: \(y(4) = \sqrt{25} = 5\)

    תשובה: \((4, 5)\)

  8. נתונה הפונקציה \(y = (ax + 1)^{3}\). שיפוע המשיק לגרף בנקודה שבה \(x = 0\) הוא 6. מצאו את \(a\).
    הצג פתרון
    דרך החשיבה

    פרמטר בתוך הפונקציה. גוזרים כרגיל, כש־\(a\) הוא מספר קבוע — שימו לב שהוא מופיע גם בנגזרת הפנימית. אחר כך מציבים \(x=0\) ומשווים לשיפוע הנתון.

    1. הנגזרת (שרשרת): \(y' = 3(ax+1)^{2}\cdot a\)
    2. הצבה \(x=0\): \(y'(0) = 3\cdot1^{2}\cdot a = 3a\)
    3. משוואה: \(3a = 6 \Rightarrow a = 2\)

    תשובה: \(a = 2\)

  9. מצאו את משוואת המשיק לגרף \(y = {\sin^{2} x}\) בנקודה שבה \(x = \dfrac{{\pi}}{4}\).
    הצג פתרון
    דרך החשיבה

    שוב נקודה ושיפוע. את \(\sin^{2}x\) גוזרים בשרשרת (כמו בשאלה 7), ואת הערכים ב־\(\tfrac{\pi}{4}\) יודעים בעל פה.

    1. הנקודה: \(y\left(\tfrac{\pi}{4}\right) = \left(\tfrac{\sqrt2}{2}\right)^{2} = \tfrac12\)
    2. הנגזרת: \(y' = 2\sin x\cos x = \sin(2x)\)
    3. השיפוע: \(y'\left(\tfrac{\pi}{4}\right) = \sin\tfrac{\pi}{2} = 1\)
    4. משוואת המשיק: \(y-\tfrac12 = x-\tfrac{\pi}{4} \Rightarrow y = x-\tfrac{\pi}{4}+\tfrac12\)

    תשובה: \(y = x-\tfrac{\pi}{4}+\tfrac12\)

  10. נתון \(h(x) = f(x^{2})\), וידוע ש־\(f'(4) = 3\). חשבו את \(h'(2)\) ואת \(h'( - 2)\).
    הצג פתרון
    דרך החשיבה

    כמו בשאלה 35: \(f'\) מוצב בפנימית \(x^{2}\). ב־\(x=2\) וב־\(x=-2\) הפנימית שווה לאותו ערך (4), אבל הנגזרת הפנימית \(2x\) שונה — ולכן התוצאות שונות.

    1. כלל השרשרת: \(h'(x) = f'(x^{2})\cdot 2x\)
    2. ב־\(x=2\): \(h'(2) = f'(4)\cdot 4 = 12\)
    3. ב־\(x=-2\): \(h'(-2) = f'(4)\cdot(-4) = -12\)

    תשובה: \(h'(2) = 12,\ h'(-2) = -12\)

  11. נתונה \(f(x) = x\sqrt{4 - x^{2}}\). מצאו את תחום ההגדרה, את הנגזרת ואת נקודות הקיצון.
    הצג פתרון
    דרך החשיבה

    מכפלה של \(x\) בשורש: כלל המכפלה ושרשרת, ואז מכנה משותף. לקיצון בודקים איפוס וסימן, ובקטע סגור צריך לבדוק גם את הקצוות.

    1. תחום הגדרה: \(4-x^{2} \ge 0 \Rightarrow -2 \le x \le 2\)
    2. הנגזרת: \(f'(x) = \sqrt{4-x^{2}} + \dfrac{x\cdot(-2x)}{2\sqrt{4-x^{2}}} = \dfrac{(4-x^{2})-x^{2}}{\sqrt{4-x^{2}}} = \dfrac{4-2x^{2}}{\sqrt{4-x^{2}}}\)
    3. איפוס: \(4-2x^{2} = 0 \Rightarrow x = \pm\sqrt2\)
    4. סימן: המכנה חיובי, הסימן לפי \(4-2x^{2}\): שלילית ב־\((-2,-\sqrt2)\), חיובית ב־\((-\sqrt2,\sqrt2)\), שלילית ב־\((\sqrt2,2)\).
    5. ערכים: \(f(\pm\sqrt2) = \pm\sqrt2\cdot\sqrt2 = \pm2\); \(f(\pm2) = 0\).

    תשובה: מינימום \((-\sqrt2,-2)\), מקסימום \((\sqrt2,2)\); בקצוות: מקסימום קצה \((-2,0)\), מינימום קצה \((2,0)\).

  12. מצאו את נקודות הקיצון של \(f(x) = {\sin^{2} x} + {\cos x}\) בתחום \(0 \lt x \lt 2{\pi}\).
    הצג פתרון
    דרך החשיבה

    הנגזרת יוצאת עם \(\sin x\) בשני האיברים, ולכן מוציאים אותו כגורם משותף. מכפלה שווה לאפס כשאחד הגורמים אפס — כך מקבלים שתי משוואות טריגונומטריות פשוטות. את הסימן בודקים בכל קטע לפי שני הגורמים.

    1. הנגזרת: \(f'(x) = 2\sin x\cos x - \sin x = \sin x(2\cos x-1)\)
    2. איפוס: \(\sin x = 0 \Rightarrow x = \pi\); \(\cos x = \tfrac12 \Rightarrow x = \tfrac{\pi}{3},\ \tfrac{5\pi}{3}\)
    3. סימן: \(+\) ב־\((0,\tfrac{\pi}{3})\), \(-\) ב־\((\tfrac{\pi}{3},\pi)\), \(+\) ב־\((\pi,\tfrac{5\pi}{3})\), \(-\) ב־\((\tfrac{5\pi}{3},2\pi)\).
    4. ערכים: \(f\left(\tfrac{\pi}{3}\right) = \tfrac34+\tfrac12 = \tfrac54\), \(f(\pi) = 0-1 = -1\), \(f\left(\tfrac{5\pi}{3}\right) = \tfrac54\).

    תשובה: מקסימום ב־\((\tfrac{\pi}{3},\tfrac54)\) וב־\((\tfrac{5\pi}{3},\tfrac54)\), מינימום ב־\((\pi,-1)\).

הפתרונות מוסתרים כדי לאפשר תרגול עצמי. לחצו על "הצג פתרון" כדי לבדוק. בהדפסה כל הפתרונות מוצגים.
