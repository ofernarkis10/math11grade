תרגילים: נגזרות של פונקציות מורכבות

42 שאלות מדורגות עם פתרונות מלאים, בשלוש רמות. הכללים וההסברים נמצאים בדף כללי הגזירה של פונקציה מורכבת.

תוכן
  1. רמה א׳: בסיס (1–15)
  2. רמה ב׳: ביסוס (16–30)
  3. רמה ג׳: רמת בגרות (31–42)
  4. חזרה לכללי הגזירה
לפני שמתחילים: בכל שאלה זהו קודם את הפונקציה הפנימית ואת החיצונית. אחר כך גזרו לפי כלל השרשרת: [f(g(x))]′ = f′(g(x))·g′(x), ופשטו את התשובה.

רמה א׳: בסיס שאלות 1–15

גזרו את הפונקציות. הפעלה ישירה של כלל אחד מהטבלה.

  1. y = (3x − 2)⁵
    הצג פתרון

    y′ = 5(3x − 2)⁴ · 3 = 15(3x − 2)⁴

  2. y = (x² + 1)⁴
    הצג פתרון

    y′ = 4(x² + 1)³ · 2x = 8x(x² + 1)³

  3. y = √(4x + 1)
    הצג פתרון

    y′ = 4 / (2√(4x + 1)) = 2 / √(4x + 1)

  4. y = 1 / (2x − 5)³
    הצג פתרון

    y = (2x − 5)⁻³

    y′ = −3(2x − 5)⁻⁴ · 2 = −6 / (2x − 5)⁴

  5. y = sin(3x)
    הצג פתרון

    y′ = 3cos(3x)

  6. y = cos(x²)
    הצג פתרון

    y′ = −sin(x²) · 2x = −2x·sin(x²)

  7. y = sin²x
    הצג פתרון

    y′ = 2sin x · cos x = sin(2x)

  8. y = (5 − 2x)⁶
    הצג פתרון

    y′ = 6(5 − 2x)⁵ · (−2) = −12(5 − 2x)⁵

    שימו לב למינוס שמגיע מהנגזרת הפנימית.

  9. y = √(x² + 16)
    הצג פתרון

    y′ = 2x / (2√(x² + 16)) = x / √(x² + 16)

  10. y = (x³ − 2x)⁴
    הצג פתרון

    y′ = 4(x³ − 2x)³ · (3x² − 2)

  11. y = 1 / (x² + 1)
    הצג פתרון

    y = (x² + 1)⁻¹

    y′ = −(x² + 1)⁻² · 2x = −2x / (x² + 1)²

  12. y = cos(5x − 1)
    הצג פתרון

    y′ = −sin(5x − 1) · 5 = −5sin(5x − 1)

  13. y = sin(x/2)
    הצג פתרון

    y′ = cos(x/2) · ½ = ½cos(x/2)

  14. y = ∛(3x + 2)
    הצג פתרון

    y = (3x + 2)^(1/3)

    y′ = ⅓(3x + 2)^(−2/3) · 3 = 1 / ∛(3x + 2)²

  15. y = tan(x²)
    הצג פתרון

    y′ = 2x / cos²(x²)

רמה ב׳: ביסוס שאלות 16–30

שורשים עם פנימית ריבועית, שילוב עם מכפלה ומנה, ושתי שכבות של הרכבה. פשטו את התשובה.

  1. y = √(x² − 6x + 10)
    הצג פתרון

    y′ = (2x − 6) / (2√(x² − 6x + 10)) = (x − 3) / √(x² − 6x + 10)

  2. y = 5 / (x² + 3)²
    הצג פתרון

    y = 5(x² + 3)⁻²

    y′ = −10(x² + 3)⁻³ · 2x = −20x / (x² + 3)³

  3. y = x(2x + 1)³
    הצג פתרון

    y′ = (2x + 1)³ + x · 3(2x + 1)² · 2

    = (2x + 1)² [ (2x + 1) + 6x ] = (2x + 1)²(8x + 1)

  4. y = x√(1 − x)
    הצג פתרון

    y′ = √(1 − x) + x · (−1)/(2√(1 − x))

    מכנה משותף: y′ = [ 2(1 − x) − x ] / (2√(1 − x)) = (2 − 3x) / (2√(1 − x))

  5. y = tan(2x)
    הצג פתרון

    y′ = 2 / cos²(2x)

  6. y = ( (x + 1)/(x − 1) )³
    הצג פתרון

    הנגזרת הפנימית (כלל המנה): [ (x+1)/(x−1) ]′ = [ (x−1) − (x+1) ] / (x−1)² = −2/(x−1)²

    y′ = 3( (x+1)/(x−1) )² · (−2)/(x−1)² = −6(x + 1)² / (x − 1)⁴

  7. y = cos³(2x)
    הצג פתרון

    y′ = 3cos²(2x) · (−sin 2x) · 2 = −6cos²(2x)·sin(2x)

  8. y = (x − 1)²(x + 2)³
    הצג פתרון

    y′ = 2(x − 1)(x + 2)³ + (x − 1)² · 3(x + 2)²

    גורם משותף (x − 1)(x + 2)²: y′ = (x − 1)(x + 2)² [ 2(x + 2) + 3(x − 1) ] = (x − 1)(x + 2)²(5x + 1)

  9. y = x / (x² + 1)²
    הצג פתרון

    y′ = [ (x² + 1)² − x · 2(x² + 1)·2x ] / (x² + 1)⁴

    מצמצמים ב־(x² + 1): y′ = [ (x² + 1) − 4x² ] / (x² + 1)³ = (1 − 3x²) / (x² + 1)³

  10. y = 1 / √(2x − 1)
    הצג פתרון

    y = (2x − 1)^(−1/2)

    y′ = −½(2x − 1)^(−3/2) · 2 = −1 / ( (2x − 1)√(2x − 1) )

  11. y = (2x + 1) / √(x² + 2)
    הצג פתרון

    y′ = [ 2√(x² + 2) − (2x + 1) · x/√(x² + 2) ] / (x² + 2)

    כופלים מונה ומכנה ב־√(x² + 2): y′ = [ 2(x² + 2) − 2x² − x ] / (x² + 2)^(3/2) = (4 − x) / (x² + 2)^(3/2)

  12. y = x·sin(2x)
    הצג פתרון

    y′ = sin(2x) + x · 2cos(2x) = sin(2x) + 2x·cos(2x)

  13. y = sin(3x)·cos(3x)
    הצג פתרון

    כלל המכפלה: y′ = 3cos(3x)·cos(3x) + sin(3x)·(−3sin 3x) = 3(cos²3x − sin²3x) = 3cos(6x)

    דרך קצרה: y = ½sin(6x), ולכן y′ = ½ · 6cos(6x) = 3cos(6x).

  14. y = √(1 + cos²x)
    הצג פתרון

    שלוש שכבות: שורש ⟵ ריבוע ⟵ קוסינוס.

    y′ = 2cos x·(−sin x) / (2√(1 + cos²x)) = −sin x·cos x / √(1 + cos²x)

  15. y = 1 / sin²x
    הצג פתרון

    y = (sin x)⁻²

    y′ = −2(sin x)⁻³ · cos x = −2cos x / sin³x

רמה ג׳: רמת בגרות שאלות 31–42

כמה שכבות, משיק, נקודות קיצון ונגזרת בנקודה.

  1. גזרו את y = √(sin x) ואת y = sin(√x). מה ההבדל?
    הצג פתרון

    [√(sin x)]′ = cos x / (2√(sin x)): החיצונית שורש, הפנימית סינוס.

    [sin(√x)]′ = cos(√x) / (2√x): החיצונית סינוס, הפנימית שורש.

  2. גזרו את y = (sin x + cos x)² והראו שהתוצאה שווה ל־2cos(2x).
    הצג פתרון

    y′ = 2(sin x + cos x)(cos x − sin x) = 2(cos²x − sin²x) = 2cos(2x)

    בדיקה בדרך אחרת: y = 1 + 2sin x cos x = 1 + sin 2x, ולכן y′ = 2cos 2x.

  3. מצאו את משוואת המשיק לגרף y = √(2x + 5) בנקודה שבה x = 2.
    הצג פתרון

    y(2) = √9 = 3

    y′ = 2/(2√(2x + 5)) = 1/√(2x + 5), ולכן y′(2) = 1/3

    y − 3 = (1/3)(x − 2) ⇒ y = x/3 + 7/3

  4. מצאו את נקודות הקיצון של f(x) = (x² − 4)³ וקבעו את סוגן.
    הצג פתרון

    f′(x) = 3(x² − 4)² · 2x = 6x(x² − 4)²

    f′(x) = 0 ⇒ x = 0, x = ±2

    הגורם (x² − 4)² אינו שלילי, ולכן סימן הנגזרת נקבע לפי 6x: שלילית עבור x < 0 וחיובית עבור x > 0.

    מינימום ב־(0, −64). ב־x = ±2 הנגזרת מתאפסת אך לא מחליפה סימן, ולכן אלה אינן נקודות קיצון (נקודות פיתול עם משיק אופקי).

  5. נתון g(x) = f(3x − 1), וידוע ש־f′(5) = 4. חשבו את g′(2).
    הצג פתרון

    g′(x) = 3f′(3x − 1)

    g′(2) = 3f′(5) = 12

  6. מצאו את תחום ההגדרה של f(x) = √(9 − x²), את תחום הגזירות שלה ואת נקודת הקיצון הפנימית.
    הצג פתרון

    תחום הגדרה: −3 ≤ x ≤ 3.

    f′(x) = −2x / (2√(9 − x²)) = −x / √(9 − x²), מוגדרת רק עבור −3 < x < 3 (בקצוות המכנה מתאפס).

    f′(x) = 0 ⇒ x = 0. הנגזרת חיובית משמאל ל־0 ושלילית מימין, לכן מקסימום ב־(0, 3). (הגרף הוא חצי מעגל עליון ברדיוס 3.)

  7. מצאו את הנקודה על הגרף של y = √(x² + 9) שבה שיפוע המשיק הוא 4/5.
    הצג פתרון

    y′ = x / √(x² + 9) = 4/5

    השיפוע חיובי, לכן x > 0. 5x = 4√(x² + 9) ⇒ 25x² = 16x² + 144 ⇒ x² = 16 ⇒ x = 4

    y(4) = √25 = 5. הנקודה: (4, 5).

  8. נתונה הפונקציה y = (ax + 1)³. שיפוע המשיק לגרף בנקודה שבה x = 0 הוא 6. מצאו את a.
    הצג פתרון

    y′ = 3(ax + 1)² · a

    y′(0) = 3a = 6 ⇒ a = 2

  9. מצאו את משוואת המשיק לגרף y = sin²x בנקודה שבה x = π/4.
    הצג פתרון

    y(π/4) = (√2/2)² = ½

    y′ = 2sin x·cos x = sin(2x), ולכן y′(π/4) = sin(π/2) = 1

    y − ½ = 1·(x − π/4) ⇒ y = x − π/4 + ½

  10. נתון h(x) = f(x²), וידוע ש־f′(4) = 3. חשבו את h′(2) ואת h′(−2).
    הצג פתרון

    h′(x) = f′(x²) · 2x

    h′(2) = f′(4) · 4 = 12

    h′(−2) = f′(4) · (−4) = −12

    בשני המקרים מציבים בפנימית את אותו ערך (4), אבל הנגזרת הפנימית 2x שונה.

  11. נתונה f(x) = x√(4 − x²). מצאו את תחום ההגדרה, את הנגזרת ואת נקודות הקיצון.
    הצג פתרון

    תחום הגדרה: −2 ≤ x ≤ 2.

    f′(x) = √(4 − x²) + x · (−2x)/(2√(4 − x²)) = [ (4 − x²) − x² ] / √(4 − x²) = (4 − 2x²) / √(4 − x²)

    f′(x) = 0 ⇒ x² = 2 ⇒ x = ±√2

    סימן הנגזרת: שלילית ב־(−2, −√2), חיובית ב־(−√2, √2), שלילית ב־(√2, 2).

    מינימום ב־(−√2, −2), מקסימום ב־(√2, 2). בקצוות: (−2, 0) מקסימום קצה, (2, 0) מינימום קצה.

  12. מצאו את נקודות הקיצון של f(x) = sin²x + cos x בתחום 0 < x < 2π.
    הצג פתרון

    f′(x) = 2sin x·cos x − sin x = sin x(2cos x − 1)

    sin x = 0 ⇒ x = π; cos x = ½ ⇒ x = π/3, 5π/3

    סימן הנגזרת: + ב־(0, π/3), − ב־(π/3, π), + ב־(π, 5π/3), − ב־(5π/3, 2π).

    מקסימום ב־(π/3, 5/4) וב־(5π/3, 5/4), מינימום ב־(π, −1).

    (f(π/3) = ¾ + ½ = 5/4, f(π) = 0 − 1 = −1.)
