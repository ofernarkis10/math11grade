תרגילים: נגזרות של פונקציות מורכבות

42 שאלות מדורגות עם פתרונות מלאים, בשלוש רמות. הכללים וההסברים נמצאים בדף כללי הגזירה של פונקציה מורכבת.

תוכן
  1. רמה א׳: בסיס (1–15)
  2. רמה ב׳: ביסוס (16–30)
  3. רמה ג׳: רמת בגרות (31–42)
  4. חזרה לכללי הגזירה
לפני שמתחילים: בכל שאלה זהו קודם את הפונקציה הפנימית ואת החיצונית. אחר כך גזרו לפי כלל השרשרת: \([f(g(x))]' = f'(g(x)) \cdot g'(x)\), ופשטו את התשובה.

רמה א׳: בסיס שאלות 1–15

גזרו את הפונקציות. הפעלה ישירה של כלל אחד מהטבלה.

  1. \(y = (3x - 2)^{5}\)
    הצג פתרון

    \(y' = 5(3x - 2)^{4} \cdot 3 = 15(3x - 2)^{4}\)

  2. \(y = (x^{2} + 1)^{4}\)
    הצג פתרון

    \(y' = 4(x^{2} + 1)^{3} \cdot 2x = 8x(x^{2} + 1)^{3}\)

  3. \(y = \sqrt{4x + 1}\)
    הצג פתרון

    \(y' = \dfrac{4}{2\sqrt{4x + 1}} = \dfrac{2}{\sqrt{4x + 1}}\)

  4. \(y = \dfrac{1}{(2x - 5)^{3}}\)
    הצג פתרון

    \(y = (2x - 5)^{-3}\)

    \(y' = - 3(2x - 5)^{-4} \cdot 2 = - \dfrac{6}{(2x - 5)^{4}}\)

  5. \(y = {\sin(3x)}\)
    הצג פתרון

    \(y' = 3{\cos(3x)}\)

  6. \(y = {\cos(x^{2})}\)
    הצג פתרון

    \(y' = - {\sin(x^{2})} \cdot 2x = - 2x \cdot {\sin(x^{2})}\)

  7. \(y = {\sin^{2} x}\)
    הצג פתרון

    \(y' = 2{\sin x} \cdot {\cos x} = {\sin(2x)}\)

  8. \(y = (5 - 2x)^{6}\)
    הצג פתרון

    \(y' = 6(5 - 2x)^{5} \cdot ( - 2) = - 12(5 - 2x)^{5}\)

    שימו לב למינוס שמגיע מהנגזרת הפנימית.

  9. \(y = \sqrt{x^{2} + 16}\)
    הצג פתרון

    \(y' = \dfrac{2x}{2\sqrt{x^{2} + 16}} = \dfrac{x}{\sqrt{x^{2} + 16}}\)

  10. \(y = (x^{3} - 2x)^{4}\)
    הצג פתרון

    \(y' = 4(x^{3} - 2x)^{3} \cdot (3x^{2} - 2)\)

  11. \(y = \dfrac{1}{x^{2} + 1}\)
    הצג פתרון

    \(y = (x^{2} + 1)^{-1}\)

    \(y' = - (x^{2} + 1)^{-2} \cdot 2x = - \dfrac{2x}{(x^{2} + 1)^{2}}\)

  12. \(y = {\cos(5x - 1)}\)
    הצג פתרון

    \(y' = - {\sin(5x - 1)} \cdot 5 = - 5{\sin(5x - 1)}\)

  13. \(y = {\sin\left(\dfrac{x}{2}\right)}\)
    הצג פתרון

    \(y' = {\cos\left(\dfrac{x}{2}\right)} \cdot {\dfrac{1}{2}} = {\dfrac{1}{2}}{\cos(\frac{x}{2})}\)

  14. \(y = \sqrt[3]{3x + 2}\)
    הצג פתרון

    \(y = (3x + 2)^{1/3}\)

    \(y' = {\dfrac{1}{3}}(3x + 2)^{ - 2/3} \cdot 3 = \dfrac{1}{\sqrt[3]{(3x + 2)^{2}}}\)

  15. \(y = {\tan(x^{2})}\)
    הצג פתרון

    \(y' = \dfrac{2x}{{\cos^{2}(x^{2})}}\)

רמה ב׳: ביסוס שאלות 16–30

שורשים עם פנימית ריבועית, שילוב עם מכפלה ומנה, ושתי שכבות של הרכבה. פשטו את התשובה.

  1. \(y = \sqrt{x^{2} - 6x + 10}\)
    הצג פתרון

    \(y' = \dfrac{2x - 6}{2\sqrt{x^{2} - 6x + 10}} = \dfrac{x - 3}{\sqrt{x^{2} - 6x + 10}}\)

  2. \(y = \dfrac{5}{(x^{2} + 3)^{2}}\)
    הצג פתרון

    \(y = 5(x^{2} + 3)^{-2}\)

    \(y' = - 10(x^{2} + 3)^{-3} \cdot 2x = - \dfrac{20x}{(x^{2} + 3)^{3}}\)

  3. \(y = x(2x + 1)^{3}\)
    הצג פתרון

    \(y' = (2x + 1)^{3} + x \cdot 3(2x + 1)^{2} \cdot 2\)

    \(= (2x + 1)^{2} [ (2x + 1) + 6x ] = (2x + 1)^{2}(8x + 1)\)

  4. \(y = x\sqrt{1 - x}\)
    הצג פתרון

    \(y' = \sqrt{1 - x} + \dfrac{x \cdot ( - 1)}{2\sqrt{1 - x}}\)

    מכנה משותף: \(y' = \dfrac{2(1 - x) - x}{2\sqrt{1 - x}} = \dfrac{2 - 3x}{2\sqrt{1 - x}}\)

  5. \(y = {\tan(2x)}\)
    הצג פתרון

    \(y' = \dfrac{2}{{\cos^{2}(2x)}}\)

  6. \(y = \left( \dfrac{x + 1}{x - 1} \right)^{3}\)
    הצג פתרון

    הנגזרת הפנימית (כלל המנה): \(\left[ \dfrac{x+1}{x - 1} \right]' = \dfrac{(x - 1) - (x+1)}{(x - 1)^{2}} = - \dfrac{2}{(x - 1)^{2}}\)

    \(y' = \dfrac{3( \frac{x+1}{x - 1} )^{2} \cdot ( - 2)}{(x - 1)^{2}} = - \dfrac{6(x + 1)^{2}}{(x - 1)^{4}}\)

  7. \(y = {\cos^{3}(2x)}\)
    הצג פתרון

    \(y' = 3{\cos^{2}(2x)} \cdot ( - {\sin 2x}) \cdot 2 = - 6{\cos^{2}(2x)} \cdot {\sin(2x)}\)

  8. \(y = (x - 1)^{2}(x + 2)^{3}\)
    הצג פתרון

    \(y' = 2(x - 1)(x + 2)^{3} + (x - 1)^{2} \cdot 3(x + 2)^{2}\)

    גורם משותף \((x - 1)(x + 2)^{2}\): \(y' = (x - 1)(x + 2)^{2} [ 2(x + 2) + 3(x - 1) ] = (x - 1)(x + 2)^{2}(5x + 1)\)

  9. \(y = \dfrac{x}{(x^{2} + 1)^{2}}\)
    הצג פתרון

    \(y' = \dfrac{(x^{2} + 1)^{2} - x \cdot 2(x^{2} + 1) \cdot 2x}{(x^{2} + 1)^{4}}\)

    מצמצמים ב־\((x^{2} + 1)\): \(y' = \dfrac{(x^{2} + 1) - 4x^{2}}{(x^{2} + 1)^{3}} = \dfrac{1 - 3x^{2}}{(x^{2} + 1)^{3}}\)

  10. \(y = \dfrac{1}{\sqrt{2x - 1}}\)
    הצג פתרון

    \(y = (2x - 1)^{ - 1/2}\)

    \(y' = - {\dfrac{1}{2}}(2x - 1)^{ - 3/2} \cdot 2 = - \dfrac{1}{(2x - 1)\sqrt{2x - 1}}\)

  11. \(y = \dfrac{2x + 1}{\sqrt{x^{2} + 2}}\)
    הצג פתרון

    \(y' = \dfrac{2\sqrt{x^{2} + 2} - \frac{(2x + 1) \cdot x}{\sqrt{x^{2} + 2}}}{x^{2} + 2}\)

    כופלים מונה ומכנה ב־\(\sqrt{x^{2} + 2}\): \(y' = \dfrac{2(x^{2} + 2) - 2x^{2} - x}{(x^{2} + 2)^{3/2}} = \dfrac{4 - x}{(x^{2} + 2)^{3/2}}\)

  12. \(y = x \cdot {\sin(2x)}\)
    הצג פתרון

    \(y' = {\sin(2x)} + x \cdot 2{\cos(2x)} = {\sin(2x)} + 2x \cdot {\cos(2x)}\)

  13. \(y = {\sin(3x)} \cdot {\cos(3x)}\)
    הצג פתרון

    כלל המכפלה: \(y' = 3{\cos(3x)} \cdot {\cos(3x)} + {\sin(3x)} \cdot ( - 3{\sin 3x}) = 3({\cos^{2} 3x} - {\sin^{2} 3x}) = 3{\cos(6x)}\)

    דרך קצרה: \(y = {\dfrac{1}{2}}{\sin(6x)}\), ולכן \(y' = {\dfrac{1}{2}} \cdot 6{\cos(6x)} = 3{\cos(6x)}\).

  14. \(y = \sqrt{1 + {\cos^{2} x}}\)
    הצג פתרון

    שלוש שכבות: שורש ⟵ ריבוע ⟵ קוסינוס.

    \(y' = \dfrac{2{\cos x} \cdot ( - {\sin x})}{2\sqrt{1 + {\cos^{2} x}}} = - \dfrac{{\sin x} \cdot {\cos x}}{\sqrt{1 + {\cos^{2} x}}}\)

  15. \(y = \dfrac{1}{{\sin^{2} x}}\)
    הצג פתרון

    \(y = ({\sin x})^{-2}\)

    \(y' = - 2({\sin x})^{-3} \cdot {\cos x} = - \dfrac{2{\cos x}}{{\sin^{3} x}}\)

רמה ג׳: רמת בגרות שאלות 31–42

כמה שכבות, משיק, נקודות קיצון ונגזרת בנקודה.

  1. גזרו את \(y = \sqrt{{\sin x}}\) ואת \(y = {\sin(\sqrt{x})}\). מה ההבדל?
    הצג פתרון

    \([\sqrt{{\sin x}}]' = \dfrac{{\cos x}}{2\sqrt{{\sin x}}}\): החיצונית שורש, הפנימית סינוס.

    \([{\sin(\sqrt{x})}]' = \dfrac{{\cos(\sqrt{x})}}{2\sqrt{x}}\): החיצונית סינוס, הפנימית שורש.

  2. גזרו את \(y = ({\sin x} + {\cos x})^{2}\) והראו שהתוצאה שווה ל־\(2{\cos(2x)}\).
    הצג פתרון

    \(y' = 2({\sin x} + {\cos x})({\cos x} - {\sin x}) = 2({\cos^{2} x} - {\sin^{2} x}) = 2{\cos(2x)}\)

    בדיקה בדרך אחרת: \(y = 1 + 2{\sin x} {\cos x} = 1 + {\sin 2x}\), ולכן \(y' = 2{\cos 2x}\).

  3. מצאו את משוואת המשיק לגרף \(y = \sqrt{2x + 5}\) בנקודה שבה \(x = 2\).
    הצג פתרון

    \(y(2) = \sqrt{9} = 3\)

    \(y' = \dfrac{2}{2\sqrt{2x + 5}} = \dfrac{1}{\sqrt{2x + 5}}\), ולכן \(y'(2) = \dfrac{1}{3}\)

    \(y - 3 = \dfrac{1}{3}(x - 2) \Rightarrow y = \dfrac{x}{3} + \dfrac{7}{3}\)

  4. מצאו את נקודות הקיצון של \(f(x) = (x^{2} - 4)^{3}\) וקבעו את סוגן.
    הצג פתרון

    \(f'(x) = 3(x^{2} - 4)^{2} \cdot 2x = 6x(x^{2} - 4)^{2}\)

    \(f'(x) = 0 \Rightarrow x = 0, x = \pm 2\)

    הגורם \((x^{2} - 4)^{2}\) אינו שלילי, ולכן סימן הנגזרת נקבע לפי \(6x\): שלילית עבור \(x \lt 0\) וחיובית עבור \(x \gt 0\).

    מינימום ב־\((0, - 64)\). ב־\(x = \pm 2\) הנגזרת מתאפסת אך לא מחליפה סימן, ולכן אלה אינן נקודות קיצון (נקודות פיתול עם משיק אופקי).

  5. נתון \(g(x) = f(3x - 1)\), וידוע ש־\(f'(5) = 4\). חשבו את \(g'(2)\).
    הצג פתרון

    \(g'(x) = 3f'(3x - 1)\)

    \(g'(2) = 3f'(5) = 12\)

  6. מצאו את תחום ההגדרה של \(f(x) = \sqrt{9 - x^{2}}\), את תחום הגזירות שלה ואת נקודת הקיצון הפנימית.
    הצג פתרון

    תחום הגדרה: \(- 3 \le x \le 3\).

    \(f'(x) = - \dfrac{2x}{2\sqrt{9 - x^{2}}} = - \dfrac{x}{\sqrt{9 - x^{2}}}\), מוגדרת רק עבור \(- 3 \lt x \lt 3\) (בקצוות המכנה מתאפס).

    \(f'(x) = 0 \Rightarrow x = 0\). הנגזרת חיובית משמאל ל־0 ושלילית מימין, לכן מקסימום ב־\((0, 3)\). (הגרף הוא חצי מעגל עליון ברדיוס 3.)

  7. מצאו את הנקודה על הגרף של \(y = \sqrt{x^{2} + 9}\) שבה שיפוע המשיק הוא \(\dfrac{4}{5}\).
    הצג פתרון

    \(y' = \dfrac{x}{\sqrt{x^{2} + 9}} = \dfrac{4}{5}\)

    השיפוע חיובי, לכן \(x \gt 0\). \(5x = 4\sqrt{x^{2} + 9} \Rightarrow 25x^{2} = 16x^{2} + 144 \Rightarrow x^{2} = 16 \Rightarrow x = 4\)

    \(y(4) = \sqrt{25} = 5\). הנקודה: \((4, 5)\).

  8. נתונה הפונקציה \(y = (ax + 1)^{3}\). שיפוע המשיק לגרף בנקודה שבה \(x = 0\) הוא 6. מצאו את \(a\).
    הצג פתרון

    \(y' = 3(ax + 1)^{2} \cdot a\)

    \(y'(0) = 3a = 6 \Rightarrow a = 2\)

  9. מצאו את משוואת המשיק לגרף \(y = {\sin^{2} x}\) בנקודה שבה \(x = \dfrac{{\pi}}{4}\).
    הצג פתרון

    \(y\left(\dfrac{{\pi}}{4}\right) = \left(\dfrac{\sqrt{2}}{2}\right)^{2} = {\dfrac{1}{2}}\)

    \(y' = 2{\sin x} \cdot {\cos x} = {\sin(2x)}\), ולכן \(y'\left(\dfrac{{\pi}}{4}\right) = {\sin\left(\dfrac{{\pi}}{2}\right)} = 1\)

    \(y - {\dfrac{1}{2}} = 1 \cdot \left(x - \dfrac{{\pi}}{4}\right) \Rightarrow y = x - \dfrac{{\pi}}{4} + {\dfrac{1}{2}}\)

  10. נתון \(h(x) = f(x^{2})\), וידוע ש־\(f'(4) = 3\). חשבו את \(h'(2)\) ואת \(h'( - 2)\).
    הצג פתרון

    \(h'(x) = f'(x^{2}) \cdot 2x\)

    \(h'(2) = f'(4) \cdot 4 = 12\)

    \(h'( - 2) = f'(4) \cdot ( - 4) = - 12\)

    בשני המקרים מציבים בפנימית את אותו ערך (4), אבל הנגזרת הפנימית \(2x\) שונה.

  11. נתונה \(f(x) = x\sqrt{4 - x^{2}}\). מצאו את תחום ההגדרה, את הנגזרת ואת נקודות הקיצון.
    הצג פתרון

    תחום הגדרה: \(- 2 \le x \le 2\).

    \(f'(x) = \sqrt{4 - x^{2}} + \dfrac{x \cdot ( - 2x)}{2\sqrt{4 - x^{2}}} = \dfrac{(4 - x^{2}) - x^{2}}{\sqrt{4 - x^{2}}} = \dfrac{4 - 2x^{2}}{\sqrt{4 - x^{2}}}\)

    \(f'(x) = 0 \Rightarrow x^{2} = 2 \Rightarrow x = \pm \sqrt{2}\)

    סימן הנגזרת: שלילית ב־\(( - 2, - \sqrt{2})\), חיובית ב־\(( - \sqrt{2}, \sqrt{2})\), שלילית ב־\((\sqrt{2}, 2)\).

    מינימום ב־\(( - \sqrt{2}, - 2)\), מקסימום ב־\((\sqrt{2}, 2)\). בקצוות: \(( - 2, 0)\) מקסימום קצה, \((2, 0)\) מינימום קצה.

  12. מצאו את נקודות הקיצון של \(f(x) = {\sin^{2} x} + {\cos x}\) בתחום \(0 \lt x \lt 2{\pi}\).
    הצג פתרון

    \(f'(x) = 2{\sin x} \cdot {\cos x} - {\sin x} = {\sin x}(2{\cos x} - 1)\)

    \({\sin x} = 0 \Rightarrow x = {\pi}\); \({\cos x} = {\dfrac{1}{2}} \Rightarrow x = \dfrac{{\pi}}{3}, \dfrac{5{\pi}}{3}\)

    סימן הנגזרת: \(+\) ב־\(\left(0, \dfrac{{\pi}}{3}\right)\), \(-\) ב־\(\left(\dfrac{{\pi}}{3}, {\pi}\right)\), \(+\) ב־\(\left({\pi}, \dfrac{5{\pi}}{3}\right)\), \(-\) ב־\(\left(\dfrac{5{\pi}}{3}, 2{\pi}\right)\).

    מקסימום ב־\(\left(\dfrac{{\pi}}{3}, \dfrac{5}{4}\right)\) וב־\(\left(\dfrac{5{\pi}}{3}, \dfrac{5}{4}\right)\), מינימום ב־\(({\pi}, - 1)\).

    (\(f\left(\dfrac{{\pi}}{3}\right) = {\dfrac{3}{4}} + {\dfrac{1}{2}} = \dfrac{5}{4}\), \(f({\pi}) = 0 - 1 = - 1\).)

הפתרונות מוסתרים כדי לאפשר תרגול עצמי. לחצו על "הצג פתרון" כדי לבדוק. בהדפסה כל הפתרונות מוצגים.
