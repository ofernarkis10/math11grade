תרגול: תנועה לינארית ותנועה על גלגל

ארבעה זוגות של שאלות מקבילות, לפי דף ההסבר: תנועה לינארית ותנועה על גלגל. בכל זוג יש שאלה על תנועה בקו ישר ושאלה על גלגל, שנפתרות באותם חמישה שלבים. פתרו קודם את השאלה הלינארית, ואחר כך את שאלת הגלגל באותה מסגרת. כל הזוויות במעלות.

שלבתנועה לינאריתתנועה על גלגל
1. נתונים\(A,\ B,\ T\)\(C,\ R,\ \theta_0,\ T\)
2. משוואת המסלול\(y = m(x - x_A) + y_A\)\((x - x_C)^2 + (y - y_C)^2 = R^2\)
3. הפרמטר לפי הזמן\(p = \dfrac{t}{T}\)\(\theta = \theta_0 \pm 360^\circ\cdot\dfrac{t}{T}\)
4. x\(x = x_A + p\,(x_B - x_A)\)\(x = x_C + R\cos\theta\)
5. yהצבה בישר: ערך אחד\(y = y_C + R\sin\theta\)

זוג 1: שליש מהדרך

1א · תנועה לינארית

נקודה נעה בתנועה קצובה מ־\(A(0,2)\) ל־\(B(9,8)\) ב־30 שניות. איפה היא אחרי 10 שניות?

הצג פתרון
  1. נתונים\(A(0,2),\ B(9,8),\ T = 30,\ t = 10\)
  2. משוואת המסלול\(m = \dfrac{8 - 2}{9 - 0} = \dfrac23\)\(y = \tfrac23x + 2\)
  3. הפרמטר לפי הזמן\(p = \dfrac{10}{30} = \dfrac13\)
  4. x לפי הפרמטר\(x = 0 + \tfrac13\cdot 9 = 3\)
  5. y מהמסלול\(y = \tfrac23\cdot 3 + 2 = 4\)

התשובה: \((3,\ 4)\)

1ב · תנועה על גלגל

מרכז גלגל ב־\((0,10)\) ורדיוסו 8. נקודה מתחילה ב־\((8,10)\), והגלגל מסתובב נגד כיוון השעון, סיבוב בכל 30 שניות. איפה הנקודה אחרי 10 שניות?

הצג פתרון
  1. נתונים\(C(0,10),\ R = 8,\ T = 30,\ t = 10\)
  2. זווית ההתחלההנקודה מתחילה ב־\((8,10)\), 8 ימינה מהמרכז \((0,10)\) ובאותו גובה, ולכן \(\theta_0 = 0^\circ\).
  3. הזווית לפי הזמן\(\theta = 0^\circ + 360^\circ\cdot\dfrac{10}{30} = 120^\circ\)
  4. x בעזרת cos\(x = 0 + 8\cos120^\circ = 8\cdot\left(-\tfrac12\right) = -4\)
  5. y בעזרת sin\(y = 10 + 8\sin120^\circ = 10 + 8\cdot\tfrac{\sqrt3}{2} = 10 + 4\sqrt3 \approx 16.93\)

התשובה: \((-4,\ 16.93)\)

זוג 2: כיוון הפוך

2א · תנועה לינארית

סירה שטה בקו ישר מ־\(A(6,-1)\) ל־\(B(-4,4)\) במהירות קבועה, ב־20 שניות. איפה היא אחרי 12 שניות?

הצג פתרון
  1. נתונים\(A(6,-1),\ B(-4,4),\ T = 20,\ t = 12\)
  2. משוואת המסלולהסירה נעה שמאלה ולמעלה, והשיפוע שלילי:\(m = \dfrac{4 - (-1)}{-4 - 6} = -\tfrac12\)\(y = -\tfrac12(x - 6) - 1 = -\tfrac12x + 2\)
  3. הפרמטר לפי הזמן\(p = \dfrac{12}{20} = 0.6\)
  4. x לפי הפרמטר\(x = 6 + 0.6\cdot(-4 - 6) = 0\)
  5. y מהמסלול\(y = -\tfrac12\cdot 0 + 2 = 2\)

התשובה: \((0,\ 2)\)

2ב · תנועה על גלגל

גלגל ענק: מרכזו ב־\((0,25)\) ורדיוסו 20. קרונית מתחילה בראש הגלגל, והגלגל מסתובב עם כיוון השעון, סיבוב בכל 50 שניות. איפה הקרונית אחרי 30 שניות?

הצג פתרון
  1. נתונים\(C(0,25),\ R = 20,\ T = 50,\ t = 30\)
  2. זווית ההתחלההקרונית מתחילה בראש הגלגל, בדיוק מעל המרכז, ולכן \(\theta_0 = 90^\circ\).
  3. הזווית לפי הזמןעם כיוון השעון, ולכן מינוס:\(\theta = 90^\circ - 360^\circ\cdot\dfrac{30}{50} = -126^\circ \equiv 234^\circ\)
  4. x בעזרת cos\(x = 0 + 20\cos234^\circ \approx 20\cdot(-0.588) = -11.76\)
  5. y בעזרת sin\(y = 25 + 20\sin234^\circ \approx 25 + 20\cdot(-0.809) = 8.82\)

התשובה: \((-11.76,\ 8.82)\), בגובה כ־8.8 מ׳

זוג 3: יותר מ־100%

3א · תנועה לינארית

גוף יוצא מ־\(A(-2,0)\), מגיע ל־\(B(1,2)\) אחרי 4 שניות, וממשיך באותו כיוון ובאותה מהירות. איפה הוא אחרי 10 שניות?

הצג פתרון
  1. נתונים\(A(-2,0),\ B(1,2),\ T = 4,\ t = 10\)
  2. משוואת המסלול\(m = \dfrac{2 - 0}{1 - (-2)} = \dfrac23\)\(y = \tfrac23(x + 2)\)
  3. הפרמטר לפי הזמן\(p = \dfrac{10}{4} = 2.5 = 250\%\)
  4. x לפי הפרמטר\(x = -2 + 2.5\cdot 3 = 5.5\)
  5. y מהמסלול\(y = \tfrac23\cdot(5.5 + 2) = 5\)

התשובה: \((5.5,\ 5)\), על הישר, הרחק מעבר ל־B

3ב · תנועה על גלגל

מרכז גלגל ב־\((2,-1)\) ורדיוסו 4. נקודה מתחילה בזווית \(\theta_0 = 30^\circ\), והגלגל מסתובב נגד כיוון השעון, סיבוב בכל 6 שניות. איפה הנקודה אחרי 20 שניות?

הצג פתרון
  1. נתונים\(C(2,-1),\ R = 4,\ T = 6,\ t = 20\)
  2. זווית ההתחלהנתונה בשאלה: \(\theta_0 = 30^\circ\).
  3. הזווית לפי הזמן\(\tfrac{20}{6} = 3\tfrac13\) סיבובים:\(\theta = 30^\circ + 360^\circ\cdot\tfrac{20}{6} = 1230^\circ\)\(1230^\circ = 3\cdot360^\circ + 150^\circ \equiv 150^\circ\)
  4. x בעזרת cos\(x = 2 + 4\cos150^\circ = 2 + 4\cdot\left(-\tfrac{\sqrt3}{2}\right) = 2 - 2\sqrt3 \approx -1.46\)
  5. y בעזרת sin\(y = -1 + 4\sin150^\circ = -1 + 4\cdot\tfrac12 = 1\)

התשובה: \((-1.46,\ 1)\). שלושת הסיבובים השלמים לא משנים את המקום.

זוג 4: הבעיה ההפוכה, מתי?

4א · תנועה לינארית

רחפן עולה בקו ישר מ־\(A(1,1)\) ל־\(B(13,10)\) במהירות קבועה, ב־12 שניות. מתי הוא בגובה 7?

הצג פתרון
  1. נתונים\(A(1,1),\ B(13,10),\ T = 12\), הגובה המבוקש \(y = 7\)
  2. משוואת המסלול\(m = \dfrac{10 - 1}{13 - 1} = 0.75\)\(y = 0.75(x - 1) + 1\)
  3. איפה על המסלול?מציבים את y:\(7 = 0.75(x - 1) + 1 \ \Rightarrow\ x = 9\)נקודה אחת: \((9,\ 7)\).
  4. הפרמטר לפי x\(9 = 1 + p\cdot 12 \ \Rightarrow\ p = \tfrac23\)
  5. מהפרמטר לזמן\(t = \tfrac23\cdot 12 = 8\)

התשובה: אחרי 8 שניות, פעם אחת בלבד

4ב · תנועה על גלגל

מרכז גלגל ב־\((0,15)\) ורדיוסו 12. נקודה מתחילה ב־\((12,15)\), והגלגל מסתובב נגד כיוון השעון, סיבוב בכל 36 שניות. מתי הנקודה בגובה 21?

הצג פתרון
  1. נתונים\(C(0,15),\ R = 12,\ T = 36\), הגובה המבוקש \(y = 21\)
  2. זווית ההתחלההנקודה מתחילה ב־\((12,15)\), ימינה מהמרכז \((0,15)\) ובאותו גובה, ולכן \(\theta_0 = 0^\circ\).
  3. הגובה בעזרת sin\(y = 15 + 12\sin\theta = 21\)\(\sin\theta = \tfrac{21 - 15}{12} = 0.5\)
  4. הזוויותבסיבוב אחד יש שתי זוויות כאלה:\(\theta = 30^\circ\ \ \text{or}\ \ \theta = 150^\circ\)
  5. x בעזרת cos\(x = 12\cos30^\circ \approx 10.39\)\(x = 12\cos150^\circ \approx -10.39\)שתי נקודות: מימין למרכז ומשמאל לו.
  6. מהזווית לזמן\(t = \dfrac{\theta - \theta_0}{360^\circ}\cdot T\)\(t_1 = \dfrac{30^\circ}{360^\circ}\cdot36 = 3\)\(t_2 = \dfrac{150^\circ}{360^\circ}\cdot36 = 15\)

התשובה: אחרי 3 ואחרי 15 שניות, ושוב כל 36 שניות.\(t = 3 + 36k\ \ \text{or}\ \ t = 15 + 36k,\quad k = 0, 1, 2, \dots\)

להשוואה: בשני החלקים שואלים מתי מגיעים לגובה מסוים. לישר יש נקודה אחת בגובה 7, ולמעגל יש שתי נקודות בגובה 21, ולכן לגלגל יש שתי תשובות בכל סיבוב.
