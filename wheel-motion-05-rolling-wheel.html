תרגול: גלגל מתגלגל

18 שאלות על גלגל שמתגלגל בלי החלקה: בכל סיבוב המרכז מתקדם היקף אחד (\(2\pi R\)), ולכן מחשבים את מהירות המרכז מתוך הסיבוב, את הסיבוב מתוך המהירות, ואת הרדיוס. ההסבר בדף התאוריה.

רמה א׳: מהסיבוב למהירות המרכז שאלות 1–8

סיבובים לשנייה, זמן מחזור, ω במעלות, וגלגול שמאלה.

  1. גלגל ברדיוס 0.5 מ׳ מתגלגל ימינה בלי החלקה, 3 סיבובים לשנייה. (א) כמה מתקדם המרכז בסיבוב אחד? (ב) מהי מהירות המרכז? (ג) מהי \(\omega\)?
    הצג פתרון
    דרך החשיבה

    בגלגול בלי החלקה כל נקודה על השפה נוגעת בקרקע פעם אחת בכל סיבוב, ולכן המרכז מתקדם היקף אחד לכל סיבוב. מספר הסיבובים בשנייה כפול ההיקף נותן את המהירות. נע ימינה, ולכן הסיבוב עם השעון.

    1. היקףשאלת מרחק
      \(2\pi R = 2\pi\cdot 0.5 = \pi \approx 3.14\)מ׳
    2. מהירותשאלת מרחק
      \(v = L\cdot n = 3\cdot\pi \approx 9.42\)מ׳/ש׳
    3. מהירות זוויתיתשאלת מרחק זוויתי
      \(|\omega| = 360n = 360\cdot 3 = 1080\)
      ימינה
      \(\Rightarrow \omega = -1080\)
    תשובה:
    \(\pi\)
    מ׳ לסיבוב
    \(v = 3\pi \approx 9.42\)מ׳/ש׳
    \(\omega = -1080^\circ/\text{s}\)
    בדיקה:
    בנוסחה
    \(|v| = \dfrac{|\omega|\pi R}{180} = \dfrac{1080\cdot\pi\cdot 0.5}{180} = 3\pi\)✓
  2. גלגל ברדיוס 2 מתגלגל ימינה ומשלים סיבוב כל 4 שניות. מצאו את מהירות המרכז ואת \(\omega\).
    הצג פתרון
    דרך החשיבה

    נתון זמן מחזור במקום סיבובים לשנייה. בזמן מחזור אחד המרכז עובר היקף אחד, ולכן המהירות היא היקף חלקי זמן המחזור.

    1. היקףשאלת מרחק
      \(L = 2\pi R = 2\pi\cdot 2 = 4\pi\)
    2. מהירותשאלת מרחק
      \(v = \dfrac{L}{T} = \dfrac{4\pi}{4} = \pi \approx 3.14\)
    3. מהירות זוויתיתשאלת מרחק זוויתי
      \(\omega = -\dfrac{360}{T} = -\dfrac{360}{4} = -90\)
    תשובה:
    \(v = \pi \approx 3.14\)
    \(\omega = -90^\circ/\text{s}\)
    בדיקה:
    \(\dfrac{90\cdot\pi\cdot 2}{180} = \pi\)✓
  3. גלגל ברדיוס 3 מתגלגל עם \(\omega = -60^\circ/\text{s}\). איזה חלק מסיבוב הוא מבצע בשנייה? כמה מתקדם המרכז בשנייה, ולאיזה כיוון?
    הצג פתרון
    דרך החשיבה

    ω נתונה במעלות. 60 מעלות מתוך 360 הן חלק מסיבוב, והמרכז מתקדם אותו חלק מההיקף. הסימן השלילי (עם השעון) אומר שהגלגל נע ימינה.

    1. חלק מסיבובשאלת מרחק זוויתי
      \(n = \dfrac{|\omega|}{360} = \dfrac{60}{360} = \dfrac16\)
    2. מרחק בשנייהשאלת מרחק
      \(v = n\cdot 2\pi R = \dfrac16\cdot 2\pi\cdot 3 = \pi \approx 3.14\)
    3. כיוון
      \(\omega \lt 0\)
      עם השעון — ימינה
    תשובה:
    \(\tfrac16\)
    סיבוב לשנייה; המרכז נע ימינה במהירות
    \(\pi \approx 3.14\)
    בדיקה:
    \(\dfrac{60\cdot\pi\cdot 3}{180} = \pi\)✓
  4. גלגל ברדיוס 1 מתגלגל שמאלה והמרכז נע במהירות \(2\pi\) יחידות לשנייה. מהו \(v_x\)? כמה סיבובים בשנייה, ומהי \(\omega\)?
    הצג פתרון
    דרך החשיבה

    כאן הכיוון הפוך מהרגיל. שמאלה: הרכיב בציר x שלילי, והגלגל מסתובב נגד כיוון השעון (דמיינו גלגל של מכונית שנוסעת אחורה). לכן ω חיובית.

    1. סימן
      \(v_x = -2\pi\)
    2. סיבוביםשאלת מרחק
      \(n = \dfrac{v}{L} = \dfrac{2\pi}{2\pi\cdot 1} = 1\)
    3. מהירות זוויתיתשאלת מרחק זוויתי
      שמאלה
      \(\Rightarrow\)
      נגד השעון
      \(\Rightarrow \omega = +360n = +360\)
    תשובה:
    \(v_x = -2\pi\)
    \(n = 1\)
    \(\omega = +360^\circ/\text{s}\)
    בדיקה:
    ב־1 שנייה סיבוב אחד, והמרכז זז
    \(2\pi\)
    שמאלה = היקף אחד ✓
  5. גלגל ברדיוס 0.25 מ׳ מתגלגל ימינה בלי החלקה, 4 סיבובים לשנייה. מהו ההיקף, מהי מהירות המרכז ומהי \(\omega\)?
    הצג פתרון
    דרך החשיבה

    1. היקףשאלת מרחק
      \(L = 2\pi R = 2\pi\cdot 0.25 = 0.5\pi \approx 1.57\)מ׳
    2. מהירותשאלת מרחק
      \(v = L\cdot n = 4\cdot 0.5\pi = 2\pi \approx 6.28\)מ׳/ש׳
    3. מהירות זוויתיתשאלת מרחק זוויתי
      \(\omega = -360n = -360\cdot 4 = -1440\)
    תשובה:
    \(v = 2\pi \approx 6.28\)
    \(\omega = -1440^\circ/\text{s}\)
    בדיקה:
    \(\dfrac{1440\cdot\pi\cdot 0.25}{180} = 2\pi\)✓
  6. גלגל ברדיוס 5 מתגלגל ימינה ומשלים סיבוב כל 10 שניות. מצאו את מהירות המרכז ואת \(\omega\).
    הצג פתרון
    דרך החשיבה

    1. היקףשאלת מרחק
      \(L = 2\pi R = 10\pi\)
    2. מהירותשאלת מרחק
      \(v = \dfrac{L}{T} = \dfrac{10\pi}{10} = \pi\)
    3. מהירות זוויתיתשאלת מרחק זוויתי
      \(\omega = -\dfrac{360}{T} = -\dfrac{360}{10} = -36\)
    תשובה:
    \(v = \pi \approx 3.14\)
    \(\omega = -36^\circ/\text{s}\)
    בדיקה:
    \(\dfrac{36\cdot\pi\cdot 5}{180} = \pi\)✓
  7. גלגל ברדיוס 6 מתגלגל עם \(\omega = -30^\circ/\text{s}\). איזה חלק מסיבוב בשנייה? כמה מתקדם המרכז בשנייה, ולאיזה כיוון?
    הצג פתרון
    דרך החשיבה

    30 מתוך 360 מעלות הם חלק מסיבוב, והמרכז מתקדם אותו חלק מההיקף.

    1. חלקשאלת מרחק זוויתי
      \(n = \dfrac{|\omega|}{360} = \dfrac{30}{360} = \dfrac{1}{12}\)
    2. מרחקשאלת מרחק
      \(v = n\cdot L = \dfrac{1}{12}\cdot 12\pi = \pi\)
    3. כיוון
      ω שלילית — ימינה
    תשובה:
    \(\tfrac{1}{12}\)
    סיבוב
    \(\pi\)
    יחידות בשנייה ימינה
    בדיקה:
    \(\dfrac{30\cdot\pi\cdot 6}{180} = \pi\)✓
  8. גלגל ברדיוס 2 מתגלגל שמאלה והמרכז נע במהירות \(4\pi\). מהו \(v_x\)? כמה סיבובים בשנייה ומהי \(\omega\)?
    הצג פתרון
    דרך החשיבה

    שמאלה: v_x שלילי ו־ω חיובית (נגד השעון).

    1. סימן
      \(v_x = -4\pi\)
    2. סיבוביםשאלת מרחק
      \(n = \dfrac{v}{L} = \dfrac{4\pi}{4\pi} = 1\)
    3. מהירות זוויתיתשאלת מרחק זוויתי
      \(|\omega| = 360n = 360\cdot 1 = 360\), נגד השעון \(\Rightarrow \omega = +360n = +360\)
    תשובה:
    \(v_x = -4\pi\)
    \(n = 1\)
    \(\omega = +360^\circ/\text{s}\)
    בדיקה:
    סיבוב בשנייה = היקף
    \(4\pi\)
    בשנייה ✓

רמה ב׳: ממהירות המרכז לסיבוב שאלות 9–14

כולל קוטר במקום רדיוס והמרת יחידות.

  1. מרכז גלגל ברדיוס 0.5 נע ימינה במהירות \(4\pi\) יחידות לשנייה. כמה סיבובים בשנייה, ומהי \(\omega\)?
    הצג פתרון
    דרך החשיבה

    הכיוון ההפוך: ידועה מהירות המרכז, ומחפשים את הסיבוב. מספר הסיבובים בשנייה הוא כמה היקפים המרכז עובר בשנייה: מהירות חלקי היקף.

    1. היקףשאלת מרחק
      \(L = 2\pi R = 2\pi\cdot 0.5 = \pi\)
    2. סיבוביםשאלת מרחק
      \(n = \dfrac{v}{L} = \dfrac{4\pi}{\pi} = 4\)
    3. מהירות זוויתיתשאלת מרחק זוויתי
      \(\omega = -360n = -360\cdot 4 = -1440\)
    תשובה:
    \(n = 4\)
    \(\omega = -1440^\circ/\text{s}\)
    בדיקה:
    \(\dfrac{180\cdot 4\pi}{\pi\cdot 0.5} = 1440\)✓
  2. קוטר גלגל אופניים 70 ס״מ. האופניים עוברים 22 מ׳ ב־10 שניות. מצאו את הרדיוס במטרים ואת מהירות המרכז, את מספר הסיבובים בשנייה (בקירוב) ואת \(\omega\).
    הצג פתרון
    דרך החשיבה

    שני מלכודות: נתון קוטר ולא רדיוס, ונתונים סנטימטרים ומטרים יחד. ממירים הכול למטרים, ומשתמשים בהיקף \(\pi d\).

    1. המרההמרת יחידות
      \(d = 0.7\)מ׳
      \(R = \dfrac{d}{2} = 0.35\)מ׳
    2. מהירותשאלת מרחק
      \(v = \dfrac{s}{t} = \dfrac{22}{10} = 2.2\)מ׳/ש׳
    3. היקףשאלת מרחק
      \(\pi d = 0.7\pi \approx 2.199\)מ׳
    4. סיבוביםשאלת מרחק
      \(n = \dfrac{v}{L} = \dfrac{2.2}{2.199} \approx 1\)
    5. מהירות זוויתיתשאלת מרחק זוויתי
      \(\omega = -360n \approx -360\cdot 1 = -360\)
    תשובה:
    \(R = 0.35\)מ׳
    \(v = 2.2\)
    מ׳/ש׳, כסיבוב אחד בשנייה
    \(\omega \approx -360^\circ/\text{s}\)
    בדיקה:
    סיבוב בשנייה וההיקף כ־2.2 מ׳: בדיוק 2.2 מ׳ בשנייה ✓
  3. רדיוס צמיג של מכונית 0.3 מ׳. המכונית נוסעת ימינה במהירות 54 קמ״ש. המירו את המהירות למ׳/ש׳, ומצאו כמה סיבובים בשנייה מבצע הצמיג ומהי \(\omega\).
    הצג פתרון
    דרך החשיבה

    הרדיוס במטרים והמהירות בקמ״ש: חייבים יחידות אחידות לפני שמחלקים. מקמ״ש למ׳/ש׳ מחלקים ב־3.6.

    1. המרההמרת יחידות
      \(v = \dfrac{v_{\text{km/h}}}{3.6} = \dfrac{54}{3.6} = 15\)מ׳/ש׳
    2. היקףשאלת מרחק
      \(L = 2\pi R = 2\pi\cdot 0.3 = 0.6\pi \approx 1.885\)מ׳
    3. סיבוביםשאלת מרחק
      \(n = \dfrac{v}{L} = \dfrac{15}{0.6\pi} \approx 7.96\)
    4. מהירות זוויתיתשאלת מרחק זוויתי
      \(\omega = -360n \approx -360\cdot 7.96 \approx -2865\)
    תשובה:
    \(15\)
    מ׳/ש׳, כ־7.96 סיבובים בשנייה
    \(\omega \approx -2865^\circ/\text{s}\)
    בדיקה:
    \(7.96\cdot 1.885 \approx 15\)✓
  4. מרכז גלגל ברדיוס 1.5 נע ימינה במהירות \(6\pi\). כמה סיבובים בשנייה, ומהי \(\omega\)?

    3. מהירות זוויתיתשאלת מרחק זוויתי

    תשובה:

    \(\omega = -720^\circ/\text{s}\)
    בדיקה:

  5. קוטר גלגל 60 ס״מ. הוא מתגלגל ימינה ועובר 18.84 מ׳ ב־6 שניות. מצאו את הרדיוס, את מהירות המרכז, את מספר הסיבובים בשנייה ואת \(\omega\).

    \(n \approx 1.67\)

  6. רדיוס צמיג 0.35 מ׳. המכונית נוסעת ימינה במהירות 72 קמ״ש. מצאו את המהירות במ׳/ש׳, את מספר הסיבובים בשנייה ואת \(\omega\).

רמה ג׳: מוצאים את הרדיוס שאלות 15–18

הרדיוס מתוך המרחק והסיבובים.

  1. גלגל מבצע 5 סיבובים מלאים בזמן שהמרכז מתקדם 31.4 מ׳. כמה מתקדם המרכז בסיבוב? מצאו את הרדיוס, ואת \(y_A\) של המרכז אם הגלגל על ציר x.
    הצג פתרון
    דרך החשיבה

    כאן הנעלם הוא הרדיוס. מרחק לסיבוב הוא ההיקף, ומההיקף מוצאים את R. בגלגל שעל הקרקע, גובה המרכז שווה לרדיוס.

    1. מרחק לסיבובשאלת מרחק
      \(L = \dfrac{s}{N} = \dfrac{31.4}{5} = 6.28\)מ׳
    2. רדיוסשאלת מרחק
      \(2\pi R = 6.28 \Rightarrow R = \dfrac{6.28}{2\pi} \approx 1\)מ׳
    3. גובה המרכזשאלת מרחק
      \(y_A = R \approx 1\)
    תשובה:
    6.28 מ׳ לסיבוב
    \(R \approx 1\)מ׳
    \(y_A \approx 1\)
    בדיקה:
    \(5\cdot 2\pi\cdot 1 \approx 31.4\)✓
  2. מרכז גלגל מתגלגל נע ימינה במהירות 6, והגלגל מסתובב ב־\(\omega = -90^\circ/\text{s}\). כמה זמן לוקח סיבוב? כמה מתקדם המרכז בסיבוב? מצאו את R.
    הצג פתרון
    דרך החשיבה

    מ־ω מקבלים זמן מחזור. בזמן הזה המרכז עובר מהירות כפול זמן, והמרחק הזה הוא ההיקף. מההיקף — הרדיוס.

    1. מחזורשאלת מרחק זוויתי
      \(T = \dfrac{360}{|\omega|} = \dfrac{360}{90} = 4\)שניות
    2. מרחקשאלת מרחק
      \(L = v\cdot T = 6\cdot 4 = 24\)
    3. רדיוסשאלת מרחק
      \(2\pi R = 24 \Rightarrow R = \dfrac{12}{\pi} \approx 3.82\)
    תשובה:
    \(T = 4\)
    \(24\)
    \(R = \tfrac{12}{\pi} \approx 3.82\)
    בדיקה:
    \(\dfrac{90\cdot\pi\cdot\frac{12}{\pi}}{180} = 6\)✓
  3. גלגל מבצע 8 סיבובים בזמן שהמרכז מתקדם 50.24 מ׳. מצאו את הרדיוס.
    הצג פתרון
    דרך החשיבה

    מרחק לסיבוב הוא ההיקף, ומההיקף הרדיוס.

    1. מרחק לסיבובשאלת מרחק
      \(L = \dfrac{s}{N} = \dfrac{50.24}{8} = 6.28\)
    2. רדיוסשאלת מרחק
      \(R = \dfrac{L}{2\pi} = \dfrac{6.28}{2\pi} \approx 1\)
    תשובה:
    \(R \approx 1\)מ׳
    בדיקה:
    \(8\cdot 2\pi \approx 50.27\)✓
  4. מרכז גלגל מתגלגל נע ימינה במהירות 10, והגלגל מסתובב ב־\(\omega = -120^\circ/\text{s}\). מצאו את זמן המחזור, את המרחק לסיבוב ואת R.
    הצג פתרון
    דרך החשיבה

    מ־ω זמן מחזור, ממהירות כפול זמן מחזור ההיקף, ומההיקף הרדיוס.

    1. מחזורשאלת מרחק זוויתי
      \(T = \dfrac{360}{|\omega|} = \dfrac{360}{120} = 3\)
    2. מרחקשאלת מרחק
      \(L = v\cdot T = 10\cdot 3 = 30\)
    3. רדיוסשאלת מרחק
      \(R = \dfrac{L}{2\pi} = \dfrac{30}{2\pi} = \dfrac{15}{\pi} \approx 4.77\)
    תשובה:
    \(T = 3\)
    \(30\)
    \(R = \tfrac{15}{\pi} \approx 4.77\)
    בדיקה:
    \(\dfrac{120\cdot\pi\cdot\frac{15}{\pi}}{180} = 10\)✓
