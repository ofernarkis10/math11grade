שיעור ראשון – חישוב הדוגמאות בנוסחה

בדף הדוגמאות חישבנו את הדולפינים, החיסכון, הרכב והתרופה שנה אחרי שנה. בדף ההסבר בנינו את הנוסחה:

f(t) = a · bt

עכשיו נפתור את אותן דוגמאות בעזרת הנוסחה – ישר לשנה 3 ולשנה 8 – ובסוף כל דוגמה נבדוק בטבלה שהנוסחה נותנת בדיוק את אותם ערכים כמו ההכפלה צעד אחר צעד.

סדר הפתרון בכל דוגמה: מזהים את a (הערך ההתחלתי), מוצאים את b (המספר שמכפילים בו), כותבים את הפונקציה, מציבים את t, ובודקים בטבלה.

דוגמה 1 – דולפינים 🐬

בשמורה ימית חיים 256 דולפינים. בכל שנה מספר הדולפינים גדל ב-50%. כמה דולפינים יהיו אחרי 3 שנים? ואחרי 8 שנים?

מזהים את הערך ההתחלתי a (בניית פונקציה)
a = 256
מתרגמים את אחוז הגידול למספר שמכפילים בו, b (בניית פונקציה)
b = 1 + p/100 b = 1 + 50/100 b = 1.5

מכיוון ש-b > 1, זו פונקציית גידול.

מציבים את a ואת b בנוסחה הכללית ומקבלים את הפונקציה
f(t) = a · bt D(t) = 256 · 1.5t
מציבים t = 3 בפונקציה ומחשבים במחשבון (חישוב ערך)
D(t) = a · bt D(3) = 256 · 1.53 D(3) = 256 · 3.375 D(3) = 864

תשובה: אחרי 3 שנים – 864 דולפינים.

מציבים t = 8 בפונקציה ומחשבים במחשבון (חישוב ערך)
D(t) = a · bt D(8) = 256 · 1.58 D(8) = 256 · 25.6289062… D(8) = 6561

תשובה: אחרי 8 שנים – 6,561 דולפינים.

דוגמה 3 – ירידת ערך של רכב 🚗

רכב נקנה ב-80,000 ₪. ערכו יורד ב-15% בכל שנה. מה ערך הרכב אחרי 3 שנים? ואחרי 8 שנים?

מזהים את הערך ההתחלתי a (בניית פונקציה)
a = 80000
מתרגמים את אחוז הירידה למספר שמכפילים בו, b (בניית פונקציה)
b = 1 − p/100 b = 1 − 15/100 b = 0.85

מכיוון ש-0 < b < 1, זו פונקציית דעיכה.

מציבים את a ואת b בנוסחה הכללית ומקבלים את הפונקציה
f(t) = a · bt V(t) = 80000 · 0.85t
מציבים t = 3 בפונקציה ומחשבים במחשבון (חישוב ערך)
V(t) = a · bt V(3) = 80000 · 0.853 V(3) = 80000 · 0.614125 V(3) = 49130

תשובה: אחרי 3 שנים – 49,130 ₪.

מציבים t = 8 בפונקציה ומחשבים במחשבון (חישוב ערך)

סיכום

  • כדי לחשב ערך אחרי t צעדים לא צריך לעבור את כל הצעדים: מציבים בנוסחה f(t) = a · bt.
  • bt הוא בדיוק "להכפיל ב-b, t פעמים" – ולכן הנוסחה והטבלה תמיד מסכימות.
  • מעגלים רק את התוצאה הסופית, לא את bt באמצע החישוב.
