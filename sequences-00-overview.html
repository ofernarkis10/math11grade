פרק 1

סדרה חשבונית

המשמעות: בכל צעד מוסיפים אותו מספר. ההפרש בין כל שני איברים עוקבים קבוע, ומסמנים אותו ב־\(d\). אם \(d \gt 0\) הסדרה עולה, אם \(d \lt 0\) היא יורדת, ואם \(d = 0\) היא קבועה.

זו גדילה לינארית: אם משרטטים את הנקודות \((n, a_{n})\), כולן נמצאות על קו ישר ששיפועו \(d\). דוגמה מהחיים: חיסכון של 200 ₪ קבועים בכל חודש.

תכונת האמצע: כל איבר הוא הממוצע של שכניו. לכן שלושה מספרים \(x, y, z\) הם סדרה חשבונית בדיוק כאשר \(2y = x + z\).

למה נוסחת הסכום עובדת? כותבים את הסכום פעמיים, פעם מההתחלה ופעם מהסוף, ומחברים. כל זוג (ראשון+אחרון, שני+לפני אחרון…) נותן אותו סכום \(a_{1} + a_{n}\), ויש n זוגות כאלה. לכן \(2S_{n} = n(a_{1} + a_{n})\).

איבר כללי\(a_{n} = a_{1} + (n - 1)d\)
הפרש בין שני איברים\(a_{m} - a_{k} = (m - k)d\)
סכום n איברים\(S_{n} = \dfrac{n(a_{1} + a_{n})}{2}\)
סכום בלי aₙ\(S_{n} = \dfrac{n[2a_{1} + (n - 1)d]}{2}\)
דוגמה פתורה

בסדרה \(3, 7, 11, 15, \ldots\) מצאו את האיבר ה־20 ואת סכום 20 האיברים הראשונים.

\(a_{1} = 3\), \(d = 7 - 3 = 4\)

\(a_{20} = 3 + 19 \cdot 4 = 79\)

\(S_{20} = \dfrac{20 \cdot (3 + 79)}{2} = 820\)

תרגילים

  1. בסדרה חשבונית \(a_{5} = 17\) ו־\(a_{12} = 38\). מצאו את \(a_{1}\) ואת \(d\).
    הצג פתרון

    \(a_{12} - a_{5} = 7d = 21\), לכן \(d = 3\).

    \(a_{1} = a_{5} - 4d = 17 - 12 = 5\).

  2. חשבו את סכום כל המספרים הדו־ספרתיים המתחלקים ב־7.
    הצג פתרון

    הסדרה: \(14, 21, \ldots , 98\) עם \(d = 7\).

    מספר האיברים: \(98 = 14 + (n - 1) \cdot 7 \Rightarrow n = 13\).

    \(S_{13} = \dfrac{13 \cdot (14 + 98)}{2} = 728\).

  3. בסדרה חשבונית \(a_{1} = - 20\), \(d = 3\).
    א. מאיזה מקום האיברים חיוביים?
    ב. מהו ה־n הקטן ביותר שעבורו \(S_{n} \gt 0\)?
    הצג פתרון

    א. \(- 20 + 3(n - 1) \gt 0 \Rightarrow n \gt 7.67\), כלומר מהאיבר השמיני (\(a_{8} = 1\)).

    ב. \(S_{n} = \dfrac{n(3n - 43)}{2} \gt 0 \Rightarrow n \gt 14.33\), לכן \(n = 15\).

    בדיקה: \(S_{14} = - 7\), \(S_{15} = 15\).

  4. המספרים \(x - 1, 2x+1, 4x - 3\) הם שלושה איברים עוקבים בסדרה חשבונית. מצאו את x ואת האיברים.
    הצג פתרון

    לפי תכונת האמצע: \(2(2x+1) = (x - 1) + (4x - 3)\)

    \(4x + 2 = 5x - 4 \Rightarrow x = 6\)

    האיברים: \(5, 13, 21\) (\(d = 8\)).

פרק 2

סדרה הנדסית

המשמעות: בכל צעד כופלים באותו מספר. המנה בין כל איבר לקודמו קבועה, ומסמנים אותה ב־\(q\) (בתנאי שאין איבר 0).

זו גדילה מעריכית: ריבית דריבית, גידול אוכלוסייה באחוז קבוע, דעיכה רדיואקטיבית. עלייה של p% בכל תקופה פירושה \(q = 1 + \dfrac{p}{100}\), וירידה של p% פירושה \(q = 1 - \dfrac{p}{100}\).

התנהגות לפי q: כאשר \(q \gt 1\) (ו־\(a_{1} \gt 0\)) הסדרה עולה; כאשר \(0 \lt q \lt 1\) היא יורדת ומתקרבת ל־0; כאשר \(q \lt 0\) הסימנים מתחלפים (סדרה מתחלפת).

תכונת האמצע: כל איבר הוא הממוצע ההנדסי של שכניו: \(y^{2} = x \cdot z\).

איבר כללי\(a_{n} = a_{1} \cdot q^{n-1}\)
יחס בין שני איברים\(\dfrac{a_{m}}{a_{k}} = q^{m-k}\)
סכום n איברים (q ≠ 1)\(S_{n} = \dfrac{a_{1}(q^{n} - 1)}{q - 1}\)
כאשר q = 1\(S_{n} = n \cdot a_{1}\)
דוגמה פתורה

בסדרה \(2, 6, 18, \ldots\) מצאו את האיבר השמיני ואת סכום 8 האיברים הראשונים.

\(a_{1} = 2\), \(q = \dfrac{6}{2} = 3\)

\(a_{8} = 2 \cdot 3^{7} = 4374\)

\(S_{8} = \dfrac{2(3^{8} - 1)}{3 - 1} = 6560\)

טעות נפוצה: מהמשוואה \(q^{2} = 9\) יש שני פתרונות, \(q = 3\) ו־\(q = - 3\). יש לבדוק את שניהם מול נתוני השאלה.

תרגילים

  1. בסדרה הנדסית \(a_{2} = 12\) ו־\(a_{5} = 324\). מצאו את \(q\) ואת \(a_{1}\).
    הצג פתרון

    \(\dfrac{a_{5}}{a_{2}} = q^{3} = 27 \Rightarrow q = 3\)

    \(a_{1} = \dfrac{12}{3} = 4\)

  2. המספרים \(x, x+6, x+18\) הם סדרה הנדסית. מצאו את x ואת המנה.
    הצג פתרון

    \((x+6)^{2} = x(x+18)\)

    \(x^{2} + 12x + 36 = x^{2} + 18x \Rightarrow x = 6\)

    האיברים \(6, 12, 24\), ו־\(q = 2\).

  3. בסדרה \(3, 6, 12, \ldots\), מהו מספר האיברים המינימלי שסכומם עולה על 1000?
    הצג פתרון

    \(S_{n} = 3(2^{n} - 1) \gt 1000 \Rightarrow 2^{n} \gt 334.3\)

    \(2^{8} = 256\) קטן מדי, \(2^{9} = 512\) מספיק, לכן \(n = 9\) (\(S_{9} = 1533\)).

  4. ביישוב גרים 5000 תושבים, והאוכלוסייה גדלה ב־4% בכל שנה. כמה תושבים יהיו בו כעבור 10 שנים?
    הצג פתרון

    \(q = 1.04\). אחרי 10 שנים: \(5000 \cdot 1.04^{10} \approx 5000 \cdot 1.4802 \approx 7401\) תושבים.

פרק 3

טור הנדסי אינסופי מתכנס

המשמעות: מחברים אינסוף איברים של סדרה הנדסית. כאשר \(|q| \lt 1\) האיברים קטנים מהר מאוד, והסכומים החלקיים \(S_{1}, S_{2}, S_{3}, \ldots\) מתקרבים למספר סופי. את הגבול הזה מגדירים כסכום הטור.

הדגמה: הולכים חצי מהדרך לקיר, אחר כך חצי מהנותר, וכן הלאה: \({\dfrac{1}{2}} + {\dfrac{1}{4}} + {\dfrac{1}{8}} + \ldots = 1\). לא מגיעים לקיר בשום צעד, אבל סך כל הצעדים הוא בדיוק המרחק.

הנוסחה מתקבלת מנוסחת הסכום הרגילה: כאשר \(|q| \lt 1\), הביטוי \(q^{n}\) שואף ל־0, ולכן \(S_{n} \to \dfrac{a_{1}}{1 - q}\).

תנאי התכנסות\(- 1 \lt q \lt 1, q \neq 0\)
סכום הטור\(S = \dfrac{a_{1}}{1 - q}\)
דוגמה פתורה

חשבו את סכום הטור \(8 + 4 + 2 + 1 + \ldots\)

\(q = {\dfrac{1}{2}}\), ו־\(|q| \lt 1\), כלומר הטור מתכנס.

\(S = \dfrac{8}{1 - {\frac{1}{2}}} = 16\)

תרגילים

  1. סכום טור הנדסי אינסופי הוא 24, והאיבר הראשון הוא 8. מצאו את המנה.
    הצג פתרון

    \(\dfrac{8}{1 - q} = 24 \Rightarrow 1 - q = {\dfrac{1}{3}} \Rightarrow q = {\dfrac{2}{3}}\)

  2. כתבו את השבר העשרוני המחזורי \(0.454545 \ldots\) כשבר פשוט.
    הצג פתרון

    \(0.45 + 0.0045 + \ldots\) הוא טור עם \(a_{1} = 0.45\), \(q = 0.01\).

    \(S = \dfrac{0.45}{0.99} = \dfrac{45}{99} = \dfrac{5}{11}\)

  3. סכום טור הנדסי אינסופי הוא 12, וסכום ריבועי איבריו (גם הוא טור אינסופי) הוא 48. מצאו את \(a_{1}\) ואת \(q\).
    הצג פתרון

    ריבועי האיברים יוצרים טור עם \(a_{1}^{2}\) ומנה \(q^{2}\):

    \(\dfrac{a_{1}}{1 - q} = 12\) ו־\(\dfrac{a_{1}^{2}}{1 - q^{2}} = 48\).

    מעלים את הראשונה בריבוע: \(\dfrac{a_{1}^{2}}{(1 - q)^{2}} = 144\). מחלקים: \(\dfrac{1 - q}{1+q} = {\dfrac{1}{3}}\).

    \(3 - 3q = 1 + q \Rightarrow q = {\dfrac{1}{2}}\), ולכן \(a_{1} = 6\).

  4. עבור אילו ערכי x הטור \(1 + (x - 1) + (x - 1)^{2} + \ldots\) מתכנס? מהו סכומו?
    הצג פתרון

    \(q = x - 1\), ונדרש \(|x - 1| \lt 1 \Rightarrow 0 \lt x \lt 2\).

    \(S = \dfrac{1}{1 - (x - 1)} = \dfrac{1}{2 - x}\)

פרק 4

סדרות המוגדרות בכלל נסיגה

המשמעות: במקום לתת נוסחה ישירה ל־\(a_{n}\), נותנים איך עוברים מאיבר לאיבר הבא, ואת נקודת ההתחלה. זה כמו מתכון: "קח את המספר הקודם, הכפל ב־3 והחסר 4".

כדי לקבוע סדרה בכלל נסיגה צריך את הכלל וגם את האיבר הראשון (ולפעמים שני איברים ראשונים, כמו בסדרת פיבונאצ'י). אותו כלל עם איבר ראשון אחר נותן סדרה אחרת.

הטכניקה המרכזית בבגרות: מגדירים סדרת עזר, למשל \(b_{n} = a_{n} + c\), ומוכיחים שהיא חשבונית או הנדסית. מסדרת העזר מוצאים נוסחה מפורשת ל־\(a_{n}\).

כלל מסדר ראשון\(a_{1} \text{נתון}, a_{n+1} = f(a_{n})\)
כלל מסדר שני\(a_{n+2} = f(a_{n+1}, a_{n})\)
חשבונית בכלל נסיגה\(a_{n+1} = a_{n} + d\)
הנדסית בכלל נסיגה\(a_{n+1} = q \cdot a_{n}\)
דוגמה פתורה

נתון \(a_{1} = 1\), \(a_{n+1} = 3a_{n} - 4\). הוכיחו ש־\(b_{n} = a_{n} - 2\) סדרה הנדסית ומצאו נוסחה ל־\(a_{n}\).

חמשת האיברים הראשונים: \(1, - 1, - 7, - 25, - 79\).

\(b_{n+1} = a_{n+1} - 2 = 3a_{n} - 6 = 3(a_{n} - 2) = 3b_{n}\), לכן \(b_{n}\) הנדסית עם \(q = 3\).

\(b_{1} = - 1 \Rightarrow b_{n} = - 3^{n-1} \Rightarrow a_{n} = 2 - 3^{n-1}\)

בדיקה: \(a_{3} = 2 - 9 = - 7\) ✓

תרגילים

  1. נתון \(a_{1} = 5\), \(a_{n+1} = a_{n} + 2n\). מצאו את \(a_{4}\) ונוסחה כללית ל־\(a_{n}\).
    הצג פתרון

    \(a_{2} = 7, a_{3} = 11, a_{4} = 17\)

    מחברים את כל ההפרשים: \(a_{n} = 5 + 2(1 + 2 + \ldots + (n - 1)) = 5 + n(n - 1)\).

    בדיקה: \(a_{4} = 5 + 12 = 17\) ✓

  2. נתון \(a_{1} = 3\), \(a_{n+1} = 2a_{n} + 1\). הוכיחו ש־\(b_{n} = a_{n} + 1\) הנדסית ומצאו את \(a_{n}\).
    הצג פתרון

    \(b_{n+1} = 2a_{n} + 2 = 2(a_{n} + 1) = 2b_{n}\)

    \(b_{1} = 4 \Rightarrow b_{n} = 4 \cdot 2^{n-1} = 2^{n+1} \Rightarrow a_{n} = 2^{n+1} - 1\)

  3. נתון \(a_{1} = a_{2} = 1\), \(a_{n+2} = a_{n+1} + a_{n}\) (סדרת פיבונאצ'י). מצאו את \(a_{8}\).
    הצג פתרון

    \(1, 1, 2, 3, 5, 8, 13, 21\), לכן \(a_{8} = 21\).

  4. נתון \(a_{1} = 2\), \(a_{n+1} = \dfrac{1}{1 - a_{n}}\). מצאו את \(a_{100}\) ואת סכום 99 האיברים הראשונים.
    הצג פתרון

    \(a_{2} = - 1, a_{3} = {\dfrac{1}{2}}, a_{4} = 2\): הסדרה מחזורית עם מחזור 3.

    \(100 = 3 \cdot 33 + 1\), לכן \(a_{100} = a_{1} = 2\).

    \(S_{99} = 33 \cdot \left(2 - 1 + {\dfrac{1}{2}}\right) = 49.5\)

פרק 5

סדרה לפי נוסחת איבר כללי

המשמעות: הסדרה היא פונקציה שהתחום שלה הוא המספרים הטבעיים: \(a_{n} = f(n)\). היתרון: מגיעים לכל איבר ישירות, בלי לחשב את כל הקודמים.

שאלות טיפוסיות:

• האם מספר נתון הוא איבר בסדרה? פותרים \(f(n) = k\) ובודקים אם יש פתרון טבעי.

• עולה או יורדת? בודקים את הסימן של \(a_{n+1} - a_{n}\).

• מה הקשר לסכום? אם נתונה נוסחה ל־\(S_{n}\), אז \(a_{n} = S_{n} - S_{n-1}\) (עבור \(n \ge 2\)), ו־\(a_{1} = S_{1}\).

מונוטוניות\(a_{n+1} - a_{n} \gt 0 \Leftrightarrow \text{עולה}\)
איבר מתוך סכומים\(a_{n} = S_{n} - S_{n-1}, n \ge 2\)
דוגמה פתורה

נתון \(a_{n} = n^{2} - 8n + 20\). האם 29 איבר בסדרה? מהו האיבר הקטן ביותר?

\(n^{2} - 8n + 20 = 29 \Rightarrow n^{2} - 8n - 9 = 0 \Rightarrow n = 9\) (הפתרון \(n = - 1\) נפסל). כן, \(a_{9} = 29\).

קודקוד הפרבולה ב־\(n = 4\), שהוא מספר טבעי, לכן האיבר הקטן ביותר הוא \(a_{4} = 4\).

שימו לב: אם הקודקוד אינו מספר שלם, בודקים את שני השלמים הקרובים אליו.

תרגילים

  1. נתון \(a_{n} = \dfrac{2n+1}{n+3}\). הוכיחו שהסדרה עולה. האם יש איבר הגדול מ־2?
    הצג פתרון

    \(a_{n+1} - a_{n} = \dfrac{2n+3}{n+4} - \dfrac{2n+1}{n+3} = \dfrac{5}{(n+3)(n+4)} \gt 0\), לכן הסדרה עולה.

    \(a_{n} = 2 - \dfrac{5}{n+3} \lt 2\) תמיד. אין איבר הגדול מ־2, והאיברים מתקרבים ל־2.

  2. סכום n האיברים הראשונים בסדרה הוא \(S_{n} = 3n^{2} + 2n\). מצאו את \(a_{n}\) והראו שהסדרה חשבונית.
    הצג פתרון

    \(a_{n} = S_{n} - S_{n-1} = 3(2n - 1) + 2 = 6n - 1\)

    \(a_{1} = S_{1} = 5 = 6 \cdot 1 - 1\) ✓. הסדרה חשבונית עם \(d = 6\).

  3. נתון \(S_{n} = 2^{n+1} - 2\). מצאו את \(a_{n}\) וקבעו את סוג הסדרה.
    הצג פתרון

    \(a_{n} = (2^{n+1} - 2) - (2^{n} - 2) = 2^{n}\), ו־\(a_{1} = S_{1} = 2\) ✓.

    סדרה הנדסית עם \(q = 2\).

  4. נתון \(S_{n} = n^{2} + n + 1\). האם הסדרה חשבונית?
    הצג פתרון

    עבור \(n \ge 2\): \(a_{n} = 2n\). אבל \(a_{1} = S_{1} = 3 \neq 2\).

    הסדרה \(3, 4, 6, 8, \ldots\) אינה חשבונית. היא חשבונית רק החל מהאיבר השני.

פרק 6

סדרות מעורבות ומשולבות

המשמעות: שאלות שבהן יותר ממבנה אחד פועל בו־זמנית. המפתח הוא לזהות את הסדרות הפשוטות שמסתתרות בתוך הסדרה המסובכת.

• סדרה שזורה: האיברים במקומות האי־זוגיים יוצרים סדרה אחת, והאיברים במקומות הזוגיים סדרה אחרת. מפרקים לשתי סדרות ומטפלים בכל אחת בנפרד.

• סדרה נגזרת: בונים סדרה חדשה מסדרה קיימת. אם \(a_{n}\) חשבונית, אז \(c^{an}\) הנדסית. אם \(a_{n}\) הנדסית חיובית, אז \({\log a_{n}}\) חשבונית. הלוגריתם הופך כפל לחיבור, והחזקה הופכת חיבור לכפל.

• שילוב חשבונית והנדסית: אותם מספרים מקיימים תנאי של סדרה חשבונית ותנאי של סדרה הנדסית (לפני ואחרי שינוי).

דוגמה פתורה

\(a_{n}\) סדרה הנדסית עם \(a_{1} = 2\), \(q = 4\). מגדירים \(c_{n} = {\log_{2} a_{n}}\). הראו ש־\(c_{n}\) חשבונית וחשבו את \(c_{1} + \ldots + c_{10}\).

\(c_{n} = {\log_{2}(2 \cdot 4^{n-1})} = 1 + 2(n - 1) = 2n - 1\)

חשבונית עם \(c_{1} = 1\), \(d = 2\).

\(S_{10} = \dfrac{10 \cdot (1 + 19)}{2} = 100\)

תרגילים

  1. שלושה מספרים יוצרים סדרה חשבונית שסכומה 15. אם מוסיפים להם 1, 4 ו־19 בהתאמה, מתקבלת סדרה הנדסית. מצאו את המספרים.
    הצג פתרון

    המספרים: \(5 - d, 5, 5+d\). אחרי ההוספה: \(6 - d, 9, 24+d\).

    \(81 = (6 - d)(24+d) \Rightarrow d^{2} + 18d - 63 = 0 \Rightarrow d = 3\) או \(d = - 21\).

    \(d = 3\): המספרים \(2, 5, 8\) (ההנדסית \(3, 9, 27\)).

    \(d = - 21\): המספרים \(26, 5, - 16\) (ההנדסית \(27, 9, 3\)).

  2. \(a_{n}\) סדרה חשבונית עם \(a_{1} = 1\), \(d = 2\). מגדירים \(b_{n} = 3^{an}\). הראו ש־\(b_{n}\) הנדסית וחשבו את סכום חמשת איבריה הראשונים.
    הצג פתרון

    \(\dfrac{b_{n+1}}{b_{n}} = 3^{a_{n+1} - a_{n}} = 3^{2} = 9\), כלומר הנדסית עם \(q = 9\).

    \(b_{1} = 3 \Rightarrow S_{5} = \dfrac{3(9^{5} - 1)}{8} = 22143\)

  3. בסדרה \(1, 2, 4, 4, 7, 8, 10, 16, \ldots\) המקומות האי־זוגיים יוצרים סדרה חשבונית והזוגיים סדרה הנדסית. חשבו את סכום 20 האיברים הראשונים.
    הצג פתרון

    אי־זוגיים: \(1, 4, 7, \ldots\) (10 איברים, \(d = 3\)): \(S = \dfrac{10(2 + 27)}{2} = 145\).

    זוגיים: \(2, 4, 8, \ldots\) (10 איברים, \(q = 2\)): \(S = 2(2^{10} - 1) = 2046\).

    סה"כ: \(145 + 2046 = 2191\).

פרק 7

אינדוקציה מתמטית

המשמעות: שיטה להוכיח טענה עבור כל המספרים הטבעיים. חושבים על שורת אבני דומינו: אם האבן הראשונה נופלת, ואם כל אבן שנופלת מפילה את הבאה, אז כל האבנים נופלות.

שלושה שלבים:

1. בסיס: בודקים שהטענה נכונה עבור \(n = 1\).

2. הנחה: מניחים שהטענה נכונה עבור \(n = k\).

3. צעד: מוכיחים, בעזרת ההנחה, שהטענה נכונה גם עבור \(n = k+1\).

בסדרות משתמשים באינדוקציה בעיקר כדי להוכיח נוסחאות סכום וכדי להוכיח שנוסחה מפורשת מתאימה לכלל נסיגה.

דוגמה פתורה

הוכיחו: \(1 + 3 + 5 + \ldots + (2n - 1) = n^{2}\)

בסיס: \(n = 1: 1 = 1^{2}\) ✓

הנחה: \(1 + 3 + \ldots + (2k - 1) = k^{2}\)

צעד: \(k^{2} + (2(k+1) - 1) = k^{2} + 2k + 1 = (k+1)^{2}\) ✓

תרגילים

  1. הוכיחו: \(1 + 2 + \ldots + n = \dfrac{n(n+1)}{2}\)
    הצג פתרון

    בסיס: \(1 = \dfrac{1 \cdot 2}{2}\) ✓

    צעד: \(\dfrac{k(k+1)}{2} + (k+1) = \dfrac{(k+1)(k+2)}{2}\) ✓

  2. הוכיחו: \(1^{2} + 2^{2} + \ldots + n^{2} = \dfrac{n(n+1)(2n+1)}{6}\)
    הצג פתרון

    בסיס: \(1 = \dfrac{1 \cdot 2 \cdot 3}{6}\) ✓

    צעד: \(\dfrac{k(k+1)(2k+1)}{6} + (k+1)^{2} = \dfrac{(k+1)[k(2k+1) + 6(k+1)]}{6}\)

    \(= \dfrac{(k+1)(2k^{2} + 7k + 6)}{6} = \dfrac{(k+1)(k+2)(2k+3)}{6}\) ✓

  3. נתון \(a_{1} = 3\), \(a_{n+1} = 2a_{n} + 1\). הוכיחו באינדוקציה ש־\(a_{n} = 2^{n+1} - 1\).
    הצג פתרון

    בסיס: \(2^{2} - 1 = 3 = a_{1}\) ✓

    צעד: \(a_{k+1} = 2(2^{k+1} - 1) + 1 = 2^{k+2} - 1\) ✓

  4. הוכיחו ש־\(7^{n} - 1\) מתחלק ב־6 לכל n טבעי.
    הצג פתרון

    בסיס: \(7 - 1 = 6\) ✓

    צעד: \(7^{k+1} - 1 = 7(7^{k} - 1) + 6\). שני המחוברים מתחלקים ב־6 (הראשון לפי ההנחה) ✓

חלוקת הנושאים בין שאלונים ושנים עשויה להשתנות. כדאי לוודא מול תוכנית הלימודים העדכנית.
