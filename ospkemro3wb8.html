מבחן: נקודה על גלגל

מתחת לכל שאלה יש תבנית לפתרון: כותרות השלבים והנוסחאות כבר כתובות, ובמקום כל ערך יש קו. קראו את השאלה, מצאו מה כל ערך בנוסחה, והשלימו את הקווים לפי הסדר. אפשר להשתמש במחשבון.

    \(y(t) = 4 + 8\sin(120^\circ + 15t)\)
    מצאו את מיקום P אחרי 2 שניות (נקודה B) ואחרי 18 שניות (נקודה D).

      \(|x_D - x_C| = |{\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\cos{\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}| = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)מ׳

    \(h_B = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}},\ \ h_D = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)מ׳

    \(h_B = y_C = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\ \checkmark\)
  3. מרכז C של גלגל ענק נמצא בגובה 15 מ׳, ורדיוס הגלגל 12 מ׳. הגלגל מסתובב עם כיוון השעון. קרונית P נמצאת בהתחלה בנקודה הגבוהה ביותר, A, ומגיעה לראשונה לגובה של המרכז אחרי 20 שניות (נקודה B). מצאו את המהירות הזוויתית ואת זמן המחזור. באיזה גובה P אחרי 50 שניות (נקודה D)? מתי היא מגיעה לראשונה לנקודה הנמוכה ביותר (נקודה E)?

    דרך החשיבה

    בנוסחה חסר נתון אחד: ω. התצפית "מהראש לגובה המרכז" נותנת זווית וזמן: עם כיוון השעון הזווית יורדת, מ־90° ל־0° (הצד הימני). מציבים אותם בנוסחת הבסיס ומוצאים את ω. מכאן הנוסחה שלמה, וכל השאר הוא הצבה.

    1. רושמים את הנתונים בסימני הנוסחה
      \(y_C = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)מ׳
      \(R = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)מ׳
      \(\theta_A = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)
      בגובה המרכז, אחרי רבע סיבוב עם כיוון השעון:
      \(t_B = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}},\ \ \theta_B = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)

      \(\alpha = \theta_B - \theta_A = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} - {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)
      \(\alpha = \omega\, t \ \Rightarrow\ \omega = \tfrac{\alpha}{t}\)
      \(\omega = \tfrac{{\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}}{{\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}} = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)

      \(T = \tfrac{360^\circ}{|\omega|} = \tfrac{360^\circ}{{\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}} = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)שניות
    4. מציבים \(t = 50\): קודם הזווית, אחר כך הגובהשאלת מרחק זוויתישאלת מיקום

      \(\theta_D = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} + ({\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}})\cdot{\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)

  4. מרכז C של גלגל ענק נמצא בגובה 18 מ׳, ורדיוס הגלגל 10 מ׳. הגלגל מסתובב נגד כיוון השעון, סיבוב בכל דקה. בהתחלה קרונית P נמצאת בנקודה A בגובה 13 מ׳, ויורדת. מצאו את המהירות הזוויתית ואת זווית ההתחלה. באיזה גובה P אחרי 20 שניות (נקודה B)? מתי היא מגיעה לראשונה לראש הגלגל (נקודה D)?

    דרך החשיבה

    הפעם חסרה זווית ההתחלה. מגובה ההתחלה מקבלים את sin θA, ויש שתי זוויות מתאימות. כיוון התנועה מכריע: נגד כיוון השעון הזווית עולה, והגובה יורד רק בצד שמאל של הגלגל (בין 90° ל־270°).

      \(y_C = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)מ׳

      \(T = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)שניות

      \(h_A = y_C + R\sin\theta_A\)
      \({\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} + {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\sin\theta_A\)
      \(\sin\theta_A = \tfrac{{\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}} - {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}}{{\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}} = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)
      \(\theta_A = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\ \ \text{or}\ \ \theta_A = {\underline{\hspace{2.6em}}\rule[-0.45em]{0pt}{0.45em}}\)
      נגד כיוון השעון: ב־ הקרונית בצד שמאל ויורדת, וב־ היא בצד ימין ועולה
