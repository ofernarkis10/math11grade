מרובעים

מקבילית, מלבן, מעוין, ריבוע, טרפז ודלתון. לכל מרובע: ההגדרה, התכונות (מה נובע מכך שהמרובע הוא מהסוג הזה) ומשפטי הזיהוי (מה מספיק כדי להוכיח שהוא מהסוג הזה). בנוסף: קטע אמצעים במשולש ובטרפז, טבלת השוואה, דוגמאות פתורות ושמונה תרגילים עם פתרון מפורט. הדף נשען על חפיפת משולשים ועל זוויות וישרים מקבילים.

1. מושגים ומשפחת המרובעים

מרובע הוא מצולע עם ארבע צלעות. צלעות נגדיות לא נוגעות זו בזו, צלעות סמוכות יוצאות מאותו קודקוד. אלכסון מחבר שני קודקודים נגדיים. סכום הזוויות בכל מרובע הוא \(360^\circ\).

שלוש מילים שחשוב להבדיל ביניהן:

  • הגדרה: מה המרובע הוא. למשל, מקבילית היא מרובע ששני זוגות צלעותיו הנגדיות מקבילים.
  • תכונה: מה נכון בכל מרובע כזה. משתמשים בתכונות כשיודעים שהמרובע הוא מקבילית ורוצים להסיק משהו.
  • משפט זיהוי: מה מספיק לבדוק כדי לדעת שהמרובע הוא מקבילית. משתמשים בו כשצריך להוכיח שמרובע הוא מקבילית.

2. מקבילית

הגדרה

מקבילית היא מרובע ששני זוגות צלעותיו הנגדיות מקבילים.

תכונות

במקבילית: (1) צלעות נגדיות שוות. (2) זוויות נגדיות שוות. (3) האלכסונים חוצים זה את זה. (4) סכום כל שתי זוויות סמוכות הוא \(180^\circ\).

איך מוכיחים את התכונות:

האלכסון \(AC\) מחלק את המקבילית לשני משולשים. \(\triangle ABC \cong \triangle CDA\) לפי זווית צלע זווית: זוויות מתחלפות בשני זוגות המקבילים והצלע המשותפת \(AC\). מהחפיפה: \(AB = CD\), \(BC = DA\) ו־\(\angle B = \angle D\). את תכונה (3) מוכיחים בחפיפה של \(\triangle AOB\) ו־\(\triangle COD\). (ראו תרגיל 7 בדף החפיפה.)

משפטי זיהוי: מרובע הוא מקבילית אם

(1) שני זוגות הצלעות הנגדיות שווים, או (2) זוג אחד של צלעות נגדיות שוות וגם מקבילות, או (3) שני זוגות הזוויות הנגדיות שווים, או (4) האלכסונים חוצים זה את זה.

שימו לב למשפט 2: צריך את אותו זוג צלעות גם שווה וגם מקביל. זוג אחד שווה וזוג אחר מקביל לא מספיק: טרפז שווה שוקיים הוא דוגמה נגדית.

4. טרפז

הגדרה

טרפז הוא מרובע עם זוג אחד בלבד של צלעות מקבילות. הצלעות המקבילות הן הבסיסים, והאחרות הן השוקיים.

תכונה

סכום שתי הזוויות שליד כל שוק הוא \(180^\circ\) (זוויות חד־צדדיות בין הבסיסים).

קטע אמצעים בטרפז

הקטע שמחבר את אמצעי השוקיים מקביל לבסיסים ושווה למחצית סכומם: \(EF = \frac{AB + DC}{2}\).

טרפז שווה שוקיים

תכונות

בטרפז שווה שוקיים זוויות הבסיס שוות, והאלכסונים שווים.

משפטי זיהוי

טרפז שזוויות הבסיס שלו שוות הוא שווה שוקיים. טרפז שהאלכסונים שלו שווים הוא שווה שוקיים.

5. דלתון

הגדרה

דלתון הוא מרובע עם שני זוגות של צלעות סמוכות שוות. האלכסון שמחבר את הקודקודים שבין הצלעות השוות הוא האלכסון הראשי (\(AC\) בשרטוט).

תכונות

האלכסון הראשי חוצה את זוויות הראש (\(A\) ו־\(C\)), מאונך לאלכסון השני וחוצה אותו. הזוויות שבין הצלעות השונות (\(\angle B\) ו־\(\angle D\)) שוות.

את התכונות מוכיחים בחפיפה \(\triangle ABC \cong \triangle ADC\) לפי צלע צלע צלע (דוגמה 4 בדף החפיפה).

6. קטע אמצעים במשולש

משפט

קטע אמצעים במשולש (הקטע שמחבר את אמצעי שתי צלעות) מקביל לצלע השלישית ושווה למחציתה.

משפט הפוך

ישר שיוצא מאמצע צלע אחת של משולש ומקביל לצלע שנייה חוצה את הצלע השלישית.

רעיון ההוכחה:

מאריכים את \(DE\) עד נקודה \(F\) כך ש־\(EF = DE\). אז \(\triangle ADE \cong \triangle CFE\) לפי צלע זווית צלע, ומכאן \(CF = AD = DB\) ו־\(CF \parallel AB\). לכן \(DBCF\) מקבילית (זוג צלעות שוות ומקבילות), ו־\(DF \parallel BC\), \(DF = BC\). כלומר \(DE = \frac{BC}{2}\).

8. דוגמאות פתורות

דוגמה 1: הוכחה שמרובע הוא מקבילית

נתון: \(ABCD\) מקבילית, והנקודות \(E\) ו־\(F\) על האלכסון \(AC\) כך ש־\(AE = CF\).

צריך להוכיח: \(BEDF\) מקבילית.

#טענהנימוק
1\(AO = OC,\ BO = OD\)במקבילית \(ABCD\) האלכסונים חוצים זה את זה (\(O\) נקודת החיתוך)
2\(AE = CF\)נתון
3\(OE = AO - AE = OC - CF = OF\)חיסור קטעים שווים (טענות 1 ו־2)
4\(BEDF\) מקביליתהאלכסונים \(EF\) ו־\(BD\) של המרובע חוצים זה את זה (טענות 1 ו־3), משפט זיהוי 4
דוגמה 2: תכונות המלבן

נתון: \(ABCD\) מלבן, ו־\(M\) אמצע הצלע \(AB\).

צריך להוכיח: \(MD = MC\).

#טענהנימוק
1\(AM = MB\)\(M\) אמצע \(AB\)
2\(\angle A = \angle B = 90^\circ\)במלבן כל הזוויות ישרות
3\(AD = BC\)במלבן (כמו בכל מקבילית) צלעות נגדיות שוות
4\(\triangle AMD \cong \triangle BMC\)צלע זווית צלע (טענות 1–3)
5\(MD = MC\)צלעות מתאימות במשולשים חופפים
דוגמה 3: אמצעי הצלעות של מרובע

נתון: \(ABCD\) מרובע כלשהו. \(K, L, M, N\) אמצעי הצלעות \(AB, BC, CD, DA\).

צריך להוכיח: \(KLMN\) מקבילית.

#טענהנימוק
1\(KL \parallel AC,\ KL = \frac{AC}{2}\)קטע אמצעים במשולש \(ABC\)
2\(NM \parallel AC,\ NM = \frac{AC}{2}\)קטע אמצעים במשולש \(ACD\)
3\(KL \parallel NM,\ KL = NM\)שני ישרים שמקבילים לישר שלישי מקבילים זה לזה; קטעים ששווים לאותו קטע
4\(KLMN\) מקביליתזוג צלעות נגדיות שוות ומקבילות (משפט זיהוי 2)

התוצאה נכונה בכל מרובע, גם אם אינו מיוחד. זה משפט ואריניון.

9. תרגול

נסו לפתור לבד, ורק אחר כך פתחו את הפתרון. בכל פתרון מופיעים התשובה ודרך הפתרון המלאה.

1. במקבילית \(ABCD\) הזווית \(\angle A\) גדולה פי 2 מהזווית \(\angle B\). מצאו את כל זוויות המקבילית.

פתרון
תשובה

\(\angle A = \angle C = 120^\circ\), \(\angle B = \angle D = 60^\circ\).

דרך הפתרון:

במקבילית זוויות סמוכות הן זוויות חד־צדדיות בין המקבילים \(AD \parallel BC\), ולכן \(\angle A + \angle B = 180^\circ\).

\(2x + x = 180\), ולכן \(\angle B = 60^\circ\) ו־\(\angle A = 120^\circ\).

זוויות נגדיות במקבילית שוות: \(\angle C = \angle A = 120^\circ\), \(\angle D = \angle B = 60^\circ\).

2. היקף מקבילית \(ABCD\) הוא 40, והצלע \(AB\) ארוכה ב־4 מהצלע \(AD\). מצאו את אורכי הצלעות.

פתרון
תשובה

\(AB = CD = 12\), \(AD = BC = 8\).

דרך הפתרון:

במקבילית צלעות נגדיות שוות, ולכן ההיקף הוא \(2(AB + AD) = 40\), כלומר \(AB + AD = 20\).

\((AD + 4) + AD = 20\), ולכן \(AD = 8\) ו־\(AB = 12\).

3. האלכסונים של מקבילית \(ABCD\) נחתכים בנקודה \(O\). נתון \(AO = 3x - 2\), \(OC = x + 6\) ו־\(BO = 2x + 1\). מצאו את אורכי האלכסונים.

פתרון
תשובה

\(AC = 20\), \(BD = 18\).

דרך הפתרון:

במקבילית האלכסונים חוצים זה את זה, ולכן \(AO = OC\): \(3x - 2 = x + 6\), ולכן \(x = 4\).

\(AO = 10\), ולכן \(AC = 20\). \(BO = 2 \cdot 4 + 1 = 9\), ולכן \(BD = 18\).

4. האלכסונים של מלבן \(ABCD\) נחתכים בנקודה \(O\). אורך כל אלכסון הוא 10, והזווית \(\angle AOB\) היא \(60^\circ\). מצאו את צלעות המלבן.

פתרון
תשובה

\(AB = 5\), \(BC = 5\sqrt3\).

דרך הפתרון:

במלבן האלכסונים שווים וחוצים זה את זה, ולכן \(AO = BO = 5\).

המשולש \(AOB\) שווה שוקיים עם זווית ראש \(60^\circ\), ולכן זוויות הבסיס גם הן \(60^\circ\) והמשולש שווה צלעות: \(AB = 5\).

במשולש ישר הזווית \(ABC\): \(BC = \sqrt{10^2 - 5^2} = \sqrt{75} = 5\sqrt3\).

5. במעוין \(ABCD\) הצלע היא 6 ו־\(\angle A = 60^\circ\). מצאו את אורכי האלכסונים.

פתרון
תשובה

\(BD = 6\), \(AC = 6\sqrt3\).

דרך הפתרון:

במעוין כל הצלעות שוות, ולכן המשולש \(ABD\) שווה שוקיים (\(AB = AD = 6\)) עם זווית ראש \(60^\circ\). לכן הוא שווה צלעות ו־\(BD = 6\).

האלכסונים במעוין מאונכים וחוצים זה את זה. במשולש ישר הזווית שנוצר: חצי \(BD\) הוא 3, והיתר הוא 6, ולכן חצי \(AC\) הוא \(\sqrt{36 - 9} = 3\sqrt3\).

\(AC = 6\sqrt3\).

6. קבעו לכל טענה אם היא נכונה, ונמקו: (א) כל מלבן הוא מקבילית. (ב) מרובע שהאלכסונים שלו מאונכים הוא מעוין. (ג) מקבילית שהאלכסונים שלה שווים היא מלבן. (ד) מעוין שהאלכסונים שלו שווים הוא ריבוע.

פתרון
תשובה

(א) נכון. (ב) לא נכון. (ג) נכון. (ד) נכון.

דרך הפתרון:

(א) לפי ההגדרה, מלבן הוא מקבילית עם זווית ישרה.

(ב) דוגמה נגדית: בדלתון האלכסונים מאונכים, אבל הוא לא מעוין. המשפט הנכון: מקבילית שהאלכסונים שלה מאונכים היא מעוין.

(ג) זה משפט זיהוי של מלבן.

(ד) מעוין הוא מקבילית. מקבילית עם אלכסונים שווים היא מלבן. מרובע שהוא גם מלבן וגם מעוין הוא ריבוע.

7. בטרפז שווה שוקיים \(ABCD\) (\(AB \parallel DC\)) נתון \(\angle A = 70^\circ\), והבסיסים הם 6 ו־14. מצאו את זוויות הטרפז ואת אורך קטע האמצעים.

פתרון
תשובה

\(\angle A = \angle B = 70^\circ\), \(\angle C = \angle D = 110^\circ\), קטע האמצעים 10.

דרך הפתרון:

בטרפז שווה שוקיים זוויות הבסיס שוות: \(\angle B = \angle A = 70^\circ\).

\(\angle A\) ו־\(\angle D\) חד־צדדיות בין הבסיסים המקבילים, ולכן \(\angle D = 110^\circ\), וגם \(\angle C = 110^\circ\).

קטע האמצעים שווה למחצית סכום הבסיסים: \(\frac{6 + 14}{2} = 10\).

8. במקבילית \(ABCD\) חוצי הזוויות \(A\) ו־\(B\) נפגשים בנקודה \(E\). הוכיחו ש־\(\angle AEB = 90^\circ\).

פתרון
תשובה

\(\angle EAB + \angle EBA = 90^\circ\), ולכן \(\angle AEB = 90^\circ\).

דרך הפתרון:

#טענהנימוק
1\(\angle DAB + \angle ABC = 180^\circ\)זוויות חד־צדדיות בין המקבילים \(AD \parallel BC\)
2\(\angle EAB = \frac{\angle DAB}{2},\ \angle EBA = \frac{\angle ABC}{2}\)\(AE\) ו־\(BE\) חוצי זוויות (נתון)
3\(\angle EAB + \angle EBA = 90^\circ\)מחצית מ־180° (טענות 1 ו־2)
4\(\angle AEB = 90^\circ\)סכום הזוויות במשולש \(ABE\)

10. טעויות נפוצות

  • להשתמש בתכונה במקום במשפט זיהוי. כדי להוכיח שמרובע הוא מקבילית צריך משפט זיהוי. "במקבילית האלכסונים חוצים זה את זה" הוא תכונה, ומשתמשים בו רק כשכבר ידוע שזו מקבילית.
  • "האלכסונים מאונכים, לכן זה מעוין". זה נכון רק למקבילית. בדלתון האלכסונים מאונכים והוא לא מעוין.
  • זוג צלעות שוות וזוג אחר מקביל. במשפט זיהוי 2 של מקבילית צריך את אותו זוג גם שווה וגם מקביל.
  • לחשוב שריבוע אינו מלבן. כל ריבוע הוא מלבן, וגם מעוין, וגם מקבילית. כל תכונה של מלבן נכונה גם בריבוע.
  • במלבן, לחשוב שהאלכסונים חוצים את הזוויות. זה נכון רק במעוין ובריבוע.
