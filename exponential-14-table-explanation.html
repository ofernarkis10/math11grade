שיעור שני - זיהוי הפונקציה מטבלה

במצגת הדוגמאות של שיעור שני קיבלנו טבלאות של מדידות – חיידקים, חיסכון, ערך של טלפון ודגים – ומצאנו מהן את הפונקציה. בדף הזה נסכם איך עושים את זה.

1. איך מזהים פונקציה מטבלה

  1. מחלקים כל ערך בערך שלפניו. המנה אומרת פי כמה הכמות גדלה (או קטנה) בצעד אחד.
  2. בודקים שכל המנות שוות. אם כן – זו פונקציה מהצורה f(t) = a · bt, והמנה היא b. אם המנות שונות – זו לא פונקציה כזו.
  3. מוצאים את הערך כאשר t = 0. זה a.
  4. כותבים את הפונקציה ובודקים ערך אחד מהטבלה.

2. האם הטבלה מתאימה בכלל?

דוגמה – האם הטבלה מתאימה לפונקציה כזו?

לפניכם שתי טבלאות. קבעו לגבי כל אחת אם היא מתארת פונקציית גדילה או דעיכה, ואם כן – מצאו את הפונקציה.

t0123
טבלה א׳812793
טבלה ב׳25811
מחלקים כל ערך בערך שלפניו בטבלה א׳ כדי לבדוק אם מכפילים במספר קבוע (זיהוי פונקציה)
27 : 81 = 1/3 9 : 27 = 1/3 3 : 9 = 1/3

בכל צעד מכפילים ב־1/3, ולכן זו פונקציית דעיכה עם b = 1/3 ו־a = 81:

f(t) = a · bt f(t) = 81 · (1/3)t
מחלקים כל ערך בערך שלפניו בטבלה ב׳ כדי לבדוק אם מכפילים במספר קבוע (זיהוי פונקציה)
5 : 2 = 2.5 8 : 5 = 1.6

המנות שונות – לא מכפילים באותו מספר, ולכן טבלה ב׳ לא מתארת פונקציית גדילה או דעיכה.

3. כשהטבלה לא מתחילה ב־t = 0

כשאין בטבלה ערך ב־t = 0, מוצאים קודם את b, ואז הולכים אחורה: בכל צעד אחורה מחלקים ב־b.

דוגמה – טבלה שמתחילה ב־t = 1

הטבלה מתארת פונקציה מהצורה f(t) = a · bt. מצאו את הפונקציה.

t1234
f(t)1236108324
מחלקים כל ערך בערך שלפניו ומוצאים את b (זיהוי פונקציה)
36 : 12 = 3 108 : 36 = 3 324 : 108 = 3 b = 3
הולכים צעד אחד אחורה – מחלקים ב־b – כדי למצוא את הערך ב־t = 0 (מציאת פרמטר)
a = f(0) = 12 : 3 = 4
כותבים את הפונקציה ובודקים ערך אחד (בניית פונקציה)
f(t) = a · bt f(t) = 4 · 3t f(4) = 4 · 34 = 4 · 81 = 324 ✓

4. מהטבלה לאחוזים

דוגמה – מהטבלה לאחוזים

מספר הציפורים בשמורה נספר בכל שנה. מצאו את הפונקציה, ובכמה אחוזים משתנה מספר הציפורים בכל שנה.

t0123
ציפורים800760722685.9
מחלקים כל ערך בערך שלפניו ומוצאים את b (זיהוי פונקציה)
760 : 800 = 0.95 722 : 760 = 0.95 685.9 : 722 = 0.95 b = 0.95
קוראים את a מהטבלה וכותבים את הפונקציה (בניית פונקציה)
a = f(0) = 800 f(t) = 800 · 0.95t
מתרגמים את b לאחוזים (חישוב ערך)
p = (1 − b) · 100 p = (1 − 0.95) · 100 = 5

מספר הציפורים קטן ב־5% בכל שנה.

5. איך ניגשים לשאלה

בצע את התהליך המתאים לסוג השאלה:

נתונה טבלת ערכים

  1. מחלקים כל ערך בערך שלפניו.
  2. בודקים שהמנה תמיד אותו מספר. המנה היא b.
  3. מוצאים בטבלה את הערך כאשר t = 0. זה a.
  4. כותבים את הפונקציה:f(t) = a · bt

אם המנה משתנה, זו לא פונקציית גדילה או דעיכה.

הטבלה לא מתחילה ב־t = 0

  1. מוצאים את b כמו קודם.
  2. הולכים אחורה: מחלקים ב־b עד t = 0.
  3. הערך שמתקבל ב־t = 0 הוא a.
  4. כותבים את הפונקציה ובודקים ערך אחד מהטבלה.

שואלים על אחוזים

  1. מוצאים את b מהטבלה.
  2. גדילה (b > 1):p = (b − 1) · 100
  3. דעיכה (b < 1):p = (1 − b) · 100

6. סיכום

  • המנה בין ערכים עוקבים היא b. אם כל המנות שוות – זו פונקציה מהצורה a · bt.
  • a הוא הערך ב־t = 0. אם הוא לא בטבלה – מחלקים ב־b אחורה עד t = 0.
  • מהמנה לאחוזים: p = (b − 1) · 100 בגדילה, p = (1 − b) · 100 בדעיכה.
