תנועה לינארית ותנועה על גלגל: אותה סדרת פעולות

בעיית נקודה על גלגל מסתובב נראית חדשה בגלל המושגים: זווית, זמן מחזור, sin ו־cos. אבל סדרת הפעולות לפתרון היא בדיוק זו של תנועה בקו ישר בין שתי נקודות: כותבים את משוואת המסלול (ישר או מעגל), מוצאים את x לפי הפרמטר (אחוז מהדרך או זווית), ומציבים במשוואת המסלול כדי למצוא את y. בדף הזה פותרים את שני סוגי הבעיות זה לצד זה, באותם חמישה שלבים. ממשיך את דף ההסבר על הגלגל המסתובב. כל הזוויות במעלות.

1. חמשת השלבים

בשני סוגי הבעיות שואלים את אותה שאלה: איפה הנקודה אחרי זמן t? ובשניהם עובדים באותה דרך:

קודם כותבים את משוואת המסלול, כלומר את הקו שעליו הנקודה נעה. בתנועה לינארית זה ישר, \(y = mx + b\), ובגלגל זה מעגל, \((x - x_C)^2 + (y - y_C)^2 = R^2\).

אחר כך מוצאים את x לפי הפרמטר. בתנועה לינארית הפרמטר הוא האחוז p מהדרך. בגלגל הפרמטר הוא הזווית θ במעלות, שהיא "אחוז מסיבוב".

לבסוף מציבים את x במשוואת המסלול ומקבלים את y.

שלבתנועה לינארית (מ־A ל־B)תנועה על גלגל
1. נתוניםנקודת התחלה \(A\), נקודת סוף \(B\), זמן הדרך \(T\)מרכז \(C\), רדיוס \(R\), זווית התחלה \(\theta_0\), זמן מחזור \(T\)
2. משוואת המסלולהישר דרך A ו־B:
\(m = \dfrac{y_B - y_A}{x_B - x_A}\)
\(y = m(x - x_A) + y_A\)		המעגל סביב המרכז:
\((x - x_C)^2 + (y - y_C)^2 = R^2\)
3. ערך הפרמטר לפי הזמן\(p = \dfrac{t}{T}\)\(\theta = \theta_0 + 360^\circ\cdot\dfrac{t}{T}\)
4. x לפי הפרמטר\(x = x_A + p\,(x_B - x_A)\)\(x = x_C + R\cos\theta\)
5. y ממשוואת המסלולמציבים את x בישר: תשובה אחתמציבים את x במעגל: שתי אפשרויות, והזווית בוחרת. בפועל זה \(y = y_C + R\sin\theta\)

בשני המקרים: משוואת המסלול, הפרמטר לפי הזמן, x לפי הפרמטר, ו־y מהמסלול.
ההבדל הוא רק בצורת המסלול: ישר או מעגל.

הערה למורה: כדאי לפתור קודם את הבעיה הלינארית על הלוח, עם שרטוט של הישר. משוואת הישר דרך שתי נקודות כבר מוכרת לתלמידים, וגם ההצבה של x כדי לקבל y. את בעיית הגלגל פותרים אחר כך באותה מסגרת: משוואת המעגל היא המסלול, ו־x מחושב לפי הזווית. כשמציבים את x במשוואת המעגל יוצאות שתי תשובות ל־y, ומשם מגיע הצורך ב־sin: הוא בוחר את התשובה הנכונה לפי הזווית.

2. מילון מקביל: אותו תפקיד, שם אחר

רוב הקושי בבעיות הגלגל הוא במושגים, לא בעבודה. לכל מושג בבעיית הגלגל יש "בן זוג" בבעיה הלינארית שממלא את אותו תפקיד:

תפקידתנועה לינאריתתנועה על גלגל
המסלולישר: \(y = mx + b\)מעגל: \((x - x_C)^2 + (y - y_C)^2 = R^2\)
מה קובע את המסלולשתי נקודות: A ו־Bמרכז ורדיוס: C ו־R
הפרמטרהאחוז מהדרך \(p\)הזווית \(\theta\) במעלות
מה זה 100%\(p = 1\): הגעה ל־\(B\)סיבוב שלם: \(360^\circ\)
הזמן ל־100%\(T\): זמן הדרך\(T\): זמן מחזור
הפרמטר לפי הזמן\(p = \dfrac{t}{T}\)\(\theta = \theta_0 + \omega t,\ \ \omega = \dfrac{360^\circ}{T}\)
x לפי הפרמטר\(x = x_A + p\,(x_B - x_A)\)\(x = x_C + R\cos\theta\)
y מהמסלולהצבה בישר: ערך אחדהצבה במעגל: שני ערכים, הזווית בוחרת (\(\sin\theta\))
כיווןמ־A לכיוון Bנגד כיוון השעון: \(+\) · עם כיוון השעון: \(-\)
יותר מ־100%ממשיכים על הישר אל מעבר ל־Bחוזרים על המעגל: אותם מקומות
שימו לב: הזווית היא בעצם האחוז בסקאלה אחרת: \(\theta = \theta_0 + 360^\circ\cdot p\). אחוז אחד מהסיבוב הוא \(3.6^\circ\).

3. סימולציה: אותו אחוז, שתי תנועות

משנים אחוז אחד, \(p\), ורואים את שתי הנקודות זזות. מימין נקודה שנעה מ־\(A(2,1)\) ל־\(B(10,7)\). משמאל נקודה על גלגל ברדיוס 10 שמרכזו בראשית, שמתחילה ב־\(\theta_0 = 0^\circ\) ומסתובבת נגד כיוון השעון. מתחת לכל אחת מופיעים חמשת השלבים עם המספרים.

סימולציה: כחול = תנועה לינארית · כתום = תנועה על גלגל

נסו את 100%: הנקודה הלינארית מגיעה ל־B, והנקודה על הגלגל חוזרת למקום ההתחלה. נסו את 150%: הלינארית ממשיכה הלאה על הקו (הקו המקווקו), ואילו על הגלגל 150% נותן בדיוק את אותו מקום כמו 50%.

דוגמה 1: אחוז פשוט מהדרך

תנועה לינארית

הולך יוצא מ־\(A(2,1)\) ומגיע ל־\(B(10,7)\) בתנועה קצובה תוך 20 שניות. איפה הוא אחרי 5 שניות?

  1. נתונים\(A(2,1),\ B(10,7),\ T = 20,\ t = 5\)
  2. משוואת המסלול\(m = \dfrac{7 - 1}{10 - 2} = \dfrac{6}{8} = 0.75\)\(y = 0.75(x - 2) + 1\)\(y = 0.75x - 0.5\)
  3. ערך הפרמטר\(p = \dfrac{5}{20} = 0.25 = 25\%\)
  4. x לפי הפרמטר\(x = 2 + 0.25\cdot(10 - 2) = 4\)
  5. y ממשוואת המסלול\(y = 0.75\cdot 4 - 0.5 = 2.5\)

התשובה: \((4,\ 2.5)\)

תנועה על גלגל

מרכז גלגל ב־\((0,12)\) ורדיוסו 10. נקודה מתחילה ב־\((10,12)\), והגלגל משלים סיבוב נגד כיוון השעון ב־60 שניות. איפה הנקודה אחרי 15 שניות?

  1. נתונים\(C(0,12),\ R = 10,\ \theta_0 = 0^\circ,\ T = 60,\ t = 15\)
  2. משוואת המסלול\(x^2 + (y - 12)^2 = 100\)
  3. ערך הפרמטר\(\theta = 0^\circ + 360^\circ\cdot\dfrac{15}{60} = 90^\circ\)
  4. x לפי הפרמטר\(x = 0 + 10\cos 90^\circ = 0\)
  5. y ממשוואת המסלול\(0^2 + (y - 12)^2 = 100\)\(y = 22\ \ \text{or}\ \ y = 2\)הזווית \(90^\circ\) היא בחצי העליון, ולכן \(y = 22\). זה בדיוק \(12 + 10\sin90^\circ\).

התשובה: \((0,\ 22)\), בראש הגלגל

מה שונה? צורת המסלול. ישר חותך כל קו אנכי בנקודה אחת, ולכן ההצבה של x נותנת y אחד. מעגל חותך קו אנכי בשתי נקודות, ולכן ההצבה נותנת שני ערכים, והזווית קובעת איזה מהם. בגלל זה בגלגל מחשבים את y ישר עם sin.

דוגמה 2: מרכז כללי וכיוון הפוך

תנועה לינארית

רחפן טס בקו ישר מ־\(A(-4,3)\) ל־\(B(8,-6)\) במהירות קבועה, ב־30 שניות. איפה הוא אחרי 10 שניות?

  1. נתונים\(A(-4,3),\ B(8,-6),\ T = 30,\ t = 10\)
  2. משוואת המסלולהישר יורד, ולכן השיפוע שלילי:\(m = \dfrac{-6 - 3}{8 - (-4)} = \dfrac{-9}{12} = -0.75\)\(y = -0.75(x + 4) + 3\)\(y = -0.75x\)
  3. ערך הפרמטר\(p = \dfrac{10}{30} = \dfrac{1}{3} \approx 33.3\%\)
  4. x לפי הפרמטר\(x = -4 + \tfrac13\cdot(8 - (-4)) = -4 + 4 = 0\)
  5. y ממשוואת המסלול\(y = -0.75\cdot 0 = 0\)

התשובה: \((0,\ 0)\)

תנועה על גלגל

גלגל ענק: מרכזו ב־\((0,20)\) ורדיוסו 15. קרונית מתחילה בראש הגלגל, והגלגל מסתובב עם כיוון השעון, סיבוב בכל 120 שניות. איפה הקרונית אחרי 40 שניות?

  1. נתונים\(C(0,20),\ R = 15,\ \theta_0 = 90^\circ,\ T = 120,\ t = 40\)
  2. משוואת המסלול\(x^2 + (y - 20)^2 = 225\)
  3. ערך הפרמטרעם כיוון השעון הזווית קטנה, ולכן סימן מינוס:\(\theta = 90^\circ - 360^\circ\cdot\dfrac{40}{120} = -30^\circ\)
  4. x לפי הפרמטר\(x = 15\cos(-30^\circ) = 7.5\sqrt3 \approx 12.99\)
  5. y ממשוואת המסלול\((y - 20)^2 = 225 - 168.75 = 56.25\)\(y = 27.5\ \ \text{or}\ \ y = 12.5\)הזווית \(-30^\circ\) מתחת למרכז, ולכן \(y = 12.5\). זה \(20 + 15\sin(-30^\circ)\).

התשובה: \((12.99,\ 12.5)\), בגובה 12.5 מ׳

מה דומה? בשני המקרים הכיוון הוא סימן. בלינארי הוא יושב בשיפוע של הישר ובהפרש \(x_B - x_A\); בגלגל הוא הפלוס או המינוס בחישוב הזווית.

דוגמה 3: יותר מ־100%

תנועה לינארית

גוף נע במהירות קבועה מ־\(A(1,2)\) ומגיע ל־\(B(4,6)\) אחרי 5 שניות, וממשיך באותו כיוון ובאותה מהירות. איפה הוא אחרי 12 שניות?

  1. נתונים\(A(1,2),\ B(4,6),\ T = 5,\ t = 12\)
  2. משוואת המסלול\(m = \dfrac{6 - 2}{4 - 1} = \dfrac43\)\(y = \tfrac43(x - 1) + 2 = \tfrac43x + \tfrac23\)
  3. ערך הפרמטר\(p = \dfrac{12}{5} = 2.4 = 240\%\). הגוף עבר יותר מפעמיים את הדרך מ־A ל־B.
  4. x לפי הפרמטר\(x = 1 + 2.4\cdot(4 - 1) = 8.2\)
  5. y ממשוואת המסלול\(y = \tfrac43\cdot 8.2 + \tfrac23 = 11.6\)

התשובה: \((8.2,\ 11.6)\), על הישר, הרחק מעבר ל־B

תנועה על גלגל

מרכז גלגל ב־\((3,4)\) ורדיוסו 5. נקודה מתחילה ב־\(\theta_0 = 0^\circ\), והגלגל מסתובב נגד כיוון השעון, סיבוב בכל 8 שניות. איפה הנקודה אחרי 19 שניות?

  1. נתונים\(C(3,4),\ R = 5,\ \theta_0 = 0^\circ,\ T = 8,\ t = 19\)
  2. משוואת המסלול\((x - 3)^2 + (y - 4)^2 = 25\)
  3. ערך הפרמטר\(\dfrac{19}{8} = 2.375 = 237.5\%\) מסיבוב:\(\theta = 360^\circ\cdot2.375 = 855^\circ\)\(855^\circ = 2\cdot360^\circ + 135^\circ \equiv 135^\circ\)
  4. x לפי הפרמטר\(x = 3 + 5\cos135^\circ \approx -0.54\)
  5. y ממשוואת המסלול\((y - 4)^2 = 25 - 12.5 = 12.5\)\(y \approx 7.54\ \ \text{or}\ \ y \approx 0.46\)הזווית \(135^\circ\) בחצי העליון, ולכן \(y \approx 7.54\), כלומר \(4 + 5\sin135^\circ\).

התשובה: \((-0.54,\ 7.54)\)

כאן ההבדל המהותי, והוא נובע מצורת המסלול: ישר ממשיך לאינסוף, ולכן \(p = 2.4\) נותן מקום חדש ורחוק. מעגל נסגר על עצמו, ולכן אחרי 100% חוזרים על אותם מקומות: 237.5% על הגלגל הוא אותו מקום כמו 37.5%. מותר להוריד סיבובים שלמים לפני החישוב.

דוגמה 4: הבעיה ההפוכה, מתי?

עכשיו נתון המקום, ושואלים מתי הנקודה נמצאת שם. שוב מתחילים ממשוואת המסלול, אבל הולכים בכיוון ההפוך: מהמקום לפרמטר, ומהפרמטר לזמן.

תנועה לינארית

נקודה נעה מ־\(A(0,0)\) ל־\(B(12,9)\) ב־6 שניות. מתי היא נמצאת ב־\((8,6)\)?

  1. נתונים\(A(0,0),\ B(12,9),\ T = 6\), המקום המבוקש \((8,6)\)
  2. משוואת המסלול\(m = \dfrac{9}{12} = 0.75,\quad y = 0.75x\)
  3. האם הנקודה על המסלול?מציבים את x במשוואה:\(0.75\cdot 8 = 6\ \checkmark\)יש נקודה אחת על הישר עם \(x = 8\).
  4. הפרמטר לפי x\(8 = 0 + p\cdot 12 \ \Rightarrow\ p = \tfrac23\)
  5. מהפרמטר לזמן\(t = p\cdot T = \tfrac23\cdot 6 = 4\)

התשובה: אחרי 4 שניות, ורק פעם אחת

תנועה על גלגל

מרכז גלגל ב־\((0,12)\) ורדיוסו 10. נקודה מתחילה בתחתית הגלגל, בגובה 2, והגלגל מסתובב נגד כיוון השעון, סיבוב בכל 60 שניות. מתי הנקודה בגובה 17?

  1. נתונים\(C(0,12),\ R = 10,\ \theta_0 = 270^\circ,\ T = 60\), הגובה המבוקש \(y = 17\)
  2. משוואת המסלול\(x^2 + (y - 12)^2 = 100\)
  3. איפה על המסלול?מציבים את y במשוואה:\(x^2 + 25 = 100 \ \Rightarrow\ x = \pm\sqrt{75} \approx \pm 8.66\)יש שתי נקודות על המעגל בגובה 17: אחת מימין למרכז ואחת משמאל.
  4. הפרמטר לפי המקום\(\sin\theta = \dfrac{17 - 12}{10} = 0.5\)\(\theta = 30^\circ\ (x \gt 0)\ \ \text{or}\ \ \theta = 150^\circ\ (x \lt 0)\)הזווית גדלה החל מ־\(270^\circ\), ולכן מגיעים קודם ל־\(390^\circ\) ואחר כך ל־\(510^\circ\).
  5. מהפרמטר לזמן\(t = \dfrac{\theta - \theta_0}{360^\circ}\cdot T\)\(t_1 = \dfrac{390^\circ - 270^\circ}{360^\circ}\cdot60 = 20\)\(t_2 = \dfrac{510^\circ - 270^\circ}{360^\circ}\cdot60 = 40\)

התשובה: אחרי 20 ואחרי 40 שניות, ושוב כל 60 שניות.\(t = 20 + 60k\ \ \text{or}\ \ t = 40 + 60k,\quad k = 0, 1, 2, \dots\)

מה שונה? המהלך זהה, וההבדל שוב נובע מצורת המסלול. קו אופקי בגובה מסוים חותך ישר (משופע) בנקודה אחת, ולכן יש תשובה אחת. אותו קו חותך מעגל בשתי נקודות, ולכן יש שתי תשובות בכל סיבוב: פעם בעלייה ופעם בירידה.

מה דומה ומה שונה

תנועה לינאריתתנועה על גלגל
סדרת הפעולותזהה: נתונים ← משוואת המסלול ← הפרמטר לפי הזמן ← x לפי הפרמטר ← y מהמסלול
המסלולישר: \(y = mx + b\)מעגל: \((x - x_C)^2 + (y - y_C)^2 = R^2\)
הפרמטראחוז מהדרך \(p\)זווית \(\theta\) במעלות (אחוז מסיבוב כפול 360)
x לפי הפרמטר\(x_A + p\,(x_B - x_A)\)\(x_C + R\cos\theta\)
y מהמסלולערך אחדשני ערכים; הזווית בוחרת, וזה \(y_C + R\sin\theta\)
אחרי 100%ממשיכים על הישרחוזרים על אותם מקומות (מחזוריות)
הבעיה ההפוכהתשובה אחתשתי תשובות בכל סיבוב, ושוב כל T
ומה עם גלגל שנוסע? בסעיף 4 בדף ההסבר המרכז של הגלגל נע על ישר, והנקודה מסתובבת סביבו על מעגל. שם משתמשים בשתי הסדרות יחד: המרכז מחושב כמו תנועה לינארית, הנקודה ביחס למרכז מחושבת כמו תנועה על גלגל, ומחברים.
