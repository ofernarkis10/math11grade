הסבר ונוסחאות

מה זו סדרה הנדסית? סדרה שבה כל איבר מתקבל מהאיבר הקודם על ידי כפל באותו מספר קבוע. המספר הזה נקרא מנת הסדרה ומסומן q. למשל ב־3, 6, 12, 24, … כופלים ב־2 בכל צעד, ולכן q = 2. בסדרה הנדסית אין איבר שווה ל־0, ולכן גם q ≠ 0.

המשמעות: סדרה הנדסית מתארת שינוי יחסי קבוע: בכל צעד גדלים (או קטנים) באותו אחוז. זה המודל של ריבית דריבית, גידול אוכלוסייה, התרבות חיידקים, ירידת ערך של רכב ודעיכה רדיואקטיבית. גדילה כזו נקראת מעריכית, והיא מהירה הרבה יותר מגדילה לינארית: בסדרה חשבונית מוסיפים, בסדרה הנדסית כופלים.

אחוזים ומנה: עלייה של p% בכל תקופה פירושה q = 1 + p/100. ירידה של p% פירושה q = 1 − p/100. למשל עלייה של 5% היא q = 1.05, וירידה של 15% היא q = 0.85.

התנהגות לפי q (עבור a₁ > 0): q > 1 עולה; 0 < q < 1 יורדת ומתקרבת ל־0; q = 1 קבועה; q < 0 הסימנים מתחלפים.

הגדרה (כלל נסיגה)aₙ₊₁ = q·aₙ
האיבר הכלליaₙ = a₁·qⁿ⁻¹
יחס בין שני איבריםaₘ/aₖ = qᵐ⁻ᵏ
סכום n איברים (q ≠ 1)Sₙ = a₁(qⁿ − 1)/(q − 1)
כאשר q = 1Sₙ = n·a₁
תכונת האמצעaₙ² = aₙ₋₁·aₙ₊₁

מאיפה באה נוסחת הסכום? כותבים Sₙ = a₁ + a₁q + … + a₁qⁿ⁻¹, וכופלים ב־q: qSₙ = a₁q + … + a₁qⁿ. מחסרים: כמעט הכול מתבטל, ונשאר qSₙ − Sₙ = a₁qⁿ − a₁.

תכונת האמצע: שלושה מספרים x, y, z (שונים מ־0) הם סדרה הנדסית אם ורק אם y² = xz. כשנתונה מכפלת שלושה איברים עוקבים, נוח לסמן אותם a/q, a, aq, כי אז המכפלה היא a³.

חילוק במקום חיסור: בסדרה חשבונית מחסרים שני איברים כדי לבודד את d. בסדרה הנדסית מחלקים שני איברים כדי לבודד את q.

מציאת n: כשהנעלם נמצא במעריך (2ⁿ > 1000), פותרים בעזרת לוגריתם או בניסוי וטעייה מושכל, ותמיד בודקים את שני המספרים השלמים הסמוכים.

טעויות נפוצות: מ־q² = 9 יש שני פתרונות, q = ±3; מ־q³ = 8 יש רק אחד. לבלבל בין a₁qⁿ לבין a₁qⁿ⁻¹; בבעיות זמן לבדוק אם "אחרי n שנים" הוא האיבר ה־n או ה־(n+1).

רמה א׳: בסיס שאלות 1–10

שימוש ישיר בנוסחאות.

  1. מצאו את המנה ואת האיבר השמיני בסדרה 3, 6, 12, …
    הצג פתרון

    q = 2

    a₈ = 3·2⁷ = 384

  2. מצאו את האיבר השישי בסדרה 81, 27, 9, …
    הצג פתרון

    q = 1/3

    a₆ = 81·(1/3)⁵ = 81/243 = 1/3

  3. מצאו את המנה ואת האיבר החמישי בסדרה 2, −6, 18, …
    הצג פתרון

    q = −3

    a₅ = 2·(−3)⁴ = 162

  4. בסדרה הנדסית a₁ = 5, q = 2. חשבו את S₆.
    הצג פתרון

    S₆ = 5(2⁶ − 1)/(2 − 1) = 315

  5. חשבו את 1 + 3 + 9 + 27 + 81 בעזרת נוסחת הסכום.
    הצג פתרון

    S₅ = 1·(3⁵ − 1)/(3 − 1) = 242/2 = 121

  6. האם 1536 הוא איבר בסדרה 3, 6, 12, …?
    הצג פתרון

    3·2ⁿ⁻¹ = 1536 ⇒ 2ⁿ⁻¹ = 512 = 2⁹ ⇒ n = 10. כן, a₁₀ = 1536.

  7. בסדרה הנדסית a₃ = 12 ו־a₆ = 96. מצאו את q ואת a₁.
    הצג פתרון

    a₆/a₃ = q³ = 8 ⇒ q = 2

    a₁ = 12/q² = 3

  8. בסדרה הנדסית a₂ = 6 ו־a₄ = 54. מצאו את כל האפשרויות ל־q ול־a₁.
    הצג פתרון

    q² = 9 ⇒ q = ±3

    q = 3: a₁ = 2. q = −3: a₁ = −2.

  9. כמה איברים יש בסדרה 2, 4, 8, …, 1024?
    הצג פתרון

    2·2ⁿ⁻¹ = 2ⁿ = 1024 ⇒ n = 10

  10. חשבו את סכום 7 האיברים הראשונים בסדרה 64, 32, 16, …
    הצג פתרון

    S₇ = 64(1 − (1/2)⁷)/(1 − 1/2) = 128·(127/128) = 127

רמה ב׳: ביסוס שאלות 11–22

תכונת האמצע, שני נעלמים ובעיות גדילה ודעיכה.

  1. המספרים x, 6, x+5 הם סדרה הנדסית. מצאו את x ואת המנה.
    הצג פתרון

    36 = x(x+5) ⇒ x² + 5x − 36 = 0 ⇒ x = 4 או x = −9

    x = 4: 4, 6, 9, q = 3/2

    x = −9: −9, 6, −4, q = −2/3

  2. שלושה מספרים יוצרים סדרה הנדסית. מכפלתם 216 וסכומם 19. מצאו אותם.
    הצג פתרון

    נסמן 6/q, 6, 6q (כי a³ = 216 ⇒ a = 6).

    6/q + 6 + 6q = 19 ⇒ 6q² − 13q + 6 = 0 ⇒ q = 3/2 או q = 2/3

    המספרים: 4, 6, 9

  3. שבצו 3 מספרים בין 2 ל־162 כך שיתקבלו 5 איברים של סדרה הנדסית.
    הצג פתרון

    2q⁴ = 162 ⇒ q⁴ = 81 ⇒ q = ±3

    6, 18, 54 או −6, 18, −54

  4. כמה איברים מהסדרה 1, 2, 4, … יש לחבר כדי שהסכום יעלה על מיליון?
    הצג פתרון

    Sₙ = 2ⁿ − 1 > 1,000,000

    2¹⁹ = 524,288 לא מספיק; 2²⁰ = 1,048,576 מספיק. התשובה: 20.

  5. הפקידו 10,000 ₪ בריבית דריבית של 5% לשנה. כמה כסף יהיה בחשבון אחרי 8 שנים?
    הצג פתרון

    10000·1.05⁸ ≈ 10000·1.4775 ≈ 14,775 ₪

  6. רכב שווה 120,000 ₪ ומאבד 15% מערכו בכל שנה. אחרי כמה שנים ערכו יירד לראשונה מתחת ל־50,000 ₪?
    הצג פתרון

    120000·0.85ⁿ < 50000 ⇒ 0.85ⁿ < 0.4167

    אחרי 5 שנים: ≈ 53,244. אחרי 6 שנים: ≈ 45,257. התשובה: 6 שנים.

  7. בסדרה הנדסית q = 3 ו־S₃ = 26. מצאו את a₁.
    הצג פתרון

    a₁(1 + 3 + 9) = 26 ⇒ a₁ = 2

  8. חשבו את סכום האיברים מ־a₆ עד a₁₀ בסדרה 1, 2, 4, …
    הצג פתרון

    S₁₀ − S₅ = (2¹⁰ − 1) − (2⁵ − 1) = 1023 − 31 = 992

  9. בסדרה הנדסית חיובית a₁·a₅ = 36. מצאו את a₃.
    הצג פתרון

    a₁·a₅ = a₁²q⁴ = (a₁q²)² = a₃²

    a₃ = 6

  10. בסדרה הנדסית a₁ + a₂ = 12 ו־a₃ + a₄ = 108. מצאו את a₁ ואת q.
    הצג פתרון

    (a₃ + a₄)/(a₁ + a₂) = q² = 9 ⇒ q = ±3

    q = 3: 4a₁ = 12 ⇒ a₁ = 3

    q = −3: −2a₁ = 12 ⇒ a₁ = −6

  11. מושבת חיידקים מכפילה את עצמה כל 20 דקות. בהתחלה יש 50 חיידקים. כמה יהיו אחרי 3 שעות?
    הצג פתרון

    3 שעות = 9 הכפלות.

    50·2⁹ = 25,600 חיידקים

  12. כדור נופל מגובה 10 מ׳, ואחרי כל פגיעה בקרקע הוא קופץ ל־60% מהגובה הקודם. לאיזה גובה יגיע אחרי הקפיצה הרביעית?
    הצג פתרון

    10·0.6⁴ = 1.296 מ׳

רמה ג׳: רמת בגרות שאלות 23–30

שאלות רב־שלביות, הוכחות ושילובים.

  1. בסדרה הנדסית בת 10 איברים, סכום כל האיברים גדול פי 4 מסכום האיברים במקומות האי־זוגיים. מצאו את q.
    הצג פתרון

    נסמן ב־A את סכום האיברים במקומות האי־זוגיים. כל איבר זוגי שווה לאי־זוגי שלפניו כפול q, לכן סכום הזוגיים הוא qA.

    A + qA = 4A ⇒ 1 + q = 4 ⇒ q = 3

  2. בסדרה הנדסית S₃ = 7 ו־S₆ = 63. מצאו את a₁ ואת q.
    הצג פתרון

    S₆ = S₃ + q³S₃ ⇒ 63 = 7(1 + q³) ⇒ q³ = 8 ⇒ q = 2

    a₁(1 + 2 + 4) = 7 ⇒ a₁ = 1

  3. הוכיחו שמכפלת n האיברים הראשונים בסדרה הנדסית היא a₁ⁿ·q^(n(n−1)/2). חשבו את המכפלה עבור a₁ = 2, q = 2, n = 5.
    הצג פתרון

    a₁·a₁q·…·a₁qⁿ⁻¹ = a₁ⁿ·q^(0+1+…+(n−1)) = a₁ⁿ·q^(n(n−1)/2)

    2⁵·2¹⁰ = 2¹⁵ = 32,768

  4. נתון aₙ = 3·2ⁿ. מצאו נוסחה ל־Sₙ ואת n שעבורו Sₙ = 3066.
    הצג פתרון

    a₁ = 6, q = 2 ⇒ Sₙ = 6(2ⁿ − 1)

    6(2ⁿ − 1) = 3066 ⇒ 2ⁿ = 512 ⇒ n = 9

  5. המספרים a, b, c הם סדרה הנדסית עם q ≠ 1, והמספרים a, 2b, 3c הם סדרה חשבונית. מצאו את q.
    הצג פתרון

    4b = a + 3c ⇒ 4aq = a + 3aq²

    3q² − 4q + 1 = 0 ⇒ q = 1/3 (הפתרון q = 1 נפסל)

  6. בתחילת כל שנה, במשך 5 שנים, מפקידים 1000 ₪ בתוכנית חיסכון עם ריבית דריבית של 4% לשנה. כמה כסף יהיה בתוכנית בסוף השנה החמישית?
    הצג פתרון

    ההפקדה הראשונה צוברת ריבית 5 שנים, האחרונה שנה אחת:

    1000(1.04 + 1.04² + … + 1.04⁵) = 1000·1.04·(1.04⁵ − 1)/0.04 ≈ 5,633 ₪

  7. aₙ סדרה הנדסית. הוכיחו ש־bₙ = aₙ·aₙ₊₁ היא סדרה הנדסית ומצאו את מנתה. עבור a₁ = 1, q = 2 חשבו את סכום חמשת האיברים הראשונים של bₙ.
    הצג פתרון

    bₙ₊₁/bₙ = aₙ₊₂/aₙ = q²

    b₁ = 1·2 = 2, מנה 4: S₅ = 2(4⁵ − 1)/3 = 682

  8. שלושה איברים עוקבים בסדרה הנדסית: סכומם 14 וסכום ריבועיהם 84. מצאו אותם.
    הצג פתרון

    a(1 + q + q²) = 14, a²(1 + q² + q⁴) = 84

    משתמשים ב־1 + q² + q⁴ = (1 + q + q²)(1 − q + q²) ומחלקים: a(1 − q + q²) = 6

    מחסרים: 2aq = 8 ⇒ aq = 4 (האיבר האמצעי)

    a + aq² = 10 ו־a·aq² = 16 ⇒ האיברים הקיצוניים 2 ו־8

    התשובה: 2, 4, 8 (או 8, 4, 2)

הפתרונות מוסתרים כדי לאפשר תרגול עצמי. לחצו על "הצג פתרון" כדי לבדוק.
