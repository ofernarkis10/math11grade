פונקציות גידול ודעיכה

נתחיל מכמה מצבים מהחיים, נחשב בהם צעד אחר צעד, ונחפש מה משותף להם. רק אחרי זה נכתוב נוסחה כללית.

1. מתחילים מדוגמאות

עבודה במחברת: בכל דוגמה העתיקו את הטבלה למחברת והשלימו אותה בעזרת מחשבון – כל ערך מחושב מהערך שלפניו. כשיוצא מספר עשרוני, עגלו לשתי ספרות אחרי הנקודה רק את התוצאה הסופית שאתם רושמים (המשיכו לחשב מהערך המלא שבמחשבון). בסיום לחצו על "הצג ערכים" ובדקו את עצמכם.

3. הנוסחה הכללית

עכשיו אפשר לכתוב את מה שגילינו בצורה כללית. פונקציית גידול או דעיכה היא פונקציה מהצורה:

f(x) = a · bx , a ≠ 0 , b > 0 , b ≠ 1
  • a – הערך ההתחלתי (256, 10000, 80000, 200 בדוגמאות). מציבים x = 0: f(0) = a · b0 = a · 1 = a
  • b – הבסיס, המספר שמכפילים בו בכל צעד (1.5, 1.05, 0.85, 0.8 בדוגמאות): f(x + 1) = a · bx+1 = (a · bx) · b = f(x) · b f(x + 1) / f(x) = b
  • המשתנה x נמצא במעריך – זה מה שמבדיל אותה מפונקציה כמו x2, שבה x נמצא בבסיס.

למה דורשים b > 0 ו-b ≠ 1?

  • אם b = 1: f(x) = a · 1x = a – פונקציה קבועה, אין גידול ואין דעיכה.
  • אם b < 0: למשל (−2)1/2 אינו מוגדר, והסימן מתחלף בין חיובי לשלילי – זו לא פונקציה של גידול או דעיכה.

4. גידול או דעיכה? – תלוי בבסיס

גידול: כאשר b > 1 (ו-a > 0) – בכל צעד הערך גדל. הפונקציה עולה. (דולפינים, חיסכון)

דעיכה: כאשר 0 < b < 1 (ו-a > 0) – בכל צעד הערך קטן. הפונקציה יורדת, אבל לעולם לא מגיעה ל-0. (רכב, תרופה)

חיבור לאחוזים

כמו שראינו בדוגמאות – גידול של p% בכל צעד פירושו הכפלה ב-1 + p/100, ודעיכה של p% פירושה הכפלה ב-1 − p/100:

גידול: b = 1 + p/100 דעיכה: b = 1 − p/100
תיאור במיליםbסוג
מכפיל את עצמו בכל צעד2גידול
גדל ב-50% בכל שנה1.5גידול

5. הגרפים ותכונותיהם

תכונות הגרף של f(x) = a · bx כאשר a > 0:

  • תחום הגדרה: כל x.
  • טווח: y > 0 – הגרף כולו מעל ציר x.
  • נקודת חיתוך עם ציר y: (0, a).
  • אין חיתוך עם ציר x.
  • אסימפטוטה אופקית: y = 0 (בגידול – כאשר x → −∞; בדעיכה – כאשר x → +∞).
  • מונוטוניות: b > 1 – עולה בכל התחום; 0 < b < 1 – יורדת בכל התחום.
  • הגרפים של y = bx ו-y = (1/b)x סימטריים זה לזה ביחס לציר y, כי (1/b)x = b−x.

דוגמה 5 – חזרה לדולפינים: קפיצה ישר לשנה 8

מציבים t = 8 בפונקציה שמצאנו (חישוב ערך)
D(t) = a · bt D(8) = 256 · 1.58 D(8) = 256 · 25.62890625 D(8) = 6561

קיבלנו בחישוב אחד את אותה תוצאה שקיבלנו אחרי 8 הכפלות בטבלה.

דוגמה 6 – מציאת הפונקציה משתי נקודות

הפונקציה f(x) = a · bx עוברת בנקודות (0, 3) ו-(2, 48). מצאו את a ואת b, וקבעו אם זו פונקציית גידול או דעיכה.

מציבים את הנקודה (0, 3) כדי למצוא את a (מציאת פרמטר)
f(0) = a · b0 3 = a · 1 a = 3
מציבים את הנקודה (2, 48) ואת a = 3 כדי למצוא את b (מציאת פרמטר)
f(2) = a · b2 48 = 3 · b2 b2 = 16 b = 4

הפתרון b = −4 נפסל, כי בסיס חייב להיות חיובי.

כותבים את הפונקציה וקובעים את סוגה לפי הבסיס
f(x) = 3 · 4x

מכיוון ש-b = 4 > 1, זו פונקציית גידול.

דוגמה 7 – זיהוי מטבלה

לפניכם שתי טבלאות. קבעו לגבי כל אחת אם היא מתארת פונקציית גידול/דעיכה, ואם כן – מצאו את הפונקציה.

x0123

טבלה ב'25811
מחלקים כל ערך בערך שלפניו בטבלה א' כדי לבדוק אם מכפילים במספר קבוע (זיהוי פונקציה)
27 / 81 = 1/3 9 / 27 = 1/3 3 / 9 = 1/3

בכל צעד מכפילים ב-1/3, ולכן זו פונקציית דעיכה עם b = 1/3 ו-a = 81:

f(x) = a · bx f(x) = 81 · (1/3)x
מחלקים כל ערך בערך שלפניו בטבלה ב' כדי לבדוק אם מכפילים במספר קבוע (זיהוי פונקציה)
5 / 2 = 2.5 8 / 5 = 1.6

לא מכפילים במספר קבוע, ולכן זו לא פונקציית גידול/דעיכה. בודקים הפרשים:

5 − 2 = 3 , 8 − 5 = 3 , 11 − 8 = 3

מוסיפים מספר קבוע – זו פונקציה קווית:

g(x) = 2 + 3x

7. שיעור שני – שאלות מורכבות: השוואה בין שתי קבוצות

בשאלות האלה יש שתי קבוצות שגדלות בקצב שונה. נתחיל בטבלה – שנה אחרי שנה – ונראה מתי הקבוצות משתוות. אחר כך נכתוב את אותו שוויון כמשוואה, ונמצא את החזקה המתאימה בלי לבנות טבלה. בסיום לחצו על "הצג ערכים" ופתחו את השלבים לבדיקה.

8. סיכום

  • פונקציית גידול/דעיכה: f(x) = a · bx, עם b > 0, b ≠ 1.
  • a הוא הערך ההתחלתי, f(0) = a.
  • בכל צעד של 1 ב-x, הערך מוכפל ב-b.
  • b > 1 – גידול; 0 < b < 1 – דעיכה.
  • שינוי של p%: b = 1 ± p/100.
  • זיהוי מטבלה: מכפילים במספר קבוע ← גידול/דעיכה; מוסיפים מספר קבוע ← פונקציה קווית.
