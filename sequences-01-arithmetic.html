הסבר ונוסחאות

מה זו סדרה חשבונית? סדרה שבה כל איבר מתקבל מהאיבר הקודם על ידי הוספת אותו מספר קבוע. המספר הזה נקרא הפרש הסדרה ומסומן \(d\). למשל ב־\(5, 8, 11, 14, \ldots\) מוסיפים 3 בכל צעד, ולכן \(d = 3\).

המשמעות: סדרה חשבונית מתארת שינוי קבוע: אותה תוספת (או אותה הפחתה) בכל צעד. משכורת שעולה ב־200 ₪ בכל שנה, מושבים בתיאטרון שבכל שורה יש 2 יותר מבשורה הקודמת, מונית שמחייבת סכום קבוע לכל קילומטר. אם משרטטים את הנקודות \((n, a_{n})\), כולן נמצאות על קו ישר ששיפועו \(d\). לכן סדרה חשבונית היא "הגרסה הבדידה" של פונקציה קווית.

כיוון הסדרה: \(d \gt 0\) סדרה עולה, \(d \lt 0\) סדרה יורדת, \(d = 0\) סדרה קבועה.

הגדרה (כלל נסיגה)\(a_{n+1} = a_{n} + d\)
האיבר הכללי\(a_{n} = a_{1} + (n - 1)d\)
מעבר בין שני איברים\(a_{m} = a_{k} + (m - k)d\)
סכום n איברים\(S_{n} = \dfrac{n(a_{1} + a_{n})}{2}\)
סכום בלי האיבר האחרון\(S_{n} = \dfrac{n[2a_{1} + (n - 1)d]}{2}\)
תכונת האמצע\(2a_{n} = a_{n-1} + a_{n+1}\)

מאיפה באה נוסחת האיבר הכללי? כדי להגיע מ־\(a_{1}\) ל־\(a_{n}\) עושים \(n - 1\) צעדים, ובכל צעד מוסיפים \(d\). לכן מוסיפים בסך הכול \((n - 1)d\).

מאיפה באה נוסחת הסכום? (הרעיון של גאוס) כותבים את הסכום פעמיים, פעם מההתחלה ופעם מהסוף, ומחברים טור טור. כל זוג נותן את אותו סכום \(a_{1} + a_{n}\), ויש \(n\) זוגות, כלומר \(2S_{n} = n(a_{1} + a_{n})\).

תכונת האמצע: כל איבר הוא ממוצע שני שכניו. לכן שלושה מספרים \(x, y, z\) הם סדרה חשבונית אם ורק אם \(2y = x + z\). באופן כללי יותר, אם \(m + k = p + r\) אז \(a_{m} + a_{k} = a_{p} + a_{r}\).

שני נעלמים, שתי משוואות: כמעט כל שאלה מסתכמת במציאת \(a_{1}\) ו־\(d\). כל נתון (איבר, סכום, יחס) מתורגם למשוואה בשני הנעלמים האלה.

טיפ: כשנתונים שלושה איברים עוקבים עם סכום, נוח לסמן אותם \(a - d, a, a+d\). כך ה־\(d\) מתבטל בסכום.

טעויות נפוצות: לשכוח שמספר האיברים מ־\(a_{k}\) עד \(a_{m}\) הוא \(m - k+1\) ולא \(m - k\); לפתור \(S_{n}\) ולקבל \(n\) שאינו טבעי בלי לעגל ולבדוק; לבלבל בין "האיבר ה־n" לבין "סכום n איברים".

רמה א׳: בסיס שאלות 1–10

שימוש ישיר בנוסחת האיבר הכללי ובנוסחת הסכום.

  1. מצאו את ההפרש ואת האיבר העשירי בסדרה \(7, 11, 15, \ldots\)
    הצג פתרון

    \(d = 4\)

    \(a_{10} = 7 + 9 \cdot 4 = 43\)

    הסבר מפורט

    ההפרש \(d\) הוא המספר שמוסיפים בכל צעד. מחשבים אותו כאיבר פחות האיבר שלפניו: \(d = a_{2} - a_{1} = 11 - 7 = 4\). כדאי לבדוק גם זוג נוסף: \(15 - 11 = 4\), ולכן ההפרש באמת קבוע.

    כדי להגיע מ־\(a_{1}\) ל־\(a_{10}\) עושים \(10 - 1 = 9\) צעדים, ובכל צעד מוסיפים \(d\). זה בדיוק מה שאומרת הנוסחה \(a_{n} = a_{1} + (n-1)d\).

    מציבים \(n = 10\): \(a_{10} = 7 + 9 \cdot 4 = 7 + 36 = 43\).

  2. מצאו את האיבר ה־20 בסדרה \(50, 46, 42, \ldots\)
    הצג פתרון

    \(d = - 4\)

    \(a_{20} = 50 + 19 \cdot ( - 4) = - 26\)

    הסבר מפורט

    ההפרש: \(d = 46 - 50 = -4\). ההפרש שלילי, כלומר הסדרה יורדת, ובכל צעד מורידים 4.

    מ־\(a_{1}\) עד \(a_{20}\) יש 19 צעדים. לפי הנוסחה: \(a_{20} = a_{1} + 19d = 50 + 19 \cdot (-4)\).

    \(19 \cdot (-4) = -76\), ולכן \(a_{20} = 50 - 76 = -26\). התוצאה שלילית, וזה הגיוני: מתחילים ב־50 ויורדים 76.

  3. בסדרה חשבונית \(a_{1} = - 3\) ו־\(d = 5\). מצאו את \(a_{15}\).
    הצג פתרון

    \(a_{15} = - 3 + 14 \cdot 5 = 67\)

    הסבר מפורט

    נתונים האיבר הראשון וההפרש, וזה כל מה שצריך כדי לחשב כל איבר.

    מציבים בנוסחת האיבר הכללי \(n = 15\): \(a_{15} = a_{1} + 14d\). מוסיפים 14 פעמים את ההפרש, לא 15, כי הצעד הראשון מתחיל כבר ב־\(a_{1}\).

    \(a_{15} = -3 + 14 \cdot 5 = -3 + 70 = 67\).

  4. האם 100 הוא איבר בסדרה \(4, 10, 16, \ldots\)? אם כן, באיזה מקום?
    הצג פתרון

    \(a_{n} = 4 + 6(n - 1) = 6n - 2\)

    \(6n - 2 = 100 \Rightarrow n = 17\). כן, \(a_{17} = 100\).

    הסבר מפורט

    מספר הוא איבר בסדרה אם יש מספר טבעי \(n\) שעבורו \(a_{n}\) שווה לו. לכן בונים קודם נוסחה ל־\(a_{n}\).

    \(a_{1} = 4\), \(d = 6\), ולכן \(a_{n} = 4 + 6(n-1) = 6n - 2\).

    פותרים \(6n - 2 = 100\): \(6n = 102\), ו־\(n = 17\). זה מספר טבעי, ולכן 100 הוא האיבר ה־17.

    בדיקה: \(a_{17} = 4 + 16 \cdot 6 = 100\).

  5. האם 200 הוא איבר בסדרה \(5, 12, 19, \ldots\)?
    הצג פתרון

    \(a_{n} = 7n - 2 = 200 \Rightarrow n = \dfrac{202}{7} \approx 28.86\)

    n אינו טבעי, לכן 200 אינו איבר בסדרה (\(a_{28} = 194\), \(a_{29} = 201\)).

    הסבר מפורט

    כמו בשאלה הקודמת, בונים נוסחה: \(a_{1} = 5\), \(d = 7\), ולכן \(a_{n} = 5 + 7(n-1) = 7n - 2\).

    פותרים \(7n - 2 = 200\): \(7n = 202\), ו־\(n = \dfrac{202}{7} \approx 28.86\).

    \(n\) אינו מספר טבעי. אין "איבר מספר 28.86", ולכן 200 אינו איבר בסדרה.

    אפשר לראות את זה גם כך: \(a_{28} = 194\) ו־\(a_{29} = 201\). הסדרה "קופצת" מעל 200 ולא נוחתת עליו.

  6. חשבו את סכום 30 האיברים הראשונים בסדרה \(2, 5, 8, \ldots\)
    הצג פתרון

    \(a_{30} = 2 + 29 \cdot 3 = 89\)

    \(S_{30} = \dfrac{30(2 + 89)}{2} = 1365\)

    הסבר מפורט

    כדי להשתמש בנוסחה \(S_{n} = \dfrac{n(a_{1} + a_{n})}{2}\) צריך את האיבר האחרון, \(a_{30}\).

    \(d = 3\), ולכן \(a_{30} = 2 + 29 \cdot 3 = 89\).

    \(S_{30} = \dfrac{30 \cdot (2 + 89)}{2} = 15 \cdot 91 = 1365\).

    הרעיון מאחורי הנוסחה: מחברים את הראשון עם האחרון, את השני עם הלפני אחרון וכן הלאה. כל זוג נותן 91, ויש 15 זוגות.

  7. חשבו את הסכום \(1 + 2 + 3 + \ldots + 100\).
    הצג פתרון

    \(S_{100} = \dfrac{100(1 + 100)}{2} = 5050\)

    הסבר מפורט

    זו סדרה חשבונית עם \(a_{1} = 1\), \(d = 1\) ו־100 איברים. האיבר האחרון הוא \(a_{100} = 100\).

    \(S_{100} = \dfrac{100 \cdot (1 + 100)}{2} = 50 \cdot 101 = 5050\).

    זה התרגיל המפורסם שגאוס פתר כילד: \(1 + 100 = 2 + 99 = \ldots = 101\), ויש 50 זוגות כאלה.

  8. כמה איברים יש בסדרה \(12, 17, 22, \ldots , 247\)?
    הצג פתרון

    \(247 = 12 + 5(n - 1) \Rightarrow n - 1 = 47 \Rightarrow n = 48\)

    הסבר מפורט

    כשהשאלה היא "כמה איברים", הנעלם הוא \(n\). האיבר האחרון ידוע: \(a_{n} = 247\).

    \(a_{1} = 12\), \(d = 5\). מציבים: \(12 + 5(n-1) = 247\).

    \(5(n-1) = 235\), כלומר \(n - 1 = 47\), ו־\(n = 48\).

    שימו לב: \(n - 1 = 47\) הוא מספר הצעדים. מספר האיברים גדול ממנו ב־1.

  9. בסדרה חשבונית \(a_{3} = 10\) ו־\(a_{7} = 26\). מצאו את \(d\) ואת \(a_{1}\).
    הצג פתרון

    \(a_{7} - a_{3} = 4d = 16 \Rightarrow d = 4\)

    \(a_{1} = a_{3} - 2d = 2\)

    הסבר מפורט

    שני איברים נתונים ושני נעלמים (\(a_{1}\) ו־\(d\)). הדרך הקצרה: ההפרש בין שני איברים שווה למספר הצעדים ביניהם כפול \(d\).

    מ־\(a_{3}\) עד \(a_{7}\) יש 4 צעדים: \(a_{7} - a_{3} = 4d\), כלומר \(26 - 10 = 16 = 4d\), ו־\(d = 4\).

    כדי למצוא את \(a_{1}\) חוזרים מ־\(a_{3}\) שני צעדים אחורה: \(a_{1} = a_{3} - 2d = 10 - 8 = 2\).

    בדיקה: \(a_{7} = 2 + 6 \cdot 4 = 26\) ✓

  10. בסדרה חשבונית \(a_{1} = 8\) ו־\(a_{20} = 65\). מצאו את \(d\) ואת \(S_{20}\).
    הצג פתרון

    \(19d = 57 \Rightarrow d = 3\)

    \(S_{20} = \dfrac{20(8 + 65)}{2} = 730\)

    הסבר מפורט

    מ־\(a_{1}\) עד \(a_{20}\) יש 19 צעדים: \(a_{20} - a_{1} = 19d\), כלומר \(65 - 8 = 57 = 19d\), ו־\(d = 3\).

    לסכום יש כבר את כל מה שצריך, האיבר הראשון והאחרון: \(S_{20} = \dfrac{20(8 + 65)}{2} = 10 \cdot 73 = 730\).

    לא היינו צריכים את \(d\) בשביל הסכום. מכיוון ש־\(a_{20}\) נתון, הנוסחה \(\dfrac{n(a_{1}+a_{n})}{2}\) היא הקצרה ביותר.

רמה ב׳: ביסוס שאלות 11–22

שאלות של שני נעלמים, תכונת האמצע ובעיות מילוליות.

  1. חשבו את סכום כל המספרים האי־זוגיים מ־1 עד 99.
    הצג פתרון

    יש 50 איברים: \(S = \dfrac{50(1 + 99)}{2} = 2500\) (וגם \(= 50^{2}\)).

    הסבר מפורט

    המספרים האי־זוגיים \(1, 3, 5, \ldots, 99\) הם סדרה חשבונית עם \(d = 2\).

    כמה איברים יש? \(1 + 2(n-1) = 99\), כלומר \(n = 50\). אפשר גם לחשוב כך: בין 1 ל־100 חצי מהמספרים אי־זוגיים.

    \(S_{50} = \dfrac{50 \cdot (1 + 99)}{2} = 2500\).

    שימו לב שיצא \(50^{2}\). זה לא מקרה: סכום \(n\) המספרים האי־זוגיים הראשונים הוא תמיד \(n^{2}\).

  2. חשבו את סכום כל המספרים התלת־ספרתיים המתחלקים ב־9.
    הצג פתרון

    \(108, 117, \ldots , 999\)

    \(n = \dfrac{999 - 108}{9} + 1 = 100\)

    \(S = \dfrac{100(108 + 999)}{2} = 55350\)

    הסבר מפורט

    צריך למצוא את המספר התלת־ספרתי הראשון והאחרון שמתחלקים ב־9.

    הראשון: \(100 : 9 \approx 11.1\), ולכן הכפולה הראשונה היא \(9 \cdot 12 = 108\). האחרון: \(999 = 9 \cdot 111\).

    זו סדרה חשבונית עם \(d = 9\). מספר האיברים: \(\dfrac{999 - 108}{9} + 1 = 99 + 1 = 100\) (מספר הצעדים ועוד 1).

    \(S = \dfrac{100(108 + 999)}{2} = 50 \cdot 1107 = 55350\).

  3. חשבו את סכום כל המספרים הדו־ספרתיים שאינם מתחלקים ב־3.
    הצג פתרון

    סכום כל הדו־ספרתיים: \(\dfrac{90(10 + 99)}{2} = 4905\)

    המתחלקים ב־3: \(12, \ldots , 99\), 30 איברים, סכום \(\dfrac{30(12 + 99)}{2} = 1665\)

    התשובה: \(4905 - 1665 = 3240\)

    הסבר מפורט

    קשה לסכום ישירות את המספרים שאינם מתחלקים ב־3. במקום זה: סכום כל הדו־ספרתיים, פחות סכום אלה שכן מתחלקים ב־3.

    כל הדו־ספרתיים: \(10, \ldots, 99\), כלומר 90 איברים. סכומם \(\dfrac{90(10 + 99)}{2} = 4905\).

    המתחלקים ב־3: \(12, 15, \ldots, 99\). מספר האיברים: \(\dfrac{99 - 12}{3} + 1 = 30\). סכומם \(\dfrac{30(12 + 99)}{2} = 1665\).

    התשובה: \(4905 - 1665 = 3240\).

  4. המספרים \(x+2, 3x - 1, 4x+2\) הם איברים עוקבים בסדרה חשבונית. מצאו את x ואת האיברים.
    הצג פתרון

    \(2(3x - 1) = (x+2) + (4x+2)\)

    \(6x - 2 = 5x + 4 \Rightarrow x = 6\)

    האיברים: \(8, 17, 26\)

    הסבר מפורט

    שלושה מספרים הם איברים עוקבים בסדרה חשבונית בדיוק כאשר האמצעי הוא הממוצע של שכניו: פעמיים האיבר האמצעי שווה לסכום הראשון והשלישי.

    מציבים: \(2(3x - 1) = (x + 2) + (4x + 2)\), כלומר \(6x - 2 = 5x + 4\), ומכאן \(x = 6\).

    האיברים: \(x + 2 = 8\), \(3x - 1 = 17\), \(4x + 2 = 26\).

    בדיקה: \(17 - 8 = 9\) ו־\(26 - 17 = 9\). ההפרש קבוע ✓

  5. שלושה מספרים יוצרים סדרה חשבונית. סכומם 21 ומכפלתם 231. מצאו אותם.
    הצג פתרון

    נסמן \(7 - d, 7, 7+d\) (כי \(3 \cdot 7 = 21\)).

    \(7(49 - d^{2}) = 231 \Rightarrow d^{2} = 16 \Rightarrow d = \pm 4\)

    המספרים: \(3, 7, 11\) (או בסדר הפוך).

    הסבר מפורט

    כשנתון הסכום של שלושה איברים עוקבים, נוח לסמן אותם \(a - d,\ a,\ a + d\). בסכום ה־\(d\) מתבטל: \(3a = 21\), ולכן \(a = 7\).

    המכפלה: \((7 - d) \cdot 7 \cdot (7 + d) = 231\). מחלקים ב־7: \((7 - d)(7 + d) = 33\).

    זה הפרש ריבועים: \(49 - d^{2} = 33\), ולכן \(d^{2} = 16\) ו־\(d = \pm 4\).

    \(d = 4\) נותן \(3, 7, 11\), ו־\(d = -4\) נותן \(11, 7, 3\). אלה אותם מספרים בסדר הפוך. בדיקה: \(3 \cdot 7 \cdot 11 = 231\) ✓

  6. בסדרה חשבונית \(a_{1} = 1\) ו־\(S_{10} = 145\). מצאו את \(d\).
    הצג פתרון

    \(145 = \dfrac{10(2 + 9d)}{2} = 5(2 + 9d)\)

    \(2 + 9d = 29 \Rightarrow d = 3\)

    הסבר מפורט

    \(a_{n}\) לא ידוע, ולכן משתמשים בצורה השנייה של נוסחת הסכום: \(S_{n} = \dfrac{n[2a_{1} + (n-1)d]}{2}\).

    מציבים \(n = 10\), \(a_{1} = 1\): \(145 = \dfrac{10(2 + 9d)}{2} = 5(2 + 9d)\).

    מחלקים ב־5: \(2 + 9d = 29\), ולכן \(9d = 27\) ו־\(d = 3\).

    בדיקה: \(a_{10} = 1 + 27 = 28\), ו־\(\dfrac{10(1 + 28)}{2} = 145\) ✓

  7. בסדרה חשבונית \(a_{1} = 40\), \(d = - 3\). מהו הסכום הגדול ביותר של איברים ראשונים, ועבור איזה n מתקבל?
    הצג פתרון

    הסכום גדל כל עוד מוסיפים איברים חיוביים.

    \(40 - 3(n - 1) \gt 0 \Rightarrow n \lt 14.33\), כלומר \(a_{14} = 1\) האחרון החיובי.

    \(S_{14} = \dfrac{14(40 + 1)}{2} = 287\)

    הסבר מפורט

    הסדרה יורדת (\(d = -3\)). בהתחלה האיברים חיוביים, ולכן הסכום גדל. מהרגע שהאיברים נעשים שליליים, כל איבר נוסף מקטין את הסכום.

    לכן הסכום המקסימלי מתקבל כשמחברים את כל האיברים החיוביים ועוצרים לפני השלילי הראשון.

    \(a_{n} = 40 - 3(n-1) > 0\) נותן \(n < 14.33\). כלומר \(a_{14} = 40 - 39 = 1\) הוא האחרון החיובי, ו־\(a_{15} = -2\) כבר שלילי.

    \(S_{14} = \dfrac{14(40 + 1)}{2} = 7 \cdot 41 = 287\).

  8. כמה איברים מהסדרה \(3, 7, 11, \ldots\) יש לחבר כדי לקבל סכום 465?
    הצג פתרון

    \(S_{n} = \dfrac{n[6 + 4(n - 1)]}{2} = n(2n + 1)\)

    \(2n^{2} + n - 465 = 0 \Rightarrow n = \dfrac{- 1 + 61}{4} = 15\)

    הסבר מפורט

    הנעלם הוא מספר האיברים \(n\). כותבים את \(S_{n}\) כביטוי ב־\(n\): \(a_{1} = 3\), \(d = 4\).

    \(S_{n} = \dfrac{n[6 + 4(n-1)]}{2} = \dfrac{n(4n + 2)}{2} = n(2n + 1)\).

    משווים ל־465: \(2n^{2} + n - 465 = 0\). בנוסחת השורשים: \(n = \dfrac{-1 \pm \sqrt{1 + 3720}}{4} = \dfrac{-1 \pm 61}{4}\).

    הפתרון החיובי הוא \(n = 15\), והשלילי נפסל, כי מספר איברים חייב להיות טבעי. בדיקה: \(15 \cdot 31 = 465\) ✓

  9. בסדרה חשבונית \(a_{2} + a_{8} = 34\) ו־\(a_{3} = 11\). מצאו את \(a_{5}\) ואת \(d\).
    הצג פתרון

    \(2 + 8 = 5 + 5\), לכן \(a_{2} + a_{8} = 2a_{5} \Rightarrow a_{5} = 17\)

    \(a_{5} - a_{3} = 2d = 6 \Rightarrow d = 3\)

    הסבר מפורט

    תכונה שימושית: אם סכום המקומות שווה, גם סכום האיברים שווה. כאן \(2 + 8 = 5 + 5\), ולכן \(a_{2} + a_{8} = a_{5} + a_{5} = 2a_{5}\).

    למה? \(a_{2} = a_{5} - 3d\) ו־\(a_{8} = a_{5} + 3d\), וה־\(3d\) מתבטלים בחיבור.

    לכן \(2a_{5} = 34\), ו־\(a_{5} = 17\).

    מ־\(a_{3}\) ל־\(a_{5}\) יש 2 צעדים: \(2d = 17 - 11 = 6\), ולכן \(d = 3\).

  10. בסדרה חשבונית בת 20 איברים \(a_{1} + a_{20} = 50\). מצאו את סכום הסדרה ואת \(a_{5} + a_{16}\).
    הצג פתרון

    \(S_{20} = \dfrac{20 \cdot 50}{2} = 500\)

    \(5 + 16 = 1 + 20\), לכן \(a_{5} + a_{16} = 50\)

    הסבר מפורט

    הסכום תלוי רק ב־\(a_{1} + a_{20}\), וזה נתון: \(S_{20} = \dfrac{20 \cdot 50}{2} = 500\).

    עבור \(a_{5} + a_{16}\) משתמשים באותה תכונה: \(5 + 16 = 21 = 1 + 20\), ולכן \(a_{5} + a_{16} = a_{1} + a_{20} = 50\).

    שימו לב שלא מצאנו את \(a_{1}\) ולא את \(d\), ולא היינו צריכים אותם.

  11. שבצו 5 מספרים בין 4 ל־40 כך שיתקבלו 7 איברים של סדרה חשבונית.
    הצג פתרון

    \(a_{7} = 4 + 6d = 40 \Rightarrow d = 6\)

    המספרים: \(10, 16, 22, 28, 34\)

    הסבר מפורט

    "לשבץ 5 מספרים" פירושו שהסדרה מתחילה ב־4, אחריה 5 מספרים חדשים, ובסוף 40. סך הכול 7 איברים: \(a_{1} = 4\), \(a_{7} = 40\).

    מ־\(a_{1}\) ל־\(a_{7}\) יש 6 צעדים: \(6d = 40 - 4 = 36\), ולכן \(d = 6\).

    המספרים המשובצים: \(10, 16, 22, 28, 34\). בדיקה: \(34 + 6 = 40\) ✓

  12. נתון \(a_{n} = 3n + 2\). חשבו את סכום האיברים מ־\(a_{11}\) עד \(a_{20}\).
    הצג פתרון

    \(a_{11} = 35\), \(a_{20} = 62\), ויש 10 איברים.

    \(S = \dfrac{10(35 + 62)}{2} = 485\)

    הסבר מפורט

    הנוסחה \(a_{n} = 3n + 2\) לינארית ב־\(n\), ולכן הסדרה חשבונית (\(d = 3\)). אז גם כל קטע ממנה הוא סדרה חשבונית.

    מחשבים את הקצוות: \(a_{11} = 35\), \(a_{20} = 62\). מספר האיברים מ־11 עד 20 הוא \(20 - 11 + 1 = 10\).

    \(S = \dfrac{10(35 + 62)}{2} = 485\).

    דרך אחרת: \(S_{20} - S_{10} = 670 - 185 = 485\). גם כך יוצא אותו דבר.

רמה ג׳: רמת בגרות שאלות 23–30

שאלות רב־שלביות, הוכחות ושילובים.

  1. בסדרה חשבונית \(S_{5} = 40\) ו־\(S_{10} = 155\). מצאו את \(a_{1}\) ואת \(d\).
    הצג פתרון

    \(\dfrac{5(2a_{1} + 4d)}{2} = 40 \Rightarrow a_{1} + 2d = 8\)

    \(\dfrac{10(2a_{1} + 9d)}{2} = 155 \Rightarrow 2a_{1} + 9d = 31\)

    מציבים \(a_{1} = 8 - 2d\): \(16 + 5d = 31 \Rightarrow d = 3\), \(a_{1} = 2\)

  2. בסדרה חשבונית בת 20 איברים, סכום האיברים במקומות האי־זוגיים הוא 210 וסכום האיברים במקומות הזוגיים הוא 240. מצאו את \(a_{1}\) ואת \(d\).
    הצג פתרון

    כל איבר זוגי גדול ב־d מהאי־זוגי שלפניו, ויש 10 זוגות: \(10d = 240 - 210 \Rightarrow d = 3\)

    האיברים האי־זוגיים יוצרים סדרה חשבונית עם הפרש \(2d = 6\): \(\dfrac{10(2a_{1} + 9 \cdot 6)}{2} = 210 \Rightarrow a_{1} = - 6\)

  3. הוכיחו שבכל סדרה חשבונית \(S_{n} = An^{2} + Bn\) (A, B קבועים). מצאו את הסדרה שבה \(S_{n} = 2n^{2} - 5n\).
    הצג פתרון

    \(S_{n} = \dfrac{d}{2}n^{2} + \left(a_{1} - \dfrac{d}{2}\right)n\), כלומר \(A = \dfrac{d}{2}\), \(B = a_{1} - \dfrac{d}{2}\).

    כאן \(d = 4\), \(a_{1} = B + \dfrac{d}{2} = - 5 + 2 = - 3\)

    \(a_{n} = 4n - 7\)

  4. דן חוסך 100 ₪ בחודש הראשון, ובכל חודש הוא חוסך 20 ₪ יותר מבחודש הקודם. אחרי כמה חודשים יגיע החיסכון הכולל ל־5000 ₪ לפחות?
    הצג פתרון

    \(S_{n} = \dfrac{n[200 + 20(n - 1)]}{2} = 10n^{2} + 90n \ge 5000\)

    \(n^{2} + 9n - 500 \ge 0 \Rightarrow n \ge 18.31\)

    בדיקה: \(S_{18} = 4860\), \(S_{19} = 5320\). התשובה: 19 חודשים.

  5. אורכי הצלעות של משולש ישר־זווית יוצרים סדרה חשבונית עם הפרש 2. מצאו אותם.
    הצג פתרון

    \((a - 2)^{2} + a^{2} = (a+2)^{2} \Rightarrow a^{2} - 8a = 0 \Rightarrow a = 8\)

    הצלעות: \(6, 8, 10\)

  6. נתונות הסדרות \(5, 9, 13, \ldots\) ו־\(3, 10, 17, \ldots\), כל אחת עם 100 איברים. כמה איברים משותפים יש להן?
    הצג פתרון

    הראשונה: \(4n + 1\) עד 401. השנייה: \(7m - 4\) עד 696.

    האיבר המשותף הראשון הוא 17, והמשותפים יוצרים סדרה חשבונית עם הפרש \(4 \cdot 7 = 28\).

    \(17 + 28(k - 1) \le 401 \Rightarrow k \le 14.7\). יש 14 איברים משותפים.

  7. בסדרה חשבונית בת 15 איברים סכום הסדרה 255. מצאו את האיבר האמצעי. הסבירו מדוע ניתן למצוא אותו בלי לדעת את \(a_{1}\) ו־\(d\).
    הצג פתרון

    \(S_{15} = \dfrac{15(a_{1} + a_{15})}{2} = 15 \cdot a_{8}\), כי \(a_{1} + a_{15} = 2a_{8}\).

    \(a_{8} = \dfrac{255}{15} = 17\)

  8. בסדרה חשבונית לא קבועה, האיברים \(a_{1}, a_{3}, a_{9}\) יוצרים סדרה הנדסית. מצאו את היחס \(\dfrac{a_{1} + a_{3} + a_{9}}{a_{2} + a_{4} + a_{10}}\).
    הצג פתרון

    \((a_{1} + 2d)^{2} = a_{1}(a_{1} + 8d) \Rightarrow 4d^{2} = 4a_{1}d \Rightarrow a_{1} = d\) (כי \(d \neq 0\))

    לכן \(a_{n} = nd\), והיחס: \(\dfrac{1 + 3 + 9}{2 + 4 + 10} = \dfrac{13}{16}\)

הפתרונות מוסתרים כדי לאפשר תרגול עצמי. לחצו על "הצג פתרון" כדי לבדוק.
