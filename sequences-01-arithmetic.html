הסבר ונוסחאות

מה זו סדרה חשבונית? סדרה שבה כל איבר מתקבל מהאיבר הקודם על ידי הוספת אותו מספר קבוע. המספר הזה נקרא הפרש הסדרה ומסומן d. למשל ב־5, 8, 11, 14, … מוסיפים 3 בכל צעד, ולכן d = 3.

המשמעות: סדרה חשבונית מתארת שינוי קבוע: אותה תוספת (או אותה הפחתה) בכל צעד. משכורת שעולה ב־200 ₪ בכל שנה, מושבים בתיאטרון שבכל שורה יש 2 יותר מבשורה הקודמת, מונית שמחייבת סכום קבוע לכל קילומטר. אם משרטטים את הנקודות (n, aₙ), כולן נמצאות על קו ישר ששיפועו d. לכן סדרה חשבונית היא "הגרסה הבדידה" של פונקציה קווית.

כיוון הסדרה: d > 0 סדרה עולה, d < 0 סדרה יורדת, d = 0 סדרה קבועה.

הגדרה (כלל נסיגה)aₙ₊₁ = aₙ + d
האיבר הכלליaₙ = a₁ + (n−1)d
מעבר בין שני איבריםaₘ = aₖ + (m−k)d
סכום n איבריםSₙ = n(a₁ + aₙ)/2
סכום בלי האיבר האחרוןSₙ = n[2a₁ + (n−1)d]/2
תכונת האמצע2aₙ = aₙ₋₁ + aₙ₊₁

מאיפה באה נוסחת האיבר הכללי? כדי להגיע מ־a₁ ל־aₙ עושים n−1 צעדים, ובכל צעד מוסיפים d. לכן מוסיפים בסך הכול (n−1)d.

מאיפה באה נוסחת הסכום? (הרעיון של גאוס) כותבים את הסכום פעמיים, פעם מההתחלה ופעם מהסוף, ומחברים טור טור. כל זוג נותן את אותו סכום a₁ + aₙ, ויש n זוגות, כלומר 2Sₙ = n(a₁ + aₙ).

תכונת האמצע: כל איבר הוא ממוצע שני שכניו. לכן שלושה מספרים x, y, z הם סדרה חשבונית אם ורק אם 2y = x + z. באופן כללי יותר, אם m + k = p + r אז aₘ + aₖ = aₚ + aᵣ.

שני נעלמים, שתי משוואות: כמעט כל שאלה מסתכמת במציאת a₁ ו־d. כל נתון (איבר, סכום, יחס) מתורגם למשוואה בשני הנעלמים האלה.

טיפ: כשנתונים שלושה איברים עוקבים עם סכום, נוח לסמן אותם a−d, a, a+d. כך ה־d מתבטל בסכום.

טעויות נפוצות: לשכוח שמספר האיברים מ־aₖ עד aₘ הוא m−k+1 ולא m−k; לפתור Sₙ ולקבל n שאינו טבעי בלי לעגל ולבדוק; לבלבל בין "האיבר ה־n" לבין "סכום n איברים".

רמה א׳: בסיס שאלות 1–10

שימוש ישיר בנוסחת האיבר הכללי ובנוסחת הסכום.

  1. מצאו את ההפרש ואת האיבר העשירי בסדרה 7, 11, 15, …
    הצג פתרון

    d = 4

    a₁₀ = 7 + 9·4 = 43

  2. מצאו את האיבר ה־20 בסדרה 50, 46, 42, …
    הצג פתרון

    d = −4

    a₂₀ = 50 + 19·(−4) = −26

  3. בסדרה חשבונית a₁ = −3 ו־d = 5. מצאו את a₁₅.
    הצג פתרון

    a₁₅ = −3 + 14·5 = 67

  4. האם 100 הוא איבר בסדרה 4, 10, 16, …? אם כן, באיזה מקום?
    הצג פתרון

    aₙ = 4 + 6(n−1) = 6n − 2

    6n − 2 = 100 ⇒ n = 17. כן, a₁₇ = 100.

  5. האם 200 הוא איבר בסדרה 5, 12, 19, …?
    הצג פתרון

    aₙ = 7n − 2 = 200 ⇒ n = 202/7 ≈ 28.86

    n אינו טבעי, לכן 200 אינו איבר בסדרה (a₂₈ = 194, a₂₉ = 201).

  6. חשבו את סכום 30 האיברים הראשונים בסדרה 2, 5, 8, …
    הצג פתרון

    a₃₀ = 2 + 29·3 = 89

    S₃₀ = 30(2 + 89)/2 = 1365

  7. חשבו את הסכום 1 + 2 + 3 + … + 100.
    הצג פתרון

    S₁₀₀ = 100(1 + 100)/2 = 5050

  8. כמה איברים יש בסדרה 12, 17, 22, …, 247?
    הצג פתרון

    247 = 12 + 5(n−1) ⇒ n − 1 = 47 ⇒ n = 48

  9. בסדרה חשבונית a₃ = 10 ו־a₇ = 26. מצאו את d ואת a₁.
    הצג פתרון

    a₇ − a₃ = 4d = 16 ⇒ d = 4

    a₁ = a₃ − 2d = 2

  10. בסדרה חשבונית a₁ = 8 ו־a₂₀ = 65. מצאו את d ואת S₂₀.
    הצג פתרון

    19d = 57 ⇒ d = 3

    S₂₀ = 20(8 + 65)/2 = 730

רמה ב׳: ביסוס שאלות 11–22

שאלות של שני נעלמים, תכונת האמצע ובעיות מילוליות.

  1. חשבו את סכום כל המספרים האי־זוגיים מ־1 עד 99.
    הצג פתרון

    יש 50 איברים: S = 50(1 + 99)/2 = 2500 (וגם = 50²).

  2. חשבו את סכום כל המספרים התלת־ספרתיים המתחלקים ב־9.
    הצג פתרון

    108, 117, …, 999

    n = (999 − 108)/9 + 1 = 100

    S = 100(108 + 999)/2 = 55350

  3. חשבו את סכום כל המספרים הדו־ספרתיים שאינם מתחלקים ב־3.
    הצג פתרון

    סכום כל הדו־ספרתיים: 90(10 + 99)/2 = 4905

    המתחלקים ב־3: 12, …, 99, 30 איברים, סכום 30(12 + 99)/2 = 1665

    התשובה: 4905 − 1665 = 3240

  4. המספרים x+2, 3x−1, 4x+2 הם איברים עוקבים בסדרה חשבונית. מצאו את x ואת האיברים.
    הצג פתרון

    2(3x−1) = (x+2) + (4x+2)

    6x − 2 = 5x + 4 ⇒ x = 6

    האיברים: 8, 17, 26

  5. שלושה מספרים יוצרים סדרה חשבונית. סכומם 21 ומכפלתם 231. מצאו אותם.
    הצג פתרון

    נסמן 7−d, 7, 7+d (כי 3·7 = 21).

    7(49 − d²) = 231 ⇒ d² = 16 ⇒ d = ±4

    המספרים: 3, 7, 11 (או בסדר הפוך).

  6. בסדרה חשבונית a₁ = 1 ו־S₁₀ = 145. מצאו את d.
    הצג פתרון

    145 = 10(2 + 9d)/2 = 5(2 + 9d)

    2 + 9d = 29 ⇒ d = 3

  7. בסדרה חשבונית a₁ = 40, d = −3. מהו הסכום הגדול ביותר של איברים ראשונים, ועבור איזה n מתקבל?
    הצג פתרון

    הסכום גדל כל עוד מוסיפים איברים חיוביים.

    40 − 3(n−1) > 0 ⇒ n < 14.33, כלומר a₁₄ = 1 האחרון החיובי.

    S₁₄ = 14(40 + 1)/2 = 287

  8. כמה איברים מהסדרה 3, 7, 11, … יש לחבר כדי לקבל סכום 465?
    הצג פתרון

    Sₙ = n[6 + 4(n−1)]/2 = n(2n + 1)

    2n² + n − 465 = 0 ⇒ n = (−1 + 61)/4 = 15

  9. בסדרה חשבונית a₂ + a₈ = 34 ו־a₃ = 11. מצאו את a₅ ואת d.
    הצג פתרון

    2 + 8 = 5 + 5, לכן a₂ + a₈ = 2a₅ ⇒ a₅ = 17

    a₅ − a₃ = 2d = 6 ⇒ d = 3

  10. בסדרה חשבונית בת 20 איברים a₁ + a₂₀ = 50. מצאו את סכום הסדרה ואת a₅ + a₁₆.
    הצג פתרון

    S₂₀ = 20·50/2 = 500

    5 + 16 = 1 + 20, לכן a₅ + a₁₆ = 50

  11. שבצו 5 מספרים בין 4 ל־40 כך שיתקבלו 7 איברים של סדרה חשבונית.
    הצג פתרון

    a₇ = 4 + 6d = 40 ⇒ d = 6

    המספרים: 10, 16, 22, 28, 34

  12. נתון aₙ = 3n + 2. חשבו את סכום האיברים מ־a₁₁ עד a₂₀.
    הצג פתרון

    a₁₁ = 35, a₂₀ = 62, ויש 10 איברים.

    S = 10(35 + 62)/2 = 485

רמה ג׳: רמת בגרות שאלות 23–30

שאלות רב־שלביות, הוכחות ושילובים.

  1. בסדרה חשבונית S₅ = 40 ו־S₁₀ = 155. מצאו את a₁ ואת d.
    הצג פתרון

    5(2a₁ + 4d)/2 = 40 ⇒ a₁ + 2d = 8

    10(2a₁ + 9d)/2 = 155 ⇒ 2a₁ + 9d = 31

    מציבים a₁ = 8 − 2d: 16 + 5d = 31 ⇒ d = 3, a₁ = 2

  2. בסדרה חשבונית בת 20 איברים, סכום האיברים במקומות האי־זוגיים הוא 210 וסכום האיברים במקומות הזוגיים הוא 240. מצאו את a₁ ואת d.
    הצג פתרון

    כל איבר זוגי גדול ב־d מהאי־זוגי שלפניו, ויש 10 זוגות: 10d = 240 − 210 ⇒ d = 3

    האיברים האי־זוגיים יוצרים סדרה חשבונית עם הפרש 2d = 6: 10(2a₁ + 9·6)/2 = 210 ⇒ a₁ = −6

  3. הוכיחו שבכל סדרה חשבונית Sₙ = An² + Bn (A, B קבועים). מצאו את הסדרה שבה Sₙ = 2n² − 5n.
    הצג פתרון

    Sₙ = (d/2)n² + (a₁ − d/2)n, כלומר A = d/2, B = a₁ − d/2.

    כאן d = 4, a₁ = B + d/2 = −5 + 2 = −3

    aₙ = 4n − 7

  4. דן חוסך 100 ₪ בחודש הראשון, ובכל חודש הוא חוסך 20 ₪ יותר מבחודש הקודם. אחרי כמה חודשים יגיע החיסכון הכולל ל־5000 ₪ לפחות?
    הצג פתרון

    Sₙ = n[200 + 20(n−1)]/2 = 10n² + 90n ≥ 5000

    n² + 9n − 500 ≥ 0 ⇒ n ≥ 18.31

    בדיקה: S₁₈ = 4860, S₁₉ = 5320. התשובה: 19 חודשים.

  5. אורכי הצלעות של משולש ישר־זווית יוצרים סדרה חשבונית עם הפרש 2. מצאו אותם.
    הצג פתרון

    (a−2)² + a² = (a+2)² ⇒ a² − 8a = 0 ⇒ a = 8

    הצלעות: 6, 8, 10

  6. נתונות הסדרות 5, 9, 13, … ו־3, 10, 17, …, כל אחת עם 100 איברים. כמה איברים משותפים יש להן?
    הצג פתרון

    הראשונה: 4n + 1 עד 401. השנייה: 7m − 4 עד 696.

    האיבר המשותף הראשון הוא 17, והמשותפים יוצרים סדרה חשבונית עם הפרש 4·7 = 28.

    17 + 28(k−1) ≤ 401 ⇒ k ≤ 14.7. יש 14 איברים משותפים.

  7. בסדרה חשבונית בת 15 איברים סכום הסדרה 255. מצאו את האיבר האמצעי. הסבירו מדוע ניתן למצוא אותו בלי לדעת את a₁ ו־d.
    הצג פתרון

    S₁₅ = 15(a₁ + a₁₅)/2 = 15·a₈, כי a₁ + a₁₅ = 2a₈.

    a₈ = 255/15 = 17

  8. בסדרה חשבונית לא קבועה, האיברים a₁, a₃, a₉ יוצרים סדרה הנדסית. מצאו את היחס (a₁ + a₃ + a₉)/(a₂ + a₄ + a₁₀).
    הצג פתרון

    (a₁ + 2d)² = a₁(a₁ + 8d) ⇒ 4d² = 4a₁d ⇒ a₁ = d (כי d ≠ 0)

    לכן aₙ = nd, והיחס: (1 + 3 + 9)/(2 + 4 + 10) = 13/16

הפתרונות מוסתרים כדי לאפשר תרגול עצמי. לחצו על "הצג פתרון" כדי לבדוק.
